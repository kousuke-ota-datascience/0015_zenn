# 0. INTRODUCTION

## 0.1. 文書の目的

本書は、A3で実施している**パイロット49件の個別伝承文書・コーディング整合化作業**について、タスク全量と各Entryの対応状況を一元管理するための作業文書である。

A3では、当初「文書は存在するが薄い18件」の高密度化を進めていたが、作業中に以下が判明した。

- 高密度化後も、最新tutorialの見出し・フィールド名から逸脱した記載が一部残る。
- 証拠記載を厚くした結果、既存Pilot Codingと現Evidenceの不整合が可視化された。
- 上記問題は18件だけの問題ではなく、**パイロット49件全体を同一基準へ揃える品質保証課題**である。
- さらに、49件のうち24件は `docs/10_each_lore/` の個別伝承文書自体が未作成である。
- D01〜D21を再判定した場合、個別Markdownだけでなく、全件コード正本Excelおよび派生評価資料との同期が必要である。

したがって、本書では49件を母集団として固定し、文書高密度化、tutorial準拠、再コーディング、未作成文書の作成、Excel同期、派生評価更新、最終QAまでを一つのreconcile工程として管理する。
