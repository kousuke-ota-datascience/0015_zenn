## 1. 結論

0025は、0024で問題となったD12を `READER_LISTENER` としており、受信者が転送／不転送にかかわらず制裁規則の直接対象になることを適切に表している。D07〜D18も、制裁前景型チェーンレターとして一貫したモデルになっている。

主な再検討点は、0024とのEntry境界をどの程度の世界モデル差として固定できるか、D04 `RETELLING` が1970–1977年の期限・人数差を最も適切に表すか、という点である。重大なsense-making崩れは確認しない。

## 2. Findings

### F10-001 — 0024とのEntry境界は成立し得るが、判定基準を明文化すべき

- 重大度: **Moderate**

0024と0025はどちらも、

```text
メッセージ受信
→ 期限付き転送規則
→ 転送／不転送に応じて吉凶が返る
→ 次の受信者へ連鎖
```

という大枠を共有する。

一方、0025では、

- D13 Primary = `CURSE_MISFORTUNE`
- D14 = `NEG`
- D17 = `TRANSFER_SUBSTITUTE`

となり、0024の「幸運獲得をPrimaryとする利用モデル」とは行為動機・主帰結・制御方法が変わっている。

したがって別Entry化は理論上成立し得る。ただし、単なる名称差や語調差ではなく、**Primary incentive / consequence / control rule が安定して変わったため別モデルとする**ことをVersion Scope説明に明示するとよい。

### F10-002 — D04 `RETELLING` は再確認余地がある

- 重大度: **Moderate**

1970年型「50時間・29人」と1977年型「数日・20人」の差は直接確認できるが、これは単純な「別の語り手・媒体による再叙述」より、自己複製文面のパラメータ変異に近い。

現taxonomyでは完全一致するChildが乏しいため `RETELLING` は候補になり得るが、

- `ACCRETION` ではないか
- 既存Childで十分表現できず軽いtaxonomy gapなのか

を横断Entryで確認する価値がある。

現行値を誤りと断定はしない。

### F10-003 — D07〜D18の因果・sense-making連鎖は良好

- 重大度: **問題なし**

```text
D07 将来の不幸・災厄
→ D08 根拠未提示の制裁命題
→ D09 転送規則＋不転送の禁忌化
→ D10 情報内容
→ D11 メッセージ受信
→ D12 受信者
→ D13 不運付与
→ D15 運勢悪化
→ D16 期限＋連鎖
→ D17 脅威を次の受信者へ移して回避
```

は一貫している。

特にD12を受信者とし、D13の直接対象と正しく接続している点は維持すべきである。

### F10-004 — D17 `TRANSFER_SUBSTITUTE` は制裁前景型に適合する

- 重大度: **問題なし／留保**

転送により同じ脅威を次の受信者へ渡すことが、自身の災厄回避条件になるため、`TRANSFER_SUBSTITUTE` は0024の `LUCK_EXPLOITATION` と区別する上でも意味がある。

ただし「本当に災厄そのものが転嫁される」のか、「単に規則遵守で制裁が解除される」のかは文面によるため、根拠文で両者を混同しないようにする。

### F10-005 — D18 L3はScope内Direct Evidenceで支持される

- 重大度: **問題なし**

1977年はVersion Scope内であり、同年の自治体広報が、

- 実流通
- 受信者の悩み
- 破棄推奨
- 派出所への相談推奨

を直接記録しているため、0024と異なりL3のScope整合は良好である。

### F10-006 — 文書書式の正規化が必要

- 重大度: **Minor**

`Entry_ID` が `25` であり、4桁ゼロ埋め `0025` ではない。D次元の見出し・フィールドもtutorial簡略形であるため、内容修正とは別に形式正規化が必要である。
