# Review 0025_00_001 — Entry 0025 不幸の手紙 / `0025_00_contents.md`

## 0. レビュー情報

- `Entry_ID`: `0025`
- `Review_Seq`: `001`
- 対象: `docs/10_each_lore/0025_fuko_no_tegami/0025_00_contents.md`
- 判定: **要修正（Major）**
- 重点観点: Evidence / Content layer、tutorial準拠、0024とのEntry境界、分析判断との責務分離

## 1. 結論

1977年『広報あかいけ』という強い直接資料を確保し、実流通、具体的転送条件、受信者の不安、自治体の破棄・警察相談勧告まで一資料で追跡できている点は非常に有用である。1970年新聞は研究資料経由、1977年広報は直接Evidenceとして強度を分けている点も適切である。

一方、文書構造は現行tutorialの正規形へ未準拠であり、0024「幸福の手紙」とのEntry境界、sense-making上の「恐怖回避策」評価をEvidence層で先取りしている。Evidence自体よりも、構造正規化と責務分離が必要である。

## 2. Findings

### F00-001 — 典拠章が `0.2.1`〜`0.2.3` の正規構造へ未準拠

- 重大度: **Major**

現在は `0.2 典拠とEvidence role` の下に資料A〜Eを直接配置している。

現行tutorialでは、

```text
0.2 典拠と証拠上の扱い
  0.2.1 一次資料・同時代資料
  0.2.2 原文ミラー・転載・復刻資料
  0.2.3 二次資料・研究資料
```

へ分ける必要がある。

1977年自治体広報、1970年新聞の研究経由確認、丸山2012/2022、後代事典は資料階層が異なるため、この正規構造への再配置が有効である。

### F00-002 — Content章がtutorialの `1.1`〜`1.10` へ未正規化

- 重大度: **Major**

現文書は、

- `1.3 主体`
- `1.4 空間・媒体`
- `1.5 条件・規則`
- `1.6 中心命題`
- `1.7 帰結`
- `1.8 不確実性`

までで構成され、現行tutorialの人物・場所・物・行動・終端・未解決点を独立させる構造と一致しない。

D07〜D17の再検討を容易にするため、`1.1 summary`〜`1.10 未解決点・不確実性` へ再配置すべきである。

### F00-003 — 0024とのEntry境界判断をEvidence層で先取りしている

- 重大度: **Moderate**

「1970年前後に不転送時の負の制裁を主要誘因として前景化した系統」「報酬中心の0024と分離する」という記述はEntry unit / Version Scopeの分析判断である。

00では、各資料について、

- 転送時の正報酬があるか
- 不転送時の制裁があるか
- 文面上どちらが強調されるか
- 条件・期限・人数

をEvidenceとして記録し、別Entryとして切る判断は10で行うべきである。

### F00-004 — sense-making上の機能評価が混入している

- 重大度: **Moderate**

「将来の災厄という不確実性を具体的転送行為へ接続し、転送を恐怖回避策として提示する」という記述はD07/D09/D17の分析に相当する。

00では「不転送なら不幸」「期限内に転送すれば制裁を回避できるとされる」という命題記録に留めるべきである。

### F00-005 — 1977年X Evidenceの扱いは良好

- 重大度: **問題なし**

1977年広報に記録された住民の悩み、行政の破棄・派出所相談勧告をX Evidenceとして使いながら、広報内の「自殺報道」は原記事未確認のため事実認定へ用いていない。このEvidence管理は維持すべきである。

## 3. 修正優先順位

1. 典拠章を `0.2.1`〜`0.2.3` へ正規化する。
2. Content章を `1.1`〜`1.10` へ正規化する。
3. 0024/0025のEntry境界判断を10へ移す。
4. sense-making機能評価を観察可能な命題・行動記述へ戻す。
5. 1977年直接Evidenceとその保留事項は維持する。

## 4. 最終判定

**Review_0025_00_001: 要修正（Major）**

直接Evidenceは強いが、現行tutorialとの差が大きく、Entry境界と意味形成分析がEvidence正本へ先取りされているためMajorとする。
