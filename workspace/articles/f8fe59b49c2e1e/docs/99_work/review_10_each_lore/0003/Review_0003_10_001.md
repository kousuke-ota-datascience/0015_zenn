## 1. 結論

D07〜D10のsense-making連鎖は概ね一貫している。学校トイレを危険空間として問題化し、共同体反復を手掛かりに、色と帰結を相関規則化し、人格的怪異主体を置くという読みは、1986年の複数採録と整合する。

一方、D11で「因果系へ入る条件」と「因果系に入った後の帰結分岐条件」が混同されている。学校トイレに居合わせることで怪異の問いかけを受け、その後に色を回答することで危害／安全が分岐するため、現行の `RESPOND_CHOOSE` Primary、`LOCATION_STATE` Secondaryは再検討が必要である。

またD18 L3を、Coding Scopeから外した1972年赤／白型のX Evidenceで成立させている。D18もVersion Scopeに整合させるなら、1986年Scope自体について社会現実層の効果を示すEvidenceが必要である。

## 2. Findings

### F10-001 — D11 Primaryが「因果系への入口」ではなく「帰結分岐条件」になっている

- 重大度: **Major**
- 現在:
  - Primary: `D11.MAN.RESPOND_CHOOSE`
  - Secondary: `D11.CON.LOCATION_STATE`

D11の中心質問は「何を契機に因果系へ入るか」である。

1986年Scopeでは、構造は概ね、

```text
学校トイレ／特定個室にいる
→ 怪異から問いを受ける
→ 色を回答する
→ 色に対応した危害／安全が生じる
```

となる。

したがって「回答する」はすでに怪異との因果関係へ入った後の**分岐条件**であり、入口そのものではない。D11 Primaryは `D11.CON.LOCATION_STATE` を第一候補として再判定し、`RESPOND_CHOOSE` をSecondaryまたは後段の条件として扱う方が自然である。

ただし、資料上「トイレにいるだけでは作用せず、回答した瞬間に初めて作用系が開始する」と明確に定義されている場合は現行値を維持し得る。その場合は根拠文で「問いかけ段階を因果作用とみなさない」理由を明示する必要がある。

### F10-002 — D18 L3がVersion Scope外の1972型Evidenceに依存している

- 重大度: **Major**

D18は `L1=1; L2=0; L3=1` とし、L3の根拠を1972年兵庫例の「低学年児童が数珠つなぎで便所へ行く」行動変化に置いている。

しかし現Version Scopeは「1986年東京都の複数採録で直接確認できる色選択型」であり、1972年赤／白型はD11〜D17のCoding Scopeから明示的に除外されている。

Scope外VersionのX Evidenceを使ってScoped D18を1にすると、

```text
内容コードは1986年型
社会効果コードは1972年型
```

というVersion混成が生じる。

D18をScope依存次元として運用するなら、1986年色選択型についてのX Evidenceを追加するか、L3を0/U相当へ再検討すべきである。

### F10-003 — D07〜D09のsense-making連鎖は概ね妥当

- 重大度: **問題なし／微調整候補**

現行は、

```text
D07: 危険な学校トイレ／未知存在
→ D08: 学校共同体で反復される証言・主張
→ D09: 色と帰結を相関規則化
```

と構成されている。

特にD09 `CORRELATION_RULE` は、赤→血・青→蒼白等の意味対応が複数採録で直接確認できるため、Primaryとして説得力が高い。

ただしD07 Primaryを `DANGEROUS_PLACE` とするなら、「この伝承がなければ何が説明されないまま残るか」への回答を一文でさらに明確化し、単に舞台がトイレだから場所コードにしたのではないことを示すとよい。

### F10-004 — D10 `YOKAI_ENTITY` はIとして妥当

- 重大度: **問題なし**

姿や由来は固定されないが、問いを理解し、回答内容に応じて結果を変える人格的主体が前提になる。死者霊等の強い由来を追加せず、人格怪異をIで置くのは保守的である。

### F10-005 — D12→D13→D15とD17は整合する

- 重大度: **問題なし**

```text
D12 回答した遭遇者
→ D13 身体攻撃
→ D15 重傷／死亡
```

の因果列は複数1986年採録で支持される。

D17も「特定色を普遍的正答としないが、各Versionに安全回答がある」という形で `CORRECT_ANSWER` をコードしており、Version差を潰していない。

## 3. Version Scope評価

1986年東京の複数採録を使い、

```text
学校トイレ
→ 不可視／正体不明の問いかけ
→ 色を選ぶ
→ 色に意味対応した危害または安全
```

までを共通核とするScopeは妥当である。

1972年赤／白、赤いちゃんちゃんこ、1990年赤マントを同じD11〜D17へ混ぜない方針も維持すべきである。
