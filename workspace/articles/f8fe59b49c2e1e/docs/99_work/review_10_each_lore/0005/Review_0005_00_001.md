# Review 0005_00_001 — Entry 0005 紫の鏡 / `0005_00_contents.md`

## 0. レビュー情報

- `Entry_ID`: `0005`
- `Review_Seq`: `001`
- 対象: `docs/10_each_lore/0005_murasaki_no_kagami/0005_00_contents.md`
- 判定: **要修正（Moderate）**
- 重点観点: Evidence / Content layer、tutorial準拠、異伝分離、分析判断との責務分離

## 1. 結論

典拠章は現行tutorialの `0.2.1`〜`0.2.3` に準拠しており、1995年書誌確認と1998–1999年採録群の役割を分け、刊行年を起源年へ読み替えない点も適切である。期限年齢、死亡／不幸、複合危険語、対抗語、人格怪異化を異伝として分離している点も良好である。

主な修正点は、summaryと一部節にsense-making分析を先取りする表現が残っていることである。Evidence正本としては、記憶条件・期限・帰結・回避異伝を記録し、自己言及性や「記憶内容そのものが運命へ作用する」という概念評価は10へ寄せる方がよい。

## 2. Findings

### F00-001 — summaryに分析的な「自己言及構造」評価が混入している

- 重大度: **Moderate**

`1.1 summary` は「忘れろと警告された語ほど意識に残りやすいため、伝承を聞かせる行為自体が、伝承内部の危険条件を新しい受容者へ成立させる自己言及的構造を持つ」と記述する。

「聞いた受容者が危険語を知る」「期限まで記憶していると死ぬ」という部分はContentである。一方、心理的な記憶残存傾向と、それを用いた「自己言及的構造」という評価は分析である。

00では次の事実に限定する方がよい。

```text
伝承を聞くことで受容者は「紫の鏡」という語を知る。
規則上、その語を指定期限まで覚えている受容者が危害対象になる。
```

この接続をD18 L2やsense-making上どう解釈するかは10へ置く。

### F00-002 — 「記憶内容そのものが運命へ作用する」は因果解釈としてやや強い

- 重大度: **Moderate**

「記憶内容そのものが時間差をもって運命へ作用する」という表現は、採録された規則の高密度パラフレーズとして理解できる一方、D10/D13の存在論・作用機構を先取りする。

Evidence文書では、

```text
『紫の鏡』を一定期限まで覚えていると死亡／不幸になるとされる
```

と記述すれば十分である。何が「因果源」で何が「作用機構」かは10で判定する。

### F00-003 — 異伝分離と証拠上の留保は良好

- 重大度: **問題なし**

以下は維持すべきである。

- 1995年公刊確認を成立年としない。
- 1995年書籍本文未実見のため具体的死亡規則を遡及しない。
- 16歳・18歳・20歳等の期限差を保持する。
- 死亡型と不幸型を区別する。
- 「紫地蔵」「赤い沼」等の複合型、「ピンクの鏡」等の対抗型を区別する。
- 血だらけの女が鏡から出る型を全Versionへ一般化しない。

### F00-004 — tutorial構造は概ね適合

- 重大度: **問題なし**

`0.2.1`〜`0.2.3`、`1.1`以降のContent整理は現行tutorialの責務に概ね沿っている。0003のような典拠章の大幅な構造不一致はない。

## 3. 修正優先順位

1. summaryから心理一般化と「自己言及的構造」という分析語を外す。
2. D10/D13を先取りする「記憶内容そのものが運命へ作用する」という表現を観察可能な規則記述へ置換する。
3. 現在の典拠・異伝・不確実性管理は維持する。

## 4. 最終判定

**Review_0005_00_001: 要修正（Moderate）**

Evidence基盤は良好で、主な修正はEvidence層と分析層の責務境界である。
