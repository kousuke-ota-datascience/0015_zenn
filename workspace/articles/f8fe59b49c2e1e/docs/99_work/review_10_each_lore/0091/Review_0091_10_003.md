## 1. 結論

Review_002で指摘したD03とD08は適切に修正されている。D03は1996年書籍本文未実見を踏まえて、現Version Scopeの具体Contentを直接確認できるWeb記事へ限定した。D08も「何かがおかしい」という違和感から `PHYSICAL_TRACE` を推定せず `U` としている。D13の「物理的な潜伏・待ち伏せ」taxonomy gapも近似Childへ押し込まず保持されている。

しかし、D18〜D21部分が現行tutorial／現行taxonomyへ更新されていない。とくにD18は、現行の「作用レイヤー（伝承内／受容者／社会現実）」ではなく旧来の「現実社会への外部効果」として `L1=行動・実践 / L2=制度・組織対応 / L3=社会的現実化` を判定しており、`0/0/0` を付与している。現行D18では、本伝承は物語内部で侵入者の潜伏・対象の察知・退避等の因果作用が生じるため少なくともL1の判定軸が異なり、現値は現行Dimensionを測定していない。D18はD07〜D18のsense-making / causal model末端に位置するためMajorとする。

加えてD19は現行code systemに存在しない `D19.NAT.NATIONAL` / Parent `D19.NAT` を使用している。現行D19は「誰の間に流通するか」を問う社会範囲taxonomyであり、全国的大衆を採る場合でも現行IDは `D19.MAS.NATIONAL_PUBLIC` である。単なるラベル置換ではなく、00の「1990年代に日本で流行」「都内女子大生のあいだで噂」「レディースコミック題材化」というHistory Evidenceから、現行taxonomy上のPrimary/Secondaryを再判定する必要がある。

## 2. Findings

### F10-001 — D18が現行「作用レイヤー」ではなく旧Dimension定義でコーディングされている

- 重大度: **Major**
- 対象: D18、D18の階層位置、D07〜D18 causal chain
- 現在値: `L1=0 / L2=0 / L3=0`, Status `I`

### 問題

現行tutorialではD18は `### 2.3.8. D18: 作用レイヤー` としてD11〜D17と同じ因果・行動モデル群に置かれ、中心質問は「因果効力は伝承内／受容者／社会現実のどこに及ぶか」である。

対象10はD18を `## 2.4. 社会実装・現実接続の次元` 配下の `### 2.4.1. D18: 現実社会への外部効果` とし、L1を「行動・実践」、L2を「制度・組織対応」、L3を「社会的現実化」と定義している。これは現行D18の3 layerと別概念である。

そのため `0/0/0` は、現行D18のvectorとして解釈できない。本Entryでは少なくとも伝承内部で侵入者の潜伏、居住者／宿泊者との同室、察知、退避等が起きるため、現行L1を旧「外部効果がない」という理由で0にすることはできない。

### 影響

D18が現行理論上の変数を測定しておらず、D07〜D18の意味形成モデル、Entry間比較、後続集計へ直接影響する。単なる見出し誤記ではない。

### 修正方向

- D18をtutorial正規位置 `2.3.8` へ移し、現行のL1/L2/L3定義で全面再判定する。
- L3を1にする場合のみ、同一Version Scopeの流通が生んだ独立X Evidenceを要求する。
- vectorのdirectness / Statusも現行coding rulesに従って再設定する。

### F10-002 — D19が現行code systemに存在しない旧コードを使用している

- 重大度: **Moderate**
- 対象: D19
- 現在値: Primary `D19.NAT.NATIONAL`; Parent `D19.NAT`; Status `I`

### 問題

現行code systemのD19に `D19.NAT.NATIONAL` / `D19.NAT` は存在しない。全国的大衆に対応する現行Childは `D19.MAS.NATIONAL_PUBLIC` / Parent `D19.MAS` である。

また、現行中心質問は単に地理的に「全国か」を問うのではなく「誰の間に伝承が流通するか」である。00には、1990年代に日本で流行したとの後代整理に加え、都内女子大生間の噂・レディースコミック題材化という異なる社会範囲Evidenceがあるため、現行taxonomyに即したPrimary/Secondary選択をやり直す必要がある。

### 修正方向

- `NATIONAL_PUBLIC` を採る場合は「日本で流行」のEvidence強度と社会範囲を明示する。
- 若者・学生等のSecondary候補を採る場合も、00の具体History Evidenceと対応付ける。
