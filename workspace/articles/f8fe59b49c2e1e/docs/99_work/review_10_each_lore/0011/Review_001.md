# 1. 結論

0011は、**明治期器具型と後代の学校・紙硬貨型を分離し、後代の憑依・祟り・終了禁忌を初期形へ遡及しない**というVersion Scope上の判断が明確である。また、D12→D13→D15の因果列も「器具へ作用する → 器具を動かす → 回答・知識を得る」と接続しており、この部分は現行規則と整合している。

一方、研究目的の中核であるsense-makingの読み方には重大な再検討が必要である。現在のD07–D09は、**こっくりさんが答えようとする未知・不確実性ではなく、儀式実行後に発生する器具運動を意味形成の出発点としている**。その結果、D13で記述すべき作用機構がD07/D08へ逆流し、意味形成モデルの入力と、モデル内部で生成される応答機構が混同されている可能性が高い。

また、D04とD20では、本文自身が「Evidence不足ではなくtaxonomy gap」と認識しているにもかかわらず `Status = U` を使用している。これは現行workflowの「Evidence不足とtaxonomy不足を分離する」という規則と整合しない。

したがって、**現状態をレビュー承認済みとはしない**。少なくともD07–D09の再判定、D04/D20のtaxonomy gap処理、`00_contents` のtutorial正規化、D11 Statusの再確認が必要である。

# 2. Findings

## F-001 — D07のPrimaryがEntryの意味形成目的より「作用後の異常現象」を優先している

- 重大度: **Major**
- 対象: `0011_10_analysis.md` D07
- 現在値:
  - Primary: `D07.ANO.UNEXPLAINED_EVENT`
  - Secondary: `D07.ISU.INFORMATION_VOID`

### 問題

現行D07は「参加者が意図的に動かしていないと感じる器具がなぜ動くのか」をPrimaryの意味形成対象としている。

しかし `0011_00_contents.md` が示す明治期確認核は、

```text
問いを発する
→ 器具が動く
→ 動きを外部主体からの意味ある回答として読む
```

という**占い・神意判断の実践**であり、利用目的として「未来、恋愛、秘密、未知情報等への回答を得る」と明記されている。

`sense-making` 補足文書では、D07は「説明を要求する何か」、すなわち意味形成モデルへ入力される異常・不可解・不確実性である。これに対し、器具運動はD11の儀式実行後にD13として発生し、D15の知識獲得へ接続する**モデル内部の作用機構**である。

したがって、現在のD07は、

```text
入力となる不確実性
```

と

```text
不確実性へ答えるためにモデル内部で生じる作用
```

を入れ替えている可能性が高い。

### 修正方向

第一候補として、D07 Primaryは `D07.ISU.INFORMATION_VOID` を再検討するべきである。

`D07.ANO.UNEXPLAINED_EVENT` は、明治期Scopeにおいて「器具がなぜ動くのか」自体が独立して説明対象として伝承化されているEvidenceが十分ならSecondary候補になり得る。ただし、単に儀式の作用機構として器具が動くことだけでは、D07 Primaryに置く根拠として弱い。

最終コードは再コーディングで確定すること。レビュー段階では現行Primaryを承認しない。

## F-002 — D08がD13で生じた結果を「意味形成契機」として再利用しており、時間・論理順序が循環している

- 重大度: **Major**
- 対象: D08
- 現在値: `D08.DEX.DIRECT_EVENT`

### 問題

現行D08は「質問後に器具が動く直接経験」を意味形成契機としている。

しかし同じ分析では、

- D11: 儀式を行う
- D13: 外部主体が器具を動かす
- D15: 回答・知識を得る

と整理されている。

つまり現在のD08は、**D11で因果系へ入った後にD13として発生する作用を、D07を問題化する先行手掛かりとして再投入している**。これは、

```text
意味形成対象
→ 意味形成契機
→ 意味付与操作
→ 因果モデル
```

という現行理論の順序から見ると循環的である。

### 修正方向

F-001に従いD07を未知情報・情報空白として捉え直す場合、D08も再判定が必要になる。

候補としては、伝承・実践を受容する出発点が既存の言い伝えや根拠未提示の主張であることをEvidenceで確認できるなら `D08.CLM` 系が考えられる。しかし、現在の `00_contents` には「参加者が何を手掛かりとして、こっくりさんなら未知情報を取得できると認識するのか」を十分に復元できる記載がない。

したがって、**現在の `DIRECT_EVENT` を維持したままではなく、まずEvidenceを補い、その後にD08を独立再判定する**のが妥当である。

## F-003 — D09 `AGENCY_ATTRIBUTION` 自体は妥当候補だが、現行の根拠は誤ったD07/D08連鎖へ依存している

- 重大度: **Moderate**
- 対象: D09
- 現在値: `D09.AGN.AGENCY_ATTRIBUTION`

### 評価

「器具の動きを、意思ある外部主体からの回答として理解する」という主体帰属は、こっくりさんの意味形成操作として十分に妥当な候補である。

ただし現行説明は、

```text
器具が勝手に動く
→ なぜ動くかが不可解
→ 外部主体を置く
```

というF-001/F-002の読み方に依存している。

Entryを「未知情報を外部主体へ問い合わせ、回答可能な世界モデルへ変換する実践」と捉えるなら、D09の説明も、**情報空白を、回答能力を持つ外部主体と応答規則へ接続する操作**として書き直す必要がある。

### 修正方向

コード自体は継続候補とするが、D07/D08再判定後に根拠を再構成する。

必要なら `D09.CTL.RITUAL_RULE` 等のSecondary候補も検討できるが、「儀式だから」というだけで追加せず、Primaryだけでは失われる独立構造かをtie-break規則で確認すること。

## F-004 — D04とD20でtaxonomy gapを `U` として保存している

- 重大度: **Major**
- 対象: D04, D20

### 問題

D04本文は、外来のテーブル・ターニングが日本の生活器具へ適応されたことをEvidence上明確としつつ、「現taxonomyでは適切なChildがない」としている。

D20本文も、外部主体が参加者より多くの情報を保持している構造は明確だが、「超自然主体が特権情報を持つChildがない」としている。

つまり両者とも本文自身が、

> Evidence不足ではなくtaxonomy gap

と判断している。

一方、`Status = U` は現行規則上 **資料不足** を意味する。`0000_workflow.md` のTaxonomy gap QAでも、Evidence不足とtaxonomy不足を明示的に分離するよう要求している。

したがって、これらを通常の `U` として集計すると、

- Evidenceが足りないEntry
- コードブックが表現能力を持たないEntry

が統計上同一化される。

### 修正方向

- D04/D20の「既存Childへ無理に近似しない」という判断自体は維持してよい。
- ただし `U` を通常のEvidence Unknownとして確定値にしない。
- 現行Status体系にはtaxonomy gap専用値がないため、**Entry修正だけでは完結しない仕様問題としてコードブック／保存規則側へエスカレーションする**。
- 少なくとも集約時にEvidence不足Uと同一扱いされないよう、明示的なgap管理が必要である。

なお、D04については `D04.REC.CONTEXT_UPDATE` 等の既存Childで定義拡張せず表現可能かも別途検討余地がある。単一Entryだけで新Childを追加しないこと。

# 3. 問題なし／維持可能と判断した点

## 3.1. Version Scopeの後代設定排除

明治器具型をScopeとし、現代紙・硬貨型、学校型禁忌、憑依・祟り、終了規則を除外している点は妥当である。

特に、後代に有名になった危険招霊型を初期形へ遡及しないという判断は、workflowとsense-making分析双方に重要である。

## 3.2. D10の競合保持

神格的解釈と狐狗狸等の人格怪異的解釈を一つへ潰さず `C` として保持している方針は妥当である。

現代の「死者霊」解釈を明治期へ遡及していない点も維持すべきである。

## 3.3. D12 → D13 → D15

現在の因果列、

```text
D12: 可動器具
→ D13: 器具を動かす
→ D15: 回答・未知情報を得る
```

は一貫しており、D12を「参加者」にしてしまう典型的な誤りを避けている。

## 3.4. D17

明治期Scopeを危害回避型にせず、未知情報取得のための意図的利用として読む方向は妥当である。

# 4. Sense-making再構成案

これは確定コードではなく、再コーディング時に検証するための作業仮説である。

現在:

```text
D07: 器具が勝手に動くのはなぜか
→ D08: 器具が動く直接経験
→ D09: 外部主体を置く
→ D11: 儀式をする
→ D13: 外部主体が器具を動かす
→ D15: 答えを得る
```

この連鎖では、D13の出来事をD07/D08の入力として再利用するため循環している。

再検討すべきモデル:

```text
未知・未来・秘密など、参加者が知り得ない情報がある
→ こっくりさんなら回答を得られるという伝承・実践を受容する
→ 回答能力を持つ外部主体を世界内へ置く
→ 所定の儀式を実行する
→ 外部主体が器具を動かす
→ 器具運動を回答として読む
→ 情報空白が埋められ、知識・予測・判断の足場を得る
```

この構造の方が、`20_what_is_sense_making.md` が定義する、

```text
不確実な入力
→ 問題化
→ 手掛かり
→ 命名・分類・原因／主体帰属・規則化
→ 予測・利用・検証規則
→ 共有可能な世界モデル
```

との対応が明瞭である。

ただし、D08を何にするかは現状Evidenceだけでは確定しない。`00_contents` をtutorial形式へ再構成する際に、明治期の参加者が実践を開始する認識上の手掛かりを資料から抽出する必要がある。

# 7. 最終判定

**Review_001判定: 要修正（Major）**

0011はVersion Scopeの切り分け、後代設定の排除、因果作用列の記述には良い部分がある。一方で、本研究の中心概念であるsense-makingについて、**「何を理解可能にする伝承なのか」と「そのために伝承内部で何が起きるのか」の層が混ざっている**。

この点は単なる表現修正ではなく、D07・D08を中心にコード値へ影響し得るため、次回レビュー前に再コーディングが必要である。
