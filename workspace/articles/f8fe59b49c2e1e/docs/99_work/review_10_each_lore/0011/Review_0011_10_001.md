## 1. 結論

Version Scopeの切り分け、後代設定の排除、D12→D13→D15の因果列には妥当な点がある。一方、D07–D09では、**こっくりさんが何を理解可能にするモデルなのか**と、**モデル内部で回答を生成する作用機構**が混同されている可能性が高い。

現在のD07は「器具がなぜ自律的に動くのか」をPrimaryとし、D08はその器具運動への直接遭遇を契機としている。しかし同じ分析では器具運動をD13の作用としているため、D13で発生する結果がD07/D08へ逆流し、意味形成モデルの論理順序が循環している。

またD04/D20では、本文自身がtaxonomy gapと判断しているにもかかわらず `Status=U` を使用しており、Evidence不足とtaxonomy不足の区別が崩れている。

## 2. Findings

### F10-001 — D07 Primaryが意味形成入力より作用後の異常現象を優先している

- 重大度: **Major**
- 現在値:
  - Primary: `D07.ANO.UNEXPLAINED_EVENT`
  - Secondary: `D07.ISU.INFORMATION_VOID`

現分析は「なぜ器具が自律的に動き、回答らしい振る舞いをするのか」をD07 Primaryとしている。

しかし明治期Scopeは占い／神意判断の実践であり、未知の未来、恋愛、秘密等に対して回答を得ることを目的としている。器具運動は、その未知情報へ答えるためにモデル内部で発生する媒介作用であり、D13にも `ENV_OBJECT_MANIPULATION` として記述されている。

したがって、D07の中心質問「この伝承がなければ何が説明されないまま残るか」へ直接答える候補としては `D07.ISU.INFORMATION_VOID` を第一に再検討すべきである。

`D07.ANO.UNEXPLAINED_EVENT` は、「器具が勝手に動く理由」自体が独立した説明対象としてScope内で伝承化されているEvidenceがある場合にSecondary候補となり得る。

### F10-002 — D08がD13の作用を先行契機として再利用し、論理循環を起こしている

- 重大度: **Major**
- 現在値: `D08.DEX.DIRECT_EVENT`

現在は「質問後に器具が動く直接経験」がD08である。

一方、同じ分析は

```text
D11 儀式を行う
→ D13 外部主体が器具を動かす
→ D15 回答・知識を得る
```

と整理している。

したがって現D08は、因果系へ入った後にD13として生じる作用を、D07の問題化に先行する手掛かりとして再投入している。

D07を情報空白として再構成するなら、D08も独立再判定する必要がある。既存の言い伝えや「この実践なら答えを得られる」という主張が受容の出発点であるEvidenceが取れるなら `D08.CLM` 系が候補になるが、現 `00_contents` だけでは確定できない。

### F10-003 — D09 `AGENCY_ATTRIBUTION` は妥当候補だが根拠を再構成すべき

- 重大度: **Moderate**
- 現在値: `D09.AGN.AGENCY_ATTRIBUTION`

「器具の動きを、意思ある外部主体からの回答として理解する」という主体帰属自体は妥当な候補である。

ただし現説明は「器具が勝手に動く不可解さ」を起点としているため、F10-001/F10-002の問題を引き継ぐ。

D07/D08再判定後は、D09を「情報空白を、回答能力を持つ外部主体と応答規則へ接続する操作」として再記述する方がsense-making定義との対応が明瞭になる。

### F10-004 — D04 / D20でtaxonomy gapを通常の `U` として扱っている

- 重大度: **Major**

D04では、外来のテーブル・ターニングが日本の生活器具へ適応された変容はEvidence上明確だが既存Childで表現しにくいとしている。

D20では、参加者より多くの情報を持つ外部主体が回答源として想定される構造は明確だが、超自然主体を情報保持者として表すChildがないとしている。

両者とも本文自身が「Evidence不足ではなくtaxonomy gap」と述べている。一方 `U` は資料不足を意味するため、通常Uとして集計するとEvidence欠損とtaxonomy欠損が同一化される。

現Status体系にtaxonomy gap専用値がないため、Entry単独で新Statusを発明せず、コード体系／保存規則の改訂候補として明示的に管理する必要がある。

### F10-005 — D11 `Status=D` はDirectnessを再確認する必要がある

- 重大度: **Moderate**
- 現在値: `D11.MAN.PERFORM_RITUAL`, `Status=D`

「複数人が器具へ接触し、問いを発する」手順は妥当なコード候補だが、現在の `00_contents` では主に東洋大学の公式整理を通じて確認されている。

1887年原典／復刻の具体的本文位置へ直接トレースできるなら `D` を維持できる。現文書上のEvidenceだけを基準にするなら `I` の方が整合的な可能性がある。

## 3. 維持可能な点

### 3.1 Version Scope

1886–1887年の明治器具型を対象とし、現代紙・硬貨型、学校型禁忌、憑依・祟り、終了規則をScope外としている判断は妥当である。

### 3.2 D10

神格的枠組みと狐狗狸等の人格怪異的解釈を一つに潰さず `C` として保持している点は妥当である。現代の死者霊解釈を遡及していない点も維持すべきである。

### 3.3 D12 → D13 → D15

```text
D12 可動器具
→ D13 器具を動かす
→ D15 回答・未知情報を得る
```

という因果列は一貫している。参加者をD12 Primaryへ置かず、直接作用を受ける物体と最終的な知識変化を分離している点は良い。

### 3.4 D17

明治期Scopeを危害回避型ではなく、未知情報取得のための意図的利用として読む方向は妥当である。

## 4. Sense-making再構成案

以下は確定コードではなく、再コーディング時に検証する作業仮説である。

現状:

```text
D07 器具が勝手に動くのはなぜか
→ D08 器具が動く直接経験
→ D09 外部主体を置く
→ D11 儀式をする
→ D13 外部主体が器具を動かす
→ D15 答えを得る
```

再検討案:

```text
未知・未来・秘密など、参加者が知り得ない情報がある
→ こっくりさんなら回答を得られるという実践を受容する
→ 回答能力を持つ外部主体を世界内へ置く
→ 所定の儀式を実行する
→ 外部主体が器具を動かす
→ 器具運動を回答として読む
→ 情報空白が埋められ、知識・予測・判断の足場を得る
```

この方が、sense-making文書の「不確実な入力→問題化→手掛かり→主体／原因帰属・規則化→予測・利用→共有可能な世界モデル」という構造へ素直に対応する。

D08は現Evidenceだけでは確定しないため、`0011_00_contents.md` の再構成時に明治期参加者が実践を開始する認識上の手掛かりを抽出してから判定する。
