## 1. 結論

Evidenceそのものは、明治期器具型と後代の学校・紙硬貨型を分離し、後代の憑依・祟り・終了禁忌を初期形へ遡及しない点で良好である。一方、現行 `0000_00_contents.md` の正規構造へ未準拠であり、Evidence layer内に `Version Scope` や「意味形成核」の分析判断が混入している。

したがって、内容の全面再調査よりも、**現有Evidenceを維持しつつtutorial正規形へ再配置し、分析判断を `0011_10_analysis.md` 側へ分離する修正**が必要である。

## 2. Findings

### F00-001 — 現行tutorialの章構造へ準拠していない

- 重大度: **Major**

現在は `0.2 Evidence role`、`0.3 典拠`、`1.1 明治期の確認核`、`1.2 現代学校型`、`1.3 安定する意味形成核`、`1.4 主体・物・場所`、`1.5 条件・規則・帰結`、`3 Evidence traceability`、`4 証拠上の保留事項` という独自構造になっている。

現行tutorialでは、少なくとも以下へ正規化する必要がある。

```text
0.2 典拠と証拠上の扱い
  0.2.1 一次資料・同時代資料
  0.2.2 原文ミラー・転載・復刻資料
  0.2.3 二次資料・研究資料
1.1 summary
1.2 詳細展開
1.3 登場人物・主体
1.4 場所・空間
1.5 物・記号・媒体
1.6 条件・規則・禁忌
1.7 異常・不可解な現象／中心命題
1.8 行動・対応
1.9 帰結・終端状態
1.10 未解決点・不確実性
2.1〜2.4 伝承史・異伝
3.1 内容と典拠の対応表
3.2 短い原文引用
3.3 証拠上の保留事項
```

現在は主体・物・場所、条件・帰結等が統合されており、後続D07〜D17の根拠を個別に追跡しにくい。

### F00-002 — Evidence layerへ分析判断・Version Scope判断が混入している

- 重大度: **Major**

`1.3 安定する意味形成核`、異伝表の `Scope上の扱い`、本文中の `明治期Scope` 等は、Evidenceの記録を越えて分析条件を固定する表現である。

workflow上、`00_contents` はEvidence / Content layerであり、主要異伝を先に保持した上で、その後Step 4でVersion Scopeを固定する。したがって、

- 明治器具型
- 紙・硬貨型
- 占い型
- 危険招霊型

の差異はEvidenceとして記載してよいが、「今回Scopeに入れる／外す」という分析判断は `10_analysis` 側へ移すべきである。

同様に「安定する意味形成核」は分析的要約であり、00では観察可能な共通構造として書くに留め、D07〜D09相当の解釈を先取りしない方がよい。

### F00-003 — 一次資料への直接トレーサビリティをもう一段強化できる

- 重大度: **Moderate**

1886年新聞については見出し・掲載日・掲載位置を確認できているが本文未実見であり、その限界は適切に明示されている。

一方、1887年『妖怪玄談 狐狗狸の事』について、現文書では東洋大学公式整理を中心に初期器具型の内容を復元している。D11等を `Direct` 判定するには、可能であれば原典または復刻本文の具体的頁・該当記述まで追跡した方がよい。

これは現Evidenceを無効とする指摘ではなく、**Direct / Inferred Statusの判定を安定させるための強化点**である。

## 3. 維持可能な点

- 明治期器具型と現代学校型を明確に分離している。
- 現代の紙・五十音・硬貨型、憑依・祟り・終了禁忌を1880年代へ遡及していない。
- 1886年新聞本文未実見、1884年伝来説の位置付け、明治期因果主体の不確定性等の保留事項を明示している。
- 1970年代学校流行のEvidenceを明治期内部の帰結と混同していない。

## 4. 修正優先順位

1. 現行 `0000_00_contents.md` の章構造へ正規化する。
2. `Scope上の扱い`、`明治期Scope`、分析的な「意味形成核」をEvidence記述から分離する。
3. 既存Evidenceを `1.3`〜`1.10` に分解し、D07〜D17の再検討に必要な事実を追跡しやすくする。
4. 可能なら1887年原典／復刻の具体的参照位置を追加する。

## 5. 最終判定

**Review_0011_00_001: 要修正（Major）**

Evidence選定と初期形／後代異伝の分離は良好だが、文書責務とtutorial正規形の点で修正が必要である。
