# Review 0006_00_001 — Entry 0006 メリーさんの電話 / `0006_00_contents.md`

## 0. レビュー情報

- `Entry_ID`: `0006`
- `Review_Seq`: `001`
- 対象: `docs/10_each_lore/0006_mary_san_no_denwa/0006_00_contents.md`
- 判定: **要修正（Moderate）**
- 重点観点: Evidence / Content layer、tutorial準拠、初期Evidenceと後代代表形の分離、分析判断との責務分離

## 1. 結論

典拠分類は現行tutorialに概ね準拠しており、1999年児童書で直接確認できる範囲と、2018年事典等で整理される後代代表形を区別している点は良好である。また1999年書誌要約だけから段階接近・「後ろにいる」までを遡及しないという留保も適切である。

一方、summaryでは「恐怖の中心」「測距装置への反転」「意味形成核」等の分析概念がEvidence記述へ混入している。また、1999年直接Evidenceと後代代表形の境界がsummary内で連続的に書かれており、後続分析でどこからがIなのかを追跡しにくい。

## 2. Findings

### F00-001 — summaryにsense-making分析が混入している

- 重大度: **Moderate**

`1.1 summary` の以下の表現は分析層に属する。

- 「恐怖の中心は…電話だけが接近距離を逐次通知すること」
- 「固定電話が…測距装置へ反転する」
- 「安全圏が縮小したことを知る」
- 「段階接近と距離ゼロへの到達を意味形成核とする」

00では、

```text
反復する電話で現在地が通知され、その位置が受信者へ近づく型が後代代表形として確認される
```

までをEvidenceとして記述し、何を「意味形成核」と評価するかは10へ分離するべきである。

### F00-002 — 1999年直接Evidenceと後代代表形をさらに明示的に分けるべき

- 重大度: **Moderate**

1999年児童書について直接確認できるのは、現記録上は少なくとも、

```text
人形のおばけ「メリーさん」
＋
反復する電話
```

である。

一方、

- 現在地の逐次通知
- 駅→近所→家の前→背後という段階接近
- 人形を捨てた元所有者への追跡

は後代代表形の整理へ依存する。

Evidence文書では各節・各表で「1999年直接確認」「後代代表形」をより機械的に識別できるようにすると、Version ScopeとStatusの再現性が上がる。

### F00-003 — 因果条件としての「人形を捨てる／手放す」は重要Evidenceとして独立させるべき

- 重大度: **Moderate**

代表形では「人形を捨てる／手放す」が反復電話・接近に先行する。これはD11の判定へ直接影響するため、単なる発端記述ではなく、

```text
どのVersionで、どの資料が「手放す→電話開始」の関係を明示するか
```

をEvidence対応表で追跡できるようにする必要がある。

現状ではこの因果関係が後代代表形としてまとまっているため、D11で「発動条件なのか単なる物語文脈なのか」を判定しにくい。

### F00-004 — 典拠上の保守性は良好

- 重大度: **問題なし**

- 1999年公刊資料を口承初出と断定しない。
- 書誌要約にない段階接近を1999年へ遡及しない。
- リカちゃん電話直接起源説を確定しない。
- 身体襲撃・死亡を全Versionの必須帰結にしない。

これらは維持すべきである。

## 3. 修正優先順位

1. summaryから「恐怖の中心」「測距装置」「意味形成核」等の分析語を除く。
2. 1999年直接Evidenceと後代代表形を節・表で明示的に分離する。
3. 「人形を捨てる／手放す→電話開始」のEvidence traceabilityを独立強化する。
4. 現在の不確実性・由来説の留保は維持する。

## 4. 最終判定

**Review_0006_00_001: 要修正（Moderate）**

Evidence選定は概ね良好だが、後代代表形に基づく分析的要約と発動条件のtraceabilityを整理する必要がある。
