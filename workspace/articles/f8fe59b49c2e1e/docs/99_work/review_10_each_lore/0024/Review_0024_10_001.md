## 1. 結論

D07〜D17のsense-making構造は概ね明瞭である。将来の吉凶を、転送／不転送という規則へ結び付け、期限付き自己複製行為として制御可能化するモデルは1922年・1951年資料と整合する。

主要な問題はD12である。現行値 `D12.FOC.PRACTITIONER` は「転送を実行する者」を直接対象とするが、同じScoped規則では**不転送者にも悪運・災難が作用する**。したがってD13の幸運／悪運付与が直接向く対象は「転送実践者」より広く、文面を受け取って規則の対象になった受信者である。`D12.AUD.READER_LISTENER` 等を第一候補として再判定すべきである。

また、D18 L3は1922 Scopeではなく1951年の制度的X Evidenceに依存しており、Version Scopeの統一性を確認する必要がある。

## 2. Findings

### F10-001 — D12 `PRACTITIONER` が負の分岐を包含できない

- 重大度: **Major**
- 現在値: `D12.FOC.PRACTITIONER`

現在のD13は、

```text
転送した場合 → 幸運
転送しない／連鎖を断った場合 → 悪運
```

という二分岐を含む。

ところが `PRACTITIONER` は転送行為を実行した者を表すため、**不実行者へ向く制裁作用の対象を表現できない**。

D12はD13の主作用が直接向けられる対象であるため、より上位の共通対象は「手紙を受け取り、規則を読んで対象化された受信者」である。`D12.AUD.READER_LISTENER` を第一候補として再判定するのが自然である。

### F10-002 — D18 L3が1922 Version Scope外の1951 Evidenceへ依存している

- 重大度: **Major**

Version Scopeは1922年日本流行層である一方、L3=1の直接根拠は1951年国会会議録である。

1951年資料が1922年型と同じ自己複製・報酬／制裁構造を保持することは強い補強になるが、Scoped D18を厳密にVersion依存で運用するなら、

```text
1922年型の現実社会効果
```

を直接・準直接に示すX Evidenceが必要である。

1951年を同一モデルの後続社会効果として許容するなら、その運用規則を明記すべきである。現状は他EntryでのScope運用と不統一になり得る。

### F10-003 — D19 `REGIONAL` のEvidenceを強化すべき

- 重大度: **Moderate**

1922年の資料が東京朝日新聞に掲載されたこと自体は、「地域・地方で流通した」ことを直接意味しない。新聞掲載地と社会的流通範囲は別概念である。

丸山2012が1922年の「流行」をどの地理範囲まで資料で確認しているかを再確認し、地域範囲を固定できなければD19は `U` を検討するべきである。

### F10-004 — D07〜D17の基本モデルは概ね妥当

- 重大度: **問題なし**

```text
D07 将来の吉凶
→ D08 根拠未提示の条件主張
→ D09 転送規則＋吉凶相関
→ D10 情報内容
→ D11 メッセージ受信
→ D13 幸運／悪運付与
→ D15 運勢変化
→ D16 期限＋連鎖
→ D17 幸運利用
```

は一貫している。

D05を `CHAIN_INSTRUCTION`、D06を条件付き信念T5とする判定も適切である。

### F10-005 — D20 `NO_HIDDEN_TRUTH` は維持候補

- 重大度: **問題なし／留保**

実行条件・期限・報酬・制裁が文面自体に開示され、専門家や内部者が別の解除情報を独占する構造を必要としないため、本Entryでは `NO_HIDDEN_TRUTH` の適合性は比較的高い。

ただし「なぜ転送で幸運が生じるのか」という因果原理が説明されないことと、D20上の隠れた情報保持者不在は区別する。

### F10-006 — 文書書式の正規化が必要

- 重大度: **Minor**

`Entry_ID` が `24` で、4桁ゼロ埋め `0024` ではない。またD次元見出し・フィールドはtutorial簡略形になっており、完全正規形ではない。

## 3. Entry境界について

0024は報酬前景型、0025は制裁前景型として分ける設計だが、1922年Scope自体が報酬＋制裁を同一文面に含む。

したがって両Entryの分割根拠は、単に「幸福という語がある／不幸という語がある」ではなく、

- Primary incentive
- 文面の中心的な行為理由
- D13/D14/D17の主構造

が安定して異なることを示す必要がある。0025レビューと横断して再確認すべき事項である。
