# Review 0019_00_001 — Entry 0019 小さいおじさん / `0019_00_contents.md`

## 0. レビュー情報

- `Entry_ID`: `0019`
- `Review_Seq`: `001`
- 対象: `docs/10_each_lore/0019_chiisai_ojisan/0019_00_contents.md`
- 判定: **要修正（Major）**
- 重点観点: Evidence / Content layer、tutorial準拠、目撃証言群の整理、分析判断との責務分離

## 1. 結論

2007年mixi、2008年公開掲示板、2009年ニュースという初期の直接流通点を固定し、2006年2ch後代転載を最古記録へ格上げしていない点は良好である。また、後代の具体的目撃証言をVariationとして使い、固定身長・服装・幸運・召喚法等を初期共有核へ遡及していない。

一方、文書構造は現行 `0000_00_contents.md` の正規形へ未準拠であり、`1.1 最小共有核`、`1.3 中心的な異常性` 等に分析判断が入っている。Evidence自体の再調査より、tutorial正規化とEvidence/Analysis責務分離を優先すべきである。

## 2. Findings

### F00-001 — 典拠章が現行tutorialの `0.2.1`〜`0.2.3` へ未準拠

- 重大度: **Major**

現在は、

```text
0.2 Evidence role
0.3 典拠
```

として資料を列挙している。

現行tutorialでは、

```text
0.2 典拠と証拠上の扱い
  0.2.1 一次資料・同時代資料
  0.2.2 原文ミラー・転載・復刻資料
  0.2.3 二次資料・研究資料
```

へ整理する。2006年2ch後代転載、2007–2009年同時代Web、2018–2022年後代資料の役割差をこの構造へ写像する必要がある。

### F00-002 — Content章がtutorialの `1.1 summary`〜`1.10` 構造へ未正規化

- 重大度: **Major**

現文書は主に、

- `1.1 最小共有核`
- `1.2 目撃形`
- `1.3 中心的な異常性`
- `1.4 条件・規則・禁忌`
- `1.5 終端`

で構成されている。

現行tutorialに従い、少なくとも、

```text
1.1 summary
1.2 詳細展開
1.3 登場人物・主体
1.4 場所・空間
1.5 物・記号・媒体
1.6 条件・規則・禁忌
1.7 異常・不可解な現象／中心命題
1.8 行動・対応
1.9 帰結・終端状態
1.10 未解決点・不確実性
```

へ分解する必要がある。

### F00-003 — `1.3 中心的な異常性` がD07/D09分析を先取りしている

- 重大度: **Moderate**

「未知生物として精密分類できることではなく、日常的な成人男性カテゴリーと極端に小さい身体サイズの矛盾」「既知カテゴリーが先にあるため異なる目撃を同じラベルで回収できる」という記述は、D07の対象選択とD09の類型化・命名をほぼそのまま先取りしている。

Evidence文書では、

```text
成人男性様の外見を持つが数cm〜数十cmと語られる
複数の異なる目撃が「小さいおじさん」の名称で共有される
```

までを記録し、なぜそれが意味形成上重要かは10へ置くべきである。

### F00-004 — 最古確認と後代Variationの扱いは良好

- 重大度: **問題なし**

- 2007年mixiを現時点のDirectな固定点とする。
- 2006年転載を補助扱いに留める。
- 後代の芸能人証言を初期核の細部へ遡及しない。
- 妖精・妖怪・霊・UMA等の正体をEvidence側で固定しない。

これらは維持すべきである。

## 3. 修正優先順位

1. 典拠章を `0.2.1`〜`0.2.3` へ正規化する。
2. Content章を `1.1`〜`1.10` のtutorial構造へ再配置する。
3. `中心的な異常性` 等の分析判断を10へ移す。
4. 現在の最古確認・後代VariationのEvidence強度管理は維持する。

## 4. 最終判定

**Review_0019_00_001: 要修正（Major）**

Evidence基盤は有用だが、現行tutorialからの構造差が大きく、意味形成分析も00へ先取りされているためMajorとする。
