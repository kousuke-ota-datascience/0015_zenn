## 1. 結論

Evidence / Contentは現行Scopeに対して良好である。高権威資料で固定できる前近代の荒廃→天変地異→鎮魂→奉祀を共有核とし、近現代の慰霊・保存・改修実践を現実側の継続として分離している。個別の工事事故・病気・死亡を高権威Evidenceなしに共有核へ戻していない。

一方、strictなtutorial構造では0.2資料ブロックに複数差分が残る。0.2.2は「直接固定していない」という散文のみで固定フィールドを持たず、0.2.3の複数資料も見出しに資料名を埋め込む一方で、tutorial所定の`資料名`・`参照確認日`等の固定フィールドが欠ける。複数資料区分にまたがるschema不一致のためModerateとする。

## 2. Findings

### F00-001 — 0.2.2 / 0.2.3がtutorial固定メタデータschemaを満たさない
- Severity: **Moderate**
- 現在の記載:
  - 0.2.2は、前近代・近代の原資料／復刻本文を直接固定していない旨を散文で記載するだけで、所定フィールドを持たない。
  - 0.2.3のA〜Dは見出し・URL・用途等を持つが、tutorial所定の`資料名`や`参照確認日`等が資料ごとに揃っていない。
- tutorial所定形式:
  - 0.2.2: `資料名 / URL・書誌情報 / 対象箇所 / 参照確認日 / 一次資料との関係 / 証拠上の注意`
  - 0.2.3: `資料名 / URL・書誌情報 / 参照確認日 / 用途`
- 影響: Evidenceの意味・用途は再構成できるが、複数資料にわたり固定schemaでの横断監査ができない。
- 修正方向: 未固定資料は明示的な「該当資料なし」等の正規ブロックにし、0.2.3各資料もtutorial所定フィールドを全て明記する。

## 3. 維持可能な点

- 現行Scopeは前近代の鎮魂伝承を中心に限定されている。
- 近現代の個別事故祟り逸話をEvidence不足のまま共有核へ一般化していない。
- 首伝説、鎮魂、奉祀、慰霊・保存・改修を時代・Evidence roleごとに区別している。
- 1.6は条件・規則・禁忌・対処／回避・利用法の5フィールドを満たす。
- 1.9は明示・暗示・未確認の3区分を満たす。
- 近現代の保存会・例祭・改修を実在実践として記録しつつ、祟りの実在証明には転用していない。
- 最古確認・前近代伝承と、具体的同時代一次史料の未固定を区別している。
