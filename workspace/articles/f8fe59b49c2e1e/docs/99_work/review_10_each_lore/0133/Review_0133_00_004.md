## 1. 結論

現行00は、前近代の鎮魂伝承、近現代の祭祀・保存・改修記録、後代の祟り語り、個別事故の未確認性を分離しようとしており、実在史と超自然因果を同一視しない点は維持できる。

一方、最初のtutorial gateで広範な構造不一致がある。`1.6`が所定5フィールドではなく散文、`1.9`が所定3区分ではなく独自4区分、`2.1〜2.4`がtutorialの「最古確認／流通・拡散／主要な異伝・派生／変容上の重要点」構造から全面的に組み替えられ、`主要な異伝・派生`が`2.5`へ移動している。`3.2/3.3`も所定見出し名と一致しない。意味的に近い情報が存在してもschema準拠の代替にはならないためModerateとする。

また、Scope中核に使われる「撤去・破壊・粗末な扱い等と事故・病気・災厄を結び付ける後代の祟り語り」が、3.1対応表で具体的資料・位置へ結び付いていない。後続10のD05/D07/D09/D11〜D15等がこの内容に依存するため、Evidence traceability上もModerate Findingとする。

## 2. Findings

### F00-001 — tutorial所定構造からの広範な逸脱
- Severity: **Moderate**
- 主な不一致:
  - `1.6. 条件・規則・禁忌`が散文のみで、tutorial所定の`条件 / 規則 / 禁忌 / 対処・回避 / 利用法`の独立フィールドを満たさない。
  - `1.9. 帰結・終端状態`が`宗教伝承上 / 後代祟り語り / 現実史 / 未確認`の独自4区分で、所定の`明示された帰結 / 暗示された帰結 / 確認されない帰結`ではない。
  - chapter 2が`2.1 最古確認層 / 2.2 近代以前から近代 / 2.3 関東大震災後 / 2.4 戦後から現在 / 2.5 主要な異伝・派生`へ再編され、tutorial所定の4節構造・順序を満たさない。
  - `3.2 短い原文引用・原文断片`、`3.3 証拠上の限界`はtutorial所定の`短い原文引用`、`証拠上の保留事項`と一致しない。
- 影響: 情報自体の多くは存在するが、固定schemaによる第三者再検査性とEntry間比較可能性を損なう。
- 修正方向: tutorialの見出し・順序・固定フィールドへ戻し、現在の内容を所定箇所へ再配置する。

### F00-002 — 後代の工事・不敬→事故／病気／災厄というScope中核のEvidence対応が不足
- Severity: **Moderate**
- 現在の記載: `1.2.5`等で、撤去・破壊・粗末な扱い、供養不足等と事故・病気・災厄を結び付ける話が「広く語られる」とする。
- Evidence対応: `3.1`は首伝説、1307/1309鎮魂、例祭、震災後整地、慰霊祭、保存会、改修を対応付けるが、後代祟り型そのものをどの資料のどの位置で確認したかが記録されていない。
- 影響: 後続10のVersion Scope、D05、D07、D09、D11〜D15等がこの内容を中核として使うため、単なる補足欠落ではない。
- 修正方向: 後代祟り型を直接確認できる資料名・URL/書誌・対象箇所を固定し、3.1へ要素別に対応付ける。固定できない個別事故・被害類型はScope中核から外すか不確実性を引き上げる。
