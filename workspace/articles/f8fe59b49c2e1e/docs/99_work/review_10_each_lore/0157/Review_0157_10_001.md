## 1. 結論

D01で1935年を古代出来事の確認年としない点、D02をUとする点は保守的である。しかしD04/D05/D18/D19で規則外の複合Status `D/I` を使用する。より本質的にはD11〜D15が「伝承を知った一般公衆が歴史認識を更新する」という受容者モデルになっており、Version Scope内部の身代わり→渡来→居住→死亡→墓という伝承世界の因果モデルと混線している。D10のCも「歴史人物」と「根拠文書」を競合ontologyとして扱っており不適切。Major。

## 2. Findings

### F10-001 — 複合Status `D/I` を複数使用
- 重大度: **Major**
- 対象: D04, D05, D18, D19
- 修正方向: 各Dimensionを単一の `D/I/U/NA/C` へ裁定する。

### F10-002 — D11〜D15が受容者の情報処理を伝承内部因果へ置換
- 重大度: **Major**
- 現在: D11=`LEARN_KNOW`、D12=`GENERAL_PUBLIC`、D13=`REALITY_REPLACEMENT`、D15=`BELIEF_REVISION`
- 問題: EntryのScoped Contentはキリストの身代わり・渡来・日本での生涯・墓比定という代替歴史説であり、「話を知る公衆への作用」が伝承内部の主因果ではない。
- 影響: one entry = one sense-making model のD11→D13→D15が、物語世界ではなく読者心理へ切り替わる。
- 修正方向: Version Scope内部で何が因果系の入口・対象・作用・終端なのかをゼロベース再構成する。受容者への影響はD18 L2/L3等と混同しない。

### F10-003 — D10 `C` が異なる分析役割を競合ontology扱い
- 重大度: **Major**
- 現在: `INDIVIDUAL_HUMAN` + `INFORMATION_CONTENT`, Status C
- 問題: キリストという伝承内人物と、竹内文書という受容者側の根拠資料は同じ中心質問への競合回答ではない。
- 修正方向: D10は伝承世界で因果源として置かれる存在を再判定し、Evidence source／cueはD08等と分離する。

### F10-004 — D06 `C` は提示差の競合性を再点検要
- 重大度: **Moderate**
- 問題: 現行自治体が真偽を委ねることと、他再話が事実主張形式を取ることは、Version Scopeの切り方次第では単なる媒体・異伝差でありCとは限らない。
- 修正方向: 同一Scope内で真実性提示が実際に矛盾するEvidenceか、外部媒体差かを分離する。

### F10-005 — D20が資料保管・観光解説主体を特権情報保持者へ変換
- 重大度: **Moderate**
- 問題: 自治体・伝承館が資料へアクセスしやすいことは、伝承世界の「真相・追加情報保持者」を意味しない。
- 修正方向: Scoped Contentに特権保持構造がなければUを検討する。

### F10-006 — tutorial正規形式を簡略化
- 重大度: **Moderate**
- 問題: 各Dの階層番号・中心質問を省略している。
- 修正方向: `0000_10_analysis.md` の所定構造へ整形する。
