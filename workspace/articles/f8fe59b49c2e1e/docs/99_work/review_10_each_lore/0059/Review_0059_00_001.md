# Review 0059_00_001 — Entry 0059 深泥池の幽霊タクシー / `0059_00_contents.md`

## 0. レビュー情報

- `Entry_ID`: `0059`
- `Review_Seq`: `001`
- 対象: `docs/10_each_lore/0059_mizorogaike_ghost_taxi/0059_00_contents.md`
- 判定: **要修正（Major）**
- 重点観点: Evidence / Content layer、tutorial準拠、1969年直接Evidenceと後代定型の分離、分析判断との責務分離

## 1. 結論

1969年10月7日『朝日新聞』京都市内版の存在・見出しを京都府立図書館のマイクロフィルム確認へ接続し、本文未実見であることを明示した上で、後代の「若い女性」「雨」「濡れた座席」「死者由来」等を初期形へ遡及しない姿勢は良好である。また、深泥池の実在性を京都市公式資料で確認しつつ、それ自体を幽霊因果の証拠にしていない。

一方、文書構造が現行tutorialの正規形へ未準拠であり、`summary`、`中心命題` 等に「伝承構造上の中心」「後代再話は幽霊だったと解釈する」といった分析判断が入り込んでいる。さらに、1969年記事本文を未実見であるため、**記事自体がどの程度深泥池を明示しているか**と、後代レファレンスが当該記事を深泥池伝承へ結び付けていることを区別して記録する必要がある。

## 2. Findings

### F00-001 — 典拠章が現行tutorialの `0.2.1`〜`0.2.3` 構造へ未準拠

- 重大度: **Major**

現在は `0.2 典拠とEvidence role` の直下に資料A〜Dを配置している。

現行tutorialでは、

```text
0.2 典拠と証拠上の扱い
  0.2.1 一次資料・同時代資料
  0.2.2 原文ミラー・転載・復刻資料
  0.2.3 二次資料・研究資料
```

へ整理する必要がある。

1969年新聞、京都府立図書館レファレンス、京都市公式資料、後代再話は証拠役割が異なるため、この分類へ再配置することでtraceabilityが明確になる。

### F00-002 — Content章がtutorialの `1.1 summary`〜`1.10` へ未正規化

- 重大度: **Major**

現在は、

- `1.1 summary`
- `1.2 初期Evidenceで固定できる最小核`
- `1.3 後代に安定化した代表形`
- `1.4 場所・主体・媒体`
- `1.5 条件・規則・禁忌`
- `1.6 中心命題`
- `1.7 帰結`
- `1.8 不確実性`

となっている。

現行tutorialに従い、主体、場所、物・媒体、条件、中心命題、行動、帰結、未解決点を `1.3`〜`1.10` へ分解するべきである。特に「場所・主体・媒体」を一表にまとめると、D10/D12/D21の根拠が追跡しにくい。

### F00-003 — summaryに分析判断が混入している

- 重大度: **Moderate**

「伝承構造上の中心は、日常業務に普通の乗客が通常の降車過程なしに消える異常が侵入すること」「後代再話はこの不在を幽霊だったと解釈する」という整理は有用だが、D07/D09/D10に近い分析である。

00では、

```text
車内にいたとされる乗客が通常の降車過程なしにいなくなったと報告された。
後代資料では、その乗客を幽霊・死者とする再話がある。
```

までをEvidenceとして保持し、意味形成上の中心性は10で判断する方がよい。

### F00-004 — 1969年記事と「深泥池」結合の直接性をさらに明示すべき

- 重大度: **Moderate**

現在確認できるDirectなものは、1969年記事の存在・日付・見出し「車から乗客消えた」と、京都府立図書館が深泥池の幽霊タクシー照会に対して当該記事を特定した事実である。

本作業では新聞本文を直接読んでいないため、

```text
記事本文そのものが深泥池を明記する
```

ことと、

```text
後代の図書館レファレンスが当該記事を深泥池伝承の初期資料として関連付ける
```

ことを区別して書く必要がある。これはD21のStatusにも影響する。

### F00-005 — 後代要素の遡及防止は良好

- 重大度: **問題なし**

以下は維持すべきである。

- 「若い女性」「雨」「濡れた座席」「病院で死亡した女性」を1969年へ遡及しない。
- 深泥池が乗車地点か目的地かを固定しない。
- 警察対応を幽霊実在の証拠にしない。
- タクシー業界の乗車拒否等を一次資料なしにX Evidence化しない。

## 3. 修正優先順位

1. 典拠章を `0.2.1`〜`0.2.3` へ正規化する。
2. Content章を `1.1`〜`1.10` へ正規化する。
3. summary・中心命題から分析判断を分離する。
4. 1969年記事本文上の深泥池明示と、後代レファレンスによる関連付けを別Evidenceとして記録する。
5. 後代定型の遡及防止は維持する。

## 4. 最終判定

**Review_0059_00_001: 要修正（Major）**

Evidenceの保守性は高いが、現行tutorialとの差が大きく、深泥池アンカーの直接性とEvidence/Analysis責務をさらに分離する必要がある。
