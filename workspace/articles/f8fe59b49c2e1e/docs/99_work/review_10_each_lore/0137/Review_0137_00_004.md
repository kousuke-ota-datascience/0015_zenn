## 1. 結論

1999年層、実在地域史、後代心霊派生・映画設定を区別し、元Webページ未固定や立札現物未確認を明示している点は維持できる。しかし、最初のtutorial gateで複数の固定schema不一致がある。`1.6`、`1.9`、`2.3`、`2.4`、`3.1`、`3.2`がtutorial所定形式から外れており、意味的に情報が存在するだけではformat準拠とはできない。

## 2. Findings

### F00-001 — tutorial所定schemaから複数箇所で逸脱している
- Severity: **Moderate**
- 主な不一致:
  - `1.6. 条件・規則・禁忌`が散文で、所定の`条件 / 規則 / 禁忌 / 対処・回避 / 利用法`の5フィールドを持たない。
  - `1.9. 帰結・終端状態`が`早期に確認できる帰結 / 研究で確認される噂内容 / 一部後代型 / すべての型に共通…`という独自区分で、所定の3区分ではない。
  - `2.3. 主要な異伝・派生`の表が3列で、tutorial所定の5列（異伝・派生 / 時期 / 地域・媒体 / 原型・主要形との差 / 典拠）を満たさない。
  - `2.4. 時系列上確認できる差分`は所定の`変容上の重要点`と一致しない。
  - `3.1`が資料別の独自列構成で、所定の`内容要素 / 典拠 / 位置 / 証拠種別 / 備考`を満たさない。
  - `3.2. 短い原文引用・原文断片`は所定の`短い原文引用`と一致しない。
- 影響: 固定schemaによる第三者再検査性とEntry間比較可能性が低下する。
- 修正方向: tutorial所定の見出し・順序・固定フィールド・表列へ戻し、現内容を対応箇所へ再配置する。

### F00-002 — 元1999年Web記録未固定なのに0.2.1「一次資料・同時代資料」として分類している
- Severity: **Moderate**
- 現在の記載: 0.2.1 Aを`1999年公開Web上の「犬鳴峠」記録`として置く一方、URL欄で「原ページを直接固定できず、鳥飼かおるの研究論文および後代保存転載を介して確認」と明記する。
- 衝突: 実際にアクセスしたEvidenceは研究論文・保存転載であり、原1999年ページではない。歴史上の原資料と現在のアクセス資料を同じEvidenceレイヤーに置くとdirectnessを過大に見せる。
- 影響: 1999年層の内容確認自体は可能だが、各要素のStatus `D/I`判断へ直接影響する。
- 修正方向: 原ページを直接固定できない限り、1999年記録は0.2.2保存転載および0.2.3研究資料を実Evidenceとして記録し、原資料との関係を明示する。原ページを固定できた場合のみ0.2.1へ具体URL・位置とともに置く。
