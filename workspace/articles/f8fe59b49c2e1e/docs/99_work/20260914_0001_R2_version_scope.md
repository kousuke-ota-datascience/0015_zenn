# 1. 固定したVersion Scope

**1979年初頭〜同年春に確認できる最小安定共有核:**  
日常社会の中に「口が裂けた女性（口裂け女）」が出現し、主として小中学生・子どもを脅かし／襲うとされる遭遇・危害型の噂。

このScopeでは、口裂け女という異常な女性主体、裂けた口という識別核、子どもを中心とする遭遇・危害関係を含める。

# 2. Scopeへ含めない要素

以下は1979年流行過程で広く知られるが、R1 Evidenceでは最初期共有核へ安全に遡及できないため、R2既定Scopeから除外する。

- 「私、きれい？」という定型質問
- マスクを外して口を見せる二段階の正体提示
- 赤いコート
- 鎌・鋏等の特定武器
- 人間離れした高速走行
- ポマード
- べっこう飴
- 「普通」「まあまあ」等の特定回答による回避
- 整形失敗・交通事故等の由来説明
- 個別地域固有の禁忌・弱点・逃走規則

これらは `00_contents` の異伝・変容史には保持するが、R3のD01〜D21では既定Scopeの直接構造として入力しない。

# 3. 根拠

1. 1979-01-26『岐阜日日新聞』「編集余記」の存在は国立国会図書館のマイクロフィルム実見で確認できるが、R1では本文全文を直接精査しておらず、質問文・武器・回避法等の具体細部は確定できない。
2. 1979-04-05『週刊新潮』記事見出しは「口のさけた女性が小・中学生を襲う」としており、少なくとも「裂けた口を持つ女性」＋「小中学生への脅威／襲撃」は流行早期の同時代資料へ接続できる。
3. 1979年3〜6月の全国誌・地方紙記事により、同年春〜初夏には広域流通していたことを確認できる。
4. 飯倉義之の専門家整理は、マスク・赤いコート・鎌・高速走行・ポマード・べっこう飴等が子ども間の反復で付加されたと整理している。したがって、それらを成立時の最小核へ一括して遡及することは避ける。

# 4. R2判定

- Version Scope: **1979年初頭〜春の「口が裂けた女性が子どもを脅かし／襲う」最小安定共有核**
- Scope Status: `I`
- 理由: 最古同時代記事の存在は直接確認できるが、本文細部を実見できていないため、複数の同時代書誌・見出しと専門家による変容史整理から保守的に最小核を推定した。
- Entry分割: 不要。R1で確認した外見・能力・弱点・回避法の差は、現段階では同一意味形成核上の変容として保持する。

# 5. R3への拘束条件

R3では上記Scopeだけを伝承構造としてコードする。除外した後代・流行過程の要素を、D07〜D17等の判定を豊かにする目的で再導入しない。Evidence不足により判定できない次元は `U`、構造上存在しない次元は `NA` とする。
