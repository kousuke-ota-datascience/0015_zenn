# 2. 現在の研究目的と分析単位

研究の中心的な問いは、単なる「怖い話の分類」ではない。

**異常・不可解・不確実・偶然・危険・不可視な制度その他の意味形成を要求する対象に対して、人々のあいだで流通する伝承が、どのような手掛かりを用い、どのような説明・因果・規則・予測・対処を与え、それをどのように共有可能な世界モデルへ変換しているか。**

分析単位は伝承エントリであり、原則として以下で定義される。

> 伝承エントリとは、人々が異常・不可解・不確実な何かを理解可能なものへ変換するために共有する、独立して伝達可能な最小の意味形成モデルである。

**1伝承エントリ = Excelの1行**である。

名前・色・被害人数・典拠の違いだけでは分割しない。一方、説明対象、因果源、発動・接触条件、作用機構、帰結・制御等の意味形成核が安定して異なる場合は別Entryとし得る。

## 5.1. `*_00_contents.md` の summary

`1.1. summary` は辞書的な2〜3文の紹介では不十分である。

目標は、**原典を毎回開かなくても、その伝承で何が起きる／何が主張されるのかを再構成できる高密度パラフレーズ**である。

固定の文字数・段落数を目標にしてはいけない。十分性は以下で判定する。

### 5.1.1. 時間的進行を持つ伝承

少なくとも以下を連続した文章として把握できること。

- 発端: 誰が、どこで、どのような通常状況から始まるか
- 異常の顕在化: 最初に何が通常から外れるか
- 展開: 異常がどう継続・反復・拡大・変質するか
- 対応: 登場人物が何を確認・回避・試行・相談・実行するか
- 転換／エスカレーション: 危険・不可解さ・因果関係がどう強まるか
- 終端: 明示的にどこで語りが終わるか
- 未解決部分: 何が説明されず、何を推測してはならないか

単なる「発端→結末」のあらすじではなく、**後続のD07〜D17等をなぜそのように分析したかが読み取れるだけの人物・場所・物・行為・順序・因果主張**を残す。

### 5.1.2. 非時間的な伝承

俗信・ジンクス・命題型噂・制度俗説等では、物語的時系列を無理に作らない。

少なくとも以下が分かること。

- 対象となる状況・行為・制度
- 成立条件・適用条件
- 中心命題・規則・因果説明
- 想定される作用・予測
- 帰結
- 回避・制御・利用方法
- どこまでが資料上確認でき、どこからが推測・後代解釈か

### 5.1.3. summary で避けること

- Candidate Master の1〜2行要約を言い換えただけにする
- コード定義を文章化するだけにする
- 原資料にない心理・真相・因果関係・結末を補う
- 後代の有名な設定を最初期版へ遡及させる
- 「投稿が途絶えた」ことを「死亡・失踪」と同一視する
- 書籍販売ページ・書誌ページだけを、物語細部の内容証拠として扱う

書誌ページはその資料の存在を証明するが、ページ本文に内容が出ていなければ、物語細部の直接証拠ではない。

## 5.2. `*_00_contents.md` 全体の粒度

summary を厚くするだけでなく、以下を後から追跡可能にする。

- `1.2. 詳細展開`: summary の各段階を分解し、可能なら頁・レス番号・採録番号・記事日付等へ対応
- `1.3. 登場人物・主体`: 主体、種別、役割、典拠上確認できる情報、典拠位置
- `1.4. 場所・空間`: 実在／比定／架空／不明を区別
- `1.5. 物・記号・媒体`: 因果や展開に重要な物・身体部位・文書・電話・商品・記号等
- `1.6. 条件・規則・禁忌`: 発動、遭遇、手順、禁止、対処、回避、利用
- `1.7. 異常・不可解な現象／中心命題`
- `1.8. 行動・対応`
- `1.9. 帰結・終端状態`: 明示／暗示／未確認を分離
- `1.10. 未解決点・不確実性`
- `2.1. 最古確認`: 実際の起源と、現在確認できる最古資料を分ける
- `2.2. 流通・拡散`
- `2.3. 主要な異伝・派生`
- `2.4. 変容上の重要点`
- `3.1. 内容と典拠の対応表`
- `3.2. 短い原文引用`: 必要最小限。長文転載しない
- `3.3. 証拠上の保留事項`

## 5.3. 典拠の優先順位

原則:

1. 一次資料・同時代資料
2. 原文ミラー・転載・復刻資料
3. 信頼できる二次資料・研究資料
4. 後代のまとめ・解説資料

Web資料は生存確認し、URL・参照範囲・確認日を可能な限り残す。

一次資料が見つからない場合は「一次資料未確認」と明示して二次資料で記録する。**見つからないこと自体は文書化不能の理由にならない。**

ただし、証拠の弱さを隠してはいけない。

## 5.4. `*_10_analysis.md` の各次元の粒度

D01〜D21は、コード表をMarkdown化するだけでは不十分である。

現在のテンプレートでは、各次元を原則として以下の順で記載する。

```text
コード値
↓
判定根拠
↓
この伝承における現れ方
↓
必要なら境界・留保
```

各次元で必ず答えるべきなのは、

> **この概念次元からこの伝承を見ると、具体的に何が起きる／何が主張される／どのような構造を取るのか。**

である。

### 5.4.1. 「判定根拠」

- `00_contents` のどの内容・典拠がコード選択を支えるのかを書く
- `D` なら直接証拠がどこにあるか
- `I` なら、どの事実とコード定義から推論したか
- `U` なら、何が確認できないため一意に判定できないか
- `NA` なら、なぜ伝承構造上その次元が成立しないか
- `C` なら、どのVersion・資料・異伝が競合するか

### 5.4.2. 「この伝承における現れ方」

ここは**コード定義の言い換えではない**。

伝承固有の人物、場所、出来事、言葉、条件、行為、帰結を使って、コードが物語・命題の中で具体的にどう機能しているかを書く。

例: きさらぎ駅の D13 が `SPATIAL_DISTORTION` である場合、単に「空間異常だから」と書いて終えない。

- 通常の鉄道路線では説明できない接続が生じる
- 見知らぬ駅へ到達する
- 現在地を既知の鉄道網・地理情報へ接続できない
- 徒歩で移動しても通常空間への復帰が成立しない
- したがって「未知の場所」よりも「既知空間同士の接続関係の崩壊」として作用している
- ただし初期版は「別世界」を明言しないので後代の異界解釈を遡及させない

というところまで書く。

これにより、

```text
原資料上の具体的展開
→ 分析者の解釈
→ コード
```

というトレーサビリティを確保する。

A3では、**薄い既存文書を先に新基準へ揃えてから、新規24件へ進む**のが現在の方針である。

# 10. 推奨するA3開始手順

2. `0000_tutorial/0000_00_contents.md` と `0000_10_analysis.md` を再取得
3. `10/20/30/90` を必要範囲で確認

8. 薄い既存Entryをすべて新基準へ揃えた後、未作成24件へ進む

# 12. 注意すべき過去の失敗

A2aでは、複数伝承を一括treeへ積んでからcommitしようとしたため、中途状態の8件だけを一括commitしてしまった。

このためユーザーから、**1伝承エントリずつ実行すること**と明示された。

またGitHub connector操作中にテストファイルを誤作成し、直後に削除したことが複数回ある。最終treeには残っていないが履歴には追加・削除コミットが残っている。

A3では、ツール確認のためのテストファイルをmainへ作成しないこと。

# 13. 研究上の重要な解釈ルール

- D02は「起源媒体」ではなく、**現在の証拠で最古に確認できる実流通媒体**
- D03はVersion Scope内で実際に確認できる流通媒体。D02と同じでもよい
- D13 `MANIFEST_ONLY` は、伝承構造上追加作用を必要としない場合のみ。証拠不足は `U`
- D13 `RST.SPATIAL_DISTORTION` は距離・接続・地理・空間関係の歪み
- D16 `EVT.SEQUENTIAL_EPISODE` は1エピソード内で複数段階が進行する構造
- D18は L1=伝承内因果、L2=受容者、L3=社会現実
- D20 `NO_ONE_KNOWS` は「伝承内に真相保持者が存在しない」強い主張なので濫用しない
- D21は抽象的背景から歴史的・制度的実在への固定度を見る

# 14. A3で最優先すること

最優先は件数を増やすことではない。

**パイロット49件について、各伝承の証拠内容と21次元の分析を、後から人間が読み返して再検討できる粒度で文書化すること。**

特に `10_analysis` はコード一覧ではなく、**21個の分析概念を通して1つの伝承を読む文書**にする。

`00_contents` は短い百科事典記事ではなく、**証拠に忠実な高密度の伝承記録**にする。

この2点を満たしたうえで、1伝承ずつcommit/pushすること。
