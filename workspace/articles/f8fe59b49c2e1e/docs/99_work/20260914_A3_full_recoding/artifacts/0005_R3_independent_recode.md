# 1. Version Scope

1998–1999年の静岡県・栃木県採録群で直接確認できる最小安定共有核、すなわち、**「紫の鏡」という危険語を知った者が、その語を将来の一定年齢・節目まで忘れずに記憶していると、期限到達時に死亡するとされる記憶期限型の俗信**をコード対象とする。

期限は16歳・18歳・20歳等で変動するため固定しない。「不幸になる」型、紫地蔵・赤い沼との複合型、ピンクの鏡による対抗型、鏡から血だらけの女が現れる人格怪異型、物理的な鏡を用いる儀式はR2でScope外としたため、D07〜D17の直接構造へ混成しない。

# 3. 因果列予備確認

R4前の予備確認として、主因果列は次のように接続する。

```text
D11: D11.INF.SAY_NAME_REMEMBER
  + Secondary: D11.CON.AGE_LIFESTAGE
→ D12: D12.AUD.READER_LISTENER
→ D13: D13.COG.COGNITION_TRIGGERED_HARM
→ D15: D15.BOD.DEATH
```

因果源はD10=`INFORMATION_CONTENT`。語を受容した人物が記憶を期限まで保持することで、認知条件が致死帰結へ接続する。

# 4. D18作用レイヤー予備確認

```text
L1 = 1  伝承内で記憶条件→死亡が作動
L2 = 1  伝承を聞いて危険語を知る現実側受容者が、伝承内容上の将来の作用対象になる
L3 = 0  現実の行動・制度・市場等への外部効果を示すX Evidenceなし
```

0005はL2の典型的な自己適用型であり、「伝承を聞くこと」と「伝承内の危険条件」が接続する点をL1だけへ吸収しない。

# 5. taxonomy gap候補

## 5.1. D17「忘却による制御」

現行D17には、次のScoped Contentを直接表すChildがない。

> 危険な情報を期限まで保持しないよう、**忘れる／記憶から失うこと自体**が回避になる。

近接候補は `D17.RUL.OBEY_TABOO` だが、「行為をしない」という通常の禁忌遵守と、意図的または結果的な**認知内容の忘却**は同一ではない。

R3ではtaxonomyを単一Entryの都合で変更せず、`D17.RUL.OBEY_TABOO / I` に暫定写像する。ただし、後続Entryでも「忘却・記憶消去」が安定した制御方式として再発する場合、D17への専用Child追加または情報制御Parentの再設計をR5横断確認候補とする。
