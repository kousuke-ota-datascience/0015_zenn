## 1. Evidence正本監査

00は、歴史人物としての平将門、実在する将門塚、飛ぶ首伝説、中世の祟り・鎮魂伝承、関東大震災後の整地・慰霊、戦後の保存・改修、後代の具体的事故逸話を分離している。特に「実際に改修不能な場所」という強い俗説を、公式の複数回整備記録で反証可能な形に整理しており、Evidence / Content layerとして妥当。

外部照合では、神田明神公式が1307年の鎮魂・1309年の奉祀を社伝として説明し、現行板石塔婆の文面を1307年の板碑拓本に由来するとしている。また2021年公式記録は1961年以降の複数回整備と第6次改修を明示する。千代田区観光協会は首飛来伝説、13世紀の祟り・再供養、関東大震災後の塚の改変を地域伝承・歴史として紹介する。

## 2. 主要Evidence

### A. 神田明神「将門塚例祭／将門塚板石塔婆」 — C / H / A

- URL: https://www.kandamyoujin.or.jp/event/detail/?id=15&m=00
- 参照確認日: 2026-09-15
- 徳治2年（1307）に真教上人が将門公の祟りを鎮め、法号を追贈したという宗教伝承を確認。
- 現行板石塔婆は、1307年に作られたと伝えられる板碑の拓本から文面を取ったと神社が説明。
- 1906年故蹟保存碑、現行祭祀・保存活動も確認。
- 注意: 現代神社の伝承説明であり、1307年の超自然因果を史実として実証するものではない。

### B. 神田明神「神田明神とは」 — C / H

- 用途: 「災厄→祟り解釈→鎮魂」という古い因果モデル。

## 3. Evidence role整理

- `C`: 塚を粗末に扱う／破壊・撤去する／供養を怠ると将門の御霊・怨霊による災いが生じるという祟りモデル。供養・鎮魂により制御する対抗規則。
- `H`: 1307年鎮魂伝承、江戸期祭祀、1906年保存碑、1925年慰霊祭、戦後保存会、2021年改修までの長期継承。
- `X`: 現実に慰霊祭・例祭・保存会・保存改修が継続し、将門を祀る宗教的・社会的実践として場所管理へ接続している。
- `A`: 平将門という歴史人物、大手町の実在将門塚、関東大震災・官庁地再建・保存改修という実在史。

## 4. Entry境界

0133は「将門塚を無礼に扱う、撤去・破壊する、供養を怠ると将門の御霊が災いを与える。鎮魂・供養・尊重によって危険を制御する」という祟り伝承を中心とする。首飛来伝説は前史として含めるが単独Entry化しない。大蔵省関係者の連続死、占領期ブルドーザー事故など高権威資料で固定できない具体逸話は共有核へ組み込まない。「一切工事できない」という版も、公式整備史と矛盾するため採らない。
