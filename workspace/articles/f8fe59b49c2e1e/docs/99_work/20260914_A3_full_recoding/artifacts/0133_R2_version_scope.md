# 0133 将門塚の祟り — R2 Version Scope

## 1. 採用Scope

> **東京都千代田区大手町の将門塚を粗末に扱う、撤去・破壊する、供養を怠る等の不敬に対し、平将門の御霊・怨霊が事故・病気・災厄等の不幸を与えるとする祟り伝承。対抗規則として鎮魂・供養・尊重・保存を含む。**

## 2. Include

- 平将門という歴史人物と大手町の実在将門塚。
- 首飛来伝説を、塚と将門の死後霊を結ぶ前史として含める。
- 塚の荒廃・不敬・撤去・破壊・供養放棄と災厄を結ぶ祟り因果。
- 鎮魂・供養・祭祀・尊重による制御。
- 関東大震災後の整地・慰霊、保存会・改修を現実史／社会的実践として区別して扱う。

## 3. Exclude / 別扱い

- 大蔵省関係者の連続死、占領期ブルドーザー事故など、今回の高権威Evidenceで直接固定できない具体逸話。
- 「将門塚は物理的に一切工事・改修できない」という強い版。公式には1961年以降複数回整備され、2021年にも第6次改修が竣功している。
- 関東大震災・事故・病気等の現実事象を、祟りの実証として扱うこと。
- 首飛来伝説だけを独立中心にすること。

## 4. 時間・媒体境界

- 神田明神社伝は1307年の鎮魂と1309年の奉祀を伝えるが、今回1307年原資料そのものは直接検証していない。
- D01の粗年代帯では前近代存在をIで置く余地がある。
- 最古流通媒体は、原資料を直接固定できないためR3で保守判定する。
- 近現代の慰霊祭・保存会・改修は、伝承が現実実践へ接続するX Evidenceとして扱う。
