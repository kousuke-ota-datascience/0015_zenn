# 0152 R2 Version Scope

- Entry: `0152` 青木ヶ原樹海で方位磁針が狂う
- Macro_Category: 科学俗説・場所ロア
- Entry_Type: 命題型俗説

## Version Scope

青木ヶ原樹海の溶岩・磁性鉱物が強い磁気を生じさせ、通常の方位磁針が正常に方向を示さなくなるため、入林者が方角・帰還経路を判断できなくなるという俗説を共有核とする。

局所的な磁気影響、樹海の現実の迷いやすさ、GPS・デジタル時計等への派生主張は区別する。現地実測・大学資料による反証は、俗説の内容ではなく真偽検証Evidenceとして保持する。

## 境界

- Include: 青木ヶ原樹海、磁性溶岩、方位磁針異常、方向判断不能・道迷いという因果鎖。
- Exclude: 「必ず死亡・永久失踪」、GPS等の機器も必ず故障するという増補を共有核へ遡及すること、局所磁気影響を全域異常へ一般化すること。
