# 0178 R2 Version Scope

## Scope

2000年8月2日の保存転載で確認できる「猿夢」原型を中心Versionとする。

- 投稿者が夢だと自覚した状態で薄暗い無人駅にいる。
- 危険を警告されつつ奇妙な「お猿さん電車」様の乗り物に乗る。
- 車内アナウンスに合わせ、乗客が順番に残酷な危害を受ける。
- 投稿者は夢だと認識して覚醒し、危害直前に脱出する。
- 年月後に同じ夢が継続し、再び覚醒して逃れるが、次回への警告が残る。

## Scope外

- 「この話を読むと読者も猿夢を見る」という2003年以降の感染型。
- 後代の動画・漫画・ゲーム等で追加された固有設定。
- 夢内の死傷を現実の事件として扱う解釈。

## Coding implication

中心Versionは「ネット上の一人称回想として提示された反復夢怪談」であり、受容者感染を含まない。そのためD18 L2は原則0、L3も独立X Evidenceがない限り0とする。
