## Version Scope

**1969年10月7日付『朝日新聞』京都市内版で公刊確認できる、京都・深泥池に結び付いた「タクシー車内にいたはずの乗客が通常の降車過程なしに消失した」とする一件を中心とする最小核。**

分析上は、実在する深泥池・タクシー・運転手・乗客消失・警察への届出という1969年確認層を中核とする。後代資料で定型化した女性客、雨夜、濡れた座席、特定の死者由来等は、1969年記事本文を本作業で直接閲覧していないため、初期Scopeの必須条件にはしない。

## Scopeへ含める要素

- 京都市／深泥池という具体的地理アンカー
- タクシーという日常交通空間
- 車内に存在したはずの乗客が通常の降車過程なしに消える異常
- 運転手が異常を認識し、現実側で警察への届出・捜索対応が発生したこと
- 出来事が新聞地域面で「怪談めいた」事案として公刊記録されたこと

## Scope外

- 雨の夜であることを必須条件とする
- 客を「若い女性」に固定すること
- 座席の水濡れ・液体を必須条件とすること
- 女性の身元、死因、自殺・病死等の由来説明
- 深泥池周辺の他の心霊伝承・病院伝承を因果的に統合すること
- 全国型「タクシー幽霊」（Entry 0060）を0059の単純な派生または0059を0060の単一起源とみなすこと

## 後代定型の扱い

京都府立図書館のレファレンスが整理した後代資料では、
- 池の脇で若い女性を乗せる型
- 深泥池まで行くよう求める型
- 消失後の座席が水浸しになる型

などが併存する。これらは0059の変異史・定型化を考えるためのH/C補助Evidenceとして保持するが、1969年最小核の必須条件へ遡及しない。
