# 0132 八幡の藪知らず — R2 Version Scope

## 1. 採用Scope

> **千葉県市川市八幡の八幡不知森について、中へ立ち入ってはならず、禁を破って入ると出られなくなる、または祟り・災いを受けるとする禁足地伝承。由来は複数説が競合し、徳川光圀侵入譚は禁忌を物語化する主要派生として含む。**

## 2. Include

- 八幡不知森という具体地点。
- 「中へ入ってはいけない」という禁足規則。
- 入ると出られないという空間異常型。
- 入ると祟り・災いがあるという祟り型。
- 日本武尊・八幡宮旧地・平将門／八門遁甲・行徳入会地等の競合由来説。
- 徳川光圀が禁を破って入り、超自然的存在に戒められる主要派生。

## 3. Exclude / 別扱い

- 由来説のいずれか一つを確定史実として採用すること。
- 徳川光圀の侵入を史実として断定すること。
- 「藪知らず」という一般語・比喩の後代用法を中心Versionへ含めること。
- 現在の物理的立入可否・土地管理規則を、伝承内の超自然的禁忌と同一視すること。
