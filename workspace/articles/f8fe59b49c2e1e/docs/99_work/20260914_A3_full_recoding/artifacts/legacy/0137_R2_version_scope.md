# 0137 R2 Version Scope

- Entry: `0137` 犬鳴村
- Macro_Category: 地域・場所ロア
- Entry_Type: 物語・伝説

## Version Scope

福岡県の犬鳴峠・旧犬鳴トンネル周辺を現実アンカーとし、細道の先に地図・行政・法制度から外れた秘密村が存在し、「日本国憲法が通じない」旨の境界表示、通信・警察等の保護不全、外来者への村人の追跡・攻撃が語られる1999年までに確認できるネット型を共有核とする。

旧犬鳴地域の実在集落、ダム建設、旧トンネル、地域事件は現実アンカーとして含めるが、都市伝説上の秘密村と同一視しない。2020年映画等の固有設定は共有核へ遡及しない。

## 境界

- Include: 地図にない村、制度外空間、境界表示、外来者排除、通信・警察不全、FOAF型生還談、実在犬鳴地域への場所固定。
- Exclude: 映画固有の超自然設定、旧集落そのものを秘密村とする事実認定、個別事件を村人犯罪の証拠とする接続。
