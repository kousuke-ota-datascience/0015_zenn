# 0225 R2 Version Scope

## Scope

昭和50年代頃から存在したと後代取材で確認される「愛媛では家庭等の蛇口からポンジュース／みかんジュースが出る」という地域ジョーク・都市伝説を原型とし、2007年にえひめ飲料がその都市伝説を意図的に実物装置へ変換した時点までをVersion Scopeとする。

## Include
- 愛媛＝みかん／ポンジュースを極端に日常化する蛇口命題。
- お国自慢・地域ジョークとしての流通説明。
- 2007年の企業による都市伝説の再現。

## Exclude
- 2008年以後の個々の空港イベントの運営詳細。
- 現在の各店舗・観光施設の営業状況。
- 蛇口装置の存在を「昔から一般家庭の水道で本当に出た」証拠とする解釈。

## Unit boundary

伝承内部の命題と、その命題が現実の企業行動を誘発した二次的社会効果を同じEntry内で時間順に区別して保持する。
