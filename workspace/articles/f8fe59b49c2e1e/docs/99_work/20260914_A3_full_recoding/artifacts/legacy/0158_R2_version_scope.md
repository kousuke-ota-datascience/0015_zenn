# 0158 R2 Version Scope

- Entry: `0158` 虚舟
- Macro_Category: 古伝承・怪異遭遇
- Entry_Type: 物語・伝説

## Version Scope

1803年の出来事として常陸国の海岸へ通常の和船と異なる舟が漂着し、中に異国風の女性、箱、不明文字等があり、村人が詮議したのち海へ戻したとする江戸期奇談を共有核とする。

20世紀以降に形状や不明文字をUFO・宇宙人へ読み替える解釈は主要な再文脈化として含めるが、江戸期共有核の説明へ遡及しない。

## 境界

- Include: 漂着、異形舟、未知女性、不明文字・箱、意思疎通困難、正体不明のまま去るという核。
- Exclude: UFO・宇宙船であったという史実認定、資料ごとの差異を単一完全版へ混成すること、1803年事件の史実性を無条件に確定すること。
