# 0250 R2 Version Scope

- Entry: `0250 七人ミサキ`
- R1 Evidence正本: `0250_00_contents.md`

## Version Scope

1935〜1943年の採録で直接確認できる**循環型七人ミサキ**を中心Scopeとする。

共有核:

- 成仏できない死者霊が「七人」の集団を構成する。
- 新たな人間を死・取り込みへ導く。
- 新規被害者が集団へ加わることに対応して、古参の一霊が成仏・離脱する。
- この更新により「七人」という集団数が維持され、次の被害者へ連鎖する。

## Scope外

- 1927年の七人の霊・七人塚型を、循環規則が既に確立した版として扱うこと。
- 特定の戦国人物、落武者、遍路、事故死者等の競合由来説を単一の正史として統合すること。
- 海・川・山・道など地域ごとの舞台差を単一地点へ固定すること。
- 後代の漫画・映像・ゲーム等の翻案設定。

## Coding implication

分析対象は個別由来ではなく、**新規被害者を取り込むことで七人集団を更新し続ける連鎖的死者霊伝承**である。成立年代と最古媒体は、循環型自体を直接確認できる1935年以後の採録と、名称を直接確認できる1927年資料を区別して判定する。
