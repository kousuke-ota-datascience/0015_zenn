# 0179 R2 Version Scope

## Scope

中心Versionは、2003年3月29日に保存記録で確認できる「くねくね」型とする。ただし生成史として2001年「分からないほうがいい」型を前段に保持する。

- 夏の田園で遠方の白い人型様の存在が不自然に動く。
- 遠くから眺めるだけでは直ちに異変は起きない。
- 双眼鏡等で詳しく見て、その正体を「理解」した者に重大な精神・人格異変が起きる。
- 知らない者には「分からないほうがいい」「見てはならない」と警告される。
- 2003年型では兄が異常化し、くねくね動くようになる。

## Scope外

- 後代に付加された正体説・古来妖怪説。
- 「くねくね」という文字列や話を読むだけで発症する型。
- 実在の精神疾患・熱中症等を物語因果と同一視する説明。

## Coding implication

D04は2001→2003の明示的増補・再構成を重視する。D11は単なる視認より「詳しく見て正体を理解する」ことを主条件とする。D18 L2/L3は0を基本とする。
