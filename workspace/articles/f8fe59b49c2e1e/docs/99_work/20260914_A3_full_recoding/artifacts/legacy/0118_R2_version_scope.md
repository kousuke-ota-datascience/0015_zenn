# 0118 函館山の切れない木 — R2 Version Scope

## 1. 採用Scope

> **函館山の登山道路周辺にある特定の木について、伐採・撤去を試みると関係者に事故・不幸・災いが起きるため、木が残されているとする地域怪談。**

## 2. Include

- 函館山の道路周辺に残る特定の木。
- 木を切る／撤去する行為が発動条件。
- 作業者・関係者へ事故・不幸が起きるという負の作用。
- そのため伐採を断念し木を残すという伝承内帰結。
- 道路が木を避けているように見える景観を、過去の祟りの痕跡として読む異伝。

## 3. Exclude / 別扱い

- 函館山の他の心霊スポット・戦争遺構・夜景ジンクス。
- 実際の植物保護条例や一般的な伐採規制。
- 工事事故・死亡事故・道路設計変更を史実として断定すること。
- 木を見る／近づくだけで危害が生じる拡張型。
