# 0188 R2 Version Scope

## 採用版
2008年8月26日、2ちゃんねる「死ぬほど洒落にならない怖い話を集めてみない？196」レス908〜916の原型投稿。

## 必須要素
1. 父方祖父母の地域で語り手が異常に背の高い女性姿と奇妙な声を知覚する。
2. 祖父母がそれを地域固有の怪異「八尺様」と同定し、語り手が「魅入られた」と説明する。
3. 八尺様は地域境界の地蔵で封じられ、魅入った若者を殺す存在として語られる。
4. Kという専門知識保持者と祖父母が、札・盛塩・防御室等の手順を指示する。
5. 八尺様は祖父の声を模倣して防御室から誘い出そうとする。
6. 翌朝、血縁男性とKによる護衛・祈祷のもと地域外へ脱出する。
7. 語り手は生存するが、以後その地域へ戻れない。
8. 後日、語り手側へ通じる道の封印地蔵が壊されたと知らされ、再発可能性を残す。

## Scope外
- 後代のイラスト・動画・二次創作による容姿固定。
- 2008年以後に付加された能力・由来・他怪異との関係。
- 匿名化された舞台を特定の実在市町村へ比定すること。
- 地蔵封印・村間協定を現実の史実として扱うこと。

## 分析原則
- 完成した一人称回想譚として扱う。
- 「見る／知覚する」ことと「魅入られる」ことを因果入口として評価する。
- 主人公は死亡せず、長期的には地域帰還禁止という生活制約が確定する。
- 地域共同体内の対処知識と宗教的専門者を伝承内情報として評価するが、外部社会実在Evidenceとは区別する。
