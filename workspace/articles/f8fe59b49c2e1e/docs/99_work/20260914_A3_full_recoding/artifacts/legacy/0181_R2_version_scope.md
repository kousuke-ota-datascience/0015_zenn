# 0181 R2 Version Scope

## Version Scope

### 採用する版
**2005年6月6日の初回遭遇譚から、2005年6月11日までに直接確認できる早期体系化まで**を「初期形成クラスター」として採用する。

これは単一投稿だけではなく、初回遭遇譚→専用スレッド→続編・由来説明→民俗板での早期照合、という数日間の形成過程そのものを分析対象にする。ただし、各設定が初回から存在したか、後で増補されたかを区別する。

### 中核必須要素
1. Sが納屋で見つけた組木状の小箱をA宅へ持参する。
2. 神職家系のMが箱を強い危険物として認識し、「コトリバコ」「シッポウ」と呼ぶ。
3. Mが父の指示を受け、Sと箱へ儀式的処置を行う。
4. 箱は怨念、指先、臍の緒等を内包する危険な呪物として説明される。
5. Mの父・祖父ら神職家系が処理・管理知識を持つとされる。
6. 初回投稿後、専用スレッドと追加調査により、箱の由来・等級・管理・危害対象が急速に体系化される。
7. 早期増補では、女性・子どもへの致死的呪い、複数等級、被抑圧集団の報復武器という説明が形成される。
8. 実在する1868年の隠岐騒動が、箱の製法伝来を説明する歴史アンカーとして怪談内へ組み込まれる。ただしこの因果接続自体は史実認定しない。

### Scope内で区別して保持する層
- **Layer A: 2005-06-06 初回遭遇譚** — 箱発見・持参、Mの識別、緊急処置、神職家系の知識。
- **Layer B: 2005-06-06〜11 早期増補** — 子取り箱解釈、女性・子どもへの危害、等級、複数世代管理、歴史由来。

### Scope外
- 2005年6月11日より後の長期民俗板考察・派生証言。
- 後年のまとめサイトが独自に整理・固定した設定。
- 動画、漫画、創作作品、後代のオカルト解釈。
- 「一封」「二封」「八開」等を古来の正式漢字表記と断定すること。
- 箱の実在、2005年以前の同名民間伝承を前提にすること。
- 被差別集落に関する匿名投稿設定を、現実の地域・住民の属性として扱うこと。

## Coding上の原則

- D04ではLayer A→Bの短期間の設定増補を直接扱う。
- D05/D06は初回の一人称回想を提示形式の核とし、早期共同考察を補助的に扱う。
- D10/D13は「呪物としての箱／呪い」を怪談内因果としてコードするが、現実の効力を認定しない。
- D18 L2は読む・聞くだけで作用する構造ではない。
- D18 L3は同一Scope内の独立X Evidence不足のため0を原則とする。
- D21では実在の隠岐騒動が怪談内の由来因果へ統合されるため、史実と虚構接続を明確に分離した上で評価する。
