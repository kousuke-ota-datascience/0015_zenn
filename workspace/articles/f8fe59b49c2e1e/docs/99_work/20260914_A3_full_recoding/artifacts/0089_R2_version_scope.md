## Version Scope

**1994年までに「日本だるま」として現代伝説集へ採録された、日本人女性の海外旅行をめぐるFOAF型の共有核。旅行中に同行者から短時間離れた女性が失踪し、その場では発見されず、後に別地点で四肢を切断された状態で再発見され、誘拐・監禁・搾取を受けていたと説明される型を対象とする。**

## Scopeへ含める要素

- 日本人女性の海外旅行という日常的出発点
- 同行者との短時間の分離後の失踪
- その場の捜索では所在が回復しないこと
- 時間経過後の再発見
- 四肢切断等の重大な身体被害
- 人間の加害者による誘拐・監禁・搾取という説明
- FOAF的な近接伝聞としての実話らしさ

## Scope外

- 香港、中国、東南アジア、フランス等の特定国を必須化すること
- 試着室・市場等の特定空間を必須化すること
- 見世物、物乞い、売春のいずれか一目的だけへ固定すること
- 特定国・民族に現実の犯罪傾向を帰属すること
- オルレアンの噂等の関連話型を同一Entryへ統合すること

## Scope Status

- Status: `I`

- Entry split: なし。
