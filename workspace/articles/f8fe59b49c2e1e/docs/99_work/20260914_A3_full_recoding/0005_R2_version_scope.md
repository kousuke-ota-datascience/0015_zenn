# 1. 固定したVersion Scope

**1998–1999年の静岡県・栃木県採録群で直接確認できる「危険語の記憶期限→死亡」型の最小安定共有核:**

> 「紫の鏡」という語を知った者が、その語を将来の一定年齢・節目まで忘れずに記憶していると、期限到達時に死亡するとされる。期限は16歳・18歳・20歳等で変動するが、危険な語の記憶保持、将来の期限、死亡という条件付き帰結が共通する。

Coding Scopeでは、特定の期限年齢を固定せず、**危険語を期限まで記憶していること自体が死亡条件になる**という構造をコードする。

# 2. Scopeへ含める要素

- 「紫の鏡」という語・情報を知ること
- その語を忘れず記憶し続けること
- 将来の一定年齢・節目が期限として設定されること
- 期限到達時まで記憶している場合に死亡するとされること
- 期限前に忘れることが、条件不成立による基本的な回避になること

# 3. Scopeへ含めない要素

以下はEvidence上確認できるが、既定Scopeの必須共通核から除外する。

- 期限年齢を必ず20歳と固定すること
- 「不幸になる」のみを帰結とする型
- 「紫地蔵」「赤い沼」等の複合危険語
- 「ピンクの鏡」等の対抗語・中和語
- 血だらけの女が鏡から出て殺すという人格怪異化した型
- 実物の紫色の鏡を見る・所有する・唱える等の物理的儀式
- 後代の由来譚・起源物語

これらは `0005_00_contents.md` のVariation / Historyとして保持するが、R3のD07〜D17等へ混成しない。

# 4. Scope固定根拠

1. 1995年『みんなの学校の怪談 緑本』は「おぼえてはいけない『紫の鏡』」を明記し、少なくとも1995年末までの学校怪談圏での存在を確認できる。ただし本文を直接実見していないため、期限年齢・死亡規則の詳細を同書へ遡及しない。
2. 1998年静岡県採録群では、18歳または20歳まで「紫の鏡」を覚えていると死ぬ型が複数確認できる。
3. 1999年栃木県採録では、16歳または20歳まで覚えていると死ぬ型が確認できる。
4. したがって、期限年齢そのものは可変だが、「危険語の記憶保持→将来期限→死亡」という条件付き因果構造は複数地域・複数採録で安定している。
5. 「不幸」「対抗語」「人格怪異」は同一採録群に存在するが、死亡型の共通核に必須ではないためScope外とする。

# 5. R2判定

- Version Scope: **1998–1999年採録群の「紫の鏡」という危険語を一定年齢まで記憶していると死亡する記憶期限型共通核**
- Scope Status: `D`
- 理由: Scopeの各必須要素は、日文研DBに収録された複数の民俗採録要約で直接確認できる。
- Entry分割: 不要。期限年齢差は同一因果規則のパラメータ差として扱う。一方、不幸型・対抗語型・人格怪異型は近接VariationとしてScope外に保持する。

# 6. R3への拘束条件

R3ではこのScopeだけを伝承構造としてコードする。

- 1995年資料はD01/D02等の来歴・流通Evidenceとして使用できるが、本文未実見のため具体的な死亡条件を1995年へ遡及しない。
- 16/18/20歳のいずれかを標準年齢として固定しない。
- 不幸型、対抗語、鏡から出る女、物理的召喚儀式をD07〜D17の判定根拠へ再導入しない。
- Evidence不足の次元は `U`、構造上非該当なら `NA` とする。
