# 1. 固定したVersion Scope

**1986年東京都の複数採録で直接確認できる色選択型の最小安定共有核:**  
学校のトイレで、姿の見えない／正体不明の問いかけ手から紙または色の選択を求められ、遭遇者が答えた色に応じて、意味的に対応する身体的危害または安全な帰結が生じるという学校伝承。

このScopeでは、以下を構造核に含める。

- 学校のトイレという遭遇空間
- 不可視または正体不明の問いかけ手
- 色・紙についての回答要求
- 遭遇者による回答／選択
- 回答色と意味的に対応する身体的帰結または安全
- 児童・生徒圏で共有される学校伝承

# 2. Scopeへ含めない要素

以下は伝承史上重要だが、R3の既定Scopeへは直接入力しない。

## 2.1. 1972年「赤い紙／白い紙」型

1972年兵庫県尼崎市の採録は、学校低学年に「赤い紙やろか、白い紙やろか」という便所怪談が流通し、児童が数珠つなぎで便所へ行くことを直接示す重要な早期史Evidenceである。

ただし日文研DB要約からは、赤／白を選んだ後の具体的帰結を確認できない。したがって、1986年に直接確認できる「回答色→身体帰結」という規則を1972年へ遡及しない。

## 2.2. 1956年「カイナデ／カイナビ」

同じ「赤い紙やろか、白い紙やろか」という句が便所怪異文脈に現れるが、便所へ入る側が怪異への対処句として発話する構造であり、問い手／答え手の役割と因果機能が逆である。

このため、0003の直接祖型・成立時点として扱わず、関連モチーフ史に留める。

## 2.3. 赤いちゃんちゃんこ／赤マント

1986年「赤いちゃんちゃんこ」、1990年「赤いマント」は、学校トイレ・不可視の声・応答要求・「赤」と身体被害の意味対応を共有する。

一方で、複数色から紙を選ぶ構造ではなく、衣服を着せる提案への応答型である。直系派生を証明するEvidenceも不足するため、0003の近接派生群として保持するが、R3既定Scopeからは除外する。

## 2.4. 個別の局所変種

次はVersionごとの差が大きいため固定しない。

- 必ず「赤／青」の二択であること
- 白・黄・紫のどれが安全か
- 赤なら死亡／引き込み／単なる血まみれのどれになるか
- 青なら窒息／失血／老化のどれになるか
- 特定番号・端・中央などの個室指定
- 怪異の具体的な姿
- 回答拒否時の帰結

# 3. 根拠

1. 1986年常光徹「学校の世間話―中学生の妖怪伝承にみる異界的空間―」由来の複数個別カードで、赤／青／白、赤／青／黄、赤／紫の型が同時に確認できる。
2. これらは選択色や安全回答が異なる一方、学校トイレ、問い、回答、回答対応の帰結という因果構造を共有する。
3. 1972年資料は問いと学校内流通を示すが、色別帰結までは直接確認できないため、1986年構造を遡及しない。
4. 赤いちゃんちゃんこ／赤マントは近接性が高いが、紙・多色選択型とは行為構造が異なり、同一Versionへ統合するとD11〜D17の因果列を混成する。

# 4. R2判定

- Version Scope: **1986年東京都で直接確認できる「学校トイレで色を選ばされ、回答色に応じて身体的危害または安全が生じる」色選択型**
- Scope Status: `D`
- 理由: 同一1986年研究資料由来の複数個別採録で、共通構造を直接比較できる。
- Entry分割: 現時点では不要。赤いちゃんちゃんこ／赤マントは近接派生群としてEvidence正本に保持するが、既定coding scopeへ混ぜない。将来、同型Entryが増え横断的に別系統として扱う必要が出た場合のみtaxonomy／Entry設計課題として再検討する。

# 5. R3への拘束条件

R3では、1986年の色選択型共通構造だけを伝承構造としてコードする。

- 1972年の学校内流通・現実行動は、D01/D02/D03/D04/D18/D19等のHistory/X Evidenceとして必要な場合に参照してよいが、1972年本文へ1986年の帰結規則を遡及しない。
- 赤いちゃんちゃんこ／赤マントの殺害・血・回避規則を、D11〜D17を豊かにする目的で再導入しない。
- 具体的な色ごとの死因より、複数採録で共有される「回答選択が帰結を決める」という因果構造を優先する。
- Evidence不足により一意に判定できない次元は `U`、構造上存在しない次元は `NA` とする。
