# 0180 R2 Version Scope

## Version Scope

### 採用する版
2004年1月の2ちゃんねる「身のまわりで変なことが起こったら実況するスレ26」における、レス98からレス635までの「はすみ」実況を中核版とする。

### 必須要素
1. 日常的な私鉄移動中に、通常の運行・経路では説明しにくい異常が始まる。
2. 通常確認できない「きさらぎ駅」に到着し、投稿者が下車する。
3. 駅・周辺の位置を家族・検索・位置情報・警察等で通常世界の地理へ回収できない。
4. 投稿者は公開掲示板で逐次実況し、参加者が検索・助言・解釈をリアルタイムに返す。
5. 線路沿い移動、異常音、片足の老人、確認不能なトンネル等、空間異常を示唆する出来事が連続する。
6. トンネル後に人物の車へ乗るが、現在地説明・進行方向・運転者の挙動が不自然になる。
7. 投稿者は逃走機会をうかがう旨を記し、その後の帰還・所在・真相が確定しない。

### Scope外
- 後代の追体験投稿、類似の「異界駅」。
- 「異世界」「あの世」を確定原因とする後代設定。
- 確立した帰還手順、禁止事項、駅共通ルール。
- 映画・ゲーム・動画・漫画等の翻案で追加された人物設定・因果説明・結末。
- 遠州鉄道の後代コンテンツ展開を初期伝承内容として扱うこと。

## 分析上の固定
- 「異界」はスレッド参加者による解釈候補であり、因果源として断定しない。
- 「投稿が途絶えた」は確認できるが、「失踪」「死亡」は確認済み帰結として扱わない。
- 主たる意味形成対象は、通常鉄道路線から説明不能な場所・経路へ接続した空間異常と、そのリアルタイム共同解釈である。
- 版変異分析では、後代の異界駅一般化・追体験・翻案を「増補・媒体横断」として参照できるが、D11/D13等の因果モデルには逆輸入しない。
