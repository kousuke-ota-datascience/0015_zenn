# 0275 R2 Version Scope

- Entry: `0275 磐梯山の手長足長`
- R1 Evidence正本: `0275_00_contents.md`

## Version Scope

1992年の直接採録で確認でき、磐梯町公的資料および2025年の自治体文化施設実践まで継承される**磐梯山・会津地方の手長足長型**を中心Scopeとする。

共有核:

- 磐梯山に手長・足長という巨大な怪物／夫婦がいる。
- 雲・雨・風・洪水等を起こし、会津地方の農作物・暮らしへ被害を与える。
- 旅の僧／弘法大師が策略と宗教的力によって手長足長を小さな容器へ封じる。
- 封印・調伏後、磐梯明神として祀られ、人々を守る側へ転換する版がある。
- 実在の磐梯山・猪苗代湖・会津地方・磐梯明神／磐椅神社系の地域宗教景観へ結び付く。
- 現代には自治体文化施設が伝承を展示・催事へ再利用している。

## Scope外

- 物語内年代806年を伝承成立年とみなすこと。
- 『新編会津風土記』の一般的な「魔魅」記述を、そのまま手長足長型の直接採録とみなすこと。
- 鳥海山など他地域の手長足長類話を同一Versionへ統合すること。
- 中国古典・鳥山石燕等の一般的な手長足長図像系を、磐梯山伝承の直接起源と断定すること。
- 2026年以後の漫画・アニメ等の創作設定を共有核へ逆流させること。

## Coding implication

分析対象は、**自然災害・農作物被害を人格怪異で説明し、宗教者による封印と神格化で地域秩序へ再編する山岳伝承**である。D01/D02は具体的な磐梯山手長足長型を直接確認できる1992年採録を基準とし、伝承内の古代年代へ遡及しない。一方D18 L3は、同じ伝承核が2025年の自治体企画展・参加型催事へ転用された独立した社会実践をVersion Scope内Evidenceとして評価する。
