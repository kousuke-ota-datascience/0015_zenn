## Version Scope

五島勉が1973年に刊行した『ノストラダムスの大予言』を主要アンカーとし、ノストラダムスの予言詩を「1999年7月に恐怖の大王が現れ、人類規模の破局・滅亡が起こる」という具体的未来予測へ対応付けた日本の大衆形を対象とする。

恐怖の大王の正体を核戦争・天体・環境危機等へ置換する解釈、続編・テレビ等による増幅、1999年通過後の再解釈・回顧は変容層として含める。16世紀原詩の全解釈史を本Entryへ混成しない。
