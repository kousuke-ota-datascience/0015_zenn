# 1. Version Scope

1986年東京都の複数採録で直接確認できる色選択型の最小安定共有核、すなわち、**学校のトイレで、姿の見えない／正体不明の問いかけ手から紙または色の選択を求められ、遭遇者が答えた色に応じて、意味的に対応する身体的危害または安全な帰結が生じるという学校伝承**をコード対象とする。

1972年赤／白型は早期History/X Evidenceとして使用できるが、1986年の色別帰結を1972年へ遡及しない。1956年カイナデ、赤いちゃんちゃんこ、赤マントは既定Content Scopeへ含めない。

# 3. 因果列予備確認

主因果列は次のように接続する。

```text
D11: D11.MAN.RESPOND_CHOOSE
  + Secondary: D11.CON.LOCATION_STATE
→ D12: D12.FOC.PROTAGONIST_EXPERIENCER
→ D13: D13.PHY.PHYSICAL_ATTACK
→ D15: D15.BOD.SEVERE_INJURY
  + Secondary: D15.BOD.DEATH
```

安全回答を選んだ分岐ではD13の攻撃が不発となる。この分岐性はD14=`MIX` とD17=`CORRECT_ANSWER` で表現し、D15へ架空の「正の身体変化」を追加しない。

# 4. 独立判定時点のtaxonomy gap候補

R3単独では、既存Childへ収まらない安定構造は確認しない。

ただし、D14/D15には「有害分岐と無作用の安全分岐が同一ルール内に併存する」伝承で、`MIX` が**正の利益と負の損失の混合**だけでなく「危害／無害分岐」をどこまで表すかという運用上の論点がある。本Entryでは、安全回答が独立した利益を与えるのではなく危害を回避するため、D14=`MIX`、D15=身体危害、D17=正答・選択という三次元の組合せで表現可能と判断し、単一Entryを理由にtaxonomy変更候補とはしない。
