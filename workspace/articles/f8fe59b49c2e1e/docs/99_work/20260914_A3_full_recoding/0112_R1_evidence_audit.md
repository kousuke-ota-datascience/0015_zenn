## 1. Evidence正本監査

00は、2008年のYahoo!知恵袋投稿を早期確認点として、「事故物件でも一度第三者を住まわせれば、次の入居者への告知義務がなくなる」という人数ベースの抜け道俗説を整理している。制度事実については国土交通省の現行案内と突合した。

## 2. 主要Evidence

### A. Yahoo!知恵袋 2008年投稿 — C / H

- URL: https://detail.chiebukuro.yahoo.co.jp/qa/question_detail/q1414125864
- 00記録上、2008年1月の投稿。
- 用途: 「一人挟めば告知義務が消える」というルール命題の早期Web確認点。

### B. 国土交通省「宅地建物取引業者による人の死の告知に関するガイドライン」 — A / correction

- 公式案内: https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/const/tochi_fudousan_kensetsugyo_const_tk3_000001_00061.html
- 令和3年10月策定。公式ページは2026-09-15時点で公開され、概要を「令和6年3月時点の最新版」として掲示。
- 公式整理は、死因、発生場所、特殊清掃、賃貸借での概ね3年、質問の有無、特段の事情等を基準にしており、「別人を一人住ませた」という人数条件を自動的な告知不要条件として示していない。
- 本Entryでは現行制度の法的助言ではなく、俗説の内容と制度事実の差をEvidenceとして記録する。

## 3. Evidence role整理

- `C`: 一度第三者を入居させる→その次から告知不要、という制度抜け道命題。
- `H`: 少なくとも2008年には公開Web Q&Aで確認でき、その後も掲示板・解説・反証記事等で再流通する。
- `X`: 俗説に基づく「サクラ入居」が実際にどの程度行われ、市場・制度へ影響したかを示す独立X Evidenceは今回固定しない。
- `A`: 宅建業者の告知実務・国交省ガイドラインという実在制度。

## 4. Entry境界

0112は「中間入居者を一人挟むことそれ自体で告知義務が消える」という単純化されたルール主張を扱う。事故物件の全告知ルール、自然死、売買と賃貸の差、3年基準等を一つの俗説へ合成しない。また、現行ガイドラインによる訂正を都市伝説の元ルール自体へ遡及しない。
