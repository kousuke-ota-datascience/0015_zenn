## 2. Version Scope

**1886–1887年に直接確認できる明治器具型の最小安定核: 複数人がテーブルまたは飯櫃の蓋等の可動器具へ手を置き、問いを発し、参加者が意図的に動かしていないと感じる器具の動きを、外部的・霊的な主体からの意味ある回答として読む占い／神意判断の実践。**

## 3. Scope固定理由

現行coding rules §5.1では、成立時のまとまった伝承形を直接確認できる場合、その最古のまとまりを既定Scopeとする。

0011では、以下を固定できる。

- 1886年7月16日『朝日新聞（大阪）』に「神下しと狐狗狸の拘引」の記事が存在。
- 1887年井上円了『妖怪玄談 狐狗狸の事』が同時代資料として存在。
- 東洋大学公式整理は、1884年頃の伊豆下田へのテーブル・ターニング伝来、1886年頃の各地流行、テーブルの代替として飯櫃の蓋と竹脚等を用いたことを示す。

したがって、後代の学校型より先に、明治期の器具型をまとまったVersionとして固定できる。

## 4. Scope内

- 複数参加者。
- 可動器具へ手を置く共同実践。
- 質問を行う。
- 器具が動く。
- その動きを意味ある回答・神意として読む。
- テーブル・飯櫃の蓋等の器具差。
- 「こっくり／狐狗狸」等の名称と外部主体帰属。ただし存在論を単一の死者霊へ固定しない。

## 5. Scope外

以下はR2既定Scopeへ含めない。

- 紙に鳥居・五十音・数字・「はい／いいえ」を書く現代型。
- 十円硬貨等を文字盤上で動かす形式。
- 途中で指を離してはいけない等の学校型禁忌。
- 正しく帰さないと憑依・祟り・死亡する等の危険ルール。
- 使用した紙・硬貨の処分規則。
- 1970年代以降の学校流行そのもの。
- 現代の「死者霊を呼ぶ」説明を明治期へ遡及すること。

これらは伝承史・変容Evidenceとして保持するが、R3のScoped coding入力にはしない。

## 6. 近接Versionとの境界

1970年代以降の学校型は、共同操作と回答取得という機能核を継承する一方、器具・記号面・危険規則・終了規則・参加者層が大きく変化している。したがって、同一Entryの後代Versionとして比較可能だが、明治期Scopeと混成して一つの手順としてコードしない。

## 7. R2 Status

- Scope Status: `D/I`
  - 1886年新聞記事の存在、1887年研究書、東洋大学公式整理により時期・器具・流行は強く確認できる。
  - 1887年原著全文の全手順を本作業で再読していないため、細部は `I` を含む。
- Entry split: `No`
  - 後代学校型は世界ルールの変容が大きいが、現時点では「共同操作物の動きを回答として読む」系譜的核を共有するため別Entryには分割せず、Versionとして分離する。

## 8. R3への引継ぎ

R3ではこの明治期Scopeのみをコードする。1976年学校流行のX EvidenceはD18 L3の横断的社会効果確認に利用可能だが、明治期伝承内部の危険帰結へは混入しない。1886年新聞見出しの「拘引」は同時代社会効果として利用する場合も、本文未実見のため細部を推測しない。
