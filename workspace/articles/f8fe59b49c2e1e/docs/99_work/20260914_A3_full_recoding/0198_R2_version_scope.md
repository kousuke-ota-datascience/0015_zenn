# 0198 R2 Version Scope

## 採用版
2007年4月18日開始の「降霊・交霊」検証実況スレッドから、4月21日に具体手順・複数参加者実況・終了法・追加注意点が形成されるまでの**初期プロトコル形成クラスター**。

## 必須要素
1. 公開掲示板で「一人（り）隠れんぼ」という名称が提示される。
2. ぬいぐるみを加工し、自分との象徴的対応を作る準備が示される。
3. 深夜、自宅内でぬいぐるみと鬼を交代する儀式的手順を行う。
4. 実践者は室内へ隠れ、異常な気配・音・声・テレビ等を観察する。
5. 提案者以外の参加者も「実践している」と実況し、閲覧者が助言・解釈を返す。
6. 不足していた終了法・注意点が実況中および同日中に追加される。
7. 終了には塩水等を用いた明示的な閉鎖手順が必要とされる。

## Scope内の区別
- **名称提示段階**: 4/18。
- **具体手順提示・第1実況段階**: 4/21未明。
- **実況中修正・終了法追加段階**: 4/21早朝。
- **追加規則・説明の補完段階**: 4/21夕方。

## Scope外
- 2007年4月21日以後に定型化された後代マニュアル。
- 動画・テレビ・映画等による後代再現。
- 2006年発祥、大学サークル実験、古来地域伝承等を独立Evidenceなしに前史として採用すること。
- 後代の自作自演告白を初期Scopeの提示内容へ逆輸入すること。これは伝承史・真実性評価の補助に限定する。

## 分析原則
- 完成済み儀式の単純伝達ではなく、掲示板上の実況共同形成として評価する。
- 「読む」だけでは怪異が発動せず、実践手順を行うことが因果入口。
- 受容者が実際に手順を再実践したという投稿は、受容後の現実行動としてD18 L3候補にする。
- 超常現象が実在したかではなく、何が起きたと提示・解釈されたかをコードする。
