## 1. Evidence正本監査

00は、実在地点、前近代史料に記録された禁足伝承、複数の由来説、徳川光圀侵入譚、後代の社会史的説明を分離しており、Evidence / Content layerとして妥当である。特に『江戸名所図会』を前近代の印刷記録として位置付け、刊行年を起源年へ読み替えていない。

外部照合では、市川市公式が現地を国道14号沿いの小竹藪として確認し、「入れば再び出られない／祟りがある」という伝承、複数由来説、光圀譚の錦絵による広域化を明示する。また市川市広報は、江戸時代以降の地誌・紀行文に「入ると出られず祟りにあう」と記録されることを確認している。

## 2. 主要Evidence

### A. 『江戸名所図会』巻之七・八幡不知森 — C / H

- 天保年間刊行。
- 市川市公式・市川市立図書館・レファレンス協同DBを経由して内容・所在を照合。
- 江戸後期には、八幡不知森が既知の場所として印刷物に記録され、立入禁忌・祟りと複数由来説が流通していたことを示す。
- 刊行年そのものを伝承生成年とはしないが、D01の粗年代帯では「前近代に存在」が直接確認できる。

### B. 市川市公式「葛飾八幡宮と文化財 — 八幡の藪知らず」 — C / H / A

- URL: https://www.city.ichikawa.lg.jp/page/7428.html
- 参照確認日: 2026-09-15
- 現在地、鳥居・祠・竹藪、入れば出られない／祟りがあるという伝承、複数由来説、徳川光圀譚を確認。
- 光圀譚が三枚綴り錦絵となり全国へ広まったという後代流通も確認。

### C. 市川市広報「八幡の藪知らず」 — H / A

- URL: https://www.city.ichikawa.lg.jp/site/kohoichikawa/5825.html
- 江戸時代以降の地誌・紀行文に「中に入ると出られず、祟りにあう」と記されることを市公式が整理。
- 現在の小規模竹藪、鳥居・祠・石碑という物的アンカーを確認。

### D. 安政4年（1857）「不知八幡森」碑 — A / H

- 市川市広報は1857年建立と説明し、江戸後期に来訪者が認識する名所として整備されていたことを示す。
- 石碑自体は祟りの実在証拠ではない。

### E. 月岡芳年「不知藪八幡之実怪」1881 — H

- 太田記念美術館資料で1881年の作品を確認。
- 光圀侵入譚が明治期に図像・興行文化へ展開したことを示す。

## 3. Evidence role整理

- `C`: 「入ってはいけない」「入ると出られない／祟りがある」という禁足地伝承、光圀侵入譚、複数由来説。
- `H`: 江戸後期印刷記録→1857石碑→明治錦絵→現代地域文化資料という長期流通。
- `X`: 禁足伝承が現代の法的立入規制・土地管理・観光行動へ与えた独立した社会効果を示すEvidenceは今回固定しない。
- `A`: 市川市八幡の実在竹藪、鳥居・祠・石碑、国道14号沿いの具体地点。

## 4. Entry境界

0132は「八幡不知森という特定地点は立入禁忌で、入れば出られない／祟りがある」という共有核を扱う。日本武尊説、八幡宮旧地説、平将門・八門遁甲説、行徳入会地説は競合する由来説明として保持する。徳川光圀譚は禁忌の物語化として主要派生に含めるが、史実としての侵入を前提としない。
