## 1. Version Scope

**1999年までに公刊確認できる「人形の怪異メリーさんから反復して電話がかかる」という核を基礎とし、同じ意味形成核を維持した後代の安定代表形から「電話で現在地を反復通知しながら受信者へ段階的に接近する」構造までを含める。**

要約すると、今回コードするのは次の型である。

> 人形の怪異「メリーさん」から受信者へ電話が繰り返しかかり、現在地の通知を重ねながら受信者との空間的距離を縮め、安全圏へ侵入する追跡・段階接近型。

## 2. Scopeに含める要素

- 人形／人形怪異としての「メリーさん」
- メリーさん側から受信者へかかる電話
- 反復着信
- 現在地通知
- 着信ごとの段階的な距離短縮
- 家前・室内・背後など、受信者の安全圏へ到達・侵入すること
- 到達自体が終端となり、その後の身体危害が未確定な型

## 3. Scopeから除外する要素

- 到達後に必ず殺害・負傷するという追加帰結
- 「振り向くと死ぬ」等の後付け禁忌
- リカちゃん電話が直接起源であるという未確定の系譜説
- リカちゃん固有の企業サービス・電話番号を成立条件とする型
- 固定電話から携帯電話・スマートフォンへの後代媒体更新それ自体
- 特定の地名・経路・建物を必須化した局地異伝
- 映像作品固有の追加設定・怪異能力

## 4. Scope固定の根拠

### 4.1. 最古層を過剰に復元しない

R1で直接固定できた早い公刊資料は1999年2月の斉藤洋『メリーさんの電話』であり、書誌・出版社紹介から「人形のおばけメリーさん」と反復する電話は確認できる。一方、成立初期の口承一次資料や1980年代成立を直接示す資料は固定できていない。

したがって、「1980年代に現在の完成形が成立していた」とは置かない。

### 4.2. 段階接近を含める理由

現在地通知→反復着信→距離短縮は、後代の代表形を他の「人形から電話が来る」怪談から識別する意味形成上の中心構造である。これは1999年書誌要約だけから同年へ遡及できる要素ではないが、後代代表形において同じ「人形からの反復電話」という核を保ったまま安定し、D11–D16の因果構造を定義するために不可欠である。

現行coding rules 5.1の「後代要素は同一の意味形成核を保ち、分析に不可欠である場合だけ含める」に従い、段階接近までScopeへ含める。ただしその成立年代は別問題としてD01等で保守的に扱う。

### 4.3. 身体危害を除外する理由

R1では、背後・家前等への到達で終わる型と、襲撃・死亡を追加する型が併存する。身体危害は全Versionの必須終端ではないため、Scopeの共通核へ含めない。

## 5. Version Scope Status

- Status: `I`
- 理由: 1999年の人形＋反復電話は直接確認できるが、段階接近までを同時点へ直接遡及できない。後代の安定代表形との構造連続性からScopeを限定的に推定する。

## 6. Entry split

- Entry split: `なし`

リカちゃん電話系譜や身体危害追加型は近接派生・異伝として保持するが、現段階で独立Entryへ分割しない。R5横断確認で意味形成核が別と判明した場合のみ再検討する。

## 7. R3への拘束条件

- D01で1999年を自動的に生成・成立年としない。
- D02で「学校怪談だから学校口承」と推定しない。最古の実流通媒体が確定しなければ`U`を許容する。
- D03は研究資料の掲載媒体と伝承の受容媒体を混同しない。
- D13/D15で、Scope外の殺害・死亡を主作用・帰結へ持ち込まない。
- D16は段階接近という一連の時間・空間進行を評価する。
- D17は有効な回避法が確認できないことと「回避不能」を区別する。
- D18 L3はX Evidenceなしに付与しない。
- リカちゃん電話との起源関係をD21等の現実アンカーへ過剰に反映しない。
