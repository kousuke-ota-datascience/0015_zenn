## Version Scope

**1990年代に日本で流通し1996年までに現代伝説集へ採録された、私的空間への人間侵入者潜伏型。自宅・ホテル等へ居住者／宿泊者より先に見知らぬ人物が侵入し、ベッド下等の死角へ隠れ、本人は危険を知らないまま同室する。第三者や違和感を介して危険が察知され、本人が退避した後に侵入者の存在が確認される型を対象とする。**

## Scopeへ含める要素
- 安全なはずの私室・宿泊室
- 侵入者の先行潜伏と死角
- 潜在的被害者が危険を知らない情報差
- 直接対決を避けて退避する展開
- 後から人間侵入者が確認されること

## Scope外
- 自宅／ホテルのどちらか一方への固定
- 刃物・殺意の明示を必須化
- 友人・恋人・警察等、発見／救助主体を一者へ固定
- 個々の実在住居侵入事件をこのFOAFの原事件とみなすこと
