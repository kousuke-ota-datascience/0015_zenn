# 0113 井の頭公園のボートに乗ると別れる — R2 Version Scope

## 1. 採用Scope

> **井の頭恩賜公園の井の頭池で、恋人同士が二人でボートに乗ると、その後二人は別れるという場所固定型ジンクス。主要な因果説明として「井の頭弁財天が嫉妬して仲を裂く」を含むが、弁財天説明を共有核の必須条件とはしない。**
