# 0157 R2 Version Scope

- Entry: `0157` 新郷村キリストの墓
- Macro_Category: 異説史・地域伝承
- Entry_Type: 命題・伝説複合型

## Version Scope

イエス・キリストはゴルゴタで死亡せず弟イスキリが身代わりとなり、本人は日本へ渡来して現在の青森県新郷村付近で生涯を終え、現地の塚がその墓である、という代替歴史説を共有核とする。竹内文書はその根拠として扱われる。

1935年の竹内文書由来説・現地比定という昭和期の顕在化と、後代の墓・伝承館・祭礼・観光への定着をVersion Scopeに含める。一方、渡来経路、年齢、家族、祭唄・家紋等を傍証とする細部は異伝として分離する。

## 境界

- Include: 磔刑回避、弟身代わり、日本渡来、新郷村での死、現地墓比定、竹内文書、地域での保存・観光化。
- Exclude: キリスト渡来の史実認定、竹内文書原資料未確認の細部、後代の言語・家紋等を古代史の直接証拠へ昇格すること。
