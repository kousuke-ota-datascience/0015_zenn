# 0019 小さいおじさん — R2 Version Scope

## 1. 前提

- Evidence正本: `docs/10_each_lore/0019_chiisai_ojisan/0019_00_contents.md`
- 再コーディング前 commit SHA: `e7ada0703530358d46b387b4feb149fc9e1b8ad9`
- R2では旧 `0019_10_analysis.md` および旧Excelのcoding値を参照しない。

## 2. Version Scope

**2007–2009年に直接確認できる初期共有核: 通常の成人男性・「おじさん」のように見えるが、人体として不可能なほど小さい存在を見たという複数の目撃報告が、「小さいおじさん／小さいオッサン」という共通名称の下に束ねられて流通する目撃カテゴリ。**

## 3. Scope固定理由

現行coding rules §5.1では成立時のまとまった形を直接確認できなければ、複数資料で確認できる最も早い安定共有核へ狭める。

- 2007年4月14日開設のmixiコミュニティに「小さいおじさん！！」という名称と複数目撃者の認識を直接確認できる。
- 2008年公開掲示板は、親指大〜50cm程度の小さい男性、目撃者多数、妖精かお化けか不明という形でカテゴリを扱う。
- 2009年同時代ニュースは「今話題の都市伝説」として多数の芸能人目撃談を同じ名称へ束ねる。

この三点から、個々の目撃談の細部ではなく、**極小成人男性様存在＋複数目撃報告＋共通名称**を最も早い安定共有核とする。

## 4. Scope内

- 成人男性・中年男性・「おじさん」様の外見。
- 通常人体として説明困難な極小サイズ。
- 目撃・視認として報告されること。
- 「小さいおじさん／小さいオッサン」というカテゴリ名。
- 複数の独立した目撃報告が同一カテゴリへ集約されること。
- 正体が確定しないこと。

## 5. Scope外

- 特定の一律身長（10cm、15cm、親指大、50cm等）の固定。
- 特定の服装、帽子、人数。
- 妖精・妖怪・霊・UMA等への正体固定。
- 幻覚・錯覚等の外部科学説明を伝承内部の正体とすること。
- 「見ると幸運になる」等の吉兆化。
- 特定神社・パワースポットへの場所固定。
- 会話・助言・いたずら等の後代具体行動。
- 召喚方法・会い方。
- 直接危害・追跡・呪い。
- 2006年2ch転載内容を確定的初期Versionとして採ること。

## 6. Scopeの性質

本Entryは一つの完成物語ではなく、**異常目撃を共有ラベルで束ねる証言カテゴリ**である。各目撃談の場所・服装・行動が一致しなくても、「人間らしい成人男性」×「極端な小ささ」という視覚的矛盾がカテゴリ境界を形成する。

## 7. R2 Status

- Scope Status: `D/I`
  - 名称付きカテゴリの2007年存在、2008年内容核、2009年複数目撃集約は直接資料で確認できる。
  - 個々の目撃が実際に起きたか、互いに同一存在を指すかは判定しない。
- Entry split: `No`
  - 妖精型・幸運型・神社付着型等は世界ルールを追加する後代VariationとしてScope外に置く。現時点では別Entryへ分割しない。

## 8. R3への引継ぎ

- 「目撃証言が存在すること」と「極小人間が実在すること」を分離する。
- D10では妖精・妖怪等へ自動分類しない。
- D11では偶発目撃を再現可能な発動条件へ読み替えない。
- D13/D15では、危害や幸運を後代Versionから追加しない。
- D18 L3は、コミュニティ形成・報道自体を自動的に社会現実効果とせず、独立したX Evidenceがある場合のみ1とする。
