# 都市伝説調査プロジェクト Handoff

## 1. プロジェクトの目的

日本の「都市伝説」を広く収集し、最終的に各物語を共通の分析軸でコード化して、**都市伝説・怪談・現代伝承がどのような構造を持つかを体系的に比較できるコーパス**を作る。

当初は洒落怖系の怪談を中心に検討していたが、調査を進めるにつれて対象を以下まで拡張した。

- 戦後口承都市伝説
- 学校怪談
- FOAF・世間話
- 身体・食品・医療俗説
- ジンクス
- 地域場所伝説
- 心霊スポット
- 古伝承の現代化
- UMA
- 企業・商品伝説
- 芸能・メディア流言
- スポーツジンクス
- 職業・労働FOAF
- 災害流言
- 都市インフラ・制度陰謀
- 疑似科学・神経神話
- 情報・メタ伝説
- ネット怪談

最終目的は「怖い話リスト」ではなく、

**未知・異常・不可解なものに対して、人間がどのように意味形成（sense-making）するか**

を比較できる体系を作ること。

# 10. Rank体系

## 10.1. rankコード定義概要

各候補について

- R = Recognition, 認知度
- C = Narrative Completeness, 物語完成度
- T = Transmission Persistence, 伝播持続性
- S = Structural Distinctiveness, 構造的独自性
- E = Evidence, 典拠確度

という観点から、各項目に得点を付与。その総合得点に応じて Rank を定義する

- Core
- Major
- Structural
- Archive

なお、Structuralは下位Rankではない。つまり

`Core/Structural`
`Major/Structural`

の併記あるということである



## 10.2. ランク基準

Core / Major / Peripheral / Structural を明確化する

### Core

日本の都市伝説を代表するレベル。

目安：

- 全国的認知度が高い
- 世代を越えて認識される
- 固有名または明確な構造を持つ
- 独立した一話として説明可能
- 複数の採録・研究・メディア展開がある

認知度 R = 5、物語完成度 C = 4〜5 が中心。

### Major

かなり有名だが、世代・地域・ジャンルが限定される。

- 特定世代には非常に有名
- 全国流通したがCoreほど普遍的ではない
- 物語またはルールが比較的安定

R = 3〜4、C = 3〜5。

### Structural

認知度より、構造上の独自性を評価する層。

例えば、

- 「ただ目撃するだけ」
- 制度そのものが都市伝説
- 身体デマ
- 吉兆
- メタ伝説
- 現実改変

など。

分類体系を拡張・検証する際に重要。

R = 1〜3でもよい。Cまたは構造的新規性が高い。

### Peripheral

保存候補。

- 地域限定
- 学校限定
- 既存伝説の変形
- 認知度が低い
- 一文程度で完結し、物語性が弱い

現段階では14軸完全コード化の優先度は低い。

- A−：保存ログなど近一次
- B：研究書・事典・出版採録

# 12. 重要な方法論

## 物語単位を安易に増やさない

同一モチーフの地域異伝は、単なる色・名称・細部違いなら別件化しない。

別件化するのは、

**因果・接触ルール・作用・帰結などの構造が変わる場合**

のみ。

## 古伝承の扱い

古いから除外しない。

採用基準：

**近現代にも流通し、場所・行動・禁忌・吉凶・観光・祭礼・社会的説明として現在の人間の行動や認識に接続しているか。**

例：

- 八幡の藪知らず
- 将門塚
- 一本だたら
- 阿波狸合戦
- 八百比丘尼
- 遠野の迷い家

など。

# 13. 特に重要な発見

## 都市伝説の複雑なルール構造はネット怪談以前から存在する

古伝承にも、

- 接触条件
- 禁忌
- 指定日
- 回避手順
- 契約
- 身代わり
- 循環
- 封印
- 吉凶
- 帰還不能

等が普通に存在する。

したがって、

「洒落怖によってルール怪談が発明された」

とは言えない。

## 都市伝説は怪談ではない

以下も重要な都市伝説圏：

- 鉄道忌避伝説
- ソニータイマー
- カーネルの呪い
- 高橋名人逮捕説
- 血液型性格判断
- 二年目のジンクス
- トイレットペーパー不足流言
- ひよこ鑑定士高給説

都市伝説を、

**異常・不確実性・偶然・不可視制度への意味形成**

として見る方が広く説明できる。
