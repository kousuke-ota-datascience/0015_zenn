## 2.3. 因果・行動モデル

### D14 帰結極性
- Primary Child / Value: `D14.NEG` — 負
- Secondary: なし
- Status: `I`

### D15 帰結領域

### D16 因果時間構造
- Primary Child / Value: `D16.EVT.SEQUENTIAL_EPISODE` — エピソード内段階進行
- Primary Parent: `D16.EVT`
- Secondary: なし
- Status: `D`

長時間無停車→未知駅→周辺探索→線路移動→老人→トンネル→車→投稿終了と、一晩の連続した出来事内で段階的に進行する。

### D17 回避・制御方式
- Primary Child / Value: `D17.UNA.NO_KNOWN_ESCAPE` — 回避法なし
- Primary Parent: `D17.UNA`
- Secondary: なし
- Status: `I`

家族・警察への連絡や参加者の助言は多数あるが、互いに矛盾するものもあり、有効性が確認された帰還法へ収束しない。対応行動が存在することと、確立した制御方式が存在することを区別する。

### D18 作用レイヤー
- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Status: `D`

L1では投稿者と空間・経路に伝承内因果が生じる。読むだけで受容者が怪異の対象になる規則はなくL2=0。遠州鉄道等の後代受容は今回のVersion Scope外なので、L3へ流用せず0とする。
