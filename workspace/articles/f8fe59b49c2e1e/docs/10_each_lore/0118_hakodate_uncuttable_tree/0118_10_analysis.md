## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.PSE.ENVIRONMENTAL_ANOMALY` — 環境異常
- Primary Parent: `D07.PSE`
- Secondary: `D07.PSE.DANGEROUS_PLACE` — 危険・怪異場所
- Status: `I`

**判定根拠**

伝承は、通常は伐採可能な自然物である木が「切れない」対象として残ることを説明対象とし、その木・周辺を危険な対象として扱う。対象木の行政上の正式同定や工事史は未確認であるため、分析概念への写像は `I` とする。

**この伝承における現れ方**

道路周辺の一本の木が、通常の自然物ではなく、手を加えると災いが起きる特別な対象として語られる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.TRC.PHYSICAL_TRACE` — 物的痕跡
- Primary Parent: `D08.TRC`
- Secondary: なし
- Status: `I`

**判定根拠**

怪談では「木が残っている」ことが過去の伐採失敗・災いと結び付けて語られる。道路回避型では道路と木の位置関係も手掛かりとして提示される。ただし、対象木の正式同定・道路工事記録は未固定であるため `I` とする。

**この伝承における現れ方**

現在残るとされる木や道路配置が、過去に「切れなかった」とする語りを支える手掛かりとして用いられる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.NOR.TABOOIZATION` — 禁忌化
- Primary Parent: `D09.NOR`
- Secondary: `D09.CAU.DIRECT_CAUSE` — 直接原因化
- Status: `I`

**判定根拠**

「木を切る→災いが起きる」という因果関係を設定し、対象木への伐採・撤去を危険な操作として扱うため、禁忌化と直接原因化が該当する。分析概念への写像を含むため `I` とする。

**この伝承における現れ方**

通常の工事・伐採行為が、この木に対して行う場合だけ災いへ接続される行為として語られる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: なし（taxonomy gap: 特定の自然物そのもの、またはその自然物に固有に付着する効力を因果源とする構造）
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

00で安定しているのは「函館山の特定の木へ手を加えると災いが起きる」という構造である。現行D10 taxonomyの `SPECIFIC_PLACE` は場所一般、`IMPERSONAL_CURSE` は非人格的呪力を表すが、**特定の自然物そのもの／自然物に固有の効力**を因果源として損失なく表すChildがない。Evidence不足ではなくtaxonomy不足であるため `U` とせず、近似Childへ押し込まずコード空欄のtaxonomy gapとして `I` を保持する。

**この伝承における現れ方**

災いは函館山一般ではなく、特定の木への操作に結び付けられる。人格霊・神格等の安定した主体は今回のScopeで確認できない。

### 2.2.5. taxonomy gap記録

- 対象次元: `D10`
- gap: 特定自然物そのもの、または特定自然物に固有に付着する効力を因果源として表すChildが現行taxonomyにない。
- 近似候補として退けたコード: `D10.SPC.SPECIFIC_PLACE`, `D10.SUP.IMPERSONAL_CURSE`
- 理由: 前者は場所へ一般化しすぎ、後者は自然物という因果源の具体性を失う。
- Evidence directness: 構造自体は確認できるが、因果存在論への分析写像を含むため `Status=I`。
- 横断確認: Global Reconciliationのtaxonomy gap候補へ送る。

### 2.3.8. D18: 作用レイヤー

**作用はどのレイヤーまで確認できるか**

- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `0`
- Status: `I`

**判定根拠**

L1では、伐採・撤去試行と関係者への災いという伝承内因果が成立する。L2について、噂を知るだけで危害が起きるEvidenceはない。L3について、道路設計変更・工事中止が現実に噂の影響で生じたことを示す独立X Evidenceは固定できていない。伝承内で「工事を断念した」と語られることを現実効果へ昇格しない。

**この伝承における現れ方**

怪談内部の因果は確認できるが、情報接触作用や現実の行政・工事判断への影響は確認しない。

### 2.4.3. D21: 現実アンカー
