## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.PSE.ENVIRONMENTAL_ANOMALY` — 環境異常
- Primary Parent: `D07.PSE` — 場所・空間・環境
- Secondary: `D07.PSE.DANGEROUS_PLACE` — 危険・怪異場所
- Status: `I` — Inferred（残存景観の不可解さと危険性を分離）

**判定根拠**

`0118_00_contents.md` が意味形成上明示する問いは、「通常なら工事で除去されそうな木がなぜ道路周辺に残っているのか」という景観上の不可解さである。その説明として「切ると災いが起こる危険な対象」という属性が付与される。

**この伝承における現れ方**

現存する木・道路配置という環境上の違和感が、単なる施工事情ではなく怪異の痕跡として読み直される。危険性はその景観を説明する二次的意味となる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.TRC.PHYSICAL_TRACE` — 物的痕跡
- Primary Parent: `D08.TRC` — 痕跡・記録
- Secondary: `D08.CLM.UNSUPPORTED_ASSERTION` — 根拠未提示の主張
- Status: `I` — Inferred（現景観と事故伝聞を手掛かりにする）

**判定根拠**

木が現在も残り、道路が避けているように見える景観が「なぜ切られなかったのか」という問題化の物的手掛かりになる。そこへ「伐採すると事故が起きた」という未確認主張が結び付く。

**この伝承における現れ方**

受容者は目の前の木を過去の祟りの痕跡として読み、伝聞事故を景観の原因説明として採用する。事故記録が確認されているわけではない点を残す。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.NOR.TABOOIZATION` — 禁忌化
- Primary Parent: `D09.NOR` — 価値・規範化
- Secondary: `D09.CAU.DIRECT_CAUSE` — 直接原因化
- Status: `I` — Inferred（景観説明を禁止規則へ変換）

**判定根拠**

「木を切る→災いが起きる」という直接因果を与え、その結果、通常の伐採・道路工事を「してはいけない行為」へ変換する。単なる吉凶評価より禁止規則形成が中心である。

**この伝承における現れ方**

なぜ木が残るのかという問いは、「過去に切ろうとして災いが起きたため、以後切ってはいけない」という社会的禁忌として閉じられる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SPC.SPECIFIC_PLACE` — 特定場所
- Primary Parent: `D10.SPC` — 場所・時空
- Secondary: `D10.SUP.IMPERSONAL_CURSE` — 非人格的呪力
- Status: `I` — Inferred（場所・木に付着した非人格的効力として判定）

**判定根拠**

因果は函館山の特定の木へ固定され、特定の霊的人物が意図的に攻撃する安定した主体像は確認できない。したがって、具体地点とそこに付着した非人格的な祟り・呪力の組合せとして扱う。

**この伝承における現れ方**

同じ伐採行為でも別の木ではなく、この木を対象にした場合だけ災いが起きるとされる。原因主体の人格・由来は空白のままでも、場所固有の効力は維持される。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

- Primary Parent: `D11.MAN` — 操作・儀式

**この伝承における現れ方**

自然物へ人間が加工を加えようとした瞬間に、通常の工事行為が禁忌破りへ変化する。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Secondary: なし
- Status: `I` — Inferred（伐採関係者が災いの対象）

**判定根拠**

災いを受けるとされるのは、伐採・工事を試みた作業員や関係者である。単なる観測者ではなく、禁忌を破る行為者が被害対象として選ばれる。

**この伝承における現れ方**

木へ手を加えた者だけが事故・不幸へ結び付けられ、通行人一般へ無差別に危害が及ぶ構造ではない。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.FAT.CURSE_MISFORTUNE` — 呪詛・不運付与

**判定根拠**

異伝では事故・怪我・死亡等の具体例が付加され得るが、共有核は「伐採しようとすると災いが起きる」であり、特定の物理機構ではなく非物理的な不運付与として最も安定する。

**この伝承における現れ方**

木を切るという通常作業が、祟りによって事故・不幸へ結び付けられる。結果の種類が変わっても「良くないことが起きる」という効力は保たれる。

### 2.3.4. D14: 帰結極性

- Primary Child / Value: `D14.NEG` — 負

**判定根拠**

伐採側に生じるとされる結果は事故・不幸・工事断念で一貫して負である。

**この伝承における現れ方**

木へ手を加えることで利益を得る型ではなく、操作を継続できなくする負の出来事が因果を閉じる。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.OPP.LUCK_MISFORTUNE` — 幸運・不運

**この伝承における現れ方**

伐採関係者に何が起きたかは再話で変わっても、「切ると良くないことが起きる」という吉凶領域の変化が禁忌を維持する。

### 2.3.6. D16: 因果時間構造

**この伝承における現れ方**

**この伝承における現れ方**

木をそのまま残すという不作為が、安全策であると同時に現在の景観を生む説明にもなる。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**
