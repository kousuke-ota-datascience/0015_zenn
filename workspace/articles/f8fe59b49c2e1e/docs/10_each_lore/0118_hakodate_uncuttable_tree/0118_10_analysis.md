# 1. 伝承エントリ基本情報

- `Entry_ID`: `0118`
- `伝承エントリ名称`: 函館山の切れない木
- `Macro_Category`: 場所・祟り・禁忌
- `Entry_Type`: 地域怪談
- `Version_Scope`: 函館山の特定の木について、伐採を試みると関係者に「怖いこと」が起こり、結果として伐採できず木が残っているとする共有核。事故・怪我・死亡の具体化、道路回避・道路線形変更、明示的な禁止・回避規則は直接Content Evidenceを固定できないため必須要素に含めない。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.PSE.ENVIRONMENTAL_ANOMALY`
- Primary Parent: `D07.PSE`
- Secondary: `D07.PSE.DANGEROUS_PLACE`
- Status: `I`

**判定根拠**

通常は伐採可能な自然物である木が、負の出来事と結び付いて「切れない」対象として残ることが不可解さの中心である。

**この伝承における現れ方**

函館山の一本の木が、手を加えようとすると負の出来事が起きる特別な対象として語られる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.TRC.PHYSICAL_TRACE`
- Primary Parent: `D08.TRC`
- Secondary: なし
- Status: `I`

**判定根拠**

「伐採できず現在もある」とされる木の残存が、過去の伐採試行と負の出来事を結ぶ手掛かりになる。

**この伝承における現れ方**

残っているとされる木そのものが、「切ろうとしたが切れなかった」という語りを支える物的手掛かりになる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAU.DIRECT_CAUSE`
- Primary Parent: `D09.CAU`

**判定根拠**

**この伝承における現れ方**

対象木への操作が、関係者に起きる負の出来事の原因として説明される。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

因果源は特定自然物そのもの、またはその自然物に固有に付着する効力として表現されるが、現行taxonomyに損失なく対応するChildがない。

**この伝承における現れ方**

人格霊・神格ではなく、函館山の特定の木自体または木に固有の効力が負の出来事を起こすものとして置かれる。

**境界・留保**

**taxonomy gap: 特定自然物そのもの、またはその自然物に固有に付着する効力。**

### 2.3.6. D16: 因果時間構造

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `0`
- Status: `I`

**判定根拠**

L1では伐採試行と関係者への負の出来事という伝承内因果が成立する。L2について情報接触だけで危害が起きるEvidenceはなく、L3について現実の工事判断・道路設計が噂の影響で変更されたことを示す独立X Evidenceは固定できない。不在判断を含むためvector全体は `I` とする。

**この伝承における現れ方**

怪談内部の因果は確認できるが、情報接触作用や現実の行政・工事判断への独立した社会効果は確認しない。
