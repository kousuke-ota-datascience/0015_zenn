# 1. 伝承エントリ基本情報

- `Entry_ID`: `0118`
- `伝承エントリ名称`: 函館山の切れない木
- `Macro_Category`: 場所・祟り・禁忌
- `Entry_Type`: 地域怪談
- `Version_Scope`: 函館山の特定の木について、伐採を試みると関係者に「怖いこと」が起こり、結果として伐採できず木が残っているとする共有核。事故・怪我・死亡の具体化、道路回避・道路線形変更、明示的な禁止・回避規則は、直接Content Evidenceを固定できないためScopeの必須要素に含めない。

函館山の特定木への伐採試行が負の出来事へ結び付く、地域的なジンクスとして語られる。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.PSE.ENVIRONMENTAL_ANOMALY` — 環境異常
- Primary Parent: `D07.PSE`
- Secondary: `D07.PSE.DANGEROUS_PLACE` — 危険・怪異場所
- Status: `I`

**判定根拠**

通常は伐採可能な自然物である木が、負の出来事と結び付いて「切れない」対象として残ることが不可解さの中心である。対象木の公式同定・工事史は未確認であるため、概念写像は推論を含む。

**この伝承における現れ方**

函館山の一本の木が、通常の自然物ではなく、手を加えようとすると負の出来事が起きる特別な対象として語られる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.TRC.PHYSICAL_TRACE` — 物的痕跡
- Primary Parent: `D08.TRC`
- Secondary: なし
- Status: `I`

**判定根拠**

「伐採できず現在もある」とされる木の残存が、過去の伐採試行と負の出来事を結ぶ手掛かりになる。道路配置は今回のScope根拠から除外する。

**この伝承における現れ方**

残っているとされる木そのものが、「過去に切ろうとしたが切れなかった」という語りを支える物的手掛かりになる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAU.DIRECT_CAUSE` — 直接原因化
- Primary Parent: `D09.CAU`
- Secondary: なし
- Status: `I`

**判定根拠**

「その木を伐採しようとする」ことと「関係者に怖いことが起こる」ことを直接因果として結ぶ。独立した禁止規範がないため `TABOOIZATION` は採用しない。

**この伝承における現れ方**

対象木への操作が、関係者に起きる負の出来事の原因として説明される。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: なし（taxonomy gap: 特定自然物そのもの、またはその自然物に固有に付着する効力）
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

災いは函館山一般ではなく特定の木への操作に固定される。現行taxonomyでは、特定自然物そのもの／自然物固有の効力を損失なく表すChildがない。`D10.SPC.SPECIFIC_PLACE` は場所へ一般化しすぎ、`D10.SUP.IMPERSONAL_CURSE` は自然物という因果源の具体性を失うため近似押込みしない。

**この伝承における現れ方**

人格霊・神格ではなく、函館山の特定の木自体または木に固有の効力が、負の出来事を起こす因果源として置かれる。

### 2.3.1. D11: 発動・接触条件

対象木を伐採しようとする操作が、怪談上の負の出来事の発動条件として直接確認できる。

**この伝承における現れ方**

見る・近づくだけではなく、対象木へ物理的変更を加えようとすることが因果系への入口となる。

**この伝承における現れ方**

### 2.3.3. D13: 作用機構

**どのように作用するか**

具体的な物理攻撃機構は固定できず、「怖いこと」という非物理的な負の出来事へ接続されるため、不運付与として保守的に写像する。

**この伝承における現れ方**

伐採試行後、関係者へ詳細不明の負の出来事が起こるとされる。

### 2.3.4. D14: 帰結極性

**この伝承における現れ方**

対象木への伐採試行は一貫して不利益・危害と結び付けられる。

### 2.3.5. D15: 帰結領域

**最終的に何が起きるか**

- Primary Child / Value: `D15.OPP.LUCK_MISFORTUNE` — 幸運・不運
- Primary Parent: `D15.OPP`
- Secondary: なし
- Status: `I`

**判定根拠**

Evidenceは具体的被害を固定せず「怖いこと」としているため、死亡・重傷ではなく広い不運・災いに写像する。

**この伝承における現れ方**

伐採関係者に詳細不明の負の出来事が生じ、作業が完遂されないとされる。

### 2.3.6. D16: 因果時間構造

**因果は時間上どのように構成されるか**

- Primary Child / Value: `D16.EVT.SEQUENTIAL_EPISODE` — エピソード内段階進行
- Primary Parent: `D16.EVT`
- Secondary: なし
- Status: `I`

**判定根拠**

伐採試行 → 負の出来事 → 伐採できない → 木が残る、という順序で語られる。一定の期限・潜伏期間は固定されない。

**この伝承における現れ方**

対象木へ手を加えようとする試行と、その後の負の出来事・作業不能・残存が一つの系列を作る。

### 2.3.7. D17: 回避・制御方式

**どう回避・制御できるか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U`

**判定根拠**

00では受容者向けの明示的な解除・回避手順を独立Evidenceとして固定できない。「切らない」をD11の単純反転から安全策として生成しない。

**この伝承における現れ方**

何が発動条件かは確認できるが、伝承自身がどの手続によって負の出来事を回避・解除できると定めるかは不明である。

### 2.3.8. D18: 作用レイヤー

**作用はどのレイヤーまで確認できるか**

- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `0`
- Status: `I`

**判定根拠**

L1では、伐採試行と関係者への負の出来事という伝承内因果が成立する。L2について、噂を知るだけで危害が起きるEvidenceはない。L3について、現実の工事判断・道路設計が噂の影響で変更されたことを示す独立X Evidenceは固定できていない。absence判断を含むvector全体は `I` とする。

**この伝承における現れ方**

怪談内部の因果は確認できるが、情報接触作用や現実の行政・工事判断への独立した社会効果は確認しない。

## 2.4. 社会的分布・現実接続の次元

### 2.4.1. D19: 流通範囲

**どの範囲で流通するか**

- Primary Child / Value: `D19.LOC.LOCAL_TRADITION` — 地域伝承圏
- Primary Parent: `D19.LOC`
- Secondary: なし
- Status: `I`

**判定根拠**

伝承内容は函館山の特定対象へ固定された地域怪談である。Web・映像・書籍によって地域外からアクセス可能であることは確認できるが、全国的大衆への浸透度は測定できないため `NATIONAL_PUBLIC` を付さない。

**この伝承における現れ方**

作用地点・名称は函館山に局所化される一方、後代媒体を通じて地域外の受容者にも紹介される。

### 2.4.2. D20: 特権情報保持者

- Primary Parent: なし
- Secondary: なし

### 2.4.3. D21: 現実アンカー

**どの程度、具体的な現実対象へ固定されるか**

- Primary Child / Value: `D21.A2` — 具体的実在対象
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

函館山は具体的実在地点であり、伝承はその特定木へ固定される。一方、対象木を自治体・管理記録で正式同定できていないため、具体対象への対応は推論を含む。

**この伝承における現れ方**
