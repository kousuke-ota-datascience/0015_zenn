# 1. 伝承エントリ基本情報

- `Entry_ID`: `0118`
- `伝承エントリ名称`: 函館山の切れない木
- `Macro_Category`: 場所・祟り・禁忌
- `Entry_Type`: 地域怪談
- `Version_Scope`: 函館山の特定の木について、伐採を試みると関係者に「怖いこと」が起こり、結果として伐採できず木が残っているとする共有核。事故・怪我・死亡の具体化、道路回避・道路線形変更、明示的な禁止・回避規則は、直接Content Evidenceを固定できないためScopeの必須要素に含めない。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象
**何が不可解・不確実なのか**
- Primary Child / Value: `D07.PSE.ENVIRONMENTAL_ANOMALY`
- Primary Parent: `D07.PSE`
- Secondary: `D07.PSE.DANGEROUS_PLACE`
- Status: `I`
**判定根拠**: 通常は伐採可能な自然物である木が、負の出来事と結び付いて「切れない」対象として残ることが不可解さの中心。
**この伝承における現れ方**: 函館山の特定木が通常の自然物とは異なる危険対象として語られる。

### 2.2.2. D08: 意味形成契機
**何を手掛かりに問題化されるか**

- Primary Parent: `D08.TRC`
- Secondary: なし

**判定根拠**: 「伐採できず現在もある」とされる木の残存が、過去の伐採試行と負の出来事を結ぶ手掛かりになる。道路配置は今回のScope根拠から除外する。
**この伝承における現れ方**: 残っている木が「切れなかった」という語りの物的手掛かりになる。

### 2.2.3. D09: 意味付与操作
**不可解なものをどう理解可能にするか**
- Primary Child / Value: `D09.CAU.DIRECT_CAUSE`
- Primary Parent: `D09.CAU`

**判定根拠**: 「その木を伐採しようとする」ことと「関係者に怖いことが起こる」ことを直接因果として結ぶ。独立した禁止規範がないため `TABOOIZATION` は撤回する。
**この伝承における現れ方**: 木への操作が負の出来事の原因として説明される。

### 2.2.4. D10: 因果源存在論
**原因を何として世界に置くか**
- Primary Child / Value: なし（taxonomy gap: 特定自然物そのもの、またはその自然物に固有に付着する効力）
- Primary Parent: なし

**判定根拠**: 災いは函館山一般ではなく特定の木への操作に固定される。`SPECIFIC_PLACE` は場所へ一般化しすぎ、`IMPERSONAL_CURSE` は自然物という因果源の具体性を失うため近似押込みしない。

- 退けた近似: `D10.SPC.SPECIFIC_PLACE`, `D10.SUP.IMPERSONAL_CURSE`
- Status: `I`
