# 1. 伝承内容

## 1.1. summary

函館山の「切れない木」は、函館山にあるとされる特定の木について、何度か伐採を試みたものの、そのたび関係者に「怖いこと」が起こり、結果として伐採できず現在も残っている、とする地域怪談として2016年のLIFULL HOME'S調査で確認できる。

ここでいう「切れない」は木材が物理的に切断不能であるという意味ではなく、伐採試行と負の出来事が結び付けられ、作業が継続できないという主張である。今回の固定Evidenceでは、負の出来事を死亡・重傷等へ具体化しない。また、「道路が木を避けた」という説明を直接記載する資料を今回固定できないため、主要異伝として本文へ採用しない。

現在確認できる流通点には、2008年由来の転載言及、2016年のWeb調査、2019年の番組情報、2023年の図書館書誌がある。これらは成立年代や媒体間の伝播経路を証明しない。
