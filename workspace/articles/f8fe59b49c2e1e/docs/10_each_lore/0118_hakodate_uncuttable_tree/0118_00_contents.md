# 1. 伝承内容

## 1.1. summary

函館山の「切れない木」は、登山道路周辺にある特定の木について、道路整備・伐採・撤去のため木を切ろうとすると関係者に事故・不幸・災いが起こり、そのため伐採できず木が残された、とする地域怪談として確認できる。

この伝承でいう「切れない」は、木材が物理的に切断不能であるという意味ではなく、伐採を試みると負の出来事が起こるため作業が継続できない、という主張として語られる。資料・再話によって、災いの具体像を事故、怪我、不幸等として表す場合や、道路が木を避けたと説明する場合があるが、今回のEvidenceから具体的な工事事故史を史実として固定することはできない。

現在参照できる確認点として、2008年由来の転載記録、2016年の都市伝説調査、2019年の怪異検証番組情報、2023年の図書館書誌がある。これらは少なくとも2000年代以降に当該名称・怪談が複数媒体で再提示されたことを示すが、最初期の成立経路や事故の一次記録を示すものではない。

中心命題は「特定の木を伐採・撤去しようとすると災いが起こるため、切ることができない」である。今回確認した資料から、「木を切らなければ安全である」という独立した回避規則や、「絶対に触れてはならない」とする受容者向けの明示的禁止文言を、中心条件の単純反転とは別のEvidenceとして固定することはできない。
