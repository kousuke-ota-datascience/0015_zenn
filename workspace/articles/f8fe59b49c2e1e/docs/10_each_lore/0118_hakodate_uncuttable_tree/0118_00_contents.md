# 0. INTRODUCTION

## 0.1. 文書の役割

**伝承名:** 函館山の切れない木

本文書は、函館山の登山道路周辺に残る木について、伐採しようとした者に災い・事故が起こるため切ることができないとする地域怪談の内容・流通・異伝・証拠上の不確実性を記録する Evidence / Content layer である。分析コードは `0118_10_analysis.md` に分離する。

パイロット Evidence Rank は `B` だが、今回の増補でも**伐採計画・事故・工事履歴を裏付ける一次資料は固定できていない**。したがって、現地で「切れない木」と呼ばれる対象が認識されていること、怪異談が少なくとも2000年代以降Web・映像・書籍で流通していることと、祟りの歴史的事実性を分離する。

# 1. 伝承内容

## 1.1. summary

函館山の「切れない木」は、山上へ向かう道路周辺に残る一本の木について、過去に道路整備などのため伐採しようとすると、作業関係者や周囲に事故・不幸が相次いだため、結局伐採できず現在まで残された、という地域怪談である。語り手は現存する木や、その木を避けるように見える道路配置を指し、「通常の工事なら取り除かれるはずの木がなぜ残っているのか」を祟りで説明する。

この伝承で重要なのは、木が物理的に硬くて切断できないという意味ではなく、**切断を試みると負の出来事が起こるため社会的に切れない**という点である。木そのものは自然物だが、人間が加工・撤去しようとした瞬間に因果が発動し、事故・不運によって操作を中止させる主体的な存在のように扱われる。

一方、今回確認できた資料は、2016年の都市伝説調査、2008年時点で既知だったことを示す掲示板転載、2019年の怪異検証番組、2023年書籍書誌などが中心である。これらは伝承が実際に流通していることを示すが、噂の中心に置かれる工事事故の一次記録ではない。したがって「事故が本当に複数回発生したから木が残った」と事実認定してはならない。

意味形成上、この話は、道路上・道路脇に残る不自然に見える自然物を、単なる施工上・景観上の事情ではなく、**場所に宿る禁止規則**として理解するモデルを与える。現在の景観が過去の祟りの痕跡として読み直されるため、木が残り続けること自体が噂を継続的に補強する。

## 1.2. 詳細展開

1. 函館山の道路整備等で木が障害になる。
2. 関係者が伐採・撤去を試みる。
3. 事故・不幸・災いが起きたとされる。
4. 偶然ではなく木の祟り／呪力と解釈される。
5. 工事側が伐採を断念し、木を残す。
6. 現在の景観が「過去に本当に切れなかった」ことの傍証として語られる。

## 1.3. 主体

| 主体 | 役割 |
|---|---|
| 木 | 祟り・禁忌の中心となる自然物 |
| 伐採・工事関係者 | 禁忌を破ろうとして災いを受ける対象 |
| 地元住民・観光者 | 木の由来を伝える流通主体 |
| 後代メディア | 地域怪談として全国へ再流通させる主体 |

## 1.4. 場所・空間

- 函館山: 強い地理アンカー。
- 登山道路周辺: 後代の現地言及で対象木が置かれる空間。
- 道路と木の位置関係: 「なぜここだけ残ったのか」を説明する視覚的証拠として働く。

## 1.5. 物・記号・媒体

- 木: 因果源・禁忌対象。
- 伐採道具・工事行為: 因果発動を試す操作。
- 道路: 木を残した社会的判断の痕跡とされる。

## 1.6. 条件・規則

- 木を切る・撤去しようとすると災いが起きる。
- 最も確実な回避は木に手を加えないこと。
- 見る・近づくだけで危害が起こる型は中心ではない。

## 1.7. 中心命題

> 函館山の特定の木は、伐採しようとすると災いが起こるため切ることができない。

## 1.8. 行動・対応

- 伐採を中止する。
- 木を避けて道路・工事計画を維持すると説明される。
- 後代の訪問者は現地を見て噂と景観を照合する。

## 1.9. 帰結

- 関係者への事故・不幸。
- 木の保存。
- 現存景観の怪異化。

## 1.10. 不確実性

- 木の正式な位置・樹種・管理記録を固定できていない。
- 伐採事故の日時・当事者・事故記録は未確認。
- 道路が本当に木を避けるため設計変更されたか未確認。
- 1980年代成立というPilot年代を直接裏付ける資料は今回得ていない。

# 2. 伝承史・異伝

## 2.1. 最古確認

今回直接追跡できる流通定点は2008年の掲示板由来記録で、それ以前の成立は未確認。Pilotは1980年代を推定しているため、年代と最古確認資料の間に大きな証拠ギャップがある。

## 2.2. 流通

地元口コミ→心霊スポット系掲示板→都市伝説調査→怪異検証番組→実話怪談書籍という複数媒体で再流通している。

## 2.3. 異伝

| 型 | 差分 |
|---|---|
| 伐採者事故型 | 作業員・関係者の事故を中心化 |
| 道路回避型 | 道路線形が木を避けたと説明 |
| 祟り一般型 | 具体事故を曖昧にし「災い」とする |

## 2.4. 変容上の重要点

「過去の事故」という検証困難な出来事と、「現在そこに木が残っている」という観察可能な景観を接続することで、噂が自己補強される。
