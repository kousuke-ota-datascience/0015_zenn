# 0. INTRODUCTION

## 0.1. 文書の役割

**伝承名:** 犬鳴村

本文書は、福岡県の犬鳴峠・旧犬鳴トンネル・犬鳴地域を現実アンカーとして流通してきた都市伝説「犬鳴村」について、確認できる**伝承内容・典拠・伝承史・異伝・証拠上の不確実性**を記録する Evidence / Content layer である。分析コードは同一ディレクトリの `0137_10_analysis.md` に分離する。

本Entryで中心に置くのは、犬鳴峠付近の細い道の先に「地図に載っていない村」があり、入口には「この先、日本国憲法は通じません」といった趣旨の警告があり、外来者は村人から排除・追跡・攻撃され、携帯電話や警察など通常社会の保護も機能しない、とする**制度外・共同体外部の危険空間モデル**である。

実在した犬鳴地域・旧集落、旧犬鳴トンネル、犬鳴ダム、地域で起きた事件・事故と、都市伝説上の「日本国憲法が通じない現存村」を同一視しない。研究論文・公的資料が確認する歴史的事実は、伝承が現実の場所へ接続するアンカーとして扱い、看板・無法村・住民の暴力等の伝承命題とは証拠上分離する。

# 1. 伝承内容

## 1.1. summary

犬鳴村は、福岡県の犬鳴峠・旧犬鳴トンネル付近に、通常の地図・行政・法制度から切り離された村が存在するという都市伝説である。代表的な型では、犬鳴峠から脇道へ入り進んだ先に、地図に載っていない集落がある。村の入口には「この先、日本国憲法は通じません」といった趣旨の立札があり、そこから先では通常の日本社会の規則や保護が機能しないとされる。

村人は外部者に対して極端に排他的で、侵入者を追跡し、斧などの武器を持って威嚇・攻撃するという型がある。携帯電話が圏外になる、近隣の公衆電話から警察へ連絡できない、警察や国家権力が介入できない、といった要素も付加される。このため犬鳴村は、単なる「怖い村」ではなく、**日本国内にありながら、日本社会の法・通信・警察・地図という通常の可視化・保護システムから外れた空間**として意味付けされる。

現在確認できる重要な早期流通定点は1999年の公開Webである。後代保存記録と研究論文から、この時点ですでに「地図にない村」「日本国憲法が通じない旨の立札」「外来者を追う村人」「通信・警察が機能しない」といった現在型の骨格が確認できる。ただし、その投稿自体が知人から聞いた話として提示されるため、1999年を生成年と断定できない。

一方、犬鳴という地名・犬鳴峠・旧犬鳴トンネル・犬鳴地域の集落は現実に存在した。鳥飼の研究は、歴史上の犬鳴地域の集落がダム建設に伴う移転等で消滅したことを整理している。福岡県の公的資料では犬鳴ダムの管理開始は1995年7月である。したがって、旧集落の移転・消滅過程とダムの完成・管理開始時点は分けて扱い、これらの現実史を「日本国憲法が通じない秘密村」の実在証拠にはしない。

意味形成上、犬鳴村の核は、実在する山間地域・旧道・トンネル・消えた集落といった断片を、**「社会の外部に隠された共同体」**というモデルへ編成する点にある。「日本国憲法が通じない」という強い定型句は、その空間が通常社会の内側でありながら制度的には外側である、という境界を一文で表現する。

## 1.2. 詳細展開

1. 福岡県の犬鳴峠・旧犬鳴トンネル周辺が危険・不気味な場所として知られる。
2. 犬鳴峠から細い道・脇道へ進むと、地図に載っていない集落があると語られる。
3. 村の入口に「この先、日本国憲法は通じません」といった趣旨の立札があるとされる。
4. 立札の先では、通信・警察・法制度など通常社会の保護が機能しないとされる。
5. 村人は外来者を異物として認識し、追跡・威嚇・暴行等で排除すると語られる。
6. 生還者・知人の体験談として語られることで、村の存在がFOAF型の現実性を得る。
7. インターネット上で地域外へ拡散し、後に書籍・映像・映画によって全国的に再提示される。
8. 旧集落、旧トンネル、ダム、地域事件等の現実断片が、後代に伝説の現実味を補強する材料として読み込まれる。

## 1.4. 場所・空間

- **犬鳴峠**: 実在地名。都市伝説の地理アンカー。
- **旧犬鳴トンネル周辺**: 実在する旧道・旧隧道の地域。心霊スポット文脈と犬鳴村伝説が接続する。
- **伝説上の犬鳴村**: 地図・行政・法制度から外れた隠れた村。実在の旧集落とは区別する。
- **犬鳴ダム・旧犬鳴地域**: 実在史のアンカー。旧集落の消滅・移転史が「消えた村」のイメージと接続し得るが、因果関係は自動的に断定しない。

## 1.5. 物・記号・媒体

- **「日本国憲法は通じません」型の立札**: 制度内／制度外の境界を可視化する中心記号。実在を裏付ける公的資料は今回固定できていない。
- **地図**: 村が「載っていない」ことにより、国家・行政の可視化から外れていることを示す。
- **携帯電話・公衆電話**: 通常社会への通信回路が切断されることを示す。
- **斧などの武器**: 村人による外来者排除の暴力性を具体化する。
- **1999年公開Web投稿**: 地域的な噂を広域流通させた確認可能な早期媒体。
- **映画・書籍**: 後代の大規模再提示媒体。

## 1.6. 条件・規則・禁忌

- 犬鳴峠周辺から脇道へ入り、村の境界を越えることが危険系への主要な入口となる。
- 立札は「ここから先は通常社会の規則が通用しない」と警告する。
- 外来者は村人から排除対象とされる。
- 最も単純な回避規則は、村を探さない・境界へ入らないことである。
- 携帯電話や警察への連絡で安全を回復できるという保証は、伝承内では否定される。

## 1.7. 異常・不可解な現象／中心命題

中心命題は次のように要約できる。

> 犬鳴峠の奥には、地図にも載らず日本の法制度も通用しない排他的な村が隠れており、外来者が入れば住民から危害を受ける。

不可解さは、超自然存在そのものより、**現代日本の国内に制度・地図・警察の支配が及ばない共同体が隠れて存在する**という社会空間上の例外にある。

## 1.8. 行動・対応

- 村を探さない。
- 脇道・旧道・封鎖地点等へ立ち入らない。
- 噂を確かめるため現地探索・肝試しを行うという逆方向の行動も後代には生じるが、伝承内の安全規則としては非接触が基本である。
- 後代の検証では、実在地域・旧集落・ダム・トンネルの史実と、無法村伝説を分離して確認する。

## 1.9. 帰結・終端状態

- 外来者が村人に追跡・威嚇される。
- 暴行・監禁・殺傷等へ発展する異伝がある。
- 通信・警察等の保護が得られず孤立するとされる。
- 1999年型では知人が追跡されたという体験談が中心であり、永続失踪・死亡をすべての版の共有終端とはしない。
- 後代には「帰れない」「消される」等の強い終端が付加されるが、共有核と区別する。

## 1.10. 未解決点・不確実性

1. 現在型の犬鳴村伝説が1999年以前の何年に成立したかは確定できない。
2. 1999年の元Webページを今回直接固定できておらず、現存するのは研究論文の参照と後代保存記録である。
3. 「日本国憲法は通じません」型の立札の実在を裏付ける公的・同時代一次資料は固定できていない。
4. 実在した犬鳴地域の旧集落と、都市伝説上の排他的な犬鳴村を同一視しない。
5. 1988年の旧犬鳴トンネル付近の事件等の現実事件が、いつ・どの程度犬鳴村伝説へ組み込まれたかは別途時系列検証が必要である。
6. 映画・後代怪談で追加された血筋・犬・異形・心霊等の要素を1999年型へ遡及しない。

# 2. 伝承史・異伝

## 2.1. 最古確認

現在固定できる重要な早期流通層は1999年10月の公開Webである。研究論文は「犬鳴峠, 1999」を参照し、「日本国憲法が通じない集落」「村を見に来た若者への恐喝・傷害」等の噂を検討対象としている。後代保存記録では、1999年10月29日のテレビ関連板投稿と、翌30日の2ちゃんねる「犬鳴峠」スレッドへの転載が確認される。

この時点で現在知られる犬鳴村の主要骨格はかなり揃っている。しかし投稿はすでに知人からの伝聞として提示されるため、1999年は「誕生年」ではなく「現時点で安全に固定できる早期流通定点」とする。

## 2.2. 流通・拡散

少なくとも1999年には公開Web掲示板で地域外へ流通し、その後、心霊・都市伝説サイト、書籍、動画、テレビ・映画等へ展開した。2015年・2018年には学術研究の対象となり、2020年には映画『犬鳴村』として大規模に再提示された。2021年の『実話怪談 犬鳴村』では伝説の広まりと新旧犬鳴地域への聞き取りがまとめられている。

このため、犬鳴村は地域の場所ロアだけでなく、公開Webを媒介に全国的な「怪村」類型へ再構成されたEntryと位置付けられる。

## 2.3. 主要な異伝・派生

| 異伝・派生 | 内容 | 共有核との差 |
|---|---|---|
| 日本国憲法不通用型 | 入口の立札が制度外空間を宣言 | 代表核 |
| 村人追跡・襲撃型 | 外来者を斧等で追い払う | 代表核に近い |
| 通信遮断型 | 携帯電話が圏外、公衆電話も警察へつながらない | 社会との切断を技術面で増補 |
| 警察介入不能型 | 国家権力が村へ入れない | 制度外共同体設定を強化 |
| 消えた旧集落との同一視 | ダム建設等で消えた現実の集落を秘密村と重ねる | 現実史との再文脈化 |
| 心霊・異形型 | 幽霊、犬・獣人的要素、血筋等を付加 | 後代派生。1999年核へ遡及しない |
| 映画版 | 2020年映画の独自人物・因果・血統設定 | 商業翻案。独立した創作設定を含む |

## 2.4. 変容上の重要点

犬鳴村は、実在する地名・峠・旧トンネル・旧集落・ダムといった現実の「場所断片」に、地図からの不可視性、法制度の不在、外部者への暴力、通信遮断といった要素を積み重ねて形成される。

特に1999年以降のインターネットは、地域外の語り手が断片を追加・再話できる環境を提供した。後代には映画・書籍がそのイメージをさらに固定・再構成する。したがって「一つの完成した原話がそのまま保存された」というより、**実在地アンカーを維持しながら、制度外共同体の設定が増補・再メディア化された**点が重要である。
