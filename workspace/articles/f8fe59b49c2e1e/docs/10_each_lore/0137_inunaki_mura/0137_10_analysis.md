# 1. 伝承エントリ基本情報

- `Entry_ID`: `0137`
- `伝承エントリ名称`: 犬鳴村
- `Macro_Category`: 地域・場所ロア
- `Entry_Type`: 物語・伝説
- `Version_Scope`: 犬鳴峠付近の奥に、地図に載らず「日本国憲法が通じない」とされる排他的な村が隠れており、外来者が境界を越えると住民から追跡・危害を受け、通信・警察等の通常社会の保護も機能しないとする型。1999年公開Webで確認できる骨格を中心とし、実在旧集落・後代心霊派生・2020年映画固有設定は区別する。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.PSE.HIDDEN_VANISHED_PLACE` — 隠れた・消えた場所
- Primary Parent: `D07.PSE`
- Secondary: `D07.INO.SYSTEM_CAPACITY_FAILURE` — 制度能力への不安
- Status: `I`

**判定根拠**

伝承は、現代日本の中に地図・行政から見えない共同体が存在し得るという空間的不確実性と、その場所で警察・通信等が機能しないという制度能力への不安を扱う。

**この伝承における現れ方**

犬鳴という実在地の奥に、通常社会から見えない村と制度的保護の不在が置かれる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.IMPORTED_MEDIA_CLAIM` — 外部媒体からの主張
- Primary Parent: `D08.CLM`
- Secondary: `D08.HIS.PLACE_NAME_RUIN` — 地名・遺構・記念物
- Status: `I`

**判定根拠**

現在追跡できる受容上の手掛かりは、1999年公開Webで知人の体験として提示された秘密村主張と、犬鳴という実在地名・旧道・旧トンネル等である。研究者側の「裏付けがない」というEvidence評価そのものをcueにはしない。

**この伝承における現れ方**

受容者はWeb上のFOAF主張と実在する犬鳴の地名・場所情報を組み合わせて「本当にどこかに村があるのではないか」と問題化する。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.SSI.GROUP_BOUNDARY` — 集団境界化

**この伝承における現れ方**

地図にない場所の不可解さが、外界と異なる規則を持つ排他的共同体の存在によって理解可能にされる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

**この伝承における現れ方**

危険は山そのものの祟りではなく、村人共同体が外来者を排除する社会主体モデルとして表現される。

**この伝承における現れ方**

村を探して奥へ進み、境界を越えた外来者が危険系へ入る。

### 2.3.2. D12: 作用対象

**この伝承における現れ方**

通常社会側から境界を越えた人物が「よそ者」として作用対象になる。

### 2.3.3. D13: 作用機構

**この伝承における現れ方**

### 2.3.4. D14: 帰結極性

追跡・威嚇・傷害等は外来者にとって負の帰結である。

**この伝承における現れ方**

境界越えは利益ではなく危険へ接続される。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U`

**判定根拠**

早期型で直接追いやすいのは「追跡され、生還して語る」という展開であり、持続的な恐怖・トラウマは明示されない。恐喝・傷害を含む型もあるが、`SEVERE_INJURY` に相当する重傷をVersion Scope全体の終端として固定できない。死亡・失踪も共有終端ではないため、D15を特定Childへ押し込まない。

**この伝承における現れ方**

外来者への追跡・危害は確認できるが、その結果として最終的にどの領域が変化するかは異伝間で安定しない。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.EVT.SEQUENTIAL_EPISODE` — エピソード内段階進行
- Primary Parent: `D16.EVT`
- Secondary: なし
- Status: `I`

**判定根拠**

1999年型の因果系は、村を探して境界へ入る→住民に認識される→追跡・威嚇／攻撃を受ける→逃走・生還する、という複数段階の訪問エピソードとして編成される。村が恒常的に存在するという背景設定自体をD16へ置かない。

**この伝承における現れ方**

危険は単なる静的な村属性ではなく、侵入後に段階的に展開する訪問・追跡エピソードとして語られる。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.AVO.FLEE_ESCAPE` — 逃走
- Primary Parent: `D17.AVO`
- Secondary: なし
- Status: `I`

**判定根拠**

早期型では追跡された外来者が生還して体験を伝えたとするため、遭遇後の逃走が具体的対応として支持される。一方、「村を探さない／境界へ入らない」を安定した伝承内制御規則として明示するEvidenceは弱く、triggerの単純反転として採用しない。

**この伝承における現れ方**

村人に発見された後は、交渉や解除儀礼ではなくその場から逃げることで危険から離脱する。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `0`
- Status: `I`

**判定根拠**

L1では村へ入った外来者が住民に追跡・危害を受ける。噂を聞くだけで標的になる構造ではないためL2=0。現地探索・肝試しが語られることはあるが、今回のEvidenceでは犬鳴村伝説が特定の社会効果を生じさせた独立X Evidenceとして十分固定できないためL3=0とする。

**この伝承における現れ方**

因果効力は伝承内の訪問者に設定され、現実社会側の効果は別途Evidenceを要する。
