### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（成立年代を安全に固定できる証拠不足）

**判定根拠**

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.PSE.HIDDEN_VANISHED_PLACE` — 隠れた・消えた場所
- Primary Parent: `D07.PSE` — 場所・空間・環境
- Secondary: `D07.INO.SYSTEM_CAPACITY_FAILURE` — 制度能力への不安
- Status: `I` — Inferred（隠れた村の存在と国家保護の不在を説明対象とする）

**判定根拠**

この伝承がなければ説明されないまま残る中心的不確実性は、「現代日本の中に、地図にも制度にも現れない共同体が存在し得るのか」である。さらに、警察・法制度・通信がその場所では機能しないという制度能力への不安が独立した追加対象となる。

**この伝承における現れ方**

犬鳴という実在地の奥に「見えない村」を置くことで、通常社会の可視化から外れた空間を説明する。同時に「そこでは国家も守ってくれない」という不安を具体化する。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.UNSUPPORTED_ASSERTION` — 根拠未提示の主張
- Primary Parent: `D08.CLM` — 命題先行
- Secondary: `D08.HIS.PLACE_NAME_RUIN` — 地名・遺構・記念物
- Status: `I` — Inferred（伝聞主張と実在地名・旧施設が結び付く）

**判定根拠**

「犬鳴峠の奥にそのような村がある」という主張自体には、1999年型で公的記録・写真等の検証可能な証拠が付されていない。一方、犬鳴という実在地名、旧トンネル、ダム、旧集落という場所痕跡が、主張を問題化・現実化する手掛かりとして働く。

**この伝承における現れ方**

根拠未提示の秘密村命題が、具体的な地名・封鎖された旧道・消えた集落等へ接続することで、「どこかに本当にあるのではないか」という探索可能性を生む。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.SSI.GROUP_BOUNDARY` — 集団境界化
- Primary Parent: `D09.SSI` — 社会・制度解釈
- Secondary: `D09.SSI.HIDDEN_STRUCTURE` — 隠れた構造化
- Status: `I` — Inferred（日本社会の内／外を制度的に分割する）

**判定根拠**

「日本国憲法が通じない」という定型句は、村人／外来者、制度内／制度外、日本社会／その外部という境界を作る。さらに、表面上は存在しないことになっている共同体と、それへ介入できない国家という隠れた社会構造を仮定する。

**この伝承における現れ方**

単なる「怖い場所」という評価ではなく、「ここから先はわれわれの社会のルールが無効」という社会的境界を設定することで、山中の不透明さを制度外共同体として理解可能にする。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.HUM.INFORMAL_GROUP` — 非制度的集団・共同体
- Primary Parent: `D10.HUM` — 人間・社会主体
- Secondary: `D10.SPC.SPECIFIC_PLACE` — 特定場所
- Status: `I` — Inferred（危険の中心を排他的村人共同体に置く）

**判定根拠**

代表型で外来者を実際に追跡・攻撃する主体は幽霊や呪力ではなく、犬鳴村の住民という共同体である。犬鳴峠・村という場所はその共同体の制度外性を成立させる不可欠な背景だが、作用主体は人間集団に置かれる。

**この伝承における現れ方**

危険は「山そのものが祟る」のではなく、「外界と異なる規則で生きる村人が外来者を排除する」という社会主体モデルとして表現される。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS` — 大衆社会
- Secondary: `D19.LOC.LOCAL_TRADITION` — 地域伝承圏
- Status: `D` — Direct（公開Web・全国書籍・映画で全国流通を確認）

**判定根拠**

1999年の公開Webで地域外へ到達し、2015年・2018年の研究対象、2020年の全国公開映画、2021年の書籍等を通じて広く認知される。起点には福岡の地域ロアがあるため地域伝承圏をSecondaryに置く。

**この伝承における現れ方**

作用地点は犬鳴という局所地名に固定される一方、受容者は地域住民に限定されず全国へ広がる。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.INS.LOCAL_RESIDENT` — 地元住民
- Primary Parent: `D20.INS` — 地元・内部者
- Secondary: なし
- Status: `I` — Inferred（村の位置・規則を知る内部者が構造上想定される）

**判定根拠**

伝承は、外来者には村の正確な位置・内部規則が分からず、村人・地元側だけがその場所とルールを知るという情報非対称を含む。現代では噂自体は公知だが、秘密村の「真相・場所」は内部者側へ偏っている構造を維持する。

**この伝承における現れ方**

外部者はFOAF情報を頼りに村を探す一方、村の住民は境界と規則を当然のものとして知ると想定される。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A2` — 具体的実在対象
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct（犬鳴峠・旧トンネル・犬鳴ダム等の具体地点へ固定）

**判定根拠**

伝承は福岡県の犬鳴峠・旧犬鳴トンネル・犬鳴地域という具体的実在対象に強く固定される。一方、旧集落の実在史やダム建設史が「日本国憲法が通じない秘密村」という因果主張を成立させる必須史実ではないため、A3/A4へ上げない。

**この伝承における現れ方**

地名を任意の「山奥の村」へ差し替えると犬鳴村固有の伝説性が失われる。実在地点が本当らしさを支えるが、伝説上の村の実在性とは別問題である。
