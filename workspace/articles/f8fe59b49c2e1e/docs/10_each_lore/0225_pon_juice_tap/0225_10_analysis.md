# 1. 伝承エントリ基本情報

- `Entry_ID`: `0225`
- `伝承エントリ名称`: 蛇口からポンジュース
- `Macro_Category`: 地域商品伝説・地域ジョーク
- `Entry_Type`: 地域事実風命題＋現実化
- `Version_Scope`: 後代取材が昭和50年代ごろの対人口承として報告する「愛媛では家庭等の蛇口からポンジュース／みかんジュースが出る」という地域ジョーク・都市伝説を中心とし、2007年にえひめ飲料が当該都市伝説を明示的に参照して実物のポンジュース蛇口を制作した変化までを含む。一般家庭水道で噂どおりの設備が実在したとは扱わない。

# 2. 分析概念次元

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: `D01.G3`
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

ラジオ関西2023の愛媛県庁取材と後代ファクトチェックは、昭和50年代ごろには当該地域ジョークが語られていたと報告する。これは成立時期を直接記録する同時代資料ではないため `I` とする。

**この伝承における現れ方**

少なくとも1970年代後半ごろの地域ジョークとして後代に記憶されているが、最初の発話者・発話年は確定できない。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Parent: `D02.ORL`
- Secondary: なし

**判定根拠**

後代取材は、他県出身者との「お国自慢」の場で愛媛県民が冗談として語ったと説明する。同時代録音・記事は未固定である。

**この伝承における現れ方**

初期流通は、愛媛の地域属性を誇張して語る対面の会話・仲間間ジョークとして再構成される。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Secondary: なし
- Status: `I`

**判定根拠**

Scopeの原型は対人口承として後代取材から確認される。2007年以後の実物装置・公式ページは伝承内容の現実利用を示すが、原型の流通媒体そのものとは分ける。

**この伝承における現れ方**

「愛媛なら蛇口からみかんジュースが出る」という短い地域ジョークが、人との会話の中で伝えられる。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.MED.COMMERCIALIZATION` — 商品・観光化
- Primary Parent: `D04.MED`
- Secondary: なし
- Status: `D`

**判定根拠**

えひめ飲料公式は、都市伝説を再現するため2007年にポンジュース蛇口を制作したと明示し、2009年地域報道は2008年以後の空港イベント利用を記録する。これは噂が商品・イベント装置へ転用された変化を直接示すHistory Evidenceである。

**この伝承における現れ方**

口頭の地域ジョークだった命題が、企業によって実際に体験できる専用蛇口へ変換され、イベント・PRへ利用される。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.PRP.FACT_CLAIM` — 事実主張
- Primary Parent: `D05.PRP`
- Secondary: なし
- Status: `I`

**判定根拠**

中心命題は「愛媛では蛇口からポンジュース／みかんジュースが出る」という地域設備についての短い事実風主張として再構成できる。初期同時代原文は未固定である。

**この伝承における現れ方**

物語を長く展開するのではなく、愛媛の日常設備について驚くべき地域事実があるかのように提示される。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T7` — 虚構・反証既知の再流通
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

後代取材は初期形を「冗談」と説明し、県・企業も「都市伝説」として再提示する。一般家庭水道の制度事実として信じることを要求する資料ではない。初期の各会話でどの程度本気らしく提示されたかは直接確認できないため `I` とする。

**この伝承における現れ方**

受容者は「本当にそんな蛇口があるのか」と驚ける一方、地域自慢の誇張・都市伝説として反復される。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ING.GROUP_STEREOTYPE` — 集団・地域ステレオタイプ
- Primary Parent: `D07.ING`

県公式・後代取材はいずれも、愛媛＝みかん／ポンジュースという強い地域イメージを背景に説明する。

**この伝承における現れ方**

「愛媛はどれほどみかんの県なのか」という地域イメージが、家庭の蛇口までジュースになるという極端な像で表現される。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

**この伝承における現れ方**

受容者は「愛媛では蛇口からジュースが出るらしい」という主張そのものを入口に地域像を理解する。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.SSI.GROUP_BOUNDARY` — 集団境界化
- Primary Parent: `D09.SSI`
- Secondary: `D09.CAT.TYPE_ASSIGNMENT` — 類型付与

**この伝承における現れ方**

普通なら水が出る蛇口からジュースが出るという差異を用いて、愛媛を特産品文化の特別な地域として描く。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.OBJ.ARTIFACT_DEVICE` — 人工物・装置
- Primary Parent: `D10.OBJ`
- Secondary: なし
- Status: `I`

**判定根拠**

伝承内部で異常な出力を生む原因は、超自然主体ではなく、ジュースを供給するとされる蛇口・給水設備という人工物として置かれる。

**この伝承における現れ方**

「愛媛の蛇口は普通の水道とは違い、ジュースを供給する設備である」という装置モデルが主張される。

D12はこの装置が異常属性を付与される対象、D10はその装置系を因果源として世界に置く存在論を表すものとして区別する。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.CON.LOCATION_STATE` — 位置・状態条件
- Primary Parent: `D11.CON`
- Secondary: なし
- Status: `I`

**判定根拠**

噂は「愛媛にある家庭等の蛇口」という場所・設備状態を条件にする。特定儀式や人物接触は必要としない。

**この伝承における現れ方**

愛媛という地域内の蛇口であることが、通常の水ではなくジュースが出るという異常属性と結び付く。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.OTD.DEVICE_INFRA` — 機器・インフラ
- Primary Parent: `D12.OTD`
- Secondary: なし
- Status: `I`

**判定根拠**

異常な属性を与えられる対象は蛇口・水道設備であり、その出力内容が通常の水からジュースへ置き換えられていると主張される。

**この伝承における現れ方**

人間の身体が変わるのではなく、地域の給水設備が「ジュースを出す蛇口」として通常とは異なる機能を持つ。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.PHY.ENV_OBJECT_MANIPULATION` — 環境・物体操作
- Primary Parent: `D13.PHY`
- Secondary: なし
- Status: `I`

**判定根拠**

伝承は蛇口の供給物を通常の水からジュースへ変える設備挙動として表現される。

**この伝承における現れ方**

蛇口を開くと、通常の水ではなくポンジュース／みかんジュースが出るという物的出力の変更が生じる。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.POS` — 正
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

後代取材では「お国自慢」の冗談として説明され、2007年以後も企業PR・体験企画として肯定的に利用される。危害・損失を中心とする伝承ではない。

**この伝承における現れ方**

愛媛の特産品が水のように豊富で身近だという、誇張された好意的地域像として機能する。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U`

**判定根拠**

Scope内の伝承内部で安定して確認できるのは「蛇口からジュースが出る」という作用そのものであり、その後に人物・身体・社会関係・財産・行動等のどの領域が最終的に変化するかは固定されない。企業PR・観光行動は伝承外の社会効果なのでD18 L3へ分離する。

**この伝承における現れ方**

蛇口の異常な出力は主張されるが、それを利用した人に持続的な別の帰結が生じるとは語られない。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.STA.STATIC_ASSOCIATION` — 静的対応・相関
- Primary Parent: `D16.STA`
- Secondary: なし
- Status: `I`

**判定根拠**

「愛媛の蛇口ならジュースが出る」という地域属性と設備属性の対応が中心で、待ち時間・反復段階・期限を主題としない。

**この伝承における現れ方**

愛媛という場所とジュース蛇口が恒常的な対応として提示される。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.NON.BENIGN_NO_CONTROL` — 無害・自然消失
- Primary Parent: `D17.NON`
- Secondary: なし
- Status: `I`

**判定根拠**

初期形はお国自慢の冗談として後代取材で説明され、危害・不利益や解除手順を伴わない。後代の実物蛇口も体験・PRとして利用される。初期同時代原文未固定のため `I` とする。

**この伝承における現れ方**

避けるべき危険を提示するのではなく、「そんな蛇口がある」という無害な地域ジョークとして成立し、危害制御を必要としない。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `1`
- Status: `I`

**判定根拠**

L1では伝承内部で蛇口がジュースを供給する。話を聞くだけで受容者に超自然作用が生じる構造は確認しないためL2=0。L3ではえひめ飲料公式が、都市伝説を再現する目的で2007年に実物装置を制作したと明示し、2008年以後のイベント利用も記録される。L2=0は不在判断なのでvector全体は `I` とする。

**この伝承における現れ方**

噂の内部では特殊な蛇口が存在し、現実側ではその噂自体が企業による装置制作・体験イベントの契機になった。

### 2.4.3. D21: 現実アンカー
