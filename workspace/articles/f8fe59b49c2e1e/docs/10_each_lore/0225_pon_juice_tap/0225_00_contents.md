# 0. INTRODUCTION

**伝承名:** 蛇口からポンジュース

本文書は、愛媛県について語られる「蛇口をひねるとポンジュース／みかんジュースが出る」という都市伝説と、その後に実物のジュース蛇口が制作・観光利用された経緯を記録するEvidence正本である。D01〜D21の分析値は `0225_10_analysis.md` で扱う。

# 1. Evidence

- 「ポンジュースの歴史」 https://www.ehime-inryo.co.jp/pomstory/index.html
- 「沿革」 https://ehime-inryo.co.jp/company/history.html
- 公式沿革は2007年11月を「ポンジュース蛇口デビュー」と記録する。
- 公式「ポンジュースの歴史」は、「愛媛県では蛇口からポンジュースが出る」という都市伝説を再現するためポンジュース蛇口を作ったと明記する。

これは、少なくとも2007年までに当該噂が制作主体に認知され、その噂を意図的に現実の装置へ翻訳したことの直接Evidenceである。

## 1.2. 愛媛県公式

- みきゃんのかんづめ https://www.pref.ehime.jp/site/mican/16868.html
- 愛媛県公式は「蛇口からみかんジュースが出る！」ことが都市伝説になったほど、愛媛＝みかんのイメージが強いと説明する。
- 県公式ページ・県政資料では後年、ポンジュース蛇口を県外PR・観光施策に用いたことも確認できる。

## 1.3. 成立時期に関する後代取材

- ラジオ関西トピックス（2023-10-04） https://jocr.jp/raditopi/2023/10/04/523159/

- 日本ファクトチェックセンター（2025） https://www.factcheckcenter.jp/fact-check/lifestyle/false-matsuyama-juice-removal/ も複数資料を照合し、1975年頃からの都市伝説、2007年の装置完成、2008年以降の空港提供を時系列化している。

これらは同時代資料ではないため、昭和50年代を厳密な初出年としては扱わず、成立年代判断は `I` とする根拠に限定する。

- 松山経済新聞（2009-01-16） https://matsuyama.keizai.biz/headline/70/
- えひめ飲料担当者は、以前から「愛媛に行くと蛇口が3つあり、その1つからポンジュースが出る」という噂があり、問い合わせもあったため、噂を生かして2007年11月にポンジュース蛇口を作ったと説明している。
- 2008年から松山空港で体験イベント化し、多数の利用者が並んだことが記録される。

# 2. 伝承内容

共有核は、**愛媛県では家庭等の蛇口をひねると水ではなくポンジュース／みかんジュースが出る**という、地域特産品を極端に日常化した主張である。

この主張は、愛媛＝みかん／ポンジュースという地域イメージを誇張するジョークとして語られたと説明される。現実の一般家庭の水道インフラにそのような機能があるという制度・設備事実は確認されない。

# 3. 変容史

## 3.1. 噂・ジョーク段階

後代取材では昭和50年代頃、大学等の他県出身者が集まる場でのお国自慢・地域ジョークとして語られたとされる。ここでは「愛媛ならそれほどみかんが身近」という地域ステレオタイプの誇張が核である。

## 3.2. 2007年の物理的実現

えひめ飲料は2007年、都市伝説を再現する目的で実物のポンジュース蛇口を制作した。これは噂が事実だったことの証明ではなく、**噂を意図的に現実装置へ変換した二次的実現**である。

## 3.3. 観光・PR資源化

2008年以後の松山空港イベント、県・企業によるPR、後年の常設・類似サービスによって、「本来はジョークだった噂を現地で体験できる」という観光コンテンツへ変化した。

# 4. Evidence boundary

- 昭和50年代という年代は後代取材に基づくため、正確な最初の発話年を証明しない。
- 「全国の愛媛県民が信じていた」「実際の家庭水道からポンジュースが出た」という主張はEvidenceから支持しない。
- 2007年以後の蛇口装置は都市伝説の真実化ではなく、都市伝説を参照した意図的な再現である。
- 現在存在する個々のジュース蛇口の営業状況はVersion Scopeの中心ではない。
