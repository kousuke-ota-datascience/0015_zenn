# 2. 初期形成内容

## 2.1. 名称とスレッド目的
2007年4月18日に開始されたスレッドは、危険とされる遊び・降霊法を参加者が実際に検証・実況することを目的としている。その候補に一人かくれんぼが含まれる。

## 2.2. 4月21日の具体化
4月21日未明、`◆iwr.CbaKEE` がぬいぐるみ、米、赤い糸、塩水等を用いる一連の方法を提示する。手順は、ぬいぐるみを加工して自分との対応関係を作り、深夜に「鬼」を交代する形式でぬいぐるみを置き、自宅内に隠れ、終了時には塩水等を用いて終結させる、という構造を持つ。

本文書では再現用マニュアルではなく伝承構造を記録するため、細部の操作手順は要約する。

## 2.3. 実況と参加者の複数化
提案者だけでなく、別の参加者が同時に実践し、押入れ等から実況する。テレビ音の停止、物音、声、誰かの気配、室内の異常等が報告される。閲覧者も実況へ反応し、退避・待機・塩水確保・終了方法等を助言する。

ログから確実に言えるのは、**複数のアカウントが「実践している」とするリアルタイム風の投稿を行ったこと**である。実際に各家庭で超常現象が生じたかはログのみから検証できない。

## 2.4. 手順の欠落と修正
初期の説明では、参加者が必要物を隠れ場所へ持ち込む点などが十分共有されず、実況中に問題化する。提案者は自分の記載漏れを認め、終了法を追加提示する。

同日夕方には、別投稿者が「一人鬼ごっこ」が本来名だとし、注意点、テレビの意味、家族同居時の危険、霊感との関係等を追加する。これらの主張が本当に既存伝承由来か、同時進行で創作・補完されたかは確定できない。

# 3. 因果・規則・対処

## 3.1. 因果入口
- 儀式用のぬいぐるみを準備・加工する。
- 深夜に一連の手順を実行する。
- ぬいぐるみを「鬼」として、自宅内へ隠れる。

読むだけ、名称を知るだけでは発動条件にならない。

## 3.2. 想定される作用
初期ログでは、儀式後に「もう一人の誰か」を感じる、テレビや音が変化する、声や気配がする、人影・霊的存在らしきものが現れる、といった経験が報告される。

提案者自身も、ぬいぐるみそのものが動くという単純な説明ではなく、黒い人物を見たという経験を語る。したがって初期形では、ぬいぐるみを媒介に何らかの霊的存在を呼び込む／自宅内で遭遇するという解釈が形成される。

## 3.3. 終了・回避
- 儀式は放置せず終了手順を行う必要があるとされる。
- 塩水を使用し、ぬいぐるみを発見し、勝敗を宣言して終結させる構造が提示される。
- ぬいぐるみは最終的に処分するよう指示される。
- 隠れている間に勝手に外へ出ること等は危険とされる。

初期ログでは、終了法・注意点が実況中に補完されており、固定済みの古来儀礼として存在したことは証明できない。

# 4. 伝承史・不確実性

## 4.1. 最古確認
現時点で日付と内容を追える明確な定点は2007年4月である。

- 4月18日: 公開スレッド開始時点で名称を確認。
- 4月21日: 具体的手順、実況、他参加者の実践、終了法追加を確認。
- 同日夕方: 追加ルール・由来らしき説明が補われる。

2006年説は二次資料に見られるが、今回のEvidenceでは同じ名称・構造を2006年に直接確認できる資料を得ていない。

## 4.2. 「古くからの降霊術」説
初期投稿者や後続投稿には「人から聞いた」「近畿・四国で知る人がいる」といった主張がある。しかし、それらは同一スレッド内の自己申告であり、2007年以前の独立記録とは区別する。

## 4.3. 自作自演・釣り説
後年、初期実況に自作自演が含まれていたとする告白・検証が存在する。これは超常現象の真実性を弱めるが、2007年の掲示板上で名称・手順・実況形式が形成・流通したという歴史的事実自体を否定しない。
