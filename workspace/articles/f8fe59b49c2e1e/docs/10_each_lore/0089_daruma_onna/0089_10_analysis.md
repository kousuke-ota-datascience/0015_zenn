# 1. 伝承エントリ基本情報

- `Entry_ID`: `0089`
- `伝承エントリ名称`: 日本だるま／だるま女
- `Macro_Category`: 犯罪・社会不安
- `Entry_Type`: 物語・伝説
- `Version_Scope`: Duke Universityの2025年研究資料が1980年代の日本で語られた「Daruma Woman」として整理する型。日本人女子大生が海外パッケージツアー中に誘拐・人身取引され、数年後に友人によって四肢切断状態で再発見される型を対象とする。旅行先の特定国、試着室、FOAF形式、明示的な回避規則は、今回の直接確認Evidenceでは必須化しない。

### 2.1.2. D02: 最古確認流通媒体

- Primary Parent: `D02.PRT` — 印刷・書簡

**判定根拠**

**この伝承における現れ方**

1980年代に流通した物語が、1994年には現代伝説集の項目として保存されている。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ICT.ABDUCTION_ASSAULT` — 誘拐・暴行
- Primary Parent: `D07.ICT` — 犯罪・対人脅威
- Secondary: `D07.ICT.HIDDEN_CRIMINAL_PRACTICE` — 隠れた犯罪慣行
- Status: `I`

**判定根拠**

旅行中の女性が誘拐・人身取引され、長期間所在不明となり、後に四肢切断状態で発見されることが中心問題である。

**この伝承における現れ方**

通常の海外旅行が、表面から見えない誘拐・搾取・身体暴力へ接続する出来事として語られる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.STY.WITNESS_REPORT` — 目撃・発見報告
- Primary Parent: `D08.STY` — 証言・語り
- Secondary: なし
- Status: `I`

**判定根拠**

物語の終端では友人が数年後に被害者を発見し、失踪後に何が起きたかが可視化される。原話の伝達形式自体は未確認なので、ここでは物語内部の発見を契機として扱う。

**この伝承における現れ方**

長く説明されなかった失踪が、友人による再発見によって重大犯罪の結果として理解される。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.AGN.AGENCY_ATTRIBUTION` — 主体化
- Primary Parent: `D09.AGN` — 主体帰属
- Secondary: `D09.CAU.DIRECT_CAUSE` — 直接原因化
- Status: `I`

**判定根拠**

失踪と身体被害を、誘拐・人身取引を行う人間主体の意図的行為へ帰属することで因果を閉じる。

**この伝承における現れ方**

行方不明の空白が、悪意ある人間による誘拐・暴力・搾取の結果として説明される。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.HUM.INFORMAL_GROUP` — 非制度的集団・共同体
- Primary Parent: `D10.HUM` — 人間主体
- Secondary: なし
- Status: `I`

**判定根拠**

研究資料では誘拐・人身取引という人間による犯罪行為として説明される。具体的な組織形態は固定できないためStatusはIとする。

**この伝承における現れ方**

超自然主体ではなく、人間の加害者が失踪と身体被害の原因として置かれる。

**この伝承における現れ方**

海外旅行中の誘拐から、長期失踪、人身取引、身体被害、再発見へ段階的に進む。

**判定根拠**

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**
