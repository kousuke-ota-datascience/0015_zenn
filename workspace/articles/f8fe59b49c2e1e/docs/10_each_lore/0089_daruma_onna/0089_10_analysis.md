# 1. 伝承エントリ基本情報

- `Entry_ID`: `89`
- `伝承エントリ名称`: 日本だるま／だるま女
- `Macro_Category`: 犯罪・社会不安
- `Entry_Type`: FOAF
- `Version_Scope`: 海外旅行中の若い女性が失踪し、後に四肢を失った状態で搾取されていると発見されるFOAF型の共有核。国名・失踪場所・搾取目的の異伝を混成しない

# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: `D01.G4` — 1980年代
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

1990年代の現代伝説集に採録され、1980〜90年代に広く流通した型として扱われるため、パイロットでは1980年代成立帯を採用した。最初期口承そのものは未確認である。

**この伝承における現れ方**

海外旅行が若者にとって現実的な行動となった時代に、異文化圏の犯罪不安を取り込む現代的警告譚として現れる。伝統的な異界旅行ではなく、観光・買い物という近代的旅行行動が危険の入口になる。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown

**判定根拠**

書籍採録以前の最古口承・雑誌・新聞等を直接確認できていないため、最古媒体を推定で埋めない。

**この伝承における現れ方**

FOAFとして口頭再話に適した内容ではあるが、「口承らしい」ことと「最古媒体が口承である」ことは別である。証拠上は流通起点を確定できない。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Child / Value: `D03.ORL.PEER_ORAL` — 友人・仲間内伝承
- Primary Parent: `D03.ORL`
- Secondary: なし
- Status: `I`

**判定根拠**

「友人の友人」「知人の旅行者」に起きた話として再話されるFOAF構造を持つため、仲間内口承をPrimaryとするパイロット判定を保持する。

**この伝承における現れ方**

話は遠い外国のニュースではなく、自分の人間関係から数段だけ離れた人物の体験として届く。その流通形式が、確認困難さと現実感を同時に生む。旧レビュー用メモには `D03:U` が残るため、本文値との不整合はtask 3で再確認する。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.STB.STABILIZED_CANON` — 定型化・カノン化
- Primary Parent: `D04.STB`
- Secondary: なし
- Status: `I`

**判定根拠**

旅行先や搾取目的は変わるが、「海外旅行→同行者から離れる→失踪→後に四肢を失った状態で発見」という骨格が安定して反復するため、定型化を保持する。

**この伝承における現れ方**

香港、東南アジアなど地名が差し替わっても、危険な海外・短時間の失踪・不可逆的身体被害という構造は残る。変異可能な外枠と固定された恐怖核を持つ。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.HRS.FOAF` — FOAF
- Primary Parent: `D05.HRS`
- Secondary: なし
- Status: `D`

**判定根拠**

主典拠が示す代表形は「友人の友人」等の近接伝聞として語られるため、FOAFを直接採用する。

**この伝承における現れ方**

語り手本人ではなく、知人関係を一段二段たどった人物が被害者になる。その距離によって、話は「実在の誰かの話らしい」が聞き手自身には検証できない状態を保つ。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T2` — 近接伝聞事実
- Primary Parent: なし
- Secondary: なし
- Status: `D`

**判定根拠**

架空話としてではなく、近い人間関係の先で実際に起きた事件のように提示されるため、この値を保持する。

**この伝承における現れ方**

「ニュースで見た」よりも「知人の知人が被害に遭った」と語ることで、受容者は自分の生活圏にもつながる現実的危険として受け取る。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ICT.STRANGER_THREAT` — 見知らぬ他者の脅威
- Primary Parent: `D07.ICT`
- Secondary: なし
- Status: `I`

**判定根拠**

海外旅行先で意図の読めない他者や犯罪者に接触する危険を中心に意味形成するため、このコードを保持する。

**この伝承における現れ方**

知らない土地で同行者から離れた瞬間、周囲の誰が安全か判断できないという不安が、誘拐・切断を行う人間主体へ具体化される。抽象的な異文化不安が対人脅威へ変換される。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.STY.FOAF_REPORT` — 近接伝聞
- Primary Parent: `D08.STY`
- Secondary: なし
- Status: `D`

**判定根拠**

危険の根拠は統計や公式警告ではなく、知人関係を通じた体験報告として提示されるため、このコードを保持する。

**この伝承における現れ方**

具体的な証拠より「実際に知り合いの周辺で起きた」という証言形式が、海外旅行の危険を問題化する手掛かりになる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAT.NAMING` — 命名
- Primary Parent: `D09.CAT`
- Secondary: なし
- Status: `I`

**判定根拠**

失踪者の極端な身体状態を「だるま」という名称でカテゴリー化し、犯罪の恐怖を短いイメージへ圧縮するため、このコードを保持する。

**この伝承における現れ方**

複雑な誘拐・監禁・搾取の過程が、「だるま女」という強烈な名称にまとめられる。名前自体が身体切断の結果を即座に想像させ、話の記憶性を高める。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.HUM.INDIVIDUAL_HUMAN` — 個人
- Primary Parent: `D10.HUM`
- Secondary: なし
- Status: `I`

**判定根拠**

怪異や運命ではなく、人間の犯罪者・加害者が原因として置かれるため、このコードを保持する。

**この伝承における現れ方**

被害は超自然現象ではなく、誘拐・監禁・身体切断を意図的に行う人間の悪意によって説明される。恐怖は「人間がここまでできる」という社会的脅威にある。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.SOC.MEET_INTERACT` — 会う・会話する
- Primary Parent: `D11.SOC`
- Secondary: なし
- Status: `I`

**判定根拠**

旅行先で見知らぬ他者・店舗・周辺人物と接触する社会的相互作用が犯罪への入口として想定されるため、このコードを保持する。

**この伝承における現れ方**

同行者から離れた女性が、店舗や市場等で見知らぬ人々の管理下へ入ることで安全圏から切り離される。特定の儀式ではなく社会的接触が因果系の入口になる。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC`
- Secondary: なし
- Status: `I`

**判定根拠**

失踪し身体被害を受ける女性旅行者が焦点人物であるため、このコードを保持する。

**この伝承における現れ方**

海外旅行者という受容者が自己投影しやすい人物が、日常的な観光から突然被害者へ転落する。その脆弱性が警告機能を強める。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.PHY.PHYSICAL_ATTACK` — 物理攻撃
- Primary Parent: `D13.PHY`
- Secondary: なし
- Status: `I`

**判定根拠**

加害者が被害者を拉致・監禁し、四肢切断等の直接的身体暴力を加える構造であるため、物理攻撃を保持する。

**この伝承における現れ方**

危険は脅迫や詐欺だけに留まらず、身体を不可逆的に改変する暴力へ進む。失踪後の空白期間が、見えない場所での物理的加害として説明される。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

失踪・監禁・重傷・場合によっては死亡という全面的に負の帰結であるため、この値を保持する。

**この伝承における現れ方**

旅行という本来楽しい行為が、短い分離を境に最悪の犯罪被害へ反転する。回復や利益は物語の中心にない。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.BOD.SEVERE_INJURY` — 重傷・障害
- Primary Parent: `D15.BOD`
- Secondary: `D15.BOD.DEATH` — 死亡（Parent: `D15.BOD`）
- Status: `I`

**判定根拠**

代表形では四肢切断という重大障害が中心で、異伝によっては死亡まで含むため、重傷をPrimary、死亡をSecondaryとして保持する。

**この伝承における現れ方**

被害の終点は単なる金銭損失や一時的監禁ではなく、身体の不可逆的破壊に置かれる。「だるま」という名称がその帰結を象徴する。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.PRG.STAGED_PROGRESSION` — 段階進行
- Primary Parent: `D16.PRG`
- Secondary: なし
- Status: `I`

**判定根拠**

旅行→分離→失踪→捜索失敗→時間経過→身体被害状態で再発見という複数段階を経るため、段階進行を保持する。

**この伝承における現れ方**

恐怖は一瞬の攻撃だけで成立せず、行方不明の時間が長引くほど「見えない間に何をされたのか」という不安が増幅する。最終発見で空白期間が極端な暴力として埋められる。旧レビュー用メモには `D16:U` が残るため、本文値との不整合はtask 3で再確認する。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.AVO.DO_NOT_ENGAGE` — 接触回避
- Primary Parent: `D17.AVO`
- Secondary: なし
- Status: `I`

**判定根拠**

話は、見知らぬ相手・場所との不用意な接触や単独行動を避ける警告として機能するため、このコードを保持する。

**この伝承における現れ方**

受容者に残る実践的教訓は、海外で一人にならない、不審な場所・人物へ近づかない、という回避行動である。犯罪の仕組みを制御するのではなく入口を避ける。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

犯罪因果は物語内の旅行者に作用するものとしてコードされ、聞いただけで同じ被害が生じる構造ではないためL1のみを保持する。

**この伝承における現れ方**

話を聞いた人の旅行行動を抑制し得るが、伝承の因果そのものは被害者の失踪・身体被害の内部で完結する。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS`
- Secondary: なし
- Status: `D`

**判定根拠**

日本の現代伝説集に代表形として採録され、特定地域だけに閉じない広域FOAFとして流通するため、このコードを保持する。

**この伝承における現れ方**

旅行先の国名は変わるが、「海外旅行者なら誰でも注意すべき話」として全国の受容者へ移植できる。ローカルな実事件ではなく広域的警告譚として機能する。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.ORG.PERPETRATOR_CRIMINAL` — 加害者・犯罪者
- Primary Parent: `D20.ORG`
- Secondary: なし
- Status: `I`

**判定根拠**

失踪後に何が起きたかを実際に知る立場として、物語内では加害者・犯罪者が置かれるため、このコードを保持する。

**この伝承における現れ方**

同行者や家族は被害者が消えた理由を知らず、空白期間の真相は加害側だけが把握している。後の再発見によって一部が推測されるが、犯行の全容は受容者に開示されない。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

海外旅行、店舗、市場、誘拐犯罪等の現実的背景を持つ一方、特定の一つの検証済み事件へ固定されないためA1を保持する。

**この伝承における現れ方**

実在し得る旅行行動と犯罪類型を使うことで現実感を得るが、場所や被害者は再話ごとに動く。具体的事件の記録ではなく、一般的現実背景上に構築されたFOAFである。
