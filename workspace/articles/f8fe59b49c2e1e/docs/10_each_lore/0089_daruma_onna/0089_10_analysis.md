# 1. 伝承エントリ基本情報

- `Entry_ID`: `0089`
- `伝承エントリ名称`: 日本だるま／だるま女
- `Macro_Category`: 犯罪・社会不安
- `Entry_Type`: 物語・伝説
- `Version_Scope`: Duke Universityの2025年研究資料が1980年代の日本で語られた「Daruma Woman」として整理する型。日本人女子大生が海外パッケージツアー中に誘拐・人身取引され、数年後に友人によって四肢切断状態で再発見される型を対象とする。旅行先の特定国、試着室、FOAF形式、明示的な回避規則は、今回の直接確認Evidenceでは必須化しない。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ICT.ABDUCTION_ASSAULT` — 誘拐・暴行
- Primary Parent: `D07.ICT` — 犯罪・対人脅威
- Secondary: `D07.ICT.HIDDEN_CRIMINAL_PRACTICE` — 隠れた犯罪慣行

**判定根拠**

**この伝承における現れ方**

通常の海外旅行が、誘拐・搾取・身体暴力へ接続する出来事として語られる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.DEX.DIRECT_EVENT` — 出来事への直接遭遇
- Primary Parent: `D08.DEX`
- Secondary: なし
- Status: `I`

**判定根拠**

物語の終端では友人自身が数年後に被害者を四肢切断状態で直接再発見し、その遭遇によって失踪後の重大被害が可視化される。再発見者による証言・報告行為はScope Contentとして固定されていないため、`WITNESS_REPORT` は採用しない。

**この伝承における現れ方**

長く説明されなかった失踪が、友人による被害者との直接再遭遇によって重大犯罪の結果として理解される。

### 2.2.3. D09: 意味付与操作

**この伝承における現れ方**

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: なし — **taxonomy gap: 個人／集団／組織未特定の人間加害主体**
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

00では、女子大生が人間の加害主体によって誘拐・人身取引されることまでは明確である。一方、その加害主体を現行D10 Childの `INDIVIDUAL_HUMAN`、`INFORMAL_GROUP`、`ORGANIZATION` のいずれかへ限定できるEvidenceはない。これは因果源が不明なのではなく、「人間加害主体までは明確だが個人／集団／組織未特定」という構造を現行Childで表現できないtaxonomy gapである。近似Childへ押し込まない。

**この伝承における現れ方**

超自然原因ではなく人間犯罪として説明されるが、加害主体の組織形態は未特定であり、現行taxonomyではその粒度を直接コードできない。
