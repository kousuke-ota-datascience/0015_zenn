**この伝承における現れ方**

香港、東南アジア等、その時代・受容者にとって「危険そうな海外」へ地名が置換される一方、短時間の分離が極端な犯罪被害へつながる恐怖核は維持される。

受容者は「遠い国で何か起きたらしい」ではなく、「自分の知人関係の延長で起きた現実の犯罪らしい」と受け取るよう促される。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ICT.ABDUCTION_ASSAULT` — 誘拐・暴行
- Primary Parent: `D07.ICT` — 対人・犯罪脅威
- Secondary: `D07.ICT.OUTGROUP_THREAT` — 外集団脅威
- Status: `D` — Direct（失踪・身体暴力と異文化圏が共有核）

**判定根拠**

物語の中心的不確実性は、海外旅行中の短時間の分離が誘拐・監禁・身体切断へつながるという対人犯罪リスクである。異文化圏への漠然とした不安も作用するが、より直接的な対象は誘拐・暴行である。

**この伝承における現れ方**

「知らない土地では、同行者から一瞬離れただけで重大犯罪へ巻き込まれるかもしれない」という不安が、失踪と身体損壊という具体的危険へ変換される。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.STY.FOAF_REPORT` — 近接伝聞
- Primary Parent: `D08.STY` — 社会的証言
- Secondary: なし
- Status: `D` — Direct（FOAF証言が危険の根拠）

**判定根拠**

危険は公式統計や制度的警告ではなく、知人関係を通じた「実際にあった」という報告によって問題化される。

**この伝承における現れ方**

「友人の友人が被害に遭った」という近接証言が、海外旅行の抽象的不安を現実に起き得る犯罪として感じさせる手掛かりになる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAU.HIDDEN_CAUSE` — 隠れた原因化
- Primary Parent: `D09.CAU` — 原因帰属
- Secondary: `D09.AGN.AGENCY_ATTRIBUTION` — 主体化
- Status: `I` — Inferred（失踪空白を犯罪主体で埋める構造から判定）

**判定根拠**

旅行者が突然消え、その場では理由が分からないという空白を、見えないところで活動する誘拐者・犯罪者の存在で説明する。さらに失踪後の空白期間を、監禁・身体切断・搾取という意図的行為へ接続する。

**この伝承における現れ方**

「なぜ人が一瞬で消えたのか」という不確実性は、表面から見えない犯罪主体が計画的に連れ去ったからだ、と理解可能にされる。後の再発見が、その隠れた原因モデルを遡及的に補強する。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.HUM.INFORMAL_GROUP` — 非制度的集団・共同体
- Primary Parent: `D10.HUM` — 人間・社会主体
- Secondary: `D10.HUM.INDIVIDUAL_HUMAN` — 個人
- Status: `I` — Inferred（複数加害者・組織的搾取型を中心に判定）

**判定根拠**

代表形では誘拐、監禁、身体切断、見世物・物乞い・売春等の継続的搾取が想定され、単独犯より複数の人間から成る非制度的犯罪集団の方が因果モデルに適合する。ただし一部再話では個人加害者として単純化され得るためSecondaryに残す。

**この伝承における現れ方**

恐怖の原因は超自然現象ではなく、旅行者を秘密裏に連れ去り、長期に搾取できる悪意ある人間集団として世界内に置かれる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.CON.LOCATION_STATE` — 位置・状態条件
- Primary Parent: `D11.CON` — 時刻・属性・状態条件
- Secondary: なし
- Status: `D` — Direct（同行者から離れた単独状態が共有核）

**判定根拠**

物語上の境界は、特定の人物と会話したことよりも、海外旅行中に同行者の監視・相互確認から切り離されて一人になることである。試着室・市場・店舗等の具体地点は変わっても、「単独状態になる」が共通条件として残る。

**この伝承における現れ方**

旅行者は同行者と一緒にいる間は通常状態にあるが、短時間一人になった瞬間から所在確認ができなくなり、失踪へ移行する。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.OTH.VICTIM_TARGET` — 特定被害者
- Primary Parent: `D12.OTH` — 他者個人
- Secondary: なし
- Status: `D` — Direct（女性旅行者が犯罪被害対象）

**判定根拠**

加害主体から見た作用対象は、失踪・監禁・身体切断の対象に選ばれる女性旅行者である。単に物語の焦点人物であることより、被害対象としての役割を優先する。

**この伝承における現れ方**

旅行者は観察者ではなく、加害者によって連れ去られ、身体を損なわれ、搾取される対象として位置付けられる。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.PHY.PHYSICAL_ATTACK` — 物理攻撃
- Primary Parent: `D13.PHY` — 身体・物質作用
- Secondary: `D13.SOC.COERCE_CONFINE` — 強制・監禁
- Status: `D` — Direct（身体切断と監禁が内容の核）

**判定根拠**

加害者は被害者を失踪させ、監禁し、四肢切断等の直接的身体暴力を加えるとされる。身体損壊をPrimary、失踪後の拘束・搾取をSecondaryとする。

**この伝承における現れ方**

短時間の失踪の裏で、被害者は自由を奪われ、身体を不可逆的に損なわれる。見えない空白期間が、継続的な人為的暴力として説明される。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct（失踪・重傷・搾取が主要帰結）

**判定根拠**

代表形は失踪、監禁、重度身体損壊、継続的搾取という全面的に負の帰結で構成される。

**この伝承における現れ方**

観光・買い物という通常の旅行が、一時的な分離を境に最悪の犯罪被害へ反転する。救済や利益は中心にない。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.BOD.SEVERE_INJURY` — 重傷・障害
- Primary Parent: `D15.BOD` — 身体・健康
- Secondary: `D15.LIF.DISAPPEARANCE` — 失踪・消失
- Status: `D` — Direct（四肢切断と長期失踪を確認）

**判定根拠**

終端で最も強く可視化されるのは四肢切断等の重大な身体障害である。そこへ至るまでの重要な中間帰結として長期失踪があり、死亡は全型に必須ではない。

**この伝承における現れ方**

同行者の視界から消えることが第一の損失であり、後の再発見によって「失踪中に身体が不可逆的に破壊された」という最終帰結が明らかになる。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.PRG.STAGED_PROGRESSION` — 段階進行
- Primary Parent: `D16.PRG` — 段階・遅延進行
- Secondary: なし
- Status: `D` — Direct（複数段階と時間経過が明示）

**判定根拠**

海外旅行→同行者から分離→失踪→捜索失敗→時間経過→重度身体損壊状態で再発見、という複数段階を経る。旧レビュー用メモの `D16:U` より、現在の高密度Evidenceでは時間構造を直接再構成できる。

**この伝承における現れ方**

恐怖は一瞬の襲撃だけでなく、「見つからない時間」が続くことで増幅する。最後の再発見が、その空白期間を隠れた暴力と搾取で埋める。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.AVO.DO_NOT_ENGAGE` — 接触回避
- Primary Parent: `D17.AVO` — 回避・逃走
- Secondary: なし
- Status: `I` — Inferred（警告機能から判定）

**判定根拠**

伝承は、海外で同行者から離れない、単独で不審な場所へ入らない、といった回避行動へ接続する。具体的な犯行手口を制御する方法ではなく、危険の入口を避ける規則である。

**この伝承における現れ方**

聞き手に残る実践的教訓は「見知らぬ土地で一人にならない」であり、犯罪集団そのものを倒す・解決する方法ではない。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（確認できる作用範囲から判定）

**判定根拠**

犯罪因果は物語内の旅行者に作用する。話を聞くこと自体が受容者を誘拐対象にする構造ではなく、噂流通が現実社会で確認可能な制度・市場結果を生んだことも今回のEvidenceでは固定していない。

**この伝承における現れ方**

受容者の旅行不安を強め得るが、伝承内で主張される誘拐・身体切断は物語内部の被害者に起こる。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: なし
- Status: `D` — Direct（現代伝説集で広域型として採録）

**判定根拠**

日本の現代伝説集に代表形として採録され、特定地域だけに閉じない広域FOAFとして扱われる。

**この伝承における現れ方**

旅行先の国名を差し替えながら、「海外旅行者なら誰でも注意すべき実話らしい話」として全国的に移植できる。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.ORG.PERPETRATOR_CRIMINAL` — 加害者・犯罪者
- Primary Parent: `D20.ORG` — 組織・加害主体
- Secondary: なし
- Status: `I` — Inferred（失踪期間の情報非対称性から判定）

**判定根拠**

同行者や家族は失踪後に何が起きているかを知らず、監禁・身体損壊・搾取の全容を把握する立場は加害側に限られる。後の再発見でも犯行の全過程は完全には開示されない。

**この伝承における現れ方**

被害者が消えた後の「空白」を知っているのは犯罪者だけであり、周囲は結果から隠れた過程を推測するしかない。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct（一般的旅行・犯罪背景に依存し固有事件へ固定されない）

**判定根拠**

海外旅行、店舗、市場、誘拐犯罪等の現実的背景を使うが、特定の検証済み事件・人物・犯罪組織へ固定されない。国名も異伝ごとに差し替えられる。

**この伝承における現れ方**

実在し得る旅行行動と犯罪類型を足場にして現実感を得る一方、具体的事件の記録ではなく一般的現実背景上に構築されたFOAFとして機能する。
