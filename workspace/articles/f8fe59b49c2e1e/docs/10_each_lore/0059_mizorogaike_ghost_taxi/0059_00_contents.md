# 1. 伝承内容

## 1.1. summary

深泥池の幽霊タクシーは、京都市北区の実在する深泥池と、タクシー車内から乗客が不可解に消失する出来事を結び付けた現代怪談である。

現在もっとも強く固定できる初期層は、1969年10月7日付『朝日新聞』京都市内版の記事である。京都府立図書館がマイクロフィルムで再確認しており、見出しは「車から乗客消えた　パトカーも“怪談”めいた届出に汗だく」。したがって、少なくとも1969年には、京都のタクシーに関する「車内にいた乗客が消えた」という異常な届出が新聞報道され、警察対応を伴ったことを確認できる。

ただし、本作業では当該記事本文全体を直接閲覧していない。このため、R1では「深泥池に関係するタクシー」「乗客消失」「怪談めいた届出」「警察対応」を初期Evidenceの安全な核とし、後代の定型怪談に現れる細部を初期形へ混入させない。

後代資料では、若い女性客、雨の夜、深泥池への移動、到着前後の消失、濡れた座席などが組み合わされる。しかし、京都府立図書館のレファレンス自体が「池の脇で女性を乗せる型」と「女性が深泥池まで行くよう求める型」の不一致を指摘している。したがって、女性客・雨・水濡れ等は伝承史上のVariationとして保持する。

伝承構造上の中心は、タクシー運転手の日常業務に「普通の乗客として見えていた存在が通常の降車過程なしに消える」という異常が侵入することである。後代再話はこの不在を「幽霊だった」と解釈するが、1969年新聞記事の存在は幽霊の実在を証明するものではない。

## 1.2. 初期Evidenceで固定できる最小核

- 京都市内のタクシーに関する乗客消失の届出があった。
- 深泥池に結び付く話として後世まで追跡されている。
- 乗客は車内にいたと認識されていたにもかかわらず、通常の降車過程なしにいなくなったとされる。
- 警察・パトカーが「怪談」めいた届出へ対応した。

## 1.3. 後代に安定化した代表形

- 運転手が女性客を乗せる。
- 女性客または走行経路が深泥池と結び付く。
- 移動中または到着時に女性客が消える。
- 一部型では、女性がいた座席が濡れている。
- 消失を「生者ではなく幽霊・死者だった」と解釈する。

- 発動儀式: なし。

## 1.6. 中心命題

**通常の乗客としてタクシーに乗っていたはずの人物が、通常の降車過程なしに車内から消失する。**

後代型では、その説明不能な消失を「乗客は幽霊・死者だった」と意味付けする。

## 1.7. 帰結

- 伝承内: 運転手は乗客の消失を確認し、正体・消失過程を確定できない。
- 後代解釈: 乗客を幽霊と理解する。
- 社会現実: 1969年記事見出しから警察・パトカーが届出へ対応したことを確認できる。
- 幽霊の実在、濡れた座席、死亡者との同一性等は、今回固定した一次Evidenceから事実認定しない。

## 1.8. 不確実性

- 1969年新聞本文全体は本作業で直接閲覧していない。
- 「若い女性」「雨」「濡れた座席」「京大病院で死亡した女性」等を初期形の確定要素としない。
- 深泥池が乗車地点か目的地かは後代Variation間で揺れる。
- 全国的な一般タクシー幽霊譚の起源を、この一件だけから確定しない。
- 「タクシー業界で乗車拒否が許された」等の後代主張は、業界一次資料未確認のためX Evidenceに使わない。

# 2. 伝承史・異伝

## 2.1. 最古確認

1969年10月7日『朝日新聞』京都市内版の記事が、現在直接追跡できる最古の強い記録である。京都府立図書館がマイクロフィルム上で所在と見出しを確認している。

この日付を伝承の絶対生成日とはみなさない。後代資料は1960年代以降の広まりを述べるが、それ以前の口承・類話の有無は別問題である。

## 2.2. 後代定型化

後代には、「女性客」「雨夜」「深泥池」「乗客消失」「水浸しの座席」が結び付く形が定型怪談として流通する。ただし資料ごとに、乗車地点・目的地・水濡れ痕跡等が異なる。

## 2.3. Variation

| Variation | 差異 |
|---|---|
| 初期乗客消失型 | 1969年記事で確実に追跡できる最小核。乗客が車から消えたという届出 |
| 深泥池目的地型 | 女性客が「深泥池まで」と依頼する |
| 深泥池乗車型 | 池付近で女性を乗せる |
| 濡れた座席型 | 消失後にシートが水浸しになる |
| 死者同定型 | 後に病院等で亡くなった女性と結び付ける |

## 2.4. 変容上の重要点

初期の「説明不能な乗客消失」という報告核に、女性性、雨・水のイメージ、死者同定、深泥池の心霊スポット性等が後代に接続され、幽霊譚として説明力と恐怖演出が強化されたとみられる。ただし、どの要素がいつ追加されたかを今回のEvidenceだけで精密に年代確定しない。
