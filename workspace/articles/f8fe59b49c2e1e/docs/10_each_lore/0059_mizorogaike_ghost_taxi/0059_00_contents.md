# 1. 伝承内容

## 1.1. summary

1969年10月7日付『朝日新聞』京都市内版には、「車から乗客消えた」という乗客消失の届出を扱う記事が存在し、見出しでは「怪談」めいた届出としてパトカー・警察対応が示されている。

京都府立図書館は、深泥池に関係するタクシー幽霊譚の照会に対して、この1969年記事を初期資料として特定している。ただし本作業では記事本文全体を直接閲覧していないため、**1969年記事本文そのものが深泥池を明記するかは未確認**である。

後代資料では、深泥池付近または深泥池への移動、若い女性客、雨、乗客の消失、濡れた座席、幽霊・死者とする説明などが組み合わされるが、細部は資料間で一致しない。

## 1.2. 詳細展開

### 1.2.1. 1969年確認層

- 車内にいたとされる乗客が、通常の降車過程を確認できないままいなくなったとする届出が記事化される。
- 見出しでは「怪談」めいた届出として扱われる。
- パトカー・警察が届出に対応したことが見出しから確認できる。

### 1.2.2. 後代再話

- タクシー運転手が女性客を乗せる型がある。
- 深泥池付近で乗せる型と、深泥池へ行くよう求められる型がある。
- 移動中または到着時に乗客が消える型がある。
- 座席が濡れている型や、乗客を死者・幽霊とする説明が付加される型がある。

## 1.7. 異常・不可解な現象／中心命題

車内にいたとされる乗客が、通常の降車過程を確認できないままいなくなったと報告された。1969年記事見出しでは、この届出が「怪談」めいたものとして扱われている。

後代資料では、消えた乗客を幽霊・死者とする再話がある。

## 1.8. 行動・対応

- 運転手が乗客を乗せ、走行する場面が語られる。
- 乗客がいなくなった後、届出が行われたとされる。
- 警察・パトカーが当該届出へ対応したことが1969年見出しで確認できる。
- 後代再話では、消失後に座席等を確認する場面が付加される型がある。

## 1.9. 帰結・終端状態

- 乗客が車内からいなくなったとされる。
- 1969年確認層では、乗客の正体や消失理由は確定しない。
- 後代では、幽霊・死者だったとする説明が付加される型がある。
- 幽霊の実在、死亡者との同一性、濡れた座席等を1969年の事実として認定しない。

## 1.10. 未解決点・不確実性

- 1969年新聞本文全体は本作業で直接閲覧していない。
- 1969年記事本文が深泥池を明記するかは未確認であり、深泥池との接続は図書館レファレンスによる関連付けを介している。
- 若い女性、雨、濡れた座席、死亡した女性等を初期形の確定要素としない。
- 深泥池が乗車地点か目的地かは後代Variation間で揺れる。
- 全国的な一般タクシー幽霊譚の起源をこの一件から確定しない。
- タクシー業界での乗車拒否等を、高品質一次資料なしに現実効果として採用しない。

# 2. 伝承史・異伝

## 2.1. 最古確認

1969年10月7日『朝日新聞』京都市内版の記事が、現在追跡できる早い同時代記録である。京都府立図書館がマイクロフィルム上で所在と見出しを確認している。

この日付を伝承の絶対生成日とはみなさない。また、記事本文自体の深泥池明記は今回直接確認していない。

## 2.2. 流通・拡散

後代資料は1960年代以降に女性幽霊が乗るタクシーの都市伝説が広まったと整理する。深泥池との地理的接続を保ちつつ、女性客、雨、水濡れ、死者同定等の細部を伴う再話が流通する。

## 2.3. 主要な異伝・派生

| Variation | 内容上の差 |
|---|---|
| 1969年乗客消失記事 | 車から乗客が消えたとする届出を記事化 |
| 深泥池目的地型 | 女性客が深泥池へ行くよう求める |
| 深泥池乗車型 | 池付近で女性客を乗せる |
| 濡れた座席型 | 消失後に座席が濡れている |
| 死者同定型 | 乗客を既に死亡した女性等と結び付ける |

## 2.4. 変容上の重要点

後代再話では、1969年に確認できる乗客消失という要素に、女性性、雨・水、深泥池の具体的経路、死者同定等が組み合わされる。どの要素がいつ付加されたかは今回のEvidenceだけで精密に年代確定しない。
