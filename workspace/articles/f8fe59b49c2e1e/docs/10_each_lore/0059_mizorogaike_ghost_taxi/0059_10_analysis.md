## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（後代資料の流通史記述から年代帯を特定）

**判定根拠**

`0059_00_contents.md` では、1969年10月7日付『朝日新聞』京都市内版の記事掲載を確認でき、後代資料には深泥池の女幽霊タクシー伝説が1960年代以降に広まったとの整理がある。最古確認日をそのまま生成日に置き換えずとも、1960年代に流通していたという記述から `D01.G2` の年代帯へ安全に置ける。

**この伝承における現れ方**

深泥池の幽霊タクシーは、少なくとも1960年代後半の都市交通環境の中で流通していた現代怪談であり、古来伝承をそのまま継承したものとしては扱わない。

**この伝承における現れ方**

最古確認層では、乗客消失の話が新聞記事として公衆へ提示されている。古い話だから口承だったと推測して起点を置かない。

**この伝承における現れ方**

個別の乗客消失報告が新聞で可視化され、その後書籍の地域怪談として再提示されることで、深泥池・女性客・消失という型が継続して流通する。

**この伝承における現れ方**

乗客消失という短い異常報告へ、幽霊解釈を補強する物的痕跡や背景説明が増補され、その蓄積によって「深泥池の幽霊タクシー」という認識可能な型が定着する。

**この伝承における現れ方**

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T6` — 真偽未確定

- Secondary: なし

**判定根拠**

新聞記事・実在地名・実在職業という現実アンカーはあるが、乗客が幽霊だったという超自然解釈は検証されない。伝承は「事実らしいが核心は確定しない」姿勢を要求する。

**この伝承における現れ方**

受容者は実在する深泥池と1969年の記事を手掛かりに話を現実へ結び付ける一方、乗客の正体と消失機構は不明のまま残る。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ANO.UNEXPLAINED_EVENT` — 説明不能事象
- Primary Parent: `D07.ANO` — 異常体験・存在
- Secondary: なし
- Status: `D` — Direct（乗客消失という異常が内容の核）

**判定根拠**

この伝承がなければ説明されないまま残る中心問題は、直前まで車内にいた乗客が通常の降車過程なしに消える出来事である。深泥池という場所や幽霊という解釈は、その異常を説明するための後段要素である。

**この伝承における現れ方**

「いたはずの人がいなくなる」という出来事が通常の交通経験から逸脱し、受容者に原因説明を要求する。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.DEX.DIRECT_EVENT` — 出来事への直接遭遇

- Status: `I` — Inferred（初期核と後代異伝を分離して判定）

**判定根拠**

中心となる運転手は、実際に乗せていたはずの客が消えていることへ遭遇する。後代型の一部では濡れた座席が物的痕跡として幽霊解釈を補強するが、この要素を1969年記事へ遡及しない。

**この伝承における現れ方**

異常の問題化は、抽象的な噂を先に信じることからではなく、運転手が車内の不在を直接確認することから始まる。後代版では残された水濡れが追加の手掛かりになる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAT.TYPE_ASSIGNMENT` — 類型化
- Primary Parent: `D09.CAT` — カテゴリー化
- Secondary: なし
- Status: `I` — Inferred（後代代表形の解釈操作から判定）

**判定根拠**

説明不能な乗客消失を、既知の「幽霊・死者が一時的に現れた」という怪異類型へ割り当てることで理解可能にする。単に名称を付けるより、既知カテゴリへ分類する操作が中心である。

**この伝承における現れ方**

乗客が突然消えたという出来事は、後代再話で「女幽霊を乗せた」という既知の怪談モデルへ整理される。これにより、消失・深泥池・濡れた座席等が同じ因果モデルの中へ収まる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SUP.GHOST_SPIRIT` — 幽霊・死者霊
- Primary Parent: `D10.SUP` — 超自然主体・力
- Secondary: なし
- Status: `I` — Inferred（後代代表形の解釈から判定）

**判定根拠**

後代の代表形では、女性客は通常の生者ではなく幽霊・死者霊と理解される。ただし、1969年記事が超自然存在を事実として証明するわけではないためStatusは `I` とする。

**この伝承における現れ方**

通常の客の姿でタクシーへ乗り込み、途中で消える死者が因果源として置かれる。抽象的な「池の呪い」より、人格的な死者の一時的顕現として語られる。

受容者は運転手の視点を通じ、普通の乗客だと思っていた人物がいなくなるという認識の破綻を経験する。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

代表形では、幽霊が運転手を直接傷害・呪詛することは中心ではなく、通常の乗客として現れ、その後消えること自体が主作用である。

**この伝承における現れ方**

死者らしき女性が日常交通の中へ一時的に顕現し、運転手に観測された後、不在になる。物理攻撃ではなく「存在していたはずの人物が消える」という観測上の切断が核になる。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負

**判定根拠**

利益・保護等の正の帰結はなく、乗客消失によって日常的な業務空間の予測可能性が崩れる。身体被害がなくても、体験者に恐怖・混乱を残す怪談として構成される。

**この伝承における現れ方**

運転手は、自分が何を乗せていたのか分からない状態に置かれ、通常の交通空間への信頼を揺さぶられる。

### 2.3.5. D15: 帰結領域

乗客の正体、消失機構、深泥池との関係は最終的に確定しない。後代再話が幽霊という説明を与えても、実証的な真相は閉じない。

**この伝承における現れ方**

運転手は「客が消えた」ことだけを知り、なぜ消えたのかは分からない。その未解決性が怪談の終端状態として保存される。

一回の乗車から消失確認までが一つの短い出来事として完結し、長期的な遅延・反復・再発を必要としない。

**この伝承における現れ方**

「客を乗せる→運ぶ→いなくなっている」という一度の観測が怪異の時間構造を作る。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

**この伝承における現れ方**

運転手は怪異を呼び出したわけでも解除するわけでもなく、日常業務の中で出来事を目撃するだけである。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Status: `I` — Inferred（地域固定と後代出版流通を併記）

**判定根拠**

物語は京都・深泥池へ強く固定された地域怪談として形成される。一方、後代の怪談・都市伝説書籍を通じて地域外の一般読者にも再提示されているため、全国的大衆をSecondaryとする。

**この伝承における現れ方**

深泥池というローカルな場所ロアが、出版物を通じて全国的な「幽霊タクシー」イメージの一例として共有される。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.NON.COMMON_KNOWLEDGE` — 一般共有
- Primary Parent: `D20.NON` — 特権なし
- Secondary: なし

**判定根拠**

運転手は体験者ではあるが、女性客の正体や消失理由を知る真相保持者ではない。秘密組織・専門家・地元古老等が追加情報を独占する構造もVersion Scopeの中心にない。

**この伝承における現れ方**

怪談として共有される情報以上の「決定的な真相」を持つ人物は設定されず、正体不明のまま広く語られる。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A2` — 具体的実在対象
- Primary Parent: なし
- Secondary: なし

**判定根拠**

京都市北区の深泥池という具体的実在地点と、1969年10月7日付『朝日新聞』京都市内版という同時代記録へ伝承が固定される。記事の存在は幽霊実在の証明ではないが、伝承の現実アンカーとしては直接確認できる。

**この伝承における現れ方**

抽象的な「どこかの池」ではなく、深泥池という特定可能な場所が怪異の舞台となり、現実の地理と伝承内容が結び付く。
