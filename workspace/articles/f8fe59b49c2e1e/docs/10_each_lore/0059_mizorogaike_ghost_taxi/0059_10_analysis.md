# 1. 伝承エントリ基本情報

- `Entry_ID`: `0059`
- `伝承エントリ名称`: 深泥池の幽霊タクシー
- `Macro_Category`: 交通・インフラ
- `Entry_Type`: 物語・伝説
- `Version_Scope`: **京都府立図書館が後代の深泥池タクシー幽霊譚の照会に対して初期資料として関連付けた、1969年10月7日付『朝日新聞』京都市内版「車から乗客消えた」の確認核**。Coding Contentとしては、車内にいたとされる乗客が通常の降車過程を確認できないままいなくなった事案を対象とする。1969年記事本文自体が深泥池を明記するかは未確認であるため、深泥池を1969年Scoped Contentの必須地点とはしない。後代の「雨夜」「若い女性」「濡れた座席」「死者由来」等もScopeの必須条件にしない。

# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: `D01.G2` — 1945–1969
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

1969年10月7日の新聞記事が強い同時代確認点であり、京都府立図書館が紹介する後代資料も1960年代以降の流布を整理する。1969年という確認日をそのまま生成日に置換せず、年代帯のみを推定する。

**この伝承における現れ方**

現在追跡できる系譜では、1960年代後半までにタクシー乗客消失を怪談めいた出来事として扱う形が確認できる。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Child / Value: `D02.PRT.NEWSPAPER` — 新聞
- Primary Parent: `D02.PRT` — 印刷・書簡
- Secondary: なし
- Status: `D` — Direct

**判定根拠**

京都府立図書館が1969年10月7日付『朝日新聞』京都市内版p.16の記事について、マイクロフィルム上の所在・日付・見出しを確認している。これより古い流通媒体は現Evidenceで固定できない。

**この伝承における現れ方**

現在固定できる早い流通点では、乗客消失の届出が地域新聞記事として公衆へ提示される。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

**判定根拠**

Version Scopeを1969年新聞確認層へ限定しており、Scoped Versionで直接固定できる媒体は新聞である。後代書籍はVariation比較のEvidenceであり、本Scopeの流通媒体へ追加しない。

**この伝承における現れ方**

単発の不可解な届出が新聞地域面を通じて社会へ可視化される。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

後代資料では、乗車地点、目的地、乗客属性、雨、濡れた座席等が異なる一方、タクシーと乗客消失という要素が再叙述される。どの細部がいつ追加されたかまでは固定しない。

**この伝承における現れ方**

乗客が消えるという核に、女性客・雨・水濡れ・死者同定等の細部を変えながら複数の再話が形成される。

### 2.1.5. D05: 提示形式

**この伝承における現れ方**

乗客消失の届出が地域ニュースとして提示され、「実際に届け出られた不可解事案」という形式を取る。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T1` — 直接体験事実
- Primary Parent: なし

確認形は、乗客が消えたという体験・届出が実際の新聞記事になったという形式を取る。ただし記事本文全体を本作業で直接閲覧していないため、提示態度の細部には推論を含む。

**この伝承における現れ方**

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ANO.UNEXPLAINED_EVENT` — 説明不能事象
- Primary Parent: `D07.ANO` — 異常体験・存在
- Secondary: なし
- Status: `D` — Direct

**判定根拠**

1969年記事見出しで直接固定できる異常核は「車から乗客が消えた」ことである。

**この伝承における現れ方**

直前まで車内にいたと認識された乗客が、通常の降車過程を確認できないまま不在になることが説明を要求する中心問題となる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.DEX.DIRECT_EVENT` — 出来事への直接遭遇
- Primary Parent: `D08.DEX` — 直接経験
- Secondary: `D08.STY.WITNESS_REPORT` — 目撃証言
- Status: `I` — Inferred

**判定根拠**

物語内部では運転手が乗客消失に遭遇したという体験が契機となり、社会へ流通する際にはその届出・証言が問題化の手掛かりとなる。

**この伝承における現れ方**

体験者にとっては乗客の不在化そのものが契機となり、読者にとっては体験者の届出が不可解な事案を知る入口になる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.UNK.MYSTERY_LABEL` — 謎として命名
- Primary Parent: `D09.UNK` — 不可知性・保留
- Secondary: なし
- Status: `D` — Direct

**判定根拠**

1969年記事見出しは事案を「怪談」めいた届出として枠付ける一方、原因を幽霊・死者等へ確定しない。初期Scopeでは既知怪異類型への断定より、不可解な事案として保持する操作が明確である。

**この伝承における現れ方**

乗客消失は説明済みの事件へ閉じられず、「怪談めいた」不可解な出来事として共有される。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown

**判定根拠**

1969年最小核は乗客消失を記録するが、その原因を死者霊、妖怪、通常の人間、自然過程等のいずれかへ一意に置かない。後代の幽霊説明を遡及しない。

**この伝承における現れ方**

何が消失を起こしたのか、乗客が何者だったのかは初期Scopeでは開いたまま残る。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.SOC.MEET_INTERACT` — 会う・会話する
- Primary Parent: `D11.SOC` — 社会関係・取引
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

タクシー運転手が通常業務で乗客と接し、客として車内へ受け入れることが乗客消失事案への入口となる。召喚儀式・禁忌等は確認できない。

**この伝承における現れ方**

日常的な乗客との相互行為が、そのまま不可解な乗客消失へ接続する。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.OTH.SPECIFIC_OTHER` — 特定他者
- Primary Parent: `D12.OTH` — 他者個人
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

D13で直接起きる変化は乗客が車内から不在になることであり、その変化を受ける対象は観測者である運転手ではなく、消失する乗客側である。乗客が被害者・被害対象だったことまではEvidenceから確定しないため `VICTIM_TARGET` は採らない。

**この伝承における現れ方**

運転手は出来事の体験者・観測者だが、中心事象で状態が変わるのは乗客である。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: なし — **taxonomy gap: 対象の消失／不在化**
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

Scopeで明示されるのは、車内にいたとされる乗客が通常の降車過程を確認できないまま不在になることである。現行D13には、この「対象の消失／不在化」を直接表すChildがない。`MANIFEST_ONLY` は追加作用がない場合のコードであり不適合、`REALITY_ALTERATION` は消失の因果機構を過剰に確定するため採らない。

**この伝承における現れ方**

中心作用は、乗客が車内に存在する状態から不在状態へ移ることであるが、その機構は未確定である。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEU` — 中立
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

1969年最小Scopeでは、乗客消失が利益・危害のどちらとして生じたかを固定できない。運転手への身体危害・呪いも必須ではないため、極性を中立とする。

**この伝承における現れ方**

不気味で不可解な事象ではあるが、Scope内Evidenceから正負の価値を直接確定しない。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.LIF.DISAPPEARANCE` — 失踪・消失
- Primary Parent: `D15.LIF` — 人生・存在・同一性
- Secondary: `D15.KNW.UNCERTAINTY_PRESERVED` — 不確実性維持
- Status: `I` — Inferred

**判定根拠**

中心的な状態変化は乗客の消失であるため、帰結領域として `DISAPPEARANCE` をPrimaryとする。同時に、正体・消失機構・その後の状態が解明されないことを認識上のSecondaryとして保持する。

**この伝承における現れ方**

人物の所在・存在状態が消失側へ変化し、その理由と真相は未解決のまま残る。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.EVT.SINGLE_EPISODE` — 単一エピソード
- Primary Parent: `D16.EVT` — 単一エピソード・事象内
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

乗客との接触、乗車中の存在認識、消失認識、届出までが一続きの乗車事案として構成される。周期・長期進行・連鎖はScope核にない。

**この伝承における現れ方**

一回の営業運行の中で不可解な消失事案が完結する。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown

**判定根拠**

1969年最小Scopeでは、乗客消失を防ぐ、怪異乗車を識別する、消失後に状態を戻す等の安定した伝承内対処法を確認できない。これは「介入不要」を意味しないため `OBSERVATIONAL_ONLY` は採らない。また警察への届出は現実側の事件対応であり、伝承内因果の制御規則ではない。

**この伝承における現れ方**

不可解な消失が起きた際に、何をすれば回避・制御できるのかは初期Scopeでは示されない。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

- `L1=1`: 伝承内部で乗客消失という異常事象が成立する。
- `L2=0`: この話を読む・聞く現実側受容者自身が同じ因果対象になる自己適用規則はない。
- `L3=0`: 1969年の警察対応は乗客消失の届出への個別対応であり、伝承流通そのものによって生じた制度・市場・社会行動の二次的結果ではない。後代の乗車拒否等についても高品質X Evidenceを固定していない。

**この伝承における現れ方**

異常作用は乗車エピソード内部に留まり、伝承を受容するだけで作用する構造や、流通による独立した社会効果は確認しない。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown

**判定根拠**

1969年に京都市内版新聞へ掲載されたことはD02/D03の媒体Evidenceであり、それだけで伝承が京都の地域共同体にどの範囲まで流通していたかを示さない。後代に京都・深泥池の地域怪談として定着したことも、1969年Scoped VersionのD19へ遡及しない。Scope内で受容集団・流通範囲を直接固定できるEvidenceが不足するためUとする。

**この伝承における現れ方**

1969年に新聞上で可視化されたことは確認できるが、当時どの社会集団・地域圏で伝承として共有されていたかは未確定である。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.PER.EXPERIENCER` — 体験者本人
- Primary Parent: `D20.PER` — 当事者・家族
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

乗客の様子や消失直前の車内状況について一次的な体験詳細を保持するのは運転手本人である。ただし、運転手が乗客の正体や消失の真相を知るわけではない。特権性は自己の体験詳細へのアクセスに限定する。

**この伝承における現れ方**

一般読者が知るのは報道・再話された範囲であり、消失前後の具体的体験情報は当事者に偏在するが、核心の謎そのものは当事者にも解けない。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

1969年Scoped Contentから直接固定できるのは、京都市内のタクシー、乗客、警察への届出という一般的な現実背景である。深泥池自体は実在し、後代の図書館レファレンスが当該記事を深泥池伝承の系譜へ関連付けるが、1969年記事本文が深泥池を明記することは未確認である。そのため具体的実在地点 `A2` はScoped Contentへ付与しない。

**この伝承における現れ方**

都市交通と警察対応という現実背景に接続する一方、1969年確認核を特定の深泥池地点へ固定することは保留する。
