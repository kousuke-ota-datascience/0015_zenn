# 1. 伝承内容

## 1.1. summary

確認できる「不幸の手紙」では、受信者に対し、同じ文面を一定期限内に一定人数へ送るよう求め、送らなければ本人に不幸・災難が訪れると告げる。

1970年資料については、研究資料を介して「50時間以内に29人」等の条件と不転送時の不幸が確認される。1977年『広報あかいけ』では、赤池町内へ「数日以内に20人へ同じ文面を出さないと不幸が訪れる」とする手紙が届いていることが直接記録されている。

## 1.2. 詳細展開

1. 手紙・葉書等を受け取る。
2. 転送しなければ不幸・災難が起きると告げられる。
3. 「○時間／○日以内」「○人へ」等の条件が示される。
4. 受信者が転送するか、無視・破棄するかを選ぶ。
5. 転送した場合、新たな受信者が同じ文面を受け取る。

## 1.3. 登場人物・主体

| 主体 | 役割 |
|---|---|
| 受信者 | 制裁条件を記した文面を受け取り、転送判断を行う |
| 前段階の送信者 | 同文を転送する |
| 次の受信者 | 新たに同じ条件を記した文面を受け取る |
| 手紙／葉書 | 不転送時の不幸、期限、人数、転送命令を保持する媒体 |
| 自治体・警察 | 1977年資料で破棄・相談を促す現実側主体 |

## 1.4. 場所・空間

- 郵便・地域社会が流通背景となる。
- 特定の怪異地点は必要としない。
- 1977年資料では赤池町内での実流通が直接確認される。

## 1.5. 物・記号・媒体

- 手紙・葉書: 1970年代型の中心媒体。
- 複製文面: 同じ転送命令・制裁条件を次の受信者へ伝える。
- 人数・期限: 転送条件として文面に記される。
- 電子メール・SNS等: 後代には媒体置換が起こるが、1970年代郵便型へ遡及しない。

## 1.6. 条件・規則・禁忌

- 条件: 不転送時の不幸と転送条件を記した文面を受信する。
- 規則: 指定期限内に指定人数へ同文を送る。
- 不遵守: 転送しない、期限・人数を守らない場合に不幸が訪れるとされる。
- 現実側対抗: 1977年赤池町は破棄または派出所への届出を推奨した。

## 1.7. 異常・不可解な現象／中心命題

チェーン文面を規定どおり他者へ転送しないことと、受信者本人の将来の不幸・災難との間に因果関係があるとする主張である。

## 1.8. 行動・対応

- 文面を読み、期限・人数を確認する。
- 指示に従う場合、同文を複製して他者へ送る。
- 無視・破棄する行動も可能である。
- 1977年資料では、受信者が悩む事例と、自治体が破棄または派出所への届出を勧める対応が確認される。

## 1.9. 帰結・終端状態

- 文面上、不転送者へ不幸・災難が訪れるとされる。
- 転送すると新しい受信者が同じ文面を受け取る。
- 1977年資料では受信者の不安と行政対応が現実側で確認される。
- 不幸の超常因果が現実に成立したことはEvidenceから確認されない。

## 1.10. 未解決点・不確実性

- 1970年新聞原紙を本作業では直接実見していない。
- 人数・期限・災厄内容にはVersion差がある。
- 文中の犠牲者事例を現実の事故記録として扱わない。
- 1977広報中の自殺報道は独立原資料未確認のため事実認定に用いない。
- 1920年代型との系譜関係は研究上確認できるが、どの時点で名称・強調点が変化したかを単一の生成年として固定しない。

# 2. 伝承史・異伝

## 2.1. 最古確認

現在のEvidenceでは、1970年秋が「不幸の手紙」という名称・制裁条件を伴う早い確認層である。11月26日付『読売新聞』の記事が研究史上参照されているが、原紙未実見であるため研究資料を介した早期確認層として扱う。

## 2.2. 流通・拡散

1977年『広報あかいけ』は、地域で実際に「不幸の手紙」が流通し、「数日以内に20人へ同文を出さないと不幸」という規則が認識されていたことを直接確認する。

後代には犠牲者事例の付加や電子メール・SNS等への媒体置換もみられる。

## 2.3. 主要な異伝・派生

| 型 | 内容上の差 |
|---|---|
| 1970年確認型 | 50時間・29人等、不転送時の不幸を含むと研究上整理される |
| 1977赤池型 | 数日以内・20人、不幸予告、自治体対応まで直接確認可能 |
| 犠牲者事例付加型 | 事故・死亡・破産等の例を文面へ追加する |
| デジタル型 | 電子メール・SNS等へ媒体を置換する |
| 報酬を含む型 | 転送時の幸運等を併記する型がある |

## 2.4. 変容上の重要点

1970年確認型と1977年赤池型では、不転送時の不幸という主張を共有する一方、期限・転送人数等の数値が異なる。後代には犠牲者例や媒体差が追加される。
