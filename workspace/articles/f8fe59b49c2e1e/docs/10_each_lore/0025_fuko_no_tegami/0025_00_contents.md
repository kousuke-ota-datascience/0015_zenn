# 0. INTRODUCTION

## 0.1. 文書の役割

**伝承名:** 不幸の手紙

本文書は、一定数への複製・転送を命じ、従わなければ不幸・死・災難が起こると脅す「不幸の手紙」について、伝承内容・流通史・異伝・証拠上の不確実性を記録する Evidence / Content layer である。分析コードは `0025_10_analysis.md` に分離する。

パイロット Evidence Rank は `B`。増補調査では、1970年秋の全国的流行を扱う後代研究、1977年自治体広報による具体的注意喚起を確認した。幸福の手紙との歴史的連続性は強いが、本Entryでは**不転送時の災厄を主要な駆動力とする型**を中心にする。

## 0.3. 証拠上の区別

1. **不幸型の核:** 転送しないと不幸が起こる。
2. **幸福の手紙との連続:** 古い幸運型にも不転送時の悪運は含まれ得るが、不幸の手紙では負の制裁が前面化する。
3. **現実効果:** 受信者が実際に転送・不安・相談行動を取るため、伝承外行動へ直接作用する。
4. **媒体変化:** 郵便→電子メール→SNSでも自己複製規則は維持される。

# 1. 伝承内容

## 1.1. summary

「不幸の手紙」は、受信者へ「この文面を一定時間内に一定人数へ送らなければ、あなたに不幸・事故・死などが起こる」と告げるチェーンレターである。手紙は未来の災厄を予告するだけでなく、その災厄を回避する唯一の手段として**同じ脅威を他人へ複製・転送すること**を要求する。受信者は被脅迫者であると同時に、次の受信者を作る伝達者へ変えられる。

文面には「○時間以内」「○人へ」といった数値条件が入り、判断を先延ばしできないよう期限を設ける型が多い。さらに、過去に指示を無視して事故・死亡・破産等に遭った人物、反対に指示に従って助かった人物を例として挙げ、因果の実在を補強することがある。これらの事例が検証可能とは限らないが、受信者には「偶然でも自分だけは試したくない」という損失回避的圧力を与える。

日本では1970年前後に「不幸の手紙」が大きく流行したとする研究・新聞史整理があり、1977年の自治体広報では、実際に地域へ流入していた「数日以内に20人へ同文を出さなければ必ず不幸が訪れる」という手紙への注意が掲載されている。行政側は破棄または派出所への届出を推奨しており、伝承が受容者の現実行動と地域社会の対応を引き起こしていたことが分かる。

意味形成上、この伝承は制御不能な災厄を「転送」という具体行動へ結び付ける。ただし幸福の手紙と違い、受信者が得るのは積極的利益ではなく、**災厄を他者へ回すことで自分が被害を免れる可能性**である。恐怖が自己複製の動機になるため、受信者が信じるほど情報は現実に増殖する。

## 1.2. 論理構造

1. **受信:** 不特定または知人から手紙が届く。
2. **脅威提示:** 転送しなければ不幸になると告げる。
3. **条件指定:** 人数・期限が示される。
4. **事例補強:** 過去の犠牲者・成功者を挙げる場合がある。
5. **選択:** 転送／破棄・無視を迫られる。
6. **転送:** 恐怖回避のため同じ文面を他者へ渡す。
7. **連鎖:** 新受信者が同じ選択へ組み込まれる。

## 1.3. 主体

| 主体 | 役割 |
|---|---|
| 受信者 | 脅威を受け、転送判断を行う |
| 送信者 | 前段階の受信者であり、連鎖を維持する |
| 次の受信者 | 新しい脅威対象・伝達者候補 |
| 文面 | 災厄予告と自己複製命令を保持する情報 |
| 警察・自治体等 | 現実側で破棄・相談を促す対抗主体 |

## 1.4. 空間

郵便網・学校・友人関係・通信網が流通空間。特定の怪異地点ではなく、ネットワーク上を移動する情報そのものが問題となる。

## 1.5. 物・記号・媒体

- 手紙・葉書。
- 人数・期限。
- 災厄事例。
- 後代の電子メール・SNSメッセージ。

## 1.6. 条件・規則

- 受信後に一定人数へ同文を送る。
- 指定期限を守る。
- 転送しないことが禁忌。
- 「破棄すればよい」という現実側の対抗規則が行政・啓発資料で提示される。

## 1.7. 中心命題

情報の転送を拒否することが、将来の不幸・事故・死を引き起こす。

## 1.8. 行動・対応

- 恐怖から転送する。
- 破棄・無視する。
- 警察・家族・学校等へ相談する。

## 1.9. 帰結

- 伝承内部: 不転送時の不幸・死。
- 受容者: 不安、転送、相談。
- 社会: 啓発・取締り・注意喚起。

## 1.10. 不確実性

- 人数・期限・災厄はVersion差が大きい。
- 文中の犠牲者事例は検証されないことが多い。
- 幸福の手紙との境界は歴史的に連続的。
- 「不幸の手紙」の最初の発生年は研究上も幅があるため、1970年を絶対起源年としない。

# 2. 伝承史・異伝

## 2.1. 最古確認

研究整理では1969–1970年頃から流行し、1970年秋には新聞で社会問題化したとされる。一方、幸福の手紙には1920年代から不転送時の悪運要素があるため、「負の脅し」という構造自体はより古い。不幸のみを前面化した型の成立と、その前史を分ける。

## 2.2. 流通

- 1960年代末〜1970年頃: 不幸型が顕在化・全国化。
- 1970年代: 学校・地域社会で反復し、行政も注意喚起。
- 後代: 電子メール・SNSへ自己複製構造を移植。

## 2.3. 異伝

| 型 | 特徴 |
|---|---|
| 災厄型 | 事故・死亡・病気等を予告 |
| 期限強化型 | 数十時間等の短い期限 |
| 犠牲者列挙型 | 過去の無視者の不幸を例示 |
| 幸福混合型 | 転送時の幸運も併記 |
| デジタル型 | メール・SNSへ媒体移行 |

## 2.4. 変容上の重要点

「幸運を得るため送る」から「不幸を避けるため送る」へインセンティブが反転しても、連鎖複製構造は同じである。
