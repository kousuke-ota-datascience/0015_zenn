# 1. 伝承内容

## 1.1. summary

「不幸の手紙」は、受信者に対して**同じ文面を一定期限内に一定人数へ送らなければ、本人に不幸・災難が訪れる**と告げる自己複製型チェーンレターである。受信者は脅威を受ける対象であると同時に、その脅威を次の受信者へ再生産する送信者候補となる。

1970年秋の初期流行を扱う研究では、「50時間以内に29人」等の厳しい転送条件と、不転送時の「必ず不幸」という制裁が前景化した型が確認される。1977年『広報あかいけ』では、赤池町内へ「数日以内に二十人へ同じ文面を出さないと必ず不幸が訪れる」という手紙が流入していることが直接記録される。

歴史的には1920年代の「幸運の手紙」が、転送時の報酬と連鎖断絶時の悪運を併記していた。1970年前後の「不幸の手紙」は、そのうち**不転送時の負の制裁を主要な行動誘因として前景化した系統**として区別できる。本Entryはこの制裁前景型を扱い、報酬を中心にする0024「幸福の手紙」と分離する。

伝承構造の核心は、将来の災厄という不確実性を「同文を規定人数へ期限内に転送する」という具体的な行為へ接続し、転送を恐怖回避策として提示する点にある。転送すれば連鎖そのものが増殖するため、回避規則と伝播機構が同じ行為に重なる。

## 1.2. 詳細展開

1. **受信:** 手紙・葉書等を受け取る。
2. **脅威提示:** 転送しなければ不幸・災難が起きると告げる。
3. **条件指定:** 「○時間／○日以内」「○人へ」等が示される。
4. **事例補強:** 犠牲者例・成功例等が付くVersionがある。
5. **選択:** 転送するか、無視・破棄するかを迫られる。
6. **転送:** 災厄回避のため同文を他者へ送る。
7. **連鎖:** 新たな受信者が同じ脅威と選択へ組み込まれる。

## 1.3. 主体

| 主体 | 役割 |
|---|---|
| 受信者 | 脅威の対象であり、転送判断を行う |
| 前段階の送信者 | 同文を転送して連鎖を維持する |
| 次の受信者 | 新たな脅威対象・送信者候補になる |
| 手紙／葉書 | 脅威・期限・人数・自己複製命令を保持する |
| 自治体・警察 | 現実側で破棄・相談を促す対抗主体 |

## 1.4. 空間・媒体

- 初期Scopeでは郵便・葉書・手紙が中心媒体。
- 特定怪異地点は必要ない。
- 後代には電子メール・SNS等へ構造が移植され得るが、1970年代郵便型へ遡及しない。

## 1.5. 条件・規則

- 発動条件: 制裁規則を含むチェーン文面を受信する。
- 伝承内規則: 指定期限内に指定人数へ同文を送る。
- 禁忌: 転送しない、期限・人数を守らない。
- 伝承内制御: 転送して災厄を回避する。
- 現実側対抗: 1977年赤池町は破棄または派出所への届出を推奨した。

## 1.6. 中心命題

**チェーン文面を規定どおり他者へ転送しないことが、受信者本人の将来の不幸・災難を引き起こす。**

通常は因果関係を確認できない情報行動と将来の災厄を一つの規則へ結び付け、その災厄を避けるための行為として同じ脅威の再送を要求する。

## 1.7. 帰結

- 伝承内Negative: 不転送者に不幸・災難が訪れる。
- 伝承内Control: 転送した者は災厄を回避できるとされる。
- Propagation: 転送により次の受信者が同じ脅威へ組み込まれる。
- Social/X: 1977年公的広報が住民の悩みと自治体の破棄・警察相談勧告を記録する。
- 不幸の超常因果が現実に成立したことはEvidenceから確認されない。

## 1.8. 不確実性

- 1970年新聞原紙を本作業では直接実見していない。
- 人数・期限・災厄内容はVersion差が大きい。
- 文中の犠牲者事例を現実の事故記録として扱わない。
- 0024の報酬前景型と、本Entryの制裁前景型を混成しない。
- 1977広報中の「自殺報道」は独立原資料未確認のため、事実認定に使わない。

# 2. 伝承史・異伝

## 2.1. 最古確認

現在のEvidenceでは、**1970年秋**が「不幸の手紙」という制裁前景型の早い確認層である。11月26日付『読売新聞』の記事が研究史上の初期資料として参照されている。ただし原紙未実見なので、1970年は絶対起源ではなく研究資料を介した早期確認層とする。

## 2.2. 1970年代の安定確認

1977年『広報あかいけ』は、地域で実際に「不幸の手紙」が流通し、「数日以内に20人へ同文を出さないと必ず不幸」という規則が認識されていたことを直接確認する。これは1970年初期資料の制裁前景構造が1970年代を通じて継続していたことを補強する。

## 2.3. 主要異伝

| 型 | 差異 |
|---|---|
| 1970年初期型 | 厳しい期限・多数転送、不転送時の不幸を強調 |
| 1977赤池型 | 数日以内・20人、不幸予告、自治体対応まで確認可能 |
| 犠牲者事例付加型 | 事故・死亡・破産等の例を文面へ追加 |
| デジタル型 | 電子メール・SNS等へ媒体を置換 |
| 幸福の手紙 | 転送時の正の報酬を前景化する近縁Entry 0024 |

## 2.4. 変容上の重要点

歴史的系譜上は「幸福の手紙」と連続するが、1970年前後に**転送しなければ不幸になる**という制裁が主要誘因として独立・前景化した点がEntry境界上重要である。
