# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（証拠不足）

**判定根拠**

`0025_00_contents.md` では、不幸型が1969〜1970年頃に顕在化・流行したとする後代研究を確認できる。一方、1920年代の「幸福の手紙」にも不転送時の悪運要素が含まれ得るため、負の制裁構造の前史と「不幸の手紙」という独立的カテゴリの生成時期を切り分けられない。1969または1970という最古確認層をそのまま生成時期へ置換しない。

**この伝承における現れ方**

「送らなければ不幸になる」という脅威型は戦後後半に明瞭なカテゴリとして可視化されるが、その構造がいつ独立して成立したかは現証拠から安全に特定できない。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Child / Value: `D02.PRT.CHAIN_LETTER` — チェーンレター
- Primary Parent: `D02.PRT` — 印刷・書簡
- Secondary: なし
- Status: `I` — Inferred（信頼できる後代資料から最初期媒体を特定）

**判定根拠**

丸山泰明2012は、1969〜1970年頃の不幸型を紙のチェーンレターとして歴史的に整理している。今回のEvidence layerではその最初期新聞記事・原文自体を固定していないため、最古媒体の値はチェーンレターとするがStatusは `D` ではなく `I` とする。

**この伝承における現れ方**

受信者は紙の手紙を受け取り、同じ文面を写して次の相手へ郵送する。脅威の内容と伝播媒体が一体化している。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Child / Value: `D03.PRT.CHAIN_LETTER` — チェーンレター
- Primary Parent: `D03.PRT` — 印刷・書簡
- Secondary: なし
- Status: `D` — Direct（1977年公的同時代資料で流通内容を確認）

**判定根拠**

1977年の『広報あかいけ』は、地域に実際に流入していた「数日以内に20人へ同文を出さなければ不幸が訪れる」という手紙を具体的に記録している。Version Scopeの中心媒体はチェーンレターとして直接確認できる。

**この伝承における現れ方**

手紙そのものが脅威を運び、その手紙を複製・郵送する行為が脅威回避と伝承拡散を同時に実現する。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.MIG.FORMAT_TRANSLATION` — 形式変換

- Status: `I` — Inferred（複数時期・異伝の比較から推定）

**判定根拠**

`0025_00_contents.md` では、紙の郵便型から電子メール・SNSへ媒体が移っても、「転送しないと不幸になる」という自己複製規則が保持される。また、期限、人数、犠牲者事例、災厄内容等が版ごとに追加・変更される。

**この伝承における現れ方**

恐怖による転送命令という核を保ちながら、媒体は物理書簡からデジタルメッセージへ形式変換し、無視した人物の事故・死亡例などの補強要素が増補される。

### 2.1.5. D05: 提示形式

**判定根拠**

**この伝承における現れ方**

受容者は怪談を聞くだけでなく、「この文面を○人へ送らなければ不幸になる」という具体的な手順と脅威を同時に提示される。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T6` — 真偽未確定

**判定根拠**

不転送と災厄の因果は検証されない一方、過去の犠牲者例や「無視した者に不幸が起きた」という逸話によって真実らしさを補強する型がある。

**この伝承における現れ方**

受信者は「嘘かもしれないが、無視して本当に不幸になれば取り返せない」という不確実性の下で転送判断を迫られる。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.DCF.FATE_OMEN` — 運命・予兆
- Primary Parent: `D07.DCF` — 死・偶然・不運
- Secondary: なし
- Status: `I` — Inferred（中心的な将来不確実性から判定）

**判定根拠**

この伝承がなければ、受信者の将来に事故・死・不幸が起こるかどうかは予測・制御できない不確実性として残る。不幸の手紙は、その未来の災厄を転送行動によって回避可能な運命規則へ変換する。

**この伝承における現れ方**

受信者は「このまま何もしなければ悪いことが起きるかもしれない」という未来の不確実性を、転送するか否かという現在の選択へ結び付ける。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.UNSUPPORTED_ASSERTION` — 根拠未提示の主張
- Primary Parent: `D08.CLM` — 命題先行
- Secondary: なし
- Status: `I` — Inferred（提示構造から判定）

**判定根拠**

「送らなければ不幸になる」という主張が、受信者の既存経験の説明ではなく、文面上の命題として先に提示される。犠牲者事例が添えられても、因果を独立に検証する証拠ではない。

**この伝承における現れ方**

受信者はすでに起きた災厄の原因を説明するのではなく、将来の災厄予告を先に受け取り、その警告を信じるかどうかを迫られる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CTL.TRANSMISSION_RULE` — 伝達規則
- Primary Parent: `D09.CTL` — 制御規則形成
- Secondary: `D09.NOR.TABOOIZATION` — 禁忌化
- Status: `D` — Direct（転送命令と不転送禁止が内容に明示）

**判定根拠**

伝承は、将来の災厄を「一定人数へ同文を転送すれば回避できる」という制御規則へ変換する。同時に、連鎖を止めることを災厄を招く禁止行為として扱う。

**この伝承における現れ方**

受信者は、不幸という制御不能な未来を「送る／送らない」という操作可能な選択に置き換える。不転送は単なる不作為ではなく、してはいけない行為として禁忌化される。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.OBJ.INFORMATION_CONTENT` — 情報内容
- Primary Parent: `D10.OBJ` — 物体・情報・記号
- Secondary: なし
- Status: `I` — Inferred（人格主体を置かない因果構造から判定）

**判定根拠**

代表形では、特定の霊・神・人物よりも、手紙に記された規則とその連鎖を止めること自体に災厄効力があるように構成される。

**この伝承における現れ方**

「この情報を受け取り、指示に従わず連鎖を止める」という情報行為が未来の不幸へ接続される。因果源は複製可能な情報内容として置かれる。

**この伝承における現れ方**

### 2.3.3. D13: 作用機構

**この伝承における現れ方**

伝承内部では不転送が受信者の運勢へ負の作用を与える。同時に、その脅威を記した媒体が次の受信者へ渡ることで、同じ因果構造が再生産される。

### 2.3.4. D14: 帰結極性

**判定根拠**

**この伝承における現れ方**

受信者を動かす中心的圧力は利益獲得ではなく、悪い結果を避けたいという損失回避である。

### 2.3.5. D15: 帰結領域

**この伝承における現れ方**

具体的な被害内容を差し替えても、「運が悪くなる」という抽象的な負の帰結が転送命令を支える。

受信→期限付き選択→転送→次の受信者という構造が反復される。個々の版で期限が設定される場合も、Entry全体の主要時間構造は連鎖伝播である。

**この伝承における現れ方**

脅威を消去するのではなく、次の人物へ同じ条件を渡すことで自分の危険を回避しようとする。回避行動そのものが伝承を存続させる。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: なし
- Status: `I` — Inferred（全国化は研究整理に基づく）

**判定根拠**

後代研究は1970年前後の全国的流行を整理し、1977年には自治体広報が地域での実流通を記録している。複数地域へ拡散し得る郵便チェーンであり、特定共同体だけに閉じない。

**この伝承における現れ方**

送信相手を地域内部へ限定しないため、郵便網を通じて不特定多数へ連鎖的に広がる。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.NON.COMMON_KNOWLEDGE` — 一般共有

- Secondary: なし

**判定根拠**

文面の期限・人数・災厄条件は受信者へ開示され、成立に専門家や秘密保持者を必要としない。

**この伝承における現れ方**

誰でも同じ文面を複製できることが、脅威と転送規則の継続条件になっている。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A0` — 匿名・抽象
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（主張成立に特定実在対象を必要としない）

**判定根拠**

伝承は実在の郵便制度を利用し、実際に自治体対応も生じたが、「転送しなければ不幸」という主張自体は特定の事件、場所、企業、人物へ固定されない。公的資料の存在は流通史・社会効果の証拠であり、伝承内容の現実アンカーを自動的に高めない。

**この伝承における現れ方**

人数・期限・犠牲者事例・送信先を差し替えても、脅威型チェーンの核は成立するため、内容自体は匿名・移植可能である。
