# 1. 伝承エントリ基本情報

- `Entry_ID`: `101`
- `伝承エントリ名称`: 海外旅行で臓器を抜かれる
- `Macro_Category`: 犯罪・社会不安
- `Entry_Type`: FOAF
- `Version_Scope`: 海外旅行者が見知らぬ相手との接触後に意識を失い、覚醒後に身体痕跡・診察等から臓器を秘密裏に摘出されたと知る共有核。旅行先、浴槽・氷・メモ、摘出臓器等の異伝を混成しない。

# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（成立年代を安全に固定できる証拠不足）

**判定根拠**

`0101_00_contents.md` は、国際的なkidney theft型が1980年代以降に知られると整理する一方、単一の起源資料・最初期伝播資料は固定していない。後代の流行期から1980年代成立を逆算しない。

**この伝承における現れ方**

海外旅行、近代医療、違法臓器取引市場という現代的背景を持つFOAFであることは分かるが、共有核が最初に成立した年代は現Evidenceから決められない。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（最古確認媒体を特定できない）

**判定根拠**

国際的流通または日本語圏流通について、口承、新聞、チェーンメール、書籍等のうち何が最も早い確認媒体かを直接固定できていない。有名な国際都市伝説であることを最古媒体の推定へ置き換えない。

**この伝承における現れ方**

口承・メール・ネット・書籍へ適応しやすいが、流通起点は不明である。後代資料の存在と起源媒体を分離する。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Child / Value: `D03.PRT.BOOK` — 書籍
- Primary Parent: `D03.PRT` — 印刷・書簡
- Secondary: なし
- Status: `D` — Direct（2020年事典掲載を確認）

**判定根拠**

`0101_00_contents.md` は『日本の都市伝説大事典』（2020）を、日本で流通する代表形・類型を確認する主典拠として固定している。この書籍は受容者へ当該伝承を提示する実際の流通媒体として直接確認できる。口承・メール・ネット再話は存在が示唆されるが、今回のEvidenceでは具体的な流通資料を固定していないため付与しない。

**この伝承における現れ方**

少なくとも今回確認したVersion Scopeでは、旅行者が臓器を盗まれる国際型FOAFが都市伝説事典を通じて読者へ提示される。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.VAR.LOCALIZATION` — 地域化
- Primary Parent: `D04.VAR` — 再話・変異
- Secondary: `D04.STB.STABILIZED_CANON` — 定型化・カノン化
- Status: `I` — Inferred（国・細部の差し替えと共有核から判定）

**判定根拠**

旅行先の国、接触場所、覚醒場所、摘出臓器、氷・浴槽・メモ等の演出は再話ごとに変わる一方、「見知らぬ相手との接触→意識喪失→秘密の摘出→覚醒→臓器喪失確認」という骨格は安定している。

**この伝承における現れ方**

受容者にとって危険感のある海外都市へ舞台を置換しつつ、本人の認識外で身体内部が商品化されるという恐怖核が保持される。地域化と定型化が併存する。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.HRS.FOAF` — FOAF
- Primary Parent: `D05.HRS` — 伝聞叙述
- Secondary: なし
- Status: `D` — Direct（近接伝聞型が代表形）

**判定根拠**

代表形は「知人・旅行者に実際に起きた事件」のように近接伝聞されるFOAFである。

**この伝承における現れ方**

被害者を語り手本人ではなく数段離れた知人へ置くことで、詳細な検証を避けながら現実の犯罪警告らしさを保つ。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T2` — 近接伝聞事実
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct（FOAF形式により近接事実として提示）

**判定根拠**

単なる創作ではなく、身近な人間関係の先で実際に起きた事件として提示される。現実に違法臓器取引が存在することは、この定型筋書きの個別事実性とは別に扱う。

**この伝承における現れ方**

実在する臓器移植・犯罪市場の語彙と近接伝聞が重なり、「具体的な筋書きも本当に起こり得る」という真実性効果を生む。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ICT.HIDDEN_CRIMINAL_PRACTICE` — 隠れた犯罪慣行
- Primary Parent: `D07.ICT` — 対人・犯罪脅威
- Secondary: `D07.ICT.STRANGER_THREAT` — 見知らぬ他者の脅威
- Status: `D` — Direct（秘密の臓器摘出・売買が共有核）

**判定根拠**

この伝承が具体化する不確実性は、一般旅行者が知らないところで高度な外科処置を伴う臓器摘出・売買の犯罪実務が存在し得るという恐怖である。見知らぬ他者への不信も重要だが、コード体系上、臓器売買等を例示する `HIDDEN_CRIMINAL_PRACTICE` がより直接的に適合する。

**この伝承における現れ方**

旅行先の表面上は通常の社交・飲食に見えても、その背後では人体を商品として扱う犯罪ネットワークが動いているという世界モデルへ変換される。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.STY.FOAF_REPORT` — 近接伝聞
- Primary Parent: `D08.STY` — 社会的証言
- Secondary: `D08.TRC.PHYSICAL_TRACE` — 物的痕跡
- Status: `I` — Inferred（受容者側と物語内被害者側の契機を区別）

**判定根拠**

受容者にとって危険が問題化される主契機は「知人の旅行者が被害に遭った」というFOAF報告である。物語内部では、覚醒後の手術痕・痛み等の身体痕跡が、被害者自身に何が起きたかを問題化する補助手掛かりになる。

**この伝承における現れ方**

聞き手は近接伝聞から秘密犯罪を知り、被害者は身体の傷から意識喪失中の出来事を逆算する。社会的証言と物的痕跡が二段階で「見えない犯罪」を可視化する。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.SSI.HIDDEN_STRUCTURE` — 隠れた構造仮定
- Primary Parent: `D09.SSI` — 社会構造化
- Secondary: `D09.CAU.HIDDEN_CAUSE` — 隠れた原因化
- Status: `I` — Inferred（犯罪ネットワーク仮定による説明構造から判定）

**判定根拠**

被害者の記憶空白、手術痕、臓器喪失という断片を、単独の偶発事件ではなく、摘出・移送・売買を秘密裏に遂行する犯罪ネットワークの存在で統合する。不可解な痕跡を「臓器泥棒」と名付ける以上に、表面下の社会構造を仮定する操作が中心である。

**この伝承における現れ方**

一旅行者への薬物投与と手術が、需要側・施術者・仲介者等を含む見えない市場の存在へ接続されることで、空白時間の出来事が理解可能になる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.HUM.INFORMAL_GROUP` — 非制度的集団・共同体
- Primary Parent: `D10.HUM` — 人間・社会主体
- Secondary: `D10.HUM.INDIVIDUAL_HUMAN` — 個人
- Status: `I` — Inferred（複数役割を要する犯罪ネットワーク型を中心に判定）

**判定根拠**

薬物投与、外科的摘出、臓器売買という共有核は、接触者一人だけより複数の人間が関与する非制度的犯罪ネットワークとして説明される型に適合する。一部再話で接触者個人が前面に出るためSecondaryに個人を残す。

**この伝承における現れ方**

旅行者へ近づく人物は入口にすぎず、その背後に施術・流通を可能にする集団が存在するという社会的因果源が置かれる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.SOC.MEET_INTERACT` — 会う・会話する
- Primary Parent: `D11.SOC` — 社会関係・取引
- Secondary: なし
- Status: `D` — Direct（見知らぬ人物との接触が共有核）

**判定根拠**

代表形では旅行者がバー・飲食店等で見知らぬ人物と接触し、飲食を伴う交流を持つことが犯罪への入口になる。薬物摂取は重要だが、現行D11体系に摂取専用Childがなく、接触場面をPrimary条件として記録する。

**この伝承における現れ方**

軽い社交を受け入れるだけで、旅行者は外見から識別できない犯罪主体の因果系へ組み込まれる。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.OTH.VICTIM_TARGET` — 特定被害者
- Primary Parent: `D12.OTH` — 他者個人
- Secondary: なし
- Status: `D` — Direct（旅行者が犯罪被害対象として選ばれる）

**判定根拠**

加害主体から見た作用対象は、薬物で無力化され臓器を摘出される旅行者である。物語の焦点人物であることより、身体を商品化される被害対象としての役割を優先する。

**この伝承における現れ方**

旅行者は財布や荷物ではなく、自身の身体内部を価値ある資源として狙われる対象になる。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.PHY.PHYSICAL_ATTACK` — 物理攻撃
- Primary Parent: `D13.PHY` — 身体・物質作用
- Secondary: `D13.SOC.COERCE_CONFINE` — 強制・監禁
- Status: `D` — Direct（薬物無力化・外科摘出が共有核）

**判定根拠**

被害者を薬物で無力化し、意識のない間に身体を切開して臓器を摘出する直接的身体侵襲が中心である。移送・拘束を伴う型もあるため、社会的強制・監禁をSecondaryとする。

**この伝承における現れ方**

本人が認識・抵抗できない状態で身体へ外科的操作が加えられ、身体内部の一部が取り去られる。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct（臓器喪失・生命危険が共有核）

**判定根拠**

臓器喪失、重大な身体障害、生命危険という全面的に負の帰結である。

**この伝承における現れ方**

通常の旅行・社交が、本人の認識を挟まず重大な身体損失へ反転する。利益や救済は主要帰結に含まれない。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.BOD.SEVERE_INJURY` — 重傷・障害
- Primary Parent: `D15.BOD` — 身体・健康
- Secondary: なし
- Status: `D` — Direct（臓器喪失が明示的終端）

**判定根拠**

明示された帰結は臓器の喪失と手術痕、重大な身体障害である。生命危険は暗示されるが、死亡は共有核として明示されていないためSecondaryから外す。

**この伝承における現れ方**

金銭ではなく身体機能の一部を永久に失うことが恐怖の終端となる。生存して目覚めることで、被害者自身が喪失を認識する構造が維持される。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.EVT.SEQUENTIAL_EPISODE` — エピソード内段階進行
- Primary Parent: `D16.EVT` — 単一エピソード・事象内
- Secondary: なし
- Status: `D` — Direct（接触から被害確認まで段階進行が明示）

**判定根拠**

接触→薬物投与→意識喪失→秘密の摘出→覚醒→身体痕跡確認→診察による被害確定、という複数段階が一続きのエピソード内で進む。旧レビュー用メモの `D16:U` より、現在の高密度Evidenceでは時間構造を直接再構成できる。

**この伝承における現れ方**

被害者の主観では中間過程が欠落するが、物語は覚醒後の痕跡からその空白を遡及的に埋め、順序立った犯罪因果を完成させる。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.AVO.DO_NOT_ENGAGE` — 接触回避
- Primary Parent: `D17.AVO` — 回避・逃走
- Secondary: `D17.RIT.MEDICAL_PROFESSIONAL` — 医療介入
- Status: `I` — Inferred（予防警告と被害後対応を分離して判定）

**判定根拠**

伝承は見知らぬ相手との不用意な接触・飲食物受領を避ける警告へ接続する。一部異伝では覚醒後のメモ等により直ちに医療機関へ行くことが求められ、被害後の生命・健康管理には専門医療介入が用いられる。

**この伝承における現れ方**

事前には因果系へ入らないことが予防となり、すでに臓器を摘出された後は医療者へ接続することが損害制御の手段になる。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（確認できる作用範囲から判定）

**判定根拠**

臓器摘出という因果は物語内部の旅行者に作用する。話を聞いただけで受容者が同じ身体被害を受ける構造ではなく、このFOAFの流通による制度・市場等の現実結果も今回のEvidenceでは固定していない。

**この伝承における現れ方**

受容者の旅行時警戒を強め得るが、伝承内容上の直接因果は犯罪者と被害者のエピソード内にある。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.TRANSNATIONAL` — 国際・越境流通
- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Status: `I` — Inferred（国際型としての整理と日本での採録から判定）

**判定根拠**

`0101_00_contents.md` は1980年代以降に国際的なkidney theft型として知られ、日本でも都市伝説として流通したと整理している。複数国・言語圏へ舞台を差し替えて流通する性格をPrimaryとし、日本国内での広域共有をSecondaryとする。

**この伝承における現れ方**

臓器泥棒の筋書きは国境を越えて移植され、各地の受容者が「外国旅行先」を別の都市・国へ差し替えて再話できる。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.ORG.PERPETRATOR_CRIMINAL` — 加害者・犯罪者
- Primary Parent: `D20.ORG` — 組織・加害主体
- Secondary: なし
- Status: `D` — Direct（意識喪失中の過程を知る側は加害者）

**判定根拠**

被害者は意識喪失中の摘出過程・移送・取引先を知らず、犯罪の実態を把握する側は加害者・ネットワークに偏る。医療者は被害結果を後から確認できても、犯罪過程全体の内部情報保持者ではない。

**この伝承における現れ方**

被害者は覚醒後の傷と欠損しか知ることができず、何が行われたかを痕跡から推測する。情報格差そのものが不可視犯罪の恐怖を強める。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct（旅行・医療・犯罪市場を用いるが固有事件へ固定されない）

**判定根拠**

海外旅行、ホテル、医療処置、臓器移植・違法取引等の現実的背景を使う一方、特定の検証済み被害事件、組織、施設へ固定されない。現実の違法臓器取引の存在を、このFOAFの個別事実性へ遡及しない。

**この伝承における現れ方**

現実社会に存在する旅行・医療・犯罪市場の語彙が強い現実感を与えるが、被害者・場所・摘出臓器等は再話ごとに変わるため一般的背景として機能する。
