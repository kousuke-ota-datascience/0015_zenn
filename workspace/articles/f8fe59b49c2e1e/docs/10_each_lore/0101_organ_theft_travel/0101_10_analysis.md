# 1. 伝承エントリ基本情報

- `Entry_ID`: `101`
- `伝承エントリ名称`: 海外旅行で臓器を抜かれる
- `Macro_Category`: 犯罪・社会不安
- `Entry_Type`: FOAF
- `Version_Scope`: 海外旅行者が見知らぬ相手との接触後に意識を失い、覚醒後に臓器を秘密裏に摘出されたと知る共有核。浴槽・メモ・臓器種類等の異伝を混成しない
- `Evidence_Rank`: `B`
- `主な成立・流通期`: 1980年代〜
- `ネット発祥`: No

# 2. 分析概念次元

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代
- Value: `D01.G4` — 1980年代
- Status: `I`

**判定根拠**
国際的なkidney theft型が1980年代以降に流通したとされ、パイロットではこの成立帯を採用した。単一の起源資料は未固定である。

**この伝承における現れ方**
海外旅行の一般化と違法臓器取引への社会的不安を組み合わせた、現代的な犯罪FOAFとして現れる。身体内部まで商品化されるという近代医療・市場社会特有の恐怖を持つ。

### 2.1.2. D02: 最古確認流通媒体
- Primary: なし
- Secondary: なし
- Status: `U`

**判定根拠**
日本語圏または国際的流通の最初期媒体を直接示す証拠が不足しているため、最古媒体を推定しない。

**この伝承における現れ方**
口承、メール、都市伝説集など多媒体に適応するが、「どこから始まったか」は話の有名さだけでは決められない。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）
- Primary Child: `D03.ORL.PEER_ORAL` — 友人・仲間内伝承
- Primary Parent: `D03.ORL`
- Secondary: なし
- Status: `I`

**判定根拠**
知人・旅行者の実体験として伝聞されるFOAF性から、パイロットでは仲間内口承をPrimaryとした。

**この伝承における現れ方**
「知り合いが海外で被害に遭った」という距離で語られることで、遠い犯罪市場の話が自分の旅行リスクへ近づけられる。

### 2.1.4. D04: 生成・変容パターン
- Primary Child: `D04.STB.STABILIZED_CANON` — 定型化・カノン化
- Primary Parent: `D04.STB`
- Secondary: なし
- Status: `I`

**判定根拠**
旅行先や臓器の種類が変わっても、接触→意識喪失→覚醒→手術痕→臓器喪失確認という筋が安定するため、定型化を保持する。

**この伝承における現れ方**
浴槽、氷、メモ等は差し替え可能な演出で、本人の認識を飛び越えて身体内部が盗まれるという核が再話を統合する。

### 2.1.5. D05: 提示形式
- Primary Child: `D05.HRS.FOAF` — FOAF
- Primary Parent: `D05.HRS`
- Secondary: なし
- Status: `D`

**判定根拠**
代表形は知人・旅行者に起きた実話として近接伝聞されるためFOAFを保持する。

**この伝承における現れ方**
被害者を語り手本人ではなく「友人の友人」程度へ置くことで、詳細な検証を避けながら現実の犯罪警告らしく提示できる。

### 2.1.6. D06: 真実性提示
- Value: `D06.T2` — 近接伝聞事実
- Status: `D`

**判定根拠**
単なる創作ではなく、近い人間関係の先で実際に起きた事件として提示される。

**この伝承における現れ方**
違法臓器取引という現実問題の存在とFOAF形式が重なり、「筋書きも本当にありそうだ」という真実性効果を生む。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象
- Primary Child: `D07.ICT.STRANGER_THREAT` — 見知らぬ他者の脅威
- Primary Parent: `D07.ICT`
- Secondary: なし
- Status: `I`

**判定根拠**
海外で意図不明の他者に接触する危険を中心に意味形成するため、このコードを保持する。

**この伝承における現れ方**
旅行先では誰を信頼してよいか分からないという不確実性が、薬物を使って身体を奪う犯罪者という具体的脅威へ変換される。

### 2.2.2. D08: 意味形成契機
- Primary Child: `D08.STY.FOAF_REPORT` — 近接伝聞
- Primary Parent: `D08.STY`
- Secondary: なし
- Status: `D`

**判定根拠**
危険の手掛かりが統計・公式発表ではなく、知人周辺の被害報告として提示されるため、このコードを保持する。

**この伝承における現れ方**
「旅行者が実際に臓器を盗まれた」という証言形式そのものが、見知らぬ相手との接触を危険として再評価させる。

### 2.2.3. D09: 意味付与操作
- Primary Child: `D09.CAT.NAMING` — 命名
- Primary Parent: `D09.CAT`
- Secondary: なし
- Status: `I`

**判定根拠**
不可解な手術痕・身体異常を「臓器泥棒」「臓器売買組織」の犯行としてカテゴリー化するため、このコードを保持する。

**この伝承における現れ方**
記憶の空白と身体の傷が、犯罪ネットワークという名前を与えられることで一つの因果モデルへまとめられる。

### 2.2.4. D10: 因果源存在論
- Primary Child: `D10.HUM.INDIVIDUAL_HUMAN` — 個人
- Primary Parent: `D10.HUM`
- Secondary: なし
- Status: `I`

**判定根拠**
原因は超自然存在ではなく、意図的に薬物投与・摘出を行う人間の加害者として置かれるため、このコードを保持する。

**この伝承における現れ方**
身体内部の喪失は怪異ではなく、人間が利益目的で他者を資源化する行為として説明される。恐怖の原因は社会の不可視な犯罪主体である。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件
- Primary Child: `D11.SOC.MEET_INTERACT` — 会う・会話する
- Primary Parent: `D11.SOC`
- Secondary: なし
- Status: `I`

**判定根拠**
見知らぬ人物との接触・飲食等が被害の入口となるため、社会的相互作用を保持する。

**この伝承における現れ方**
旅行者が軽い社交を受け入れるだけで犯罪者の因果系へ入る。危険人物を外見から識別できないことが警告性を高める。

### 2.3.2. D12: 作用対象
- Primary Child: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC`
- Secondary: なし
- Status: `I`

**判定根拠**
臓器を摘出される旅行者本人が直接作用対象である。

**この伝承における現れ方**
旅行者は財産ではなく自身の身体そのものを奪われる被害者となる。受容者が自己投影しやすい一般旅行者である点が重要である。

### 2.3.3. D13: 作用機構
- Primary Child: `D13.PHY.PHYSICAL_ATTACK` — 物理攻撃
- Primary Parent: `D13.PHY`
- Secondary: なし
- Status: `I`

**判定根拠**
薬物による無力化と外科的臓器摘出という直接的身体侵襲が中心であるため、物理攻撃を保持する。

**この伝承における現れ方**
被害者の意識を遮断した状態で身体を切開し臓器を取り出す、という不可逆的な物質作用として危険が描かれる。

### 2.3.4. D14: 帰結極性
- Value: `D14.NEG` — 負
- Status: `I`

**判定根拠**
臓器喪失・生命危険という明確に負の結果である。

**この伝承における現れ方**
楽しい旅行が、一度の社交接触から重大な身体損失へ反転する。救済や利益は中心にない。

### 2.3.5. D15: 帰結領域
- Primary Child: `D15.BOD.SEVERE_INJURY` — 重傷・障害
- Primary Parent: `D15.BOD`
- Secondary 1 Child: `D15.BOD.DEATH` — 死亡
- Secondary 1 Parent: `D15.BOD`
- Status: `I`

**判定根拠**
主要帰結は臓器喪失による重大な身体障害で、異伝上は死亡可能性も伴うためこの組み合わせを保持する。

**この伝承における現れ方**
金銭損失ではなく身体機能の一部を永久に失うことが恐怖の終端となる。生命維持そのものが危うくなる。

### 2.3.6. D16: 因果時間構造
- Primary Child: `D16.EVT.SEQUENTIAL_EPISODE` — エピソード内段階進行
- Primary Parent: `D16.EVT`
- Secondary: なし
- Status: `I`

**判定根拠**
接触→薬物→意識喪失→摘出→覚醒→被害確認という段階が一つのエピソード内で順次進むため、このコードを保持する。

**この伝承における現れ方**
被害者の認識では途中が丸ごと欠落するが、物語構造上は明確な段階進行を持ち、覚醒後に空白時間の因果が再構成される。

### 2.3.7. D17: 回避・制御方式
- Primary Child: `D17.AVO.DO_NOT_ENGAGE` — 接触回避
- Primary Parent: `D17.AVO`
- Secondary: なし
- Status: `I`

**判定根拠**
見知らぬ相手との不用意な接触や飲食物受領を避ける警告として機能するため、このコードを保持する。

**この伝承における現れ方**
犯罪組織を倒す方法ではなく、因果系へ入らないことが唯一の予防として示唆される。旅行時の対人警戒へ行動を誘導する。

### 2.3.8. D18: 作用レイヤー
- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `0`
- Status: `I`

**判定根拠**
身体被害は伝承内の旅行者に作用するもので、聞いただけで同じ身体作用を受ける構造ではない。

**この伝承における現れ方**
受容者の旅行行動には影響し得るが、物語上の臓器摘出因果は被害者のエピソード内に限定される。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲
- Primary Child: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS`
- Secondary: なし
- Status: `D`

**判定根拠**
日本の都市伝説事典に広域型として採録され、国際的にも類型が知られるため、全国的大衆を保持する。

**この伝承における現れ方**
旅行先を差し替えて各地で再話でき、特定共同体だけの秘密ではなく一般旅行者への警告として広がる。

### 2.4.2. D20: 特権情報保持者
- Primary Child: `D20.ORG.PERPETRATOR_CRIMINAL` — 加害者・犯罪者
- Primary Parent: `D20.ORG`
- Secondary: なし
- Status: `I`

**判定根拠**
意識喪失中に何が行われたか、犯罪ネットワークの実態を知る側として加害者が置かれるため、このコードを保持する。

**この伝承における現れ方**
被害者は覚醒後の痕跡しか知らず、摘出過程や取引先を把握できない。真相情報が加害側へ偏在すること自体が恐怖を強める。

### 2.4.3. D21: 現実アンカー
- Value: `D21.A1` — 一般的現実背景
- Status: `I`

**判定根拠**
海外旅行、ホテル、医療処置、違法取引等の現実的背景を持つが、特定の検証済み事件へ固定されないためA1を保持する。

**この伝承における現れ方**
現実に存在する旅行・医療・犯罪市場の語彙を使うことで本当らしさを得る一方、被害者や場所は再話ごとに動く。
