地域内部の禁足知識が、江戸後期には名所案内・地誌系の印刷物へ入り、地域外の読者にも受容可能な伝承として流通していたことが確認できる。

**この伝承における現れ方**

「なぜ入ってはいけないのか」という一点に対して、宗教・軍事・方術・土地制度・著名人逸話が順次付加される。伝承は一つの起源説へ収束せず、禁忌を説明する複数モデルを保持したまま長期継承される。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.RUL.TABOO` — 禁忌

- Status: `D` — Direct（「入るな」という禁足規則と由来物語が資料上明示）

**判定根拠**

最小共有核は「八幡不知森へ入ってはいけない」という禁止規則であり、入れば出られない・祟りに遭うという警告が伴う。徳川光圀侵入譚や複数の由来説は、この禁忌を物語・解説で補強する。

**この伝承における現れ方**

完全な事件物語を知らなくても「入るな」という一文で伝承が機能する一方、禁を破った光圀へ白髪の老人が警告する物語が、禁忌の妥当性を具体化する。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T3` — 共同体既知事実
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（地域で既知の禁足地として提示される）

**判定根拠**

江戸期資料では地域住民が立入を禁じる場所として記述され、現代の公的地域案内でも「昔から知られる伝承」として紹介される。個人の一回的体験談ではなく、地域で継承されてきた既知の場所知識として本当らしさが提示される。

**この伝承における現れ方**

受容者は「誰か一人が見た怪異」ではなく、「ここは昔から入ってはいけない場所だ」という共同体的既知性を通じて禁忌を受け取る。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.PSE.DANGEROUS_PLACE` — 危険・怪異場所
- Primary Parent: `D07.PSE` — 場所・空間・環境
- Secondary: `D07.PSE.SPATIAL_ROUTE_ANOMALY` — 空間・経路異常
- Status: `D` — Direct（危険な禁足地と「入ると出られない」が共有核）

**判定根拠**

説明されるべき不可解さは、市街地にある小規模な竹藪が、なぜ「入ってはいけない危険な場所」として長期に区別されるのかという点にある。代表形では、見た目の狭さに反して内部へ入ると出られないという空間異常も伴う。

**この伝承における現れ方**

日常空間のすぐ隣にある小さな藪が、境界を越えた瞬間に通常空間とは異なる危険領域へ変わる。物理的な大きさと「脱出できない」という語りの落差が怪異性を生む。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.INHERITED_SAYING` — 既存の言い伝え
- Primary Parent: `D08.CLM` — 命題先行
- Secondary: `D08.HIS.PLACE_NAME_RUIN` — 地名・遺構・記念物
- Status: `D` — Direct（禁足の言い伝えと現地の名称・石碑・祠が確認できる）

**判定根拠**

意味形成は、まず「昔から入ってはいけない」という言い伝えによって開始される。同時に、「八幡不知森」という名称、1857年の石碑、鳥居・祠、現存する竹藪が、言い伝えを具体地点へ固定する観察可能な手掛かりになる。

**この伝承における現れ方**

受容者は先に禁忌を知り、現地の名・標識・境界物を見ることで、通常の竹藪を「由来のある禁足地」として再認識する。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.NOR.TABOOIZATION` — 禁忌化
- Primary Parent: `D09.NOR` — 価値・規範化
- Secondary: `D09.HST.HISTORICAL_ANCHOR` — 歴史接続
- Status: `I` — Inferred（立入禁止の規範化と複数の歴史由来化を確認）

**判定根拠**

伝承は、通常なら立ち入れる小空間を「越えてはいけない境界」として禁忌化する。さらに、将門、日本武尊、葛飾八幡宮、光圀等の歴史・宗教的要素を接続し、禁忌が存在する理由を説明可能にする。

**この伝承における現れ方**

単なる私有地・未利用地ではなく、「歴史的・宗教的理由があるため触れてはならない場所」として意味が与えられ、立入回避が規範化される。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SPC.SPECIFIC_PLACE` — 特定場所
- Primary Parent: `D10.SPC` — 場所・時空
- Secondary: `D10.SUP.IMPERSONAL_CURSE` — 非人格的呪力
- Status: `I` — Inferred（場所固有の効力と祟り型が共有される）

**判定根拠**

代表形では、八幡不知森という場所そのものが通常空間と異なる効力を持つとされる。祟り型では特定の幽霊を必須とせず、禁を破った者へ災いが及ぶ非人格的な祟りとして説明される。光圀譚の白髪の老人は著名な物語異伝だが、共有核の唯一の因果主体ではない。

**この伝承における現れ方**

危険は「ある人物に狙われる」ことではなく、「この境界を越えること」そのものに付着している。場所と祟りが一体化した禁足地モデルである。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.MOV.ENTER_PASS_CROSS` — 入る・通る・越える
- Primary Parent: `D11.MOV` — 移動・空間進入
- Secondary: なし
- Status: `D` — Direct（内部への立入が禁忌違反条件）

**判定根拠**

藪の外から見ることではなく、境界を越えて内部へ立ち入ることが、脱出不能・祟りの因果系へ入る明示条件である。

**この伝承における現れ方**

鳥居・祠・竹藪の外側は日常空間だが、内部へ一歩入ることが「してはいけない行為」とされ、そこから怪異作用が始まる。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC` — 焦点人物
- Secondary: なし
- Status: `D` — Direct（禁を破って入る人物が作用対象）

**判定根拠**

代表形では「中へ入った者」が脱出不能・祟りの作用を受ける。光圀侵入譚ではその役割が徳川光圀という固有人物へ具体化される。

**この伝承における現れ方**

作用対象は藪そのものではなく、禁足境界を越えた人間である。受容者は自分も入れば同じ危険へ入ると理解できる。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.RST.SPATIAL_DISTORTION` — 空間異常
- Primary Parent: `D13.RST` — 現実・時空作用
- Secondary: `D13.FAT.CURSE_MISFORTUNE` — 呪詛・不運付与
- Status: `D` — Direct（脱出不能型と祟り型が資料上確認される）

**判定根拠**

共有核には、小規模な藪へ入った者が「出られなくなる」という空間作用と、禁忌違反に対して「祟りがある」という吉凶作用が併存する。どちらも歴史的・現代的解説資料で伝承内容として確認できる。

**この伝承における現れ方**

場所内部では通常の距離・出口関係が機能しなくなったかのように扱われ、別系統では禁忌違反そのものが災いを招くとされる。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct（脱出不能・祟りはいずれも負）

**判定根拠**

代表的な帰結は、戻れない、迷う、祟られる、警告を受けるといった負の結果であり、禁を破ることによる利益型は共有核にない。

**この伝承における現れ方**

立入は「試す価値のある冒険」ではなく、避けるべき危険な選択として提示される。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.OPP.LUCK_MISFORTUNE` — 幸運・不運
- Primary Parent: `D15.OPP` — 吉凶・機会
- Secondary: `D15.LIF.DISAPPEARANCE` — 失踪・消失
- Status: `I` — Inferred（祟り型をPrimary、非帰還型を独立Secondaryとして統合）

**判定根拠**

「祟りがある」という型では最終結果の具体種別が固定されず、広い不運・災厄として語られる。一方、「入ると出られない」という型は外部から見た非帰還・失踪へ接続するため、独立したSecondaryとして保持する。すべての型で永久失踪や死亡が明示されるわけではないため、`DISAPPEARANCE` をPrimaryには置かない。

**この伝承における現れ方**

禁を破った者には不特定の災いが予告され、より強い型では共同体へ戻れない存在になる。帰結の具体性には異伝差がある。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.STA.STATIC_RULE` — 静的規則
- Primary Parent: `D16.STA` — 無時間的・静的関係
- Secondary: なし
- Status: `I` — Inferred（禁足地の条件規則として判定）

**判定根拠**

伝承の核は「八幡不知森へ入るなら、脱出不能・祟りが生じる」という恒常的条件規則であり、特定の待ち時間・進行段階・周期が意味上重要ではない。場所が長く危険視されること自体ではなく、発動条件と帰結の時間編成を測るため、旧 `ENDURING_CONDITION` より `STATIC_RULE` が適合する。

**この伝承における現れ方**

何月何日だけ危険になるのでも、一定時間後に祟りが発現するのでもない。「入るな」という禁忌規則が常時成立していることが中心である。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.RUL.OBEY_TABOO` — 禁忌遵守
- Primary Parent: `D17.RUL` — 規則遵守
- Secondary: なし
- Status: `D` — Direct（立入禁止を守ることが明示的回避）

**判定根拠**

最も一貫した回避法は、八幡不知森へ立ち入らないことである。解除儀礼・正答・供物等を必要とする共有核は確認できない。

**この伝承における現れ方**

危険を解決するのではなく、境界を越えないことで因果系へ入らない。伝承の社会的機能と回避法が同じ「立入禁止」に集約される。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=1`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（伝承内因果に加え、歴史資料に現実の立入回避行動が記録される）

**判定根拠**

L1では、立入者が脱出不能・祟りを受けるという伝承内因果が明示される。L2は、伝承を聞く・読むこと自体が超自然作用の条件にはならないため0とする。L3については、『江戸名所図会』系の記述で地域住民が祟りを理由に立入を禁じていたとされ、伝承・禁忌が現実の場所利用行動へ接続した証拠があるため1とする。

**この伝承における現れ方**

怪異因果は物語内部にとどまらず、現実の「入らない」という行動規範と場所境界の維持にも接続する。ただし、現在の鳥居・祠・土地管理のすべてが伝承だけを原因として成立したとは断定しない。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.LOC.LOCAL_TRADITION` — 地域伝承圏
- Primary Parent: `D19.LOC` — 地域共同体
- Secondary: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Status: `I` — Inferred（地域伝承を基盤としつつ印刷・図像で広域化）

**判定根拠**

伝承の場所・禁忌・由来は市川市八幡の地域史と不可分であり、地域伝承圏が基盤である。一方、江戸期の名所図会や明治期の錦絵、現代Webを通じて地域外にも広く紹介されているため、全国的大衆をSecondaryとする。

**この伝承における現れ方**

作用地点は極めて局所的だが、話そのものは印刷文化・図像・観光地域案内を通じて外部へ流通し、「八幡の藪知らず」という名称が全国的にも認識可能になっている。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.UNK.NO_ONE_KNOWS` — 誰も知らない
- Primary Parent: `D20.UNK` — 到達不能・不明
- Secondary: なし
- Status: `I` — Inferred（複数の由来説が併存し決定的真相保持者がいない）

**判定根拠**

現在確認できる資料では、禁足の真の起源について神聖地説、将門説、八門遁甲説、日本武尊説、入会地説等が並存し、どれか一つを真相として保持する主体は固定できない。地元住民・伝承知識者は諸説を知り得るが、「真相を独占する主体」とは言えない。

**この伝承における現れ方**

伝承は「地元だけが秘密を知る」構造より、古くからの禁忌の理由が複数説へ分岐し、真相が開かれたまま継承される構造を持つ。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A2` — 具体的実在対象
- Primary Parent: なし
- Secondary: なし

**判定根拠**

八幡不知森は千葉県市川市八幡に実在し、現地の竹藪、鳥居、祠、1857年の石碑等によって具体的に特定できる。由来異伝には歴史人物が組み込まれるが、共有核の成立に特定史実の真偽を必須としないため、Version Scope全体としては `A2` を採る。

**この伝承における現れ方**

「どこかの入ってはいけない森」ではなく、市川市八幡の特定地点であることが伝承の識別条件である。歴史説はこの実在地点へ後から意味を重ねる。
