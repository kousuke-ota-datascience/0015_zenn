# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: `D01.G0` — 前近代（〜1867）
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

市川市公式が江戸期の地誌・紀行等に現れる伝承として説明しており、パイロットでは前近代成立帯を推定した。

**この伝承における現れ方**

八幡の一画を禁足地として扱う伝承は、現代のネット怪談として新規生成されたのではなく、近世以前の地域伝承・地誌記述と結び付くものとして位置付けられる。task 1で最古原資料を追加固定するまでは `I` を保持する。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（証拠不足）

**判定根拠**

パイロット時点の典拠では、最古の口承記録・地誌・図像等のうちどれを最古流通媒体として固定すべきかを一意に判定する証拠が不足している。

**この伝承における現れ方**

古い伝承であることと、最古確認媒体が口承であることは同義ではない。現段階では媒体を推測で埋めず `U` を保持する。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Child / Value: `D03.ORL.LOCAL_ORAL` — 地域口承
- Primary Parent: `D03.ORL` — 口承・限定共同体
- Secondary: `D03.WEB.WEBSITE` — Webサイト（Parent: `D03.WEB` — オープンWeb・ソーシャル）
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

パイロットは地域伝承としての継承をPrimary、公的Webサイトによる現代再提示をSecondaryとして扱った。

**この伝承における現れ方**

禁足地の言い伝えが地域共同体の知識として継承され、現代には自治体Webサイト等から広域の受容者へ再提示されるという二層の流通像を持つ。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.MIG.DIGITAL_REAMPLIFICATION` — ネット再増幅
- Primary Parent: `D04.MIG` — 媒体移行
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

古い地域伝承が現代Web上で再提示・再発見されるというパイロット判断を保持する。

**この伝承における現れ方**

前近代からの禁足地伝承が、公的サイトや後代ネット記事を通じて現代の「ミステリースポット」文脈にも接続し得る。変容の中心をネット再増幅とする妥当性はtask 3で再測定する。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.RUL.TABOO` — 禁忌
- Primary Parent: `D05.RUL` — 規則・警告形式
- Secondary: なし

**判定根拠**

代表形は「藪へ入ってはいけない」という禁止規則として提示されるため、この値を保持する。

**この伝承における現れ方**

完全な事件物語を知らなくても、「入ると出られない／祟られるので立ち入るな」という警告だけで伝承が機能する。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T3` — 共同体既知事実
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

地域で古くから知られる禁足地として共有されるというパイロット判断を保持する。

**この伝承における現れ方**

個人の一回的証言より、「昔からここには入らない」という共同体的な既知性が本当らしさを支える。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.PSE.DANGEROUS_PLACE` — 危険・怪異場所
- Primary Parent: `D07.PSE` — 場所・空間・環境
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

実在する小規模な藪が、なぜ立入不能・危険な場所として扱われるのかが伝承の中心にある。

**この伝承における現れ方**

通常なら容易に通過できそうな小さな空間が、入れば戻れない・祟られる特別な領域として意味付けされる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.INHERITED_SAYING` — 既存の言い伝え
- Primary Parent: `D08.CLM` — 命題先行
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

個々の体験前から「入ってはいけない」という言い伝えが存在し、それ自体が場所を問題化する。

**この伝承における現れ方**

受容者はまず禁忌を教えられ、その後に場所を見るため、藪の普通の外観も危険な境界として認識される。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.NOR.GOOD_BAD_VALUATION` — 吉凶・善悪評価
- Primary Parent: `D09.NOR` — 価値・規範化
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

立入行為を「してはいけない悪い行為」として規範化するパイロット判定を保持する。

**この伝承における現れ方**

物理的に通行可能かどうかではなく、立ち入ること自体が禁忌違反として評価され、場所利用の可否が道徳・吉凶の問題へ変換される。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SPC.SPECIFIC_PLACE` — 特定場所
- Primary Parent: `D10.SPC` — 場所・時空
- Secondary: `D10.SUP.IMPERSONAL_CURSE` — 非人格的呪力（Parent: `D10.SUP` — 超自然主体・力）
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

八幡不知森という特定場所自体と、そこに付着する非人格的な祟りを因果源とするパイロット判定を保持する。

**この伝承における現れ方**

誰か一人の幽霊に襲われるというより、藪の内部へ入ること自体が危険であり、場所そのものが通常空間と異なる効力を持つとされる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.MOV.ENTER_PASS_CROSS` — 入る・通る・越える
- Primary Parent: `D11.MOV` — 移動・空間進入
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

藪の内部へ立ち入ることが禁忌違反と怪異発動の入口になる。

**この伝承における現れ方**

外から見るだけではなく、境界を越えて内部へ入る行為によって、迷失・祟りの因果系へ入るとされる。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC` — 焦点人物
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

禁を破って立ち入る人物が、迷失・祟りの作用を受ける主体として置かれる。

**この伝承における現れ方**

徳川光圀侵入譚のように具体人物が与えられる場合もあるが、代表形では「中へ入った者」一般が作用対象になる。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.RST.SPATIAL_DISTORTION` — 空間異常
- Primary Parent: `D13.RST` — 現実・時空作用
- Secondary: `D13.FAT.CURSE_MISFORTUNE` — 呪詛・不運付与（Parent: `D13.FAT` — 運命・吉凶作用）
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

小さな藪にもかかわらず出られなくなるという空間異常と、禁忌違反への祟りを主要作用とするパイロット判定を保持する。

**この伝承における現れ方**

実在空間の物理的広さと「戻れない」という伝承上の性質が矛盾することで、場所が通常空間とは異なるものとして表現される。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

迷失・脱出不能・祟りという帰結は負である。

**この伝承における現れ方**

禁忌を破ることで利益を得る中心Versionはなく、立入は一貫して危険な選択として語られる。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.LIF.DISAPPEARANCE` — 失踪・消失
- Primary Parent: `D15.LIF` — 人生・存在・同一性
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

「入ると出られない」という代表形を、立入者の失踪・消失へ結び付けるパイロット判定を保持する。

**この伝承における現れ方**

外部から見れば小さな藪へ入った人物が戻らないという形で、存在位置が共同体から失われる。ただし全異伝で死亡・永続失踪が明示されるわけではないため、task 3で再測定対象となり得る。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.STA.ENDURING_CONDITION` — 持続状態
- Primary Parent: `D16.STA` — 無時間的・静的関係
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

藪が恒常的に禁足・危険な場所として存在し続けるというパイロット判定を保持する。

**この伝承における現れ方**

特定の一夜だけ危険になるのではなく、「いつ入っても禁忌」という持続的な場所属性として語られる。パイロット末尾メモには `D16:U` と残っており本文値と矛盾するため、task 3およびExcel正本照合で解消する。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.AVO.DO_NOT_ENGAGE` — 接触回避
- Primary Parent: `D17.AVO` — 回避・逃走
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

最も明確な対処は藪へ立ち入らないことである。

**この伝承における現れ方**

危険の解除法を学ぶより、境界を越えないという単純な回避規則が共同体に共有される。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

パイロットは迷失・祟りという伝承内因果をL1として採用し、受容者行動・社会現実効果を0とした。

**この伝承における現れ方**

L1では立入者が怪異作用を受ける。一方、禁足地として長期に回避される現実行動をL2/L3へどう反映するかはtask 3で証拠要件を再確認する。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.LOC.LOCAL_TRADITION` — 地域伝承圏
- Primary Parent: `D19.LOC` — 地域共同体
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

特定地点の禁足地伝承として地域共同体に根差すというパイロット判定を保持する。

**この伝承における現れ方**

全国にも名称は知られるが、伝承の作用地点は市川市八幡の具体的な藪であり、地域史・場所知識と不可分である。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.INS.LOCAL_RESIDENT` — 地元住民
- Primary Parent: `D20.INS` — 地元・内部者

**判定根拠**

禁足の言い伝え・由来を保持する主体として地元住民と宗教・民俗知識者を置くパイロット判定を保持する。

**この伝承における現れ方**

外来者より地域側が「入ってはいけない理由」や諸由来を知るという情報差が想定される。ただし現代では公的Web上にも情報が公開されており、真の秘密保持者といえるかはtask 3で再検討余地がある。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A2` — 具体的実在対象
- Primary Parent: なし
- Secondary: なし

**判定根拠**
