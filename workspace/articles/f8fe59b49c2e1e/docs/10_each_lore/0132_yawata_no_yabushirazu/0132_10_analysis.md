# 2. 分析概念次元

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

`0132_00_contents.md` では、寛延2年（1749）の『葛飾記』に立入忌避・非帰還・祟り・里諺という共有核が記録されている。これは少なくとも前近代にはVersion Scopeの中核が存在した確認点であるが、1749年を生成年とは確定できないため `I` とする。

**この伝承における現れ方**

現代に新規生成した怪談ではなく、少なくとも1749年には禁足地伝承の共有核が記録されている。ただし実際の起源はそれ以前を含め未確定である。

**この伝承における現れ方**

地域の禁足知識が、少なくとも1749年には地誌系の書物へ記録され、「昔より里諺に云ひ伝へたり」とする既知の言い伝えとして提示される。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**この伝承における現れ方**

前近代の書物と現代Webの双方で、八幡不知森の場所・禁足・祟り・由来説明が受容者へ提示される。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Parent: `D04.CON`

00では、神聖地、将門関係、八門遁甲・死門、日本武尊、入会地等、同じ禁足の由来を異なる形で説明する複数Versionが確認でき、単一の由来へ収束していない。一方、どのVersionからどのVersionが派生したかを示す連続的History Evidenceは固定できないため `ACCRETION` や `CROSS_MEDIA` は付さない。

**この伝承における現れ方**

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.RUL.TABOO` — 禁忌
- Primary Parent: `D05.RUL`
- Secondary: `D05.HYB.NARRATIVE_EXPLANATION` — 物語＋解説
- Status: `D`

**判定根拠**

中心核は「中へ入ってはいけない」という禁止規則であり、1749年資料では入る者がいない里諺、後続資料では里人による立入禁止が記録される。光圀侵入譚や複数由来説がその規則を物語・解説として補う。

**この伝承における現れ方**

由来の詳細を知らなくても「八幡不知森へ入ってはならない」という禁足規則だけで伝承が成立し、後代の物語・由来説明が周囲に付随する。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

1749年『葛飾記』は「昔より里諺に云ひ伝へたり」とし、後続資料も里人が立入を禁じる既知の場所として記述する。個人の一回的体験談ではなく共同体的な共有知識として提示されるが、原発話の真実性態度そのものを直接採録した資料ではないため `I` とする。

**この伝承における現れ方**

「ここは昔から入ってはいけない場所である」という共同体的既知性が、伝承の本当らしさを支える。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.PSE.DANGEROUS_PLACE` — 危険・怪異場所
- Primary Parent: `D07.PSE`
- Secondary: `D07.PSE.SPATIAL_ROUTE_ANOMALY` — 空間・経路異常
- Status: `D`

**判定根拠**

実在する特定の藪が危険な禁足地として区別され、「入ると出られない」という空間異常型が1749年資料を含む歴史資料・公的整理で確認できる。

**この伝承における現れ方**

市街地内の具体的な小空間が、内部へ入ると非帰還・祟りが起こる危険な場所として扱われる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.INHERITED_SAYING` — 既存の言い伝え
- Primary Parent: `D08.CLM`
- Secondary: `D08.HIS.PLACE_NAME_RUIN` — 地名・遺構・記念物
- Status: `D`

**判定根拠**

1749年『葛飾記』が「昔より里諺に云ひ伝へたり」と記す既存の言い伝えが直接の契機であり、八幡不知森という名称、1857年石碑、現地の鳥居・祠・竹藪が具体地点を固定する手掛かりとなる。

**この伝承における現れ方**

受容者は既存の禁足伝承と、名称・石碑・現存地点を対応させてこの場所を危険な禁足地として認識できる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.NOR.TABOOIZATION` — 禁忌化
- Primary Parent: `D09.NOR`
- Secondary: `D09.HST.HISTORICAL_ANCHOR` — 歴史接続
- Status: `I`

**判定根拠**

特定空間への侵入を「してはいけない行為」として規範化し、その理由を将門、日本武尊、八幡宮、光圀、入会地等の歴史・伝説的要素へ結び付けるため、禁忌化と歴史接続に写像する。

**この伝承における現れ方**

八幡不知森への立入制限が、複数の歴史・宗教・社会史的説明と結び付けて理解される。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SPC.SPECIFIC_PLACE` — 特定場所
- Primary Parent: `D10.SPC`
- Secondary: `D10.SUP.IMPERSONAL_CURSE` — 非人格的呪力
- Status: `I`

**判定根拠**

八幡不知森という特定場所そのものへ異常効力が固定され、祟り型では安定した単一人格主体を必須とせず、場所に付随する非人格的な災いとして語られる。光圀譚の人格的警告主体は全Scope共通ではない。

**この伝承における現れ方**

危険は任意の藪ではなく八幡不知森という場所へ固定され、侵入自体が非帰還・祟りへ接続される。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**この伝承における現れ方**

### 2.3.2. D12: 作用対象

**この伝承における現れ方**

禁足地へ入った本人が、迷失・祟り・警告を受ける主体になる。

### 2.3.3. D13: 作用機構

**この伝承における現れ方**

### 2.3.4. D14: 帰結極性

- Secondary: なし

**この伝承における現れ方**

### 2.3.5. D15: 帰結領域

**最終的に何が起きるか**

- Primary Child / Value: `D15.OPP.LUCK_MISFORTUNE` — 幸運・不運
- Primary Parent: `D15.OPP`
- Secondary: `D15.LIF.DISAPPEARANCE` — 失踪・消失
- Status: `I`

**判定根拠**

祟り型では帰結種別が固定されず広い災いとして語られる一方、非帰還型では共同体へ戻れない結果が主要内容となる。1749年資料には死亡を伴う強い表現もあるが、死亡を全型へ一般化しない。`DISAPPEARANCE` は非帰還型への分析写像としてSecondaryに保持する。

**この伝承における現れ方**

禁忌違反には不特定の災いが予告され、強い型では藪から戻れない状態となる。

### 2.3.6. D16: 因果時間構造

**この伝承における現れ方**

時期に依存せず、八幡不知森の境界を越えることと負の帰結が結び付けられる。

### 2.3.7. D17: 回避・制御方式

**どう回避・制御できるか**

- Primary Child / Value: `D17.RUL.OBEY_TABOO` — 禁忌遵守
- Primary Parent: `D17.RUL`
- Secondary: なし

**この伝承における現れ方**

内部へ入らないという禁足の遵守が、伝承に付随する明示的な共同体行動規範として現れる。

### 2.3.8. D18: 作用レイヤー

**作用はどのレイヤーまで確認できるか**

- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `1`
- Status: `I`

**判定根拠**

L1では侵入者への非帰還・祟りという伝承内因果がある。L2について、伝承を知るだけで怪異が発動するEvidenceはない。L3について、歴史資料が里人による立入忌避・禁止を記録しており、伝承信念と現実の場所利用行動の接続を示す独立X Evidenceとして限定的に評価できる。現在の土地管理全体を伝承効果へ帰属させない。absence判断を含むvector全体は `I` とする。

**この伝承における現れ方**

怪異因果は伝承内部だけでなく、少なくとも歴史記録上は「入らない／入らせない」という共同体の現実行動にも接続している。
