# 1. 伝承エントリ基本情報

- `Entry_ID`: `0132`
- `伝承エントリ名称`: 八幡の藪知らず
- `Macro_Category`: 場所・異界・祟り・禁忌
- `Entry_Type`: 禁足地伝承／場所伝説
- `Version_Scope`: 千葉県市川市八幡の八幡不知森について、中へ立ち入ってはならず、禁を破って入ると出られなくなる、または祟り・災いを受けるとする禁足地伝承。日本武尊・葛飾八幡宮・平将門／八門遁甲・行徳入会地等は異なる由来説明として保持し、徳川光圀侵入譚は禁忌を具体的な物語として示す主要派生として含む。各由来説を一つの史実へ統合しない。

# 2. 分析概念次元

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: `D01.G0` — 前近代（〜1867）
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

天保年間の『江戸名所図会』に立入禁忌・祟りと複数の由来説明が記録されており、少なくとも前近代にはVersion Scopeの共有核が存在したと推定できる。刊行年を起源年とはしないため `D` ではなく `I` とする。

**この伝承における現れ方**

現代に新規生成した怪談ではなく、江戸後期には禁足地伝承として記録されていたことが確認できる。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Parent: `D02.PRT`
- Secondary: なし
- Status: `I`

**判定根拠**

公的書誌・復刻案内を通じ、天保年間の『江戸名所図会』に八幡不知森の伝承が印刷されていたことを確認する。今回は原本本文を直接閲覧せず、公的パスファインダー・復刻案内を介して固定しているため `I` とする。

**この伝承における現れ方**

地域の禁足知識が江戸後期には名所案内・地誌系の印刷物へ収録されていた。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Parent: `D03.PRT`

- Status: `I`

**判定根拠**

前近代の地誌・名所図会と、現代の市川市・市川市立図書館Webで伝承の再提示を確認できる。ただし、Primaryの前近代書籍は今回原本本文を直接固定せず、公的な書誌・復刻案内を介しているため、portfolio全体のStatusは `I` とする。錦絵は現行D03 taxonomyへ無理に割り当てない。

**この伝承における現れ方**

印刷資料と現代Webの双方で、八幡不知森の場所・禁足・由来説明が確認できる。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.CON.CONTESTED_VERSION` — 競合版併存
- Primary Parent: `D04.CON`
- Secondary: なし
- Status: `I`

**判定根拠**

00では、神聖地、将門関係、八門遁甲・死門、日本武尊、入会地等、同じ禁足の由来を異なる形で説明する複数のVersionが確認でき、単一の由来へ収束していない。この併存を `CONTESTED_VERSION` に写像する。一方、どのVersionからどのVersionが派生したか、いつ増補されたか、媒体間でどう移行したかは連続的History Evidenceで固定できないため `ACCRETION` や `CROSS_MEDIA` をSecondaryへ付さず、Statusは `I` とする。

**この伝承における現れ方**

「入るな」という規則を共有しながら、その理由を説明する由来Versionが複数併存する。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.RUL.TABOO` — 禁忌
- Primary Parent: `D05.RUL`
- Secondary: `D05.HYB.NARRATIVE_EXPLANATION` — 物語＋解説
- Status: `D`

**判定根拠**

中心核は「中へ入ってはいけない」という禁止規則であり、光圀侵入譚や複数の由来説がその規則を物語・解説として補うことを資料上確認できる。

**この伝承における現れ方**

由来の詳細を知らなくても禁足規則だけで伝承が成立し、後代の物語や由来説明がその周囲に付随する。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T3` — 共同体既知事実
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

『江戸名所図会』系の記録では、里人が立入を禁じる既知の場所として記述され、個人の一回的体験談ではなく地域の共有知識として提示される。ただし、原発話の真実性態度を直接採録した資料ではないため `I` とする。

**この伝承における現れ方**

「ここは昔から入ってはいけない場所である」という共同体的な既知性が伝承の提示形式を支える。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.PSE.DANGEROUS_PLACE` — 危険・怪異場所
- Primary Parent: `D07.PSE`
- Secondary: `D07.PSE.SPATIAL_ROUTE_ANOMALY` — 空間・経路異常
- Status: `D`

**判定根拠**

実在する特定の藪が危険な禁足地として区別され、「入ると出られない」という空間異常型が主要な内容として公的資料・歴史資料整理で確認できる。

**この伝承における現れ方**

市街地内の具体的な小空間が、内部へ入ると非帰還・祟りが起こる場所として扱われる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.INHERITED_SAYING` — 既存の言い伝え
- Primary Parent: `D08.CLM`
- Secondary: `D08.HIS.PLACE_NAME_RUIN` — 地名・遺構・記念物
- Status: `D`

**判定根拠**

江戸期から記録される「入るな／入れば祟りがある」という既存の言い伝えが直接の契機であり、八幡不知森という名称、1857年石碑、現地の鳥居・祠・竹藪が具体地点を固定する手掛かりとなる。

**この伝承における現れ方**

受容者は既存の禁足伝承と、名称・石碑・現存地点を対応させてこの場所を認識できる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.NOR.TABOOIZATION` — 禁忌化
- Primary Parent: `D09.NOR`
- Secondary: `D09.HST.HISTORICAL_ANCHOR` — 歴史接続
- Status: `I`

**判定根拠**

特定空間への侵入を「してはいけない行為」として規範化し、その理由を将門、日本武尊、八幡宮、光圀、入会地等の歴史・伝説的要素へ結び付けるため、禁忌化と歴史接続に写像する。これは分析概念への解釈を含むため `I` とする。

**この伝承における現れ方**

場所の立入制限が、複数の歴史・宗教的説明と結び付けて語られる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SPC.SPECIFIC_PLACE` — 特定場所
- Primary Parent: `D10.SPC`
- Secondary: `D10.SUP.IMPERSONAL_CURSE` — 非人格的呪力
- Status: `I`

**判定根拠**

八幡不知森という特定場所そのものへ異常効力が固定され、祟り型では安定した単一人格主体を必須とせず、場所に付随する非人格的な災いとして語られる。光圀譚では人格的警告主体も現れるが、全Scope共通の因果主体ではない。

**この伝承における現れ方**

危険は任意の藪ではなく八幡不知森という場所へ固定され、侵入自体が祟り・非帰還へ接続される。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.MOV.ENTER_PASS_CROSS` — 入る・通る・越える
- Primary Parent: `D11.MOV`
- Secondary: なし
- Status: `D`

**判定根拠**

藪の内部へ立ち入ることが、禁忌違反・非帰還・祟りの条件として直接確認できる。

**この伝承における現れ方**

外から場所を見るだけではなく、境界を越えて内部へ入ることが因果系への入口となる。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC`
- Secondary: なし
- Status: `D`

**判定根拠**

禁を破って内部へ入った人物自身が、迷失・祟り・警告の対象となる。光圀譚では侵入者本人が具体的に作用対象として描かれる。

**この伝承における現れ方**

禁足地へ入った本人が、非帰還または災いを受ける主体になる。

### 2.3.3. D13: 作用機構

**どのように作用するか**

- Primary Child / Value: `D13.RST.SPATIAL_DISTORTION` — 空間異常
- Primary Parent: `D13.RST`
- Secondary: `D13.FAT.CURSE_MISFORTUNE` — 呪詛・不運付与
- Status: `D`

**判定根拠**

「入ると出られない」という空間作用と、「禁を破ると祟り・災いがある」という作用の双方が資料上確認される。全型で死亡等の同一結果を要求しない。

**この伝承における現れ方**

主要型では内部へ入ると通常の帰還ができなくなり、別型では禁忌違反に災いが返る。

### 2.3.4. D14: 帰結極性

**結果はどの方向の価値を持つか**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `D`

**判定根拠**

脱出不能、祟り、災いはいずれも禁忌違反者に対する負の帰結として直接確認できる。

**この伝承における現れ方**

藪への侵入は利益・保護ではなく危害・非帰還へ結び付けられる。

### 2.3.5. D15: 帰結領域

**最終的に何が起きるか**

- Primary Child / Value: `D15.OPP.LUCK_MISFORTUNE` — 幸運・不運
- Primary Parent: `D15.OPP`
- Secondary: `D15.LIF.DISAPPEARANCE` — 失踪・消失
- Status: `I`

**判定根拠**

祟り型では帰結種別が固定されず広い災いとして語られる一方、非帰還型では共同体へ戻れない結果が主要内容となる。永久失踪・死亡を全型へ一般化しないため、`DISAPPEARANCE` はSecondaryとして `I` で保持する。

**この伝承における現れ方**

禁忌違反には不特定の災いが予告され、強い型では藪から戻れない状態となる。

### 2.3.6. D16: 因果時間構造

**因果は時間上どのように構成されるか**

- Primary Child / Value: `D16.STA.STATIC_RULE` — 静的規則
- Primary Parent: `D16.STA`
- Secondary: なし
- Status: `I`

**判定根拠**

「この場所へ入れば出られない／祟りが生じる」という恒常的条件規則であり、特定の期限・潜伏期間・段階進行を必要としない。時間構造への写像を含むため `I` とする。

**この伝承における現れ方**

時期に依存せず、境界を越えることと負の帰結が結び付けられる。

### 2.3.7. D17: 回避・制御方式

**どう回避・制御できるか**

- Primary Child / Value: `D17.RUL.OBEY_TABOO` — 禁忌遵守
- Primary Parent: `D17.RUL`
- Secondary: なし
- Status: `D`

**判定根拠**

本件では、単なる条件反転ではなく、『江戸名所図会』系の記録で里人が祟りを理由に立入を禁じる共同体規範が直接報告される。この独立Evidenceに基づき `OBEY_TABOO` を採用する。解除儀礼・脱出手順は共有核にない。

**この伝承における現れ方**

内部へ入らないという立入禁忌の遵守が、資料上明示された現実の行動規範として記録される。

### 2.3.8. D18: 作用レイヤー

**作用はどのレイヤーまで確認できるか**

- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `1`
- Status: `I`

**判定根拠**

L1では侵入者への非帰還・祟りという伝承内因果がある。L2について、伝承を知るだけで怪異が発動するEvidenceはない。L3について、『江戸名所図会』系の記録が、里人が祟りを理由に実際に立入を禁じていたことを報告しており、伝承信念と現実の場所利用行動の接続を示す独立した歴史X Evidenceとして評価できる。ただし、現在の土地管理全体を伝承効果へ帰属させない。

**この伝承における現れ方**

怪異因果は伝承内部だけでなく、少なくとも江戸期記録上は「入らない」という共同体の実行規範にも接続している。

## 2.4. 社会的分布・現実接続の次元

### 2.4.1. D19: 流通範囲

**どの範囲で流通するか**

- Primary Child / Value: `D19.LOC.LOCAL_TRADITION` — 地域伝承圏
- Primary Parent: `D19.LOC`
- Secondary: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Status: `I`

**判定根拠**

市川市八幡の具体地点・地域史に不可分な伝承である一方、江戸期名所図会、明治錦絵、現代Webを通じて地域外の読者・観客へも提示されたことが確認できる。全国的な浸透率を数量的に測定したものではないため `I` とする。

**この伝承における現れ方**

作用地点は局所的だが、場所と伝承の物語は地域外へも印刷・図像・Webを通じて流通する。

### 2.4.2. D20: 特権情報保持者

**誰が特権的な情報を保持するか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U`

**判定根拠**

禁足の真の起源について複数説が併存し、地元住民、神職、歴史研究者等の誰か一者へ真相保持を固定できるEvidenceはない。「誰も知らない」と伝承内で明示されるわけでもない。

**この伝承における現れ方**

由来諸説が複数あることと、特権的な真相保持者が存在する／しないことを区別する。

### 2.4.3. D21: 現実アンカー

**どの程度、具体的な現実対象へ固定されるか**

- Primary Child / Value: `D21.A2` — 具体的実在対象
- Primary Parent: なし
- Secondary: なし
- Status: `D`

**判定根拠**
