# 1. 伝承エントリ基本情報

- `Entry_ID`: `0157`
- `伝承エントリ名称`: 新郷村キリストの墓
- `Macro_Category`: 異説史・地域伝承
- `Entry_Type`: 命題・伝説複合型
- `Version_Scope`: イエス・キリストは磔刑で死亡せず、弟イスキリが身代わりとなり、本人は日本へ再渡来して現在の青森県新郷村戸来で生涯を終え、現地の塚がその墓であるとする代替歴史説。1935年に竹内文書と現地の塚が結び付けられたとする後代地域史、現在の墓・伝承館・祭礼による再提示を含む。渡来経路、年齢、家族、祭唄・家紋等の細部は共有核から分離する。
