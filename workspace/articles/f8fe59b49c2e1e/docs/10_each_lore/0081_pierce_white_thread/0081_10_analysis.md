## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.BHF.BODY_ANOMALY` — 身体異常
- Primary Parent: `D07.BHF` — 身体・健康・食品
- Secondary: なし
- Status: `D` — Direct（白い糸と身体危険が共有核）

**判定根拠**

耳から白い糸状のものが出るという身体異常と、それが眼の障害へつながるという身体構造の不可解さが、伝承内容に直接置かれている。

**この伝承における現れ方**

耳と眼という離れた器官が、見える一本の糸で直結しているという単純なモデルによって、見えない身体内部の不確実性が問題化される。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.DEX.PERCEPTUAL_ANOMALY` — 知覚異常
- Primary Parent: `D08.DEX` — 直接経験
- Secondary: `D08.CLM.UNSUPPORTED_ASSERTION` — 根拠未提示の主張
- Status: `C` — Competing（物語型と警告命題型で契機が異なる）

**判定根拠**

物語型では、ピアス穴から白い糸が見えるという異常知覚が最初の問題化契機になる。一方、警告型では「それは視神経で引くと失明する」という主張そのものが聞き手へ先に与えられる。主要異伝間で契機が競合するため `C` とする。

**この伝承における現れ方**

体験談では「耳から何か白いものが出ている」という発見から話が動き、短い俗説では「その白いものは危険だ」という説明から始まる。どちらも最終的に同じ身体モデルへ収束する。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAU.DIRECT_CAUSE` — 直接原因化
- Primary Parent: `D09.CAU` — 原因帰属
- Secondary: `D09.CAT.NAMING` — 命名
- Status: `I` — Inferred（共有因果モデルから判定）

**判定根拠**

伝承は白い糸を「視神経」と名付けるだけでなく、「それを引くことが失明を直接起こす」と因果を閉じる。意味形成の中心は、身体異常から重大障害までを一本の直接原因関係として説明することにある。

**この伝承における現れ方**

正体不明の白いものが視神経と命名され、その瞬間に「引く→神経が損なわれる→失明する」という分かりやすい因果鎖へ変換される。複雑な解剖学を単純な機械的モデルへ圧縮する。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.NAT.BIOPHYSIO_PROCESS` — 生理・生物過程
- Primary Parent: `D10.NAT` — 自然・生物物理過程
- Secondary: なし
- Status: `D` — Direct（人体の神経構造として説明）

**判定根拠**

超自然的主体ではなく、人間の身体内部の神経構造とその損傷という生理学的過程が原因として明示される。実際の医学的正誤とは独立して、伝承内の存在論は自然科学的である。

**この伝承における現れ方**

恐怖の原因は呪いではなく、「人体には耳から眼へつながる糸状の神経がある」という誤った身体モデルである。だからこそ医療情報のように語りやすい。

- Secondary: なし
- Status: `D` — Direct（白い糸を引く操作が帰結条件）

**判定根拠**

**この伝承における現れ方**

主人公は白い糸を異物だと思って除去しようとする。その「引く」という能動操作が、観察段階から不可逆的な障害へ入る境界になる。

危険は不特定多数へ同時に広がるのではなく、ピアス穴と白い糸を操作した当人の身体へ返る。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

**この伝承における現れ方**

糸を引くことで眼につながる神経が損なわれ、視界が暗くなる・失明するという身体変化が起きると語られる。疑似医学的だが、因果機構は物理・生理作用として提示される。
