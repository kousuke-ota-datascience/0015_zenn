# 1. 伝承エントリ基本情報

- `Entry_ID`: `0081`
- `伝承エントリ名称`: ピアスの白い糸
- `Macro_Category`: 身体・医療・食品
- `Entry_Type`: 物語・伝説
- `Version_Scope`: 雪村2017が1989年『週刊明星』掲載例として整理する「白い糸＝視神経、その切断によって失明する」型を中心とし、1997年に確認される視力低下・目のツボ型は変異確認に用いる。1994年書籍は書誌・目次のみ確認できるため、本文未実見の細部はScope根拠に使用しない。

**この伝承における現れ方**

現在追跡できる最古の流通確認点は、少女向け雑誌の記事として紹介された例である。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

**この伝承における現れ方**

雑誌で紹介・検証され、現代伝説集にも同名項目として収録される形で印刷媒体を横断している。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.VAR.RETELLING` — 再話
- Primary Parent: `D04.VAR` — 再話・変異
- Secondary: `D04.VAR.ACCRETION` — 要素付加
- Status: `I`

**判定根拠**

1989年の「白い糸＝視神経、切断で失明」という説明に対し、1997年には「目のツボ」「視力低下」等の別説明が確認される。時系列上の差は確認できるが、どの型からどの型が直接派生したかまでは固定できない。

**この伝承における現れ方**

耳への穿孔と視覚障害を結ぶ核を保ちながら、身体説明と帰結の強度が再話ごとに変化する。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.HRS.FOAF` — FOAF
- Primary Parent: `D05.HRS` — 伝聞・口承形式
- Secondary: `D05.PRP.PREDICTIVE_CLAIM` — 予測命題
- Status: `I`

**判定根拠**

雪村2017が引用する1989年・1997年の例では、友人・先輩・友人の友人に起きた被害として語られる。そこから「ピアス穴と視覚障害が結び付く」という一般化された危険主張も形成されている。

**この伝承における現れ方**

身近な他者に起きた出来事として提示され、その事例から同様の身体危険があり得るという主張へ接続する。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T2` — 近接伝聞事実
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

被害は話し手本人ではなく、友人・先輩・友人の友人等に実際に起きた出来事として提示される。研究論文を介した再構成であるためStatusはIとする。

**この伝承における現れ方**

受容者から数段離れた実在人物の被害として語ることで、本当らしさを付与する。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Parent: `D07.BHF` — 身体・健康・食品
- Secondary: `D07.BHF.MEDICAL_RISK` — 医療リスク

**この伝承における現れ方**

耳への小さな身体加工が、視力喪失という遠隔の重大障害へつながるとされる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.STY.FOAF_REPORT` — 近接伝聞
- Primary Parent: `D08.STY` — 証言・語り
- Secondary: `D08.TRC.PHYSICAL_TRACE` — 物的痕跡
- Status: `I`

**判定根拠**

受容者側では友人・先輩等の被害報告が問題化の入口となり、物語内部では白い糸という可視的対象が説明の手掛かりとなる。

**この伝承における現れ方**

身近な人物の被害談と、耳から現れるとされる白い糸が、身体危険を具体化する手掛かりとなる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAT.TYPE_ASSIGNMENT` — 類型化
- Primary Parent: `D09.CAT` — カテゴリー化

**判定根拠**

白い糸を「視神経」と分類し、その切断を失明の直接原因へ結び付けることで、不可解な身体事象を単純な因果モデルへ変換する。

**この伝承における現れ方**

正体不明の白い糸が既知の身体構造名を与えられ、切断→失明という因果列に組み込まれる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.NAT.BIOPHYSIO_PROCESS` — 生理・生物過程
- Primary Parent: `D10.NAT` — 自然・生物物理過程
- Secondary: なし
- Status: `I`

**判定根拠**

伝承内では視神経・身体内部構造の損傷という生理学的説明が原因として置かれる。医学的正否とは分離する。

**この伝承における現れ方**

超自然主体ではなく、人体内部の構造が誤ってモデル化され、視覚障害の原因とされる。

**この伝承における現れ方**

**この伝承における現れ方**

### 2.3.7. D17: 回避・制御方式
