# 1. 伝承エントリ基本情報

- `Entry_ID`: `81`
- `伝承エントリ名称`: ピアスの白い糸
- `Macro_Category`: 身体・医療・食品
- `Entry_Type`: 物語・伝説
- `Version_Scope`: 「ピアス穴から白い糸が出て、それを視神経と説明し、引くと失明する」という共有核。後代の細部を混成しない

# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: `D01.G4` — 1980年代
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

1994年刊『ピアスの白い糸―日本の現代伝説』に採録され、1980〜90年代の若者文化と結び付いた伝承として扱われるため、パイロットでは1980年代成立帯を採用した。ただし最初期口承そのものは未確認である。

**この伝承における現れ方**

ピアスが若者の身体装飾として社会的に可視化した時期に、「新しい身体改変には見えない危険がある」という不安を取り込んで成立した伝承として現れる。古来の禁忌ではなく、現代的ファッションと身体知識の不足が接続した話である。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（証拠不足）

**判定根拠**

1994年の採録は確認できるが、その前に口承・雑誌・テレビ等のどの媒体で最初に流通したかを直接示す証拠を固定できていない。

**この伝承における現れ方**

「学校で聞いた」「友人から聞いた」といった語られ方が想定されるが、それだけで最古媒体を口承と断定すると推測になる。したがって、伝承内容の親しみやすさとは別に、証拠上の最古媒体は `U` を維持する。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Parent: `D03.ORL` — 口承・限定共同体
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

若年者間の現代伝説として友人・学校内で再話される性格を持つため、パイロットでは仲間内口承をPrimaryとした。

**この伝承における現れ方**

身体の秘密を教える警告話として、「白い糸を引くと失明するらしい」と短く伝えられることに適している。長い物語よりも、友人間で危険情報として回覧されることで力を持つ。旧レビュー用メモには `D03:U` が残るため、本文値との不整合はtask 3で再確認する。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.STB.STABILIZED_CANON` — 定型化・カノン化
- Primary Parent: `D04.STB` — 安定・固定
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

人物や細部は変わっても、「ピアス穴→白い糸→視神経→引くと失明」という連鎖が広く認識される定型として維持されるため、このコードを保持する。

**この伝承における現れ方**

再話ごとに糸の長さ、引いた瞬間の症状、説明者などが変わっても、白い糸を視神経とする疑似解剖学的説明は残る。物語の核が短く覚えやすいため、定型化しやすい。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし

**判定根拠**

実話型、友人の友人型、単純な警告命題型など複数の提示形式があり、パイロット時点の資料では一つをPrimaryに固定できなかった。

**この伝承における現れ方**

ある再話では「知り合いが失明した」というエピソードとして語られ、別の再話では「白い糸は視神経だから引くな」という警告だけが流通する。内容核は同じでもコミュニケーション形式が変わるため `U` を維持する。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T6` — 真偽未確定
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

身体の仕組みについて実話・医学知識らしく語られるが、主張自体は解剖学的に誤っている。伝承内では真実として警告される一方、検証可能な医学事実ではないため真偽未確定を保持する。

**この伝承における現れ方**

「視神経」という専門用語が、本当らしさを与える。聞き手にとって身体内部は見えないため、専門用語を伴う単純な説明が、誤っていてももっともらしい危険情報として機能する。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.BHF.BODY_ANOMALY` — 身体異常
- Primary Parent: `D07.BHF` — 身体・健康・食品
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

耳から白い糸が出るという身体異常と、それが失明へつながるという身体危険が伝承の中心に直接置かれているため、このコードを保持する。

**この伝承における現れ方**

不可解さは、ピアス穴のような小さな身体変化が、なぜ眼という別器官の重大障害へつながるのかという点にある。伝承はその未知を「白い糸＝視神経」という一目で理解できるモデルへ変換する。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.UNSUPPORTED_ASSERTION` — 根拠未提示の主張
- Primary Parent: `D08.CLM` — 命題先行
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

「白い糸は視神経である」「引くと失明する」という主張が、解剖学的証拠を伴わず因果説明として提示されるため、このコードを保持する。

**この伝承における現れ方**

聞き手は実際に神経を確認するのではなく、語り手から危険な身体知識として説明を受ける。その断言が、ピアスと失明を結ぶ問題設定そのものになる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAT.NAMING` — 命名
- Primary Parent: `D09.CAT` — カテゴリー化
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

正体不明の白い糸を「視神経」と名付けることで、異物と失明の関係を即座に理解可能にするため、命名を保持する。

**この伝承における現れ方**

白いものが何なのか分からない状態から、「これは目につながる神経だ」と分類される瞬間に、行為の危険性が確定する。命名がそのまま因果説明と警告へ変換される。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.NAT.BIOPHYSIO_PROCESS` — 生理・生物過程
- Primary Parent: `D10.NAT` — 自然・生物物理過程
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

伝承は呪い・霊ではなく、人体の神経という生理学的対象を原因として説明するため、このコードを保持する。

**この伝承における現れ方**

恐怖の原因は超自然存在ではなく、「人間の身体は実はこうできている」という誤った自然科学モデルである。だからこそ、怪談というより危険な医学知識のような顔で流通できる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.NCR.INTRINSIC_PROPERTY` — 内在属性のみ
- Primary Parent: `D11.NCR` — 接触不要
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

パイロットでは危険を、外部怪異との接触ではなく身体内部に元から存在するとされる神経構造に由来するものとして扱い、このコードを保持する。

**この伝承における現れ方**

白い糸の危険性は、誰かに呪われたり感染したりして生じるのではない。ピアス穴によって、もともと身体内にあるとされる重要構造が露出するというモデルで説明される。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC` — 焦点人物
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

ピアスを開け、糸を発見し、失明リスクを負う本人が焦点人物であるため、このコードを保持する。

**この伝承における現れ方**

危険は一般社会ではなく、身体を改変した当人へ直接返る。本人の好奇心や異物除去行動が、その身体に重大な結果を生む構図になっている。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.COG.INFORMATION_INDUCED_ACTION` — 情報誘導・行動誘発
- Primary Parent: `D13.COG` — 認知・情報作用
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

パイロットでは、伝承情報が「白い糸をどう理解し、どう扱うか」という行動選択を誘導する構造を重視し、このコードを保持する。

**この伝承における現れ方**

「それは視神経で、引くと失明する」という情報が、聞き手の身体認識と行動を直接変える。白い糸を見た際に触らない、ピアスを危険視する、といった行動が、情報そのものによって誘発される。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

中心的帰結は失明・視力喪失という重大な身体障害であり、明確に負である。

**この伝承における現れ方**

軽い身体装飾から、取り返しのつかない障害へ一気に転落する点が恐怖を形成する。可逆的な失敗ではなく「一度引けば終わる」という不可逆性が強調される。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.BOD.SEVERE_INJURY` — 重傷・障害
- Primary Parent: `D15.BOD` — 身体・健康
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

最終的な変化は視力の喪失という身体障害に置かれるため、このコードを保持する。

**この伝承における現れ方**

物語の終端では、噂を信じる・怖がるだけでなく、体験者の身体機能そのものが失われるとされる。恐怖が抽象的不安ではなく、失明という具体的障害へ固定される。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.EVT.SEQUENTIAL_EPISODE` — エピソード内段階進行
- Primary Parent: `D16.EVT` — 単一エピソード・事象内
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

ピアスを開ける→白い糸が出る→引く→失明する、という複数段階が一つの短いエピソード内で順次進むため、このコードを保持する。

**この伝承における現れ方**

危険は長期間蓄積するのではなく、一連の行動の順序に沿って顕在化する。特に「糸を引く」という段階が、異常の観察から不可逆的帰結への転換点になる。旧レビュー用メモには `D16:U` が残るため、本文値との不整合はtask 3で再確認する。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

日本の現代伝説を扱う書籍に代表例として採録され、地域固有の一話ではなく広く知られる身体俗説として扱われるため、全国的大衆を保持する。

**この伝承における現れ方**

特定の学校や都市だけに固定されず、「ピアスを開ける若者なら誰にでも起こり得る話」として再話できる。全国的な若者文化の共通不安へ接続しやすい。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

**この伝承における現れ方**

医師が説明者として登場する異伝があっても、その知識は物語の終わりで聞き手にも共有される。真相を独占する秘密の集団は必要なく、誰でも他人へ警告できる構造である。

### 2.4.3. D21: 現実アンカー
