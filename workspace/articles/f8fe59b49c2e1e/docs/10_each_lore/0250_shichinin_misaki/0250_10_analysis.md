# 1. 伝承エントリ基本情報

- `Entry_ID`: `0250`
- `伝承エントリ名称`: 七人ミサキ
- `Macro_Category`: 怪異・亡霊伝承
- `Entry_Type`: 循環型死者霊集団伝承
- `Version_Scope`: 1935〜1943年の採録で直接確認できる循環型七人ミサキを中心Scopeとする。新規被害者が七人集団へ加わることに対応して古参の一霊が成仏・離脱し、七人という集団数を維持しながら次の被害者へ連鎖する共有核を分析対象とする。1927年の七人の霊・七人塚型を循環規則確立済み版とは扱わず、地域ごとの競合由来説や後代翻案もScope外とする。

# 3. 分析上の重要点

- 1927年の名称採録と、1935年以後に直接確認できる循環型を区別する。成立年代を前近代へ遡及しない。
- D13/D16は「七人」という固定人数そのものより、新規被害者との交代で集団が持続する伝播構造を優先する。
- D18 L3は塚・祭祀の存在だけから社会現実への独立作用を推定せず0とする。
- 地域異伝に固有の戦国人物・事故・遍路等を単一史実起源としてD21 A4へ引き上げない。
