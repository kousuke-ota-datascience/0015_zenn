# 1. 伝承エントリ基本情報

- `Entry_ID`: `0250`
- `伝承エントリ名称`: 七人ミサキ
- `Macro_Category`: 怪異・亡霊伝承
- `Entry_Type`: 循環型死者霊集団伝承
- `Version_Scope`: 1935〜1943年の採録で確認できる循環型七人ミサキを中心Scopeとする。新たな被害者が生じることと古参霊の成仏・離脱が対応し、七人という集団数が維持される型を対象とする。1927〜1928年の七人の霊・七人塚型は前史として分離し、地域ごとの競合由来説を単一の歴史起源へ統合しない。
