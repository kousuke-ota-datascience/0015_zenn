# 0. INTRODUCTION

**伝承名:** 七人ミサキ

本文書は七人ミサキの早期採録と循環構造を記録するEvidence正本である。分析値は `0250_10_analysis.md` で扱う。

# 1. 典拠

## 1.1. 最古確認群
国際日本文化研究センター「怪異・妖怪伝承データベース」には、1927年『民族』掲載の早川孝太郎「参遠山村手記」に「七人ミサキ」の呼称を含む採録がある。静岡県の事例で、山に入った7人の狩人が戻らず、7人の霊を祀って塚を作ったとされる。

- https://www.nichibun.ac.jp/cgi-bin/YoukaiDB3/youkai_card.cgi?ID=2240141

1928年『旅と伝説』にも七人みさき／七人塚の採録があり、亡霊・七人の死者・塚という地域伝承が記録される。

- https://www.nichibun.ac.jp/cgi-bin/YoukaiDB3/youkai_card.cgi?ID=1231562

## 1.2. 循環構造の早期確認

1935年高知県の採録では「七人ミサキは、7人の人をひきずりこまないと成仏できない」とされる。1938年『民間伝承』の高知県宿毛市事例では「いつも7人で組み、人を引くごとに一番古いミサキから仏になる」と明示される。

- https://www.nichibun.ac.jp/YoukaiCard/2180728.html

1943年『旅と伝説』「七人みさきに就て（一）」にも、人を一人取るごとに一つの亡霊が成仏する型、遭遇すると死ぬ／発熱する型、各地の由来譚が複数収録される。

# 2. 伝承内容

共有核として採用するのは、**成仏できない複数の死者霊が「七人」の集団を構成し、新たな人間を死・取り込みへ導くことで、古参の一霊が成仏して抜けるため、七人という集団が更新されながら持続する**という循環型である。

地域によって、海・川・道・山、事故死者・横死者・落武者・遍路等へ由来が変化する。発熱・精神錯乱・溺死・取り殺し等、具体的な被害も一定しない。

# 3. 変異・境界

- 1927年の「七人ミサキ」呼称記録は、七人の霊を祀る塚の伝承であり、後の循環ルールまで直接示さない。
- 循環型は1935〜1938年に直接確認できる。
- 「七人ミサキ」という名称が近世以前に存在した可能性を、近代採録だけから成立年代G0へ遡及しない。
- 個別の戦国武将・落武者・遍路等の由来説は競合する地域異伝であり、共有核ではない。
- 実在の特定人物・事故を、七人ミサキの超自然的原因として史実認定しない。

# 4. Evidence summary

- 最古確認呼称: 1927年印刷資料。
- 循環構造の直接確認: 1935〜1938年。
- 流通地域: 高知・愛媛を中心に西日本各地、ほか静岡・愛知等の関連型。
- 中心機構: 新規被害者の取り込みと古参霊の離脱による七人集団の更新。
