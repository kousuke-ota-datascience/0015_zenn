# 2. 伝承内容

## 2.1. 発端
語り手は高校3年になる直前、父方祖父母の農家を訪れる。庭で、人が発するような「ぽぽぽ」系の音を聞き、約2メートルの生垣から頭が出るほど背の高い、帽子と白っぽいワンピース姿の女性を見る。

語り手が祖父母へ、異常に背が高く奇妙な声を出す女性を見たと話すと、祖父母は強く動揺する。祖母はそれを「八尺様」と呼び、語り手が魅入られたと説明する。

## 2.2. 地域内説明
祖母の説明では、八尺様は八尺ほどの背丈を持つ女性姿の怪異で、衣服や年齢の見え方は人によって異なるが、異常な高身長、頭部の何か、奇妙な声が共通する。旅人について来たという噂もあるが由来は不確定とされる。

八尺様は地域内に地蔵で封じられ、移動できる道の境界四か所に地蔵が置かれているとされる。魅入られた者は数日以内に取り殺されると説明され、過去にも被害があったという。

周辺村との協定や水利権との交換で八尺様を地域に留めた可能性が語られるが、語り手自身も推測形で述べ、確定史実ではない。

## 2.3. 防御の一夜
祖父はKという老婆を連れて来る。Kは語り手へ札を渡し、祖父らは二階の一室を新聞紙・札・盛塩・仏像等で防御する。語り手は翌朝7時まで絶対に部屋から出ない、家族の声がしても応答しない、札を離さないよう指示される。

深夜、窓を叩く音がし、祖父によく似た声が外から語り手を誘う。語り手は指示を思い出し、仏像の前で祈る。「ぽぽぽ」という声と窓を叩く音が続き、盛塩は黒く変色する。朝まで部屋を出ずに持ちこたえる。

## 2.4. 地域外への脱出
翌朝、語り手は九人乗りのバンの中央に座らされ、周囲を血縁のある男性たちに囲まれる。Kは念仏様の文言を唱え、語り手は目を閉じて下を向くよう命じられる。移動中、八尺様らしき白いワンピースの姿が車と並走し、窓を叩く音がする。

やがてKが「抜けた」と判断し、語り手は父の車へ移る。握っていた札は黒く変色していたとされる。父は、自身の幼少期にも八尺様に魅入られて死亡した知人がいたと語る。

## 2.5. 帰結
語り手は祖父母の地域へ二度と行かないよう念を押され、十年以上戻っていない。祖父の葬儀にも行けなかったと語る。

後日、祖母から「語り手の家へ通じる道にある封印の地蔵が壊された」と連絡があり、物語は再発可能性を残して終わる。

# 3. 構造上の要点

- 特別な儀式で八尺様を呼ぶ話ではなく、地域滞在中の偶発的視認から始まる。
- 「見る」ことと「魅入られる」ことが接触条件として強く結びつく。
- 八尺様は対象者の身内の声を模倣し、防御空間から誘い出そうとする。
- 対処は個人知ではなく、祖父母・K・地域血縁者が共有するローカル知識と儀礼手順に依存する。
- 生存には、防御室、札、指示遵守、視認回避、専門者の祈祷、血縁者による護衛、地域外への脱出が組み合わされる。
- 語り手は生存するが、以後その地域へ戻れないという長期的制約を受ける。

# 4. Evidence上の不確実性

- 投稿内容が現実の出来事か創作かは、匿名投稿のみから確定できない。
- 地域名は伏字・匿名化され、特定の実在市町村へ確定できない。
- 八尺様が2008年以前から実在の民間伝承として語られていたことを示す独立資料は今回確認していない。
- 地蔵による封印、周辺村との協定、水利権との交換は物語内部の説明であり、現実の制度史としては確認していない。
- 後代の画像・動画・二次創作で固定された容姿や追加能力はScope外とする。
