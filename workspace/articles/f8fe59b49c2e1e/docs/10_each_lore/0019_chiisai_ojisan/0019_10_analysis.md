# 1. 伝承エントリ基本情報

- `Entry_ID`: `19`
- `伝承エントリ名称`: 小さいおじさん
- `Macro_Category`: 全国型怪異・儀式
- `Entry_Type`: 目撃伝承・現代怪異
- `Version_Scope`: 2007–2009年に直接確認できる初期共有核。通常の成人男性・「おじさん」のように見えるが、人体として不可能なほど小さい存在を見たという複数の目撃報告が、「小さいおじさん／小さいオッサン」という共通カテゴリに束ねられて流通する目撃伝承を対象とする。妖精・妖怪・霊・UMAへの正体固定、幸運、特定神社、会話、召喚方法、直接危害、固定身長・服装等はScope外とする。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown

**判定根拠**

2007年までに名称付きカテゴリが存在したことは直接確認できるが、これは生成時期そのものを示さない。2006年の2ch投稿は後代転載のみで原スレッドを固定できず、1990年代成立説も今回のEvidenceでは確認できない。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

**判定根拠**

2007年4月14日開設のmixi「小さいおじさん！！」コミュニティを直接確認できる。2006年2ch転載は原資料未固定のため、現時点の最古Direct Evidenceには採用しない。

**この伝承における現れ方**

現在確認できる最初期の流通点では、目撃経験がSNS上の名称付きコミュニティへ持ち寄られ、同種体験として共有される。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Child / Value: `D03.WEB.SNS` — SNS
- Primary Parent: `D03.WEB` — オープンWeb・ソーシャル

- Status: `D` — Direct

**判定根拠**

2007年mixi、2008年公開掲示板、2009年オンラインニュースをScope期間内に直接確認できる。テレビ言説への言及はあるが、個別放送資料を直接固定していないため放送媒体は付与しない。

**この伝承における現れ方**

初期共有核は、SNSでの体験共有、掲示板での募集・証言、Web記事での再提示という複数の公開ネット媒体を通じて広がる。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.COL.MULTI_AUTHOR` — 複数投稿者増殖
- Primary Parent: `D04.COL` — 共同・分散生成
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

単一の原物語が再話されるより、複数の目撃者・投稿者による異なる目撃報告が「小さいおじさん」という共通カテゴリへ追加され、カテゴリの内容が厚くなる。2007–2009年資料で複数証言の集約を確認できるが、それを生成機構として位置付ける判断は推論を含む。

**この伝承における現れ方**

一つのカノン物語が反復されるのではなく、場所・服装・行動の異なる目撃談が追加されることで「同じ種類の存在」の輪郭が形成される。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.HYB.MULTI_TESTIMONY` — 複数証言
- Primary Parent: `D05.HYB` — 集合・複合形式
- Secondary: `D05.EXP.EXPERIENCE_SUMMARY` — 体験要約
- Status: `I` — Inferred

**判定根拠**

Scopeは単一の完成した体験談ではなく、複数人物の「見た」という短い報告を束ねた目撃カテゴリとして成立する。個々の報告は短い体験要約である。

**この伝承における現れ方**

受容者は一人の主人公の物語ではなく、別々の人物が似た存在を見たという証言の束として「小さいおじさん」を知る。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T6` — 真偽未確定
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

個々の目撃者は直接体験として語る一方、2009年にはカテゴリ全体が「都市伝説」として提示され、存在の実在性は確定されない。Version Scopeが単一証言ではなく目撃カテゴリであるため、カテゴリ全体が要求する認識論的スタンスを採る。

**この伝承における現れ方**

「私は見た」という証言が複数存在しても、それらが同一の実在存在を示すかは閉じられず、受容者には真偽未確定の存在カテゴリとして提示される。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ANO.UNKNOWN_EXISTENCE` — 未知存在
- Primary Parent: `D07.ANO` — 異常体験・存在
- Secondary: `D07.ANO.ANOMALOUS_PERCEPTION` — 異常知覚・体験
- Status: `I` — Inferred

**判定根拠**

この伝承がなければ、「人体として説明しにくいほど小さい成人男性様の何かが存在するのか」「目撃者が見たものは何だったのか」という不確実性が残る。個々の視覚体験そのものも問題だが、複数証言が共通カテゴリへ集約されるため未知存在をPrimaryとする。

**この伝承における現れ方**

日常空間で一瞬見えた説明不能な像を、単なる見間違いとして消去せず、「通常とは異なる小型の人型存在がいるかもしれない」という共有可能な問題へ変換する。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.DEX.PERCEPTUAL_ANOMALY` — 知覚異常
- Primary Parent: `D08.DEX` — 直接経験
- Secondary: `D08.STY.COMMUNITY_REPETITION` — 共同体反復証言
- Status: `I` — Inferred

**判定根拠**

各報告の起点は、通常人体として説明しにくい極小男性様存在を視覚的に知覚したという体験である。さらに同種報告が複数人から反復されることが、単独の見間違いではなく共通問題として扱う手掛かりを強める。

**この伝承における現れ方**

「見た」という個々の視覚異常が出発点となり、類似証言の反復によって「同じ種類の何かを複数人が見ている」という問題へ拡張される。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAT.TYPE_ASSIGNMENT` — 類型化
- Primary Parent: `D09.CAT` — カテゴリー化
- Secondary: `D09.CAT.NAMING` — 命名
- Status: `I` — Inferred

**判定根拠**

場所・服装・大きさ・行動が必ずしも一致しない複数の目撃を、「通常より極端に小さい成人男性様存在」という共通特徴に基づいて同一類型へ束ねる操作が中心である。「小さいおじさん」という呼称はその類型を共有・検索可能にする名称としてSecondaryに置く。

**この伝承における現れ方**

ばらばらの目撃体験を個別の不可解事例として残さず、「これは小さいおじさんの目撃だ」という既知の型へ分類することで、異なる証言同士を同じ現象として理解できるようにする。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown

**判定根拠**

2008年の同時代公開掲示板自体が「妖精？！お化け？！何でもいい」と正体を開いたままにし、初期共有核では妖精・妖怪・霊・未知生物のいずれにも固定されない。後代の外部説明や妖怪解釈から存在論を補わない。

**この伝承における現れ方**

目撃を同じ類型として整理することはできても、その類型が何者で、なぜ現れるのかという存在論は初期Scopeでは未決定のまま残る。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.PAS.SPONTANEOUS_SELECTION` — 偶然選ばれる・遭遇する
- Primary Parent: `D11.PAS` — 受動発生
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

安定した召喚法・場所・時刻条件はなく、目撃者は日常状況で偶発的に対象となる。「見る」は体験の構成要素だが、「見れば再現的に発動する」という規則ではない。

**この伝承における現れ方**

目撃者は意図して怪異を呼び出すのではなく、日常の中で突然、極小男性様存在を視認する。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC` — 焦点人物
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

D13主作用は異常存在が一人の目撃者に対して顕現・認識されることであり、その直接の体験主体を作用対象とする。

**この伝承における現れ方**

怪異の効果は、物体破壊や身体攻撃ではなく、目撃者の前に現れて認識されることで成立する。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.MAN.MANIFEST_ONLY` — 顕現のみ
- Primary Parent: `D13.MAN` — 顕現・観測
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

初期共有核に共通して確認できるのは、極小成人男性様存在が現れて視認されることまでである。攻撃・追跡・会話・予言・幸運付与は必須でない。

**この伝承における現れ方**

「小さいおじさん」は何かを強制的に起こす主体としてより、日常空間へ一時的に現れる観測対象として機能する。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEU` — 中立
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

初期共有核の目撃自体には固定した利益・危害がない。後代の幸運・恐怖・危害解釈をScopeへ混入しない。

**この伝承における現れ方**

目撃は奇妙さを残すが、身体被害や利益を必須の終端としない。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.KNW.UNCERTAINTY_PRESERVED` — 不確実性維持
- Primary Parent: `D15.KNW` — 世界認識・知識
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

目撃後も正体・原因・再現条件は解明されず、「何を見たのか」という不確実性が残る。名称と類型は得られるが、真相は得られない。

**この伝承における現れ方**

受容者は「小さいおじさん」という理解枠を得る一方、その存在が実在するのか、何者なのかという核心の不確実性は維持される。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.EVT.SINGLE_OBSERVATION` — 単発観測
- Primary Parent: `D16.EVT` — 単一エピソード・事象内
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

最小核は一回の短い目撃で完結し、期限・追跡・長期進行を必須としない。

**この伝承における現れ方**

一度の視認が体験単位となり、その後も持続的に作用する規則はScope核に含まれない。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.NON.OBSERVATIONAL_ONLY` — 観測のみ
- Primary Parent: `D17.NON` — 制御不要
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

Scope核は危害を必須とせず、召喚・排除・回避・利用の安定手順もない。観測だけで体験が完結するため制御不要型を採る。

**この伝承における現れ方**

遭遇後に必ず何かをしなければならない規則はなく、目撃者は異常を見たという経験だけを持ち帰る。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

L1では伝承内部で異常存在が目撃者へ顕現する。L2は、話を聞く・読むだけで現実側受容者が作用対象になる規則がない。L3は、コミュニティ形成・ニュース化・流通自体を社会現実上の作用結果とは数えず、制度・市場・行動変化を示す独立したX Evidenceを固定していないため0とする。

**この伝承における現れ方**

因果作用は目撃場面の内部に留まり、受容者への自己適用や、確認可能な社会制度・市場変化まではScope内で生じない。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.NET.SNS_VIRAL` — SNS・拡散ネットワーク
- Primary Parent: `D19.NET` — ネットワーク公開圏
- Secondary: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Status: `I` — Inferred

**判定根拠**

2007年mixi共同体、2008年公開掲示板、2009年オンラインニュースというネットワーク越しの目撃報告集約が直接確認できる。2009年には全国的著名人の名を伴う「今話題の都市伝説」として大衆圏へ再提示されている。

**この伝承における現れ方**

特定地域の口承ではなく、ネットワーク上で離れた目撃者の報告が結び付けられ、全国的大衆へ可視化される。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.PER.EXPERIENCER` — 体験者本人
- Primary Parent: `D20.PER` — 当事者・家族
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

個々の目撃の追加的な細部を直接知る主体は体験者本人であり、カテゴリは複数の当事者証言の集積から成立する。正体・解除法を独占する専門家・組織はScope内に成立しない。

**この伝承における現れ方**

受容者が得られる情報は各目撃者の体験報告に依存し、目撃時の具体的状況は当事者だけが一次的に保持する。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

日常生活空間と通常の成人男性像を利用するが、特定地点・実在人物・事件・制度を伝承内容の成立条件としない。芸能人名は流通Evidenceであり、伝承内容の固定アンカーではない。

**この伝承における現れ方**

身近な住宅・屋外・日常空間へ移植可能な目撃譚であり、特定聖地や歴史事件がなければ成立しない伝承ではない。
