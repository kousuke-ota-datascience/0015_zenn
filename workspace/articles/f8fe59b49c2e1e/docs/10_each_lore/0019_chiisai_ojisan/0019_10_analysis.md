# 1. 伝承エントリ基本情報

- `Entry_ID`: `19`
- `伝承エントリ名称`: 小さいおじさん
- `Macro_Category`: 全国型怪異・儀式
- `Entry_Type`: 物語・伝説
- `Version_Scope`: 平成期以降に「小さいおじさん」と呼ばれる極小の成人男性様存在の目撃談群。非危害・単発目撃を中心とし、幸運・会話・妖精等の意味付けは派生として扱う。

# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（証拠不足）

**判定根拠**

`0019_00_contents.md` では平成期以降のメディア流通と2018年までの事典整理を確認できるが、1990年代その他の生成年代を直接示す成立初期資料は固定できていない。旧Pilotの1990年代を、後代の知名度から逆算しない。

**この伝承における現れ方**

現代的な名称・メディア環境と強く結び付く伝承であることは分かるが、最初の目撃・命名・カテゴリ形成がいつ起きたかは現証拠では決められない。

### 2.1.2. D02: 最古確認流通媒体

**判定根拠**

個別の最初期目撃談、最初のテレビ放送、口頭伝承、雑誌掲載等を一意に固定できない。後代にテレビ・Webが重要だったことから最古媒体を推定しない。

**この伝承における現れ方**

複数媒体が混在してカテゴリを増幅したことは確認できるが、最初に人から人へ流れた回路は不明のまま保持する。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

**判定根拠**

後代整理では芸能人の体験談・テレビ番組が知名度形成に大きく関わり、その後動画・Webで反復される。個々の一次放送資料を今回固定していないためStatusは`I`とする。

**この伝承における現れ方**

短い目撃談が放送で広く共有され、その映像・発言が動画サイト等で再視聴・再話される。媒体は個別体験を全国的な共通カテゴリへ束ねる役割を持つ。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

既存の目撃談が動画・Web上で検索可能・再視聴可能になり、「小さいおじさん」という共通像が強化される。後代には幸運・会話・妖精等の意味が追加されるため増補をSecondaryとする。

**この伝承における現れ方**

テレビ等で一過性だった目撃談がネット上で蓄積され、別の目撃者が既存カテゴリへ新しい体験を追加する循環が形成される。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.EXP.EXPERIENCE_SUMMARY` — 体験要約
- Primary Parent: `D05.EXP` — 体験叙述
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

代表形は「日常空間で小さいおじさんを見た」という短い個人目撃報告であり、召喚・儀式・手順を提示しない。旧 `RITUAL_PROCEDURE` は内容と明確に不整合であるため変更する。

**この伝承における現れ方**

目撃者は、どこで何をしていた時に何を見て、どう見失ったかを短く報告する。伝承は実践方法ではなく体験叙述として提示される。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T1` — 直接体験事実
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

個々の目撃談は「自分が実際に見た」という本人経験として提示される。第三者が実在を検証できるかとは別に、語りの真実性形式は直接体験である。

**この伝承における現れ方**

「確かに見た」という目撃者の主観確信が語りの本当らしさを支え、短時間で見失ったため外部検証が困難になる。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ANO.UNKNOWN_EXISTENCE` — 未知存在
- Primary Parent: `D07.ANO` — 異常体験・存在
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

人間に似るが通常サイズではない正体不明存在が本当にいるのか、何者なのかが中心的不確実性である。

**この伝承における現れ方**

目撃者は「おじさん」と認識できるほど人間らしい像を見ながら、人間として説明できない縮尺のため既知カテゴリだけでは処理できない。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.DEX.DIRECT_EVENT` — 出来事への直接遭遇
- Primary Parent: `D08.DEX` — 直接経験
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

代表的目撃談では、目撃者自身の視覚経験が「何を見たのか」という問いの契機になる。他者の噂だけで因果系が始まるものではない。

**この伝承における現れ方**

通常の生活中に極小の人間様存在が視界へ入り、その知覚経験を説明する必要が生じる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAT.NAMING` — 命名
- Primary Parent: `D09.CAT` — カテゴリー化
- Secondary: `D09.CAT.TYPE_ASSIGNMENT` — 類型化
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

曖昧な極小人間の目撃を「小さいおじさん」と名付けることで、別人の体験談と比較・蓄積できるカテゴリが形成される。旧 `RITUAL_RULE` に相当する制御規則は代表形に存在しない。

**この伝承における現れ方**

未知の像が、既知の社会的人物類型「おじさん」を縮小した名称へ変換される。その名称が後続の目撃を同じ類型へ割り当てる枠組みになる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.BIO.ANOMALOUS_ORGANISM` — 異常生物・UMA
- Primary Parent: `D10.BIO` — 異常生物・内在存在
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

目撃核は妖怪・霊と断定せず、「人間に似るが通常ではあり得ない身体サイズを持つ存在」が物理的にそこにいるという形で提示される。後代の妖怪・妖精解釈をPrimaryへ遡及させない。

**この伝承における現れ方**

正体説明が付く前の段階では、目撃対象は未知の小型人間様存在として世界内に置かれる。存在論を超自然主体へ過剰確定しない。

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.SEN.VISUAL_EXPOSURE` — 見る
- Primary Parent: `D11.SEN` — 感覚曝露
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

目撃談は視覚的に存在を認識することで成立し、召喚・接触・操作を必要としない。

**この伝承における現れ方**

偶然視界へ入った瞬間に体験が成立し、その後の観察・見失いへ進む。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC` — 焦点人物
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

個々の目撃者が異常知覚を経験し、報告の焦点となる。

**この伝承における現れ方**

集団全体へ作用するのではなく、一人の観察者の視界・認識に体験が焦点化される。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

**判定根拠**

代表形では存在が見えること以上の安定した作用を必須としない。追跡・攻撃・予言は派生である。

**この伝承における現れ方**

短時間そこに現れ、見られ、見失われるだけで怪異体験が完成する。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEU` — 中立
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

中心形では目撃者への利益・身体危害・社会的損失が必須ではない。

**この伝承における現れ方**

### 2.3.5. D15: 帰結領域

観察後も正体・実在理由は解明されず、「何だったのか」が残る。

**この伝承における現れ方**

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

**判定根拠**

**この伝承における現れ方**

見る→短時間観察する→見失う、という一事象で体験が終了する。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

**判定根拠**

中心形では危害回避・制御・利用の安定手順がなく、目撃者は観察・確認するだけである。

**この伝承における現れ方**

存在を捕まえる、追い払う、召喚する等の方法は核に含まれず、制御問題そのものが成立しにくい。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

L1では伝承内で異常存在が目撃者の知覚対象となる。伝承を読む・聞くだけで受容者本人へ同じ現象が発動する規則はなく、メディアでカテゴリが形成されたことだけをL3の社会効果へ拡張しない。

**この伝承における現れ方**

因果効力は個々の目撃エピソード内に置かれ、後代メディアの再分類は流通・意味形成として別次元で扱う。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

特定地域に固定されず、テレビ・動画・Web等の大衆媒体を通じて広域に共有されるカテゴリとして整理される。ただし今回の固定資料だけで全国認知率を直接測定していないためStatusは`I`とする。

**この伝承における現れ方**

どの地域の日常空間でも目撃可能な存在として再話でき、土地固有伝承に閉じない。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.NON.COMMON_KNOWLEDGE` — 一般共有
- Primary Parent: `D20.NON` — 特権なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

正体を説明できる権威者は置かれず、名称・目撃特徴は公衆へ共有される。

**この伝承における現れ方**

各目撃者が独立に「自分も見た」と報告を追加でき、真相情報を独占する内部者を必要としない。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

室内・庭・道路等の一般的な日常空間を背景にするが、特定の実在地点・事件・人物へ固定されない。完全な抽象A0ではなく、日常現実環境に埋め込まれた目撃型としてA1を用いる。

**この伝承における現れ方**

目撃場所・人物を別地域へ置換しても、「極小のおじさんを見た」という核が維持される。
