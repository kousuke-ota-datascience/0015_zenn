# 1. 伝承エントリ基本情報

- `Entry_ID`: `19`
- `伝承エントリ名称`: 小さいおじさん
- `Macro_Category`: 全国型怪異・儀式
- `Entry_Type`: 目撃伝承・現代怪異
- `Version_Scope`: **2007–2009年に直接確認できる初期共有核。通常の成人男性・「おじさん」のように見えるが、人体として不可能なほど小さい存在を見たという複数の目撃報告が、「小さいおじさん／小さいオッサン」という共通名称の下に束ねられて流通する目撃カテゴリ。**
- Scope外: 妖精・妖怪・霊・UMAへの正体固定、幸運、特定神社、会話、召喚方法、直接危害、固定身長・服装等。

# 2. 分析概念次元

## 2.1. 来歴・流通・提示

### D01: 生成年代

- Value: なし
- Status: `U`

2007年までに名称付きカテゴリが存在したことは直接確認できるが、これは伝承の生成時期そのものを示さない。2006年の2ch投稿は後代転載のみで原スレッドを固定できず、1990年代成立説も今回のEvidenceでは確認できない。

### D02: 最古確認流通媒体

- Primary: `D02.WEB.SNS`
- Parent: `D02.WEB`
- Status: `D`

2007年4月14日開設のmixi「小さいおじさん！！」コミュニティを直接確認できる。2006年2ch転載は原資料未固定のため、現時点の最古Direct evidenceには採用しない。

### D03: 確認流通媒体ポートフォリオ

- Primary: `D03.WEB.SNS`
- Secondary: `D03.WEB.FORUM`; `D03.WEB.WEBSITE`
- Parent: `D03.WEB`
- Status: `D`

2007年mixi、2008年公開掲示板、2009年オンラインニュースをScope期間内に直接確認できる。テレビ言説への言及はあるが、個別放送資料をR1で直接固定していないためBRDは付与しない。

### D04: 生成・変容パターン

- Primary: `D04.COL.MULTI_AUTHOR`
- Parent: `D04.COL`
- Status: `I`

単一の原物語が再話されるより、複数の目撃者・芸能人・投稿者による異なる目撃報告が「小さいおじさん」という共通カテゴリへ追加され、カテゴリの内容が厚くなる構造を持つ。2007–2009年資料で複数証言の集約を直接確認できるが、それを生成機構として位置付ける判定は推論を含むため`I`とする。

### D05: 提示形式

- Primary: `D05.HYB.MULTI_TESTIMONY`
- Secondary: `D05.EXP.EXPERIENCE_SUMMARY`
- Parent: `D05.HYB`
- Status: `I`

Scopeは単一体験談ではなく、複数人物の「見た」という短い体験報告を束ねた目撃カテゴリとして成立する。個別の構成要素は短い体験要約である。

### D06: 真実性提示

- Value: `D06.T6` — 真偽未確定
- Status: `I`

個々の目撃者は直接体験として語る一方、2009年にはカテゴリ全体が「都市伝説」として提示され、存在の実在性は確定されない。Version Scopeが単一証言ではなく目撃カテゴリであるため、カテゴリ全体が要求する認識論的スタンスを`T6`とする。R3の`D`は、資料が明示する個々の証言とカテゴリ全体の真実性を区別すると強すぎるためR4で`I`へ修正した。

## 2.2. 意味形成

### D07: 意味形成対象

- Primary: `D07.ANO.UNKNOWN_EXISTENCE`
- Secondary: `D07.ANO.ANOMALOUS_PERCEPTION`
- Parent: `D07.ANO`
- Status: `I`

この伝承がなければ、「極端に小さい成人男性様の何かがいるのか／今見たものは何だったのか」という未知存在と異常視覚体験が説明されないまま残る。

### D08: 意味形成契機

- Primary: `D08.DEX.PERCEPTUAL_ANOMALY`
- Secondary: `D08.STY.COMMUNITY_REPETITION`
- Parent: `D08.DEX`
- Status: `I`

各報告の起点は、通常人体として説明しにくい極小男性様存在を見るという視覚的異常である。さらに同種の目撃報告が複数人から反復されることが、共通カテゴリとしての意味形成を強化する。

### D09: 意味付与操作

- Primary: `D09.CAT.NAMING`
- Parent: `D09.CAT`
- Status: `I`

サイズ・服装・場所・行動の異なる短い目撃を「小さいおじさん」という一つの名称で束ねることが中心的な認知操作である。`TYPE_ASSIGNMENT`はこのEntryでは命名と独立した追加構造として十分に分離できないためSecondaryに置かない。

### D10: 因果源存在論

- Primary: なし
- Status: `U`

2008年の同時代公開掲示板自体が「妖精？！お化け？！何でもいい」と正体を開いたままにし、初期共有核では妖精・妖怪・霊・未知生物のいずれにも固定されない。後代の外部説明や妖怪解釈から存在論を補わない。

## 2.3. 因果・行動モデル

### D11: 発動・接触条件

- Primary: `D11.PAS.SPONTANEOUS_SELECTION`
- Parent: `D11.PAS`
- Status: `I`

安定した召喚法・場所・時刻条件はなく、目撃者は日常状況で偶発的に対象となる。「見る」は体験の構成要素ではあるが、「見れば再現的に発動する」という発動規則ではないため`VISUAL_EXPOSURE`をPrimaryにしない。

### D12: 作用対象

- Primary: `D12.FOC.PROTAGONIST_EXPERIENCER`
- Parent: `D12.FOC`
- Status: `I`

D13主作用は異常存在が一人の目撃者に対して顕現・認識されることであり、その直接の体験主体を作用対象とする。

### D13: 作用機構

- Primary: `D13.MAN.MANIFEST_ONLY`
- Parent: `D13.MAN`
- Status: `I`

初期共有核に共通して確認できるのは、極小成人男性様存在が現れて視認されることまでである。攻撃・追跡・会話・予言・幸運付与は必須でないため追加作用を置かない。

### D14: 帰結極性

- Value: `D14.NEU`
- Status: `I`

初期共有核の目撃自体には固定した利益・危害がない。後代の幸運・恐怖・危害解釈をScopeへ混入しない。

### D15: 帰結領域

- Primary: `D15.KNW.UNCERTAINTY_PRESERVED`
- Parent: `D15.KNW`
- Status: `I`

目撃後も正体・原因・再現条件は解明されず、「何を見たのか」という不確実性が残る。目撃によって未知が解消されるのではなく、名称を持つ新たな未知対象が形成される。

### D16: 因果時間構造

- Primary: `D16.EVT.SINGLE_OBSERVATION`
- Parent: `D16.EVT`
- Status: `I`

最小核は一回の短い目撃で完結し、期限・追跡・長期進行を必須としない。

### D17: 回避・制御方式

- Primary: `D17.NON.OBSERVATIONAL_ONLY`
- Parent: `D17.NON`
- Status: `I`

Scope核は危害を必須とせず、召喚・排除・回避・利用の安定手順もない。観測だけで体験が完結するため、制御不要型を採る。

### D18: 作用レイヤー

- `D18.L1=1`
- `D18.L2=0`
- `D18.L3=0`
- Status: `I`

L1では伝承内部で異常存在が目撃者へ顕現する。L2は、話を聞く・読むだけで現実側受容者が作用対象になる規則がないため0。L3は、コミュニティ形成・ニュース化・流通自体を社会現実上の作用結果とは数えず、制度・市場・行動変化を示す独立したX EvidenceをR1で固定していないため0とする。

## 2.4. 社会的埋め込み

### D19: 流通範囲

- Primary: `D19.NET.SNS_VIRAL`
- Secondary: `D19.MAS.NATIONAL_PUBLIC`
- Parent: `D19.NET`
- Status: `I`

2007年mixi共同体、2008年公開掲示板、2009年オンラインニュースというネットワーク越しの目撃報告集約が直接確認できる。2009年には多数の全国的著名人の名を伴う「今話題の都市伝説」として大衆圏へ再提示されており、全国的大衆をSecondaryとする。

### D20: 特権情報保持者

- Primary: `D20.PER.EXPERIENCER`
- Parent: `D20.PER`
- Status: `I`

個々の目撃の追加的な細部を直接知る主体は体験者本人であり、カテゴリは複数の当事者証言の集積から成立する。正体・解除法を独占する専門家・組織はScope内に成立しない。

### D21: 現実アンカー

- Value: `D21.A1` — 一般的現実背景
- Status: `I`

日常生活空間と通常の成人男性像を利用するが、特定地点・実在人物・事件・制度を伝承内容の成立条件としない。芸能人名は流通Evidenceであって、伝承内容の固定アンカーではない。

# 3. R4 Entry QA

## 3.1. D12 → D13 → D15 causal QA

```text
D12: 目撃者・体験者
→ D13: 極小成人男性様存在が顕現し視認される
→ D15: 正体・原因が解明されず不確実性が残る
```

**結果: Pass。** 身体危害・幸運等はR2 Scope外であり因果列へ追加しない。

## 3.2. D18 L3 evidence QA

R1で確認した資料は、名称付きコミュニティ形成、掲示板上の体験募集、ニュース化・メディア再流通を示す。しかし、伝承流通が制度・市場・現実行動等を変化させたことを独立に示す`X` Evidenceは固定していない。

**結果: `L3=0`を維持。Pass。**

## 3.3. U / NA / C QA

- `D01=U`: 2007年最古確認点を生成時期へ変換しないため妥当。
- `D10=U`: 初期Scopeが正体を開いたままにしており、存在論を推測で埋めないため妥当。
- `NA`: なし。
- `C`: なし。

**結果: Pass。**

## 3.4. taxonomy gap QA

2007–2009年Scopeは現行taxonomyで表現可能であり、確定的な新Child要求はない。

**結果: Pass。baseline変更なし。**
