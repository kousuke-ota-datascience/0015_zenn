# 1. 伝承内容

## 1.1. 最小共有核

2007–2009年までに直接確認できる流通資料から、安全に共有核として取り出せるのは次である。

1. **通常の成人男性・おじさんのように見えるが、人体としてあり得ないほど小さい存在**が語られる。
2. それを「小さいおじさん／小さいオッサン」と呼ぶ。
3. 特定の一人だけでなく、複数の目撃者・体験談が同じ名称の下に束ねられている。
4. 正体は妖精・お化け等と推測されるが、共有核では確定しない。
5. 召喚手順、特定場所、危害、幸運、会話等は全体共通ではない。

この核は、長い一つの物語ではなく、**短い目撃証言群をカテゴリ名で束ねる現代怪異**として成立する。

## 1.2. 目撃形

後代の直接証言を含めると、室内、浴室、映画館、屋外等の日常空間で、数cm〜数十cm程度の成人男性様存在を短時間見る型が確認できる。服装・人数・行動は一致しない。

橋本環奈の2020年証言では約10cm、浴槽の縁を走る緑の三角帽子の男性。釈由美子の2022年証言では缶コーヒー程度の大きさで、人目を避けた場所に現れ、映画館でポップコーンを拾う等の行動が語られる。これらはVariationであり、初期核へ細部を遡及しない。

## 1.3. 中心的な異常性

中心は「未知生物として精密分類できること」ではなく、**日常的な成人男性カテゴリーと極端に小さい身体サイズの矛盾**である。「おじさん」という既知カテゴリーが先にあるため、外見差の大きい個別目撃も同じラベルで回収できる。

## 1.4. 条件・規則・禁忌

- 発生: 偶発的目撃として語られる。
- 再現条件: 安定した召喚法・時刻・場所は初期共有核で確認できない。
- 禁忌: 共通しない。
- 危害: 必須ではない。
- 幸運: 後代に「見ると幸運」等の付加があるが、2007–2009年核には必須でない。
- 会話: 一部後代証言ではあるが、共有核ではない。

## 1.5. 終端

代表的な最小形では、目撃者が小さい男性様存在を見たという報告自体で完結し、正体・原因・再現条件は解決されない。捕獲・物証・公的確認は共有核に含まれない。

# 2. 伝承史・流通

## 2.1. 最古確認

- **2007年4月14日:** mixi上に「小さいおじさん！！」コミュニティが開設されていることを現在直接確認できる。したがって、少なくともこの時点で名称付きカテゴリと複数目撃談の認識がオンライン共同体上に存在した。
- **2006年8月11日:** 後代転載には同名の2ch投稿が残るが、原スレッド未固定のため確定的最古記録にはしない。
- 1990年代成立を直接示す資料は今回固定できなかった。

## 2.2. 2008–2009年の拡散

2008年の公開掲示板では「ダウンタウンDXで話題」「mixiコミュ」と結びつけて体験談が募集され、2009年のニュースでは「今話題の都市伝説」とされ、多数の芸能人の名が目撃者として列挙されている。

この時期には、テレビでの芸能人語り、Webコミュニティ、掲示板、ニュース記事が相互参照し、**個別の異常知覚報告を『小さいおじさん』という共通カテゴリへ集約する循環**が成立していたと判断できる。

## 2.3. 後代の変容

- 具体的な服装・サイズ・人数・場所が増殖する。
- 妖精・妖怪・霊・幻覚等の正体説明が付く。
- 「見ると幸運」等の吉兆化が進む型がある。
- 特定神社との場所付着が生じる型がある。
- 芸能人目撃談そのものが伝承の信憑性を補強する材料として反復利用される。
