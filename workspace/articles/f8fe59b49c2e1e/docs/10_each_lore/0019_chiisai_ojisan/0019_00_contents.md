# 1. 伝承内容

## 1.1. summary

「小さいおじさん」は、日常生活の中で、成人男性・中年男性の外見を持ちながら、数センチから数十センチ程度しかないように見える存在を偶発的に目撃したという体験談群である。出現場所は室内、庭、道路、自然環境など一定せず、特定の時刻・儀式・禁忌も共有されない。目撃者は短時間その存在を認識するが、近づく前に物陰へ消える、視界から外れる、いつの間にかいなくなる等で終わることが多い。

この伝承の異常性は、「おじさん」というきわめて日常的で社会的に理解しやすい人物像と、「人間としてあり得ない身体サイズ」が結合する点にある。未知生物の詳細な形態を語るのではなく、既知の人間カテゴリーを縮小しただけの像であるため、目撃者は一目で「小さい人間」「小さいおじさん」と認識できる。その単純さが異なる体験談を同じカテゴリへ束ねやすくしている。

代表的な目撃談では、存在は目撃者へ直接攻撃せず、予言・呪い・強制的な追跡も行わない。したがって、物語的な危険の解決よりも「今見たものは何だったのか」という認識的不確実性が終端に残る。後代には幸運の前兆、妖精・妖怪、精霊、幻覚等の説明が付く場合があるが、それらは目撃核に必須ではない。

平成期以降、芸能人の体験談やテレビ、動画サイト、Webまとめ等によって知名度が増し、「自分も見た」という新しい体験談が既存カテゴリへ回収されるようになったと考えられる。すなわち、メディアは単に話を広めるだけでなく、曖昧な知覚経験へ「小さいおじさん」という既成ラベルを提供する役割も持つ。

## 1.2. 詳細構造

1. **通常状況:** 目撃者が室内・屋外等の日常環境にいる。
2. **異常知覚:** 視界に人間に似た極小の存在が入る。
3. **カテゴリ認識:** 服装・体格・顔つき等から「おじさん」に見えると判断する。
4. **観察:** 数秒〜短時間、動き・位置を確認する。
5. **消失:** 物陰へ入る、見失う、突然いなくなる等で観察が終わる。
6. **事後解釈:** 妖怪・妖精・錯覚等の説明候補が後から与えられる。
7. **未解決:** 正体は確定しない。

| 主体 | 役割 |
|---|---|
| 小さいおじさん | 目撃される異常存在 |
| 目撃者 | 知覚・報告主体 |

## 1.4. 場所・空間

特定聖地へ固定されない。室内、庭、道路、自然環境等の通常空間に出現するため、異常は場所より**存在のサイズと人間らしさ**に集中する。

## 1.5. 物・記号・媒体

- 小型の人間身体: 中心的識別特徴。
- 服装: 中年男性らしさを補強するが統一されない。
- テレビ・動画・Web: 個別目撃談を同じ名称へ集約する後代媒体。

## 1.6. 条件・規則

- 偶発目撃が中心。
- 呼び出し手順、特定禁忌、安定した出現条件は確認できない。
- 見ること自体が危害を発動するという規則も中心形にはない。

## 1.7. 中心異常

通常の成人男性に見える存在が、人間として説明困難な極端な縮尺で日常空間に存在する。

## 1.8. 行動・対応

目撃者は観察、追視、確認を試みるが、存在を捕捉・検証できないまま見失うことが多い。

## 1.9. 帰結

- 驚き・不可解さ。
- 正体不明のまま体験が終了。
- 直接危害のない型が中心。

## 1.10. 不確実性

- 個々の体験談同士が同一の伝承系譜に属するか不明。
- 身長・服装・場所を一般化しない。
- 芸能人の後代再話を最初期目撃へ遡及させない。
- 妖精・妖怪・幻覚等は説明仮説であり、目撃内容そのものではない。

# 2. 伝承史・異伝

## 2.1. 最古確認

Pilotは1990年代成立を推定するが、今回の増補では1990年代の一次的な最古目撃資料を固定できていない。確実に言えるのは、平成期以降のメディア環境で「小さいおじさん」という共通名が広く流通し、2018年までには現代怪異事典で独立項目的に整理されていることである。

## 2.2. 流通

口頭の体験談、テレビ番組、芸能人の語り、動画サイト、Web再話が相互に補強し、全国的な目撃カテゴリへ成長した。

## 2.3. 異伝

| 型 | 差分 |
|---|---|
| 室内目撃 | 家具・床・室内物の近くで見る |
| 屋外目撃 | 庭・道路・自然環境で見る |
| 非接触型 | 見るだけで終わる |
| 会話・予兆型 | 後代に会話・幸運等の意味を追加 |
| 妖精・妖怪解釈 | 正体説明を追加 |

## 2.4. 変容上の重要点

個々の短い知覚体験が、メディア流通によって「小さいおじさん」という名称へ収斂し、その名称を知った受容者が新たな体験を同カテゴリで報告する循環が形成される。
