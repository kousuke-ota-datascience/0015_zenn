# 1. 伝承内容

## 1.1. summary

虚舟の主要形は、享和3年（1803）2月22日に常陸国の海岸へ、通常の舟とは異なる形状の舟が漂着したとする奇談である。国立公文書館所蔵『弘賢随筆』の記録では、舟は香盒のような形で、上部にガラス障子、底に鉄板があり、中には水・食糧と一人の女性がいた。女性は二尺四方ほどの箱を所持していたとされ、舟内には記号のようなものが記されていた。

地元の古老は女性を外国の王の娘ではないかと推測し、箱の中身についても推測を述べる。しかし、その推測は確認された真相として提示されない。幕府・領主への届け出や長崎への輸送には費用がかかるという理由が語られ、女性は再び舟へ乗せられ、沖へ引き出されたと記録される。女性・箱・記号・舟の由来は確定しないまま終わる。

『兎園小説』等にも類似の常陸国うつろ舟奇談が記録され、研究では複数文書の存在が確認されている。一方、舟を「UFO」、女性を宇宙人等として読む説明は江戸期記録の確定解ではない。近現代の研究・再話で生じた別の解釈層として分離する。

## 1.2. 詳細展開

### 1.2.1. 海岸への漂着

『弘賢随筆』は、1803年2月22日に常陸国の「はらやどり」とされる浜へ奇妙な舟が漂着したと記す。国立公文書館は現在の茨城県神栖市波崎舎利浜ではないかという比定説を紹介するが、比定を物語内の確定地名とはしない。

### 1.2.2. 舟の観察

舟は香盒のような形で長さ約3間、上部にガラス障子、底に鉄板を備えたとされる。通常の和船とは異なる外観が具体的に描写される。

### 1.2.3. 女性・箱・記号

舟内には水・食糧と一人の女性がおり、女性は二尺四方ほどの箱を持つ。舟には解読されない記号がある。古老や記録者は外国の王女等の可能性を推測するが、女性の出自は確定しない。

### 1.2.4. 詮議と推測

村人側は、女性・箱・舟の正体について既知の外国や過去の漂着譚を手掛かりに説明を試みる。箱の内容についても推測が語られるが、開封・確認による解決は提示されない。

### 1.2.5. 海へ戻す終端

幕府・領主へ届け出ると長崎への輸送等の費用がかかるという理由が語られ、女性は再び舟へ乗せられて沖へ引き出される。物語は正体を確定しないまま終わる。

# 2. 伝承史・異伝

## 2.1. 最古確認

現在、国立公文書館所蔵『弘賢随筆』に「享和3年（1803）2月22日、常陸国への漂着」とする記録が残る。また研究資料は、曲亭馬琴らの『兎園小説』（1825年）等、江戸期に複数の文書が同系奇談を記録したことを示す。

ここで1803年は記録された出来事の日付であり、現存文書の成立日や伝承の実際の生成日と同一ではない。最古確認は「前近代に文書記録が存在する」範囲に限定する。

## 2.2. 流通・拡散

- 江戸期: 『弘賢随筆』『兎園小説』等の文書に常陸国うつろ舟奇談が記録される。
- 近現代: 古文書の復刻・研究を通じて再提示される。
- 現代: 舟の形状等からUFOとの類似を論じる再解釈が、研究・一般向け記事等で流通する。

江戸期から現代までの全流通経路を連続的に復元できる資料は今回固定していない。
