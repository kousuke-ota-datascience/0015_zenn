# 1. 伝承エントリ基本情報

- `Entry_ID`: `112`
- `伝承エントリ名称`: 事故物件は一度別人を住ませれば告知義務が消える
- `Macro_Category`: 制度・陰謀
- `Entry_Type`: 命題型噂
- `Version_Scope`: 「事故物件では、事故後に一人の入居者を挟めば、その次の入居者への告知義務が消える」という代表命題を中心とし、2008年Yahoo!不動産Q&Aで確認できる同型命題、2010年代の掲示板再話・反証再流通までを内容理解の補助に含める。外国人・アルバイト等の人物設定は派生として扱い、中心命題へ必須化しない。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: `D01.G5` — 1990年代
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

パイロットでは本伝承を平成期以降の制度噂と捉え、1990年代成立として `D01.G5` を付与している。今回の増補で直接本文まで確認できた最古資料は2008年11月のYahoo!不動産Q&Aであり、そこでは複数回答者が「次の入居者まで告知すればよい」「次の次には告知義務がない」「間に一人住めば義務が消える」とほぼ同型の規則を当然の知識として提示している。

**この伝承における現れ方**

この俗説は、心理的瑕疵・事故物件という比較的新しい不動産消費者語彙と結び付き、「何人先まで告知するのか」という実務の不透明さを一人分の入居履歴で切る規則として流通する。少なくとも2008年にはオンライン上で既知の知識として現れており、2010年代には怪談・掲示板・一般Q&Aへ再流通している。

今回確認した直接証拠だけでは1990年代成立を固定できない。`D01.G5 / I` は既存Pilot Codingとして保持するが、証拠面ではtask 3の再検討対象である。2008年を起源年と読み替えない。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.CON.DEBUNK_RECIRCULATION` — 反証を伴う再流通
- Primary Parent: `D04.CON` — 論争・起源変化
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

2012年の掲示板ではすでに「今は間に1人住んだくらいじゃ告知義務は消えない」という訂正が投稿されている。2021年の国土交通省ガイドライン策定後は、不動産解説記事等が「一人挟めば自動的に告知不要」という理解を修正する文脈で元の俗説を再提示する。

**この伝承における現れ方**

俗説は反証によって消えるのではなく、反証文の中で元の命題が引用・要約されることで再流通する。「昔は一人挟めばよかった」「そういう裏技があるらしい」「今はそれでは消えない」という時制付きの再話へ変形し、制度変更・ガイドライン策定そのものが伝承を再提示する契機になる。

最初期から反証型だったわけではない。`DEBUNK_RECIRCULATION` は確認された流通史全体をみたパイロット判定として保持する。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.PRP.FACT_CLAIM` — 事実主張
- Primary Parent: `D05.PRP` — 命題・主張形式
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

2008年Q&Aでは、「次の次の人には告知義務がない」「間に一人でも住めば義務が消える」という一般規則として提示される。必ずしも個別事件の物語を必要とせず、制度上の事実として断定される。

**この伝承における現れ方**

受容者は「ある物件でそうだった」という一事例より、「事故物件一般にはこういうルールがある」という一般命題を受け取る。後代に外国人やアルバイトを一人挟む逸話が付いても、それらは中心命題を具体化する補助物語であり、核は制度的事実主張である。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T4` — 一般・制度・科学事実
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

語りは「怖い話として信じるか」ではなく、宅地建物取引上の実務・告知義務に関する実在ルールとして理解されることを要求する。2008年Q&Aでも回答者は法・業界知識らしいものとして提示する。

**この伝承における現れ方**

信憑性は「宅建業界には一般人が知らない運用がある」「契約上は次の人まで」といった制度知識の権威性によって作られる。したがって真実性提示は個人的体験談より制度的事実性に依存する。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.INO.HIDDEN_RULE_PROCEDURE` — 隠れた制度・手続
- Primary Parent: `D07.INO` — 制度・組織
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

流通資料の中心質問は、事故物件で「いつまで」「何人後まで」「どのような場合に」過去の死を知らせる必要があるのか、という一般消費者から見えにくい告知実務である。

**この伝承における現れ方**

不確実性は人の死そのものではなく、死の事実が不動産取引上いつまで意味を持つのかという制度境界にある。俗説は、専門判断・個別事情・時間経過等が絡む不透明な問題を「一人挟む」という見えない手続規則として説明する。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.OPA.OPAQUE_RULE` — 不透明な規則・判断
- Primary Parent: `D08.OPA` — 技術・制度の不透明性
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

同じ「人が死んだ物件」であっても、誰に何を告げるべきかが一見して分からず、一般人が法律・業界慣行を直接観察できないことがQ&Aの問いを生む。

**この伝承における現れ方**

「自分が契約する物件で過去の事故を知らされなかったとしても、本当に事故がなかったのか」という情報非対称が契機になる。規則の不透明性があるからこそ、単純な裏ルールが説明力を持つ。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.SSI.SYSTEM_LOGIC` — 制度論理化
- Primary Parent: `D09.SSI` — 社会・制度解釈
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

俗説は、不透明な告知判断を「事故発生→最初の入居者には告知→一人居住→次から不要」という明確な手順へ変換する。

**この伝承における現れ方**

個別事情ごとの判断を捨て、入居者の人数という数えられる変数へ制度を還元する。その結果、一般人でも「なぜ知らされない事故物件があり得るのか」を短い制度モデルとして理解できる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.HUM.ORGANIZATION` — 組織・制度主体
- Primary Parent: `D10.HUM` — 人間・社会主体
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

俗説の作用は幽霊や呪いではなく、貸主・仲介業者・不動産制度といった人間の組織・制度的運用によって生じるとされる。

**この伝承における現れ方**

「一人挟む」という手順を理解し利用できる主体として不動産業者が置かれることが多い。後代派生では、業者が情報格差を意図的に利用する加害的主体として強調される。

中心命題だけなら制度規則自体が原因で、特定組織の悪意を必須としない。`ORGANIZATION` はパイロットの解釈を保持したもの。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.NCR.AMBIENT_EFFECT` — 環境・社会に広く作用
- Primary Parent: `D11.NCR` — 接触不要
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

この伝承は、特定の呪物への接触や儀式実行によって作動するのではなく、不動産取引制度の中にいる者へ一般的に適用される規則として提示される。

**この伝承における現れ方**

事故物件に関する取引が発生すると、当事者が俗説を知っているか否かに関わらず「一人挟めば告知状態が変わる」という制度効果が働く、と想定される。受容者が話を聞くこと自体は発動条件ではない。

実際には「事故発生」「最初の入居者」という具体条件を持つため、D11のコード適合性にはtask 3で再検討余地がある。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.AUD.GENERAL_PUBLIC` — 一般公衆
- Primary Parent: `D12.AUD` — 受容者・公衆
- Secondary: `D12.ORG.INSTITUTION_SYSTEM` — 制度・社会システム（Parent: `D12.ORG` — 組織・制度）
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

俗説が直接問題化するのは、事故歴を知らされる／知らされない入居希望者である。同時に、告知義務という制度運用そのものが作用対象として説明される。

**この伝承における現れ方**

一般の契約者は「知らされない側」として情報効果を受ける。制度側では、一人分の入居履歴が入ったことで告知対象か否かが切り替わるとされ、社会システムの状態変化が説明される。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.COG.INFORMATION_INDUCED_ACTION` — 情報誘導・行動誘発
- Primary Parent: `D13.COG` — 認知・情報作用
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

俗説を信じる受容者は、「事故物件でも一人挟めば告知されない」「告知がなかっただけでは安全とは言えない」と理解し、物件確認や契約判断を変え得る。業者側の派生では、告知回避のため一時入居者を入れる行動が誘発されると語られる。

**この伝承における現れ方**

作用は物理現象ではなく、制度についての情報が行動を変える形で生じる。買い手・借り手には警戒・追加確認、業者には「一人挟む」という操作の選択肢を与える情報モデルになる。

中心命題内部の制度作用と、受容者への情報効果をどちらをPrimaryに置くかはtask 3で再検討する。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.MIX` — 混合
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

俗説上、貸主・業者にとっては物件価値低下や成約困難を回避できる利得がある一方、後続入居者にとっては重要情報を知らされない不利益がある。

**この伝承における現れ方**

同じ「一人挟む」という操作が、売り手側には正、買い手・借り手側には負として働くため、伝承内部で価値が一方向に揃わない。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.BEH.COMPLIANCE_DECISION` — 遵守・意思決定変化
- Primary Parent: `D15.BEH` — 行動・選択
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

中心帰結は、貸主・業者が告知するかしないか、入居希望者が追加確認するか、その物件を契約するか、といった遵守・意思決定に現れる。

**この伝承における現れ方**

俗説は「告知義務の有無」という制度解釈を具体的な行動選択へ接続する。受容者にとっても、告知を受けなかった場合のリスク評価や物件選択が変化する。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.STA.STATIC_RULE` — 静的規則
- Primary Parent: `D16.STA` — 無時間的・静的関係
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

伝承は、特定の一回的物語を追うより、「事故後の最初の入居者／その次」という制度上の対応関係を一般規則として提示する。各具体事例では順序があるが、伝承として重要なのはその順序を抽象化した恒常ルールである。

**この伝承における現れ方**

「事故→一人目→二人目」という時間順は、具体例の出来事列というより、「一人目までは告知、二人目から不要」という静的な条件対応表として受容される。どれだけ長く待つかより、入居者の序数が意味を持つ。

パイロット末尾メモには `D16:U` と残っており、本文の `D16.STA.STATIC_RULE / D` と内部矛盾している。task 2では本文値を保持し、task 3およびExcel正本照合で解消する。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.INF.VERIFY_DEBUNK` — 検証・反証
- Primary Parent: `D17.INF` — 情報・技術的制御
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

受容者側は、制度資料を確認する、貸主・業者へ質問する、事故物件情報サイトや周辺情報を調べるなど、情報検証によって俗説または隠れた事故歴への不確実性を減らせる。2021年国交省ガイドラインは、俗説の単純規則を制度面から検証する外部資料になる。

**この伝承における現れ方**

この噂への対抗手段は呪術的回避ではなく、情報源を増やし、制度の実際を照合し、単純な一般則を反証することにある。反証自体が再流通を生む点がD04とも接続する。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

過去の死亡事実、告知実務、入居履歴等の追加情報を持つ主体として、貸主・管理会社・不動産業者等が想定される。受容者はそれらを完全には観察できない。

**この伝承における現れ方**

俗説が不安を生む核心は、「業者は事故歴を知っているが、一般の入居希望者は知らないかもしれない」という非対称性にある。一人挟む手順を知る者も業界側として表象されやすく、制度知識と物件固有情報の双方が組織側に偏在する。

国土交通省などの制度権限主体と、物件情報を保持する民間業者は同一ではない。コード名が両者を粗視化している点はtask 3で再確認する。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A3` — 実在制度・社会史が成立条件
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

本伝承は、実在する賃貸・売買契約、宅地建物取引業者、心理的瑕疵、人の死の告知実務という制度的背景がなければ成立しない。2021年国交省ガイドラインは、その現実制度を直接確認できる公的アンカーである。

**この伝承における現れ方**

語りの説得力は「本当に存在する不動産制度の、一般人には見えにくい抜け道」という現実接続に依存する。架空企業や架空法令へ置き換えると、制度俗説としての意味形成力が大きく損なわれる。
