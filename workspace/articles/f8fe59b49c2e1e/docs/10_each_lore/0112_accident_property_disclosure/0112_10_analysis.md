# 1. 伝承エントリ基本情報

- `Entry_ID`: `0112`
- `伝承エントリ名称`: 事故物件は一度別人を住ませれば告知義務が消える
- `Macro_Category`: 制度・陰謀
- `Entry_Type`: 命題型噂
- `Version_Scope`: 少なくとも2008年までに公開Web上で確認でき、その後も派生・反証を伴って再流通する制度抜け道俗説。「事故物件でも、一度だけ別の人物を入居させて退去させれば、その次の契約では人の死に関する告知義務が自動的に消える」という人数ベースの条件規則を対象とする。現行制度の正しさそのものはScope外で、制度Anchorとして別管理する。

# 3. 横断QA

## 3.1. Review_003対応

- D12 Secondary `SPECIFIC_OTHER` を除外し、D13 Primaryが直接作用する制度・社会システムだけを作用対象として保持した。
- D13 Secondary `CONCEAL_SUPPRESS` を除外し、独立した隠蔽作用ではなく制度操作の帰結として整理した。
- Review_002で解消済みのD20不存在Child・外部制度Anchor混入の修正は維持した。

## 3.2. Sense-making chain

```text
告知義務がいつ消えるか分かりにくい制度上の不透明さ
→ 制度判断の見えにくさがcueとなる
→ 「一人入居者を挟む」と制度状態が切り替わる単純ロジックへ整理
→ 不動産業者・貸主等の制度運用主体を原因側に置く
→ 「一人居住済み」という物件履歴状態が条件になる
→ 告知制度状態へ直接作用する
→ 入居履歴を利用して告知状態を切り替える制度操作として説明
→ 次回契約で告知しないという判断へ帰結
→ 派生形ではこの規則を戦略的に利用する
```

後続契約者の情報不足は制度状態変更を介した影響として保持し、D12 Secondaryの直接作用対象には置かない。告知しないという帰結も、独立した隠蔽作用としてD13 Secondaryへ重複計上しない。
