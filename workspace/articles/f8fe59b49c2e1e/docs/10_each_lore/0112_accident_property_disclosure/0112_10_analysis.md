# 1. 伝承エントリ基本情報

- `Entry_ID`: `0112`
- `伝承エントリ名称`: 事故物件は一度別人を住ませれば告知義務が消える
- `Macro_Category`: 制度・陰謀
- `Entry_Type`: 命題型噂
- `Version_Scope`: 少なくとも2008年までに公開Web上で確認でき、その後も派生・反証を伴って再流通する制度俗説。「事故物件でも、一度だけ別の人物を入居させて退去させれば、その次の契約では人の死に関する告知義務が自動的に消える」という人数ベースの条件規則を中心Scopeとする。2010年由来転載で確認される意図的な中間入居の手口化は、中心規則から派生した後代増補としてD04等の変容史には用いるが、D07〜D17の中心因果モデルへ遡及させない。現行制度の正しさそのものはScope外で、制度Anchorとして別管理する。

## 3.2. Sense-making chain

```text
告知義務がいつ消えるか分かりにくい制度上の不透明さ
→ 制度判断の見えにくさがcueとなる
→ 「一人入居者を挟む」と制度状態が切り替わる単純ロジックへ整理
→ 因果源は制度・法的ルールそのもの（D10 taxonomy gap）
→ 「一人居住済み」という物件履歴状態が条件になる
→ 告知義務・告知状態という制度状態が直接対象になる
→ 条件充足により制度状態が自動切替する（D13 taxonomy gap）
→ 次回契約で告知しなくてよいという実務判断へ帰結
→ 時間構造は人数条件にもとづく静的規則
```

2010年由来転載の意図的中間入居は、中心命題とは分離してD04の後代増補として保持する。中心因果モデルには、特定業者の意図、戦略利用、利得・不利益の評価を遡及させない。
