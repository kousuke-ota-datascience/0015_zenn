# 3. 分析上の重要点

- 具体的な磐梯山手長足長型の成立年代は、直接確認できる1992年採録を基準にし、物語内806年や一般的な「魔魅」記述から前近代へ遡及しない。
- 本伝承の意味形成核は、地域の風雨・洪水・不作を人格怪異へ原因帰属し、宗教的調伏と神格化によって脅威を地域秩序へ組み直す点にある。
- D11の広域作用とD17の封印・宗教者介入を混同しない。前者は怪異側の発動条件、後者は制御方式である。
- D18 L3は神社・伝承の存在だけから推定せず、2025年の自治体文化施設による具体的企画展・参加型催事をX Evidenceとする。
- D21 A4は弘法大師・磐梯明神等を物語が因果統合することを示すだけであり、その由来を歴史的事実と認定しない。
