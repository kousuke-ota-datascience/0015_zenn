# 1. 伝承エントリ基本情報

- `Entry_ID`: `0133`
- `伝承エントリ名称`: 将門塚の祟り
- `Macro_Category`: 歴史人物・怨霊・場所・禁忌
- `Entry_Type`: 祟り伝承／場所伝説
- `Version_Scope`: 神田明神・公的観光資料で確認できる、将門塚の荒廃後に周辺で天変地異が起こり、人々が平将門の御神威を恐れ、真教上人が御霊を慰め、その後神田明神へ奉祀したとする前近代の祟り・鎮魂伝承を中心とする。近現代の慰霊祭・例祭・保存活動は現実側の継続実践として含む。高権威資料で具体的に固定できない個別の工事事故・病気・死亡逸話、および「一切工事できない」という強い版はScopeの必須要素に含めない。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.DCF.MISFORTUNE_STREAK` — 不運・成功失敗の偏り
- Primary Parent: `D07.DCF`
- Secondary: `D07.PSE.DANGEROUS_PLACE` — 危険・怪異場所
- Status: `I`

**判定根拠**

将門塚の荒廃後に天変地異が続いたという伝承が、偶然の災厄ではなく将門の御神威と結び付けられる。

**この伝承における現れ方**

場所の荒廃と周辺の災厄が、将門塚に関係する一つの不可解な事態として束ねられる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Parent: `D08.HIS`
- Secondary: `D08.HIS.HISTORICAL_EVENT` — 歴史事件・戦争・災害
- Status: `I`

**判定根拠**

実在する将門塚と平将門の歴史、塚の荒廃後に起きたと伝えられる天変地異が、祟り・鎮魂伝承を考える具体的手掛かりになる。

**この伝承における現れ方**

抽象的な怨霊話ではなく、実在史跡と歴史人物へ不可解な災厄が接続される。

### 2.2.3. D09: 意味付与操作

**この伝承における現れ方**

災厄が将門の御霊という人格的・歴史的原因によって理解可能にされる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SUP.GHOST_SPIRIT` — 幽霊・死者霊

**判定根拠**

伝承では人々が将門の御神威を恐れ、真教上人が御霊を慰めたとされるため、因果源は平将門の死者霊として再構成できる。

**この伝承における現れ方**

将門塚という場所に結び付いた将門の御霊が、鎮められるべき主体として置かれる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

00で固定できる条件は「将門塚が荒廃した状態」であり、現行D11 taxonomyには「祭祀対象の荒廃・維持放棄」という状態／不作為条件へ直接対応するChildがない。撤去・破壊を共有条件へ引き上げない。

**この伝承における現れ方**

将門塚が荒れた状態になった後、周辺の天変地異が将門の御神威と結び付けて語られる。

**境界・留保**

**taxonomy gap: 祭祀対象の荒廃・維持放棄という状態／不作為条件。** 近似Childへ押し込まない。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.GRP.UNSPECIFIED_PEOPLE` — 不特定人群
- Primary Parent: `D12.GRP`

**この伝承における現れ方**

作用対象は特定の一人ではなく、将門塚周辺の人々として表現される。

### 2.3.3. D13: 作用機構

**この伝承における現れ方**

**この伝承における現れ方**

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `1`
- Status: `I`

**判定根拠**

L1では荒廃後の災厄と将門の御霊を結ぶ伝承内因果がある。L3は慰霊祭、例祭、保存会、複数回の整備という現実実践が確認できる。L2=0は「知るだけで祟られる」構造を確認していないという不在判断であるためvector全体を `D` としない。

**この伝承における現れ方**

伝承内の祟り・鎮魂因果に加え、現実側では将門塚の慰霊・祭祀・保存という実践が継続する。

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.LOC.LOCAL_TRADITION` — 地域伝承圏
- Primary Parent: `D19.LOC`
- Secondary: なし
- Status: `I`

**判定根拠**

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Parent: なし
- Secondary: なし
