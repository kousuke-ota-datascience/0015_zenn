# 1. 伝承エントリ基本情報

- `Entry_ID`: `0133`
- `伝承エントリ名称`: 将門塚の祟り
- `Macro_Category`: 歴史人物・怨霊・場所・禁忌
- `Entry_Type`: 祟り伝承／場所伝説
- `Version_Scope`: 東京都千代田区大手町の将門塚について、塚の荒廃、粗末な扱い、撤去・破壊・無礼な改変、供養の不足等の不敬と、平将門の御霊・怨霊による事故・病気・災厄等を結び付ける祟り伝承。真教上人による鎮魂、近現代の慰霊・例祭・保存活動を関連する制御・対応形として含む。高権威資料で固定できない個別事故逸話や「一切工事できない」という強い版はScopeの必須要素に含めない。

# 2. 分析概念次元

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: `D01.G0` — 前近代（〜1867）
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

神田明神の現在の由緒説明は1307年の鎮魂、1309年の奉祀を伝える。前近代に将門の御霊・鎮魂伝承が存在したと推定できるが、1307年当時の原資料を今回直接確認していないため `I` とする。

**この伝承における現れ方**

近代都市開発だけを契機に新規生成した話ではなく、前近代の将門御霊・鎮魂伝承を背景に持つ。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Parent: なし
- Secondary: なし
- Status: `U`

**判定根拠**

前近代の伝承年代は確認できるが、最古の流通媒体が口承、寺社縁起、板碑、文書等のどれであったかは現在のEvidenceから固定できない。

**この伝承における現れ方**

伝承の古さと最古媒体を分離し、年代だけから口承等を推定しない。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**この伝承における現れ方**

現在は宗教組織・公的観光主体のWebを通じて将門塚の伝承が地域外にも提示される。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし

**判定根拠**

前近代の鎮魂伝承、近現代の慰霊・保存史、後代の工事祟り逸話が複数時点に存在することは確認できる。しかし、どの語りがいつどの事件を取り込み、どの方向へ変化したかを連続したHistory Evidenceとして固定できない。実事件への付着、時代適応、増補を推測でコードしない。

**この伝承における現れ方**

複数時代の語り・実践は確認できるが、伝承の変容方向自体は未確定である。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Status: `I`

**判定根拠**

Scopeには塚の荒廃・不敬と災厄を結ぶ禁止的規則があり、首伝説・鎮魂伝承・後代祟り譚がその背景説明になる。現代資料からこの提示形式を再構成しているため `I` とする。

**この伝承における現れ方**

「将門塚を粗末に扱うと祟りがある」という規則と、その理由を示す由来・鎮魂物語が組み合わされる。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U`

**判定根拠**

現代の公的・宗教組織資料が超自然部分を「伝説」「由緒」「言い伝え」として紹介していることは確認できるが、伝承自身が受容者へ `T5` 等のどの真実性態度を要求するかを直接固定できない。外部資料のジャンルラベルや「念のため敬意を払う」という分析者推論をD06へ変換しない。

**この伝承における現れ方**

祟り内容は確認できる一方、それを受容者がどの信念強度で受け取るべきかは今回のEvidenceから一意に言えない。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.DCF.MISFORTUNE_STREAK` — 不運・成功失敗の偏り
- Primary Parent: `D07.DCF`
- Secondary: `D07.PSE.DANGEROUS_PLACE` — 危険・怪異場所
- Status: `I`

**判定根拠**

塚の荒廃・不敬と同時期に語られる災厄・不幸が、偶然の出来事ではなく将門の祟りと理解される。結果として将門塚自体が慎重に扱う場所となる。

**この伝承における現れ方**

種類の異なる不幸が「将門塚への不敬」という共通の説明対象へ束ねられる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.HIS.HISTORICAL_EVENT` — 歴史事件・戦争・災害
- Primary Parent: `D08.HIS`
- Secondary: `D08.HIS.PLACE_NAME_RUIN` — 地名・遺構・記念物
- Status: `I`

**判定根拠**

平将門の死、関東大震災後の整地等の歴史と、実在する将門塚・碑・祭祀が祟り語りの具体的手掛かりになる。

**この伝承における現れ方**

抽象的な怨霊話ではなく、実在史跡と歴史上の出来事が将門の祟りを考える入口になる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAU.DIRECT_CAUSE` — 直接原因化
- Primary Parent: `D09.CAU`

- Status: `I`

**判定根拠**

事故・病気・災厄等を将門の御霊への不敬の結果として因果接続し、平将門・将門塚の歴史へ結び付け、塚を粗末に扱わないという規範を形成する。

**この伝承における現れ方**

ばらばらの不幸が将門の怒りという人格的な原因へまとめられる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SUP.GHOST_SPIRIT` — 幽霊・死者霊
- Primary Parent: `D10.SUP`
- Secondary: `D10.SPC.SPECIFIC_PLACE` — 特定場所
- Status: `I`

**判定根拠**

祟りの主体は平将門の御霊・怨霊として語られ、その作用は将門塚という特定地点へ固定される。

**この伝承における現れ方**

場所そのものの無人格的作用ではなく、将門の死者霊が怒り・鎮められる主体として置かれる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.MAN.CREATE_ALTER_MANIPULATE` — 作る・加工・操作する
- Primary Parent: `D11.MAN`
- Secondary: なし
- Status: `I`

**判定根拠**

撤去・破壊・粗末な改変等の作為的な不敬は `CREATE_ALTER_MANIPULATE` で部分的に表現できる。一方、Scopeに含まれる「供養を怠る／維持を放棄する」という不作為条件はEvidence上の構造として確認候補であるにもかかわらず、現行D11 taxonomyに直接対応するChildがない。

**この伝承における現れ方**

塚へ無礼に手を加える型と、塚を荒廃させる・供養を欠く型の双方が因果入口として語られる。

**境界・留保**

**taxonomy gap: 供養を怠る／維持を放棄する不作為条件。** 既存Childへ近似的に押し込まず、`CREATE_ALTER_MANIPULATE` は撤去・破壊等の作為型だけを表す部分コードとして扱う。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.OTH.VICTIM_TARGET` — 特定被害者
- Primary Parent: `D12.OTH`

**判定根拠**

祟りは塚の荒廃・撤去・改変等の不敬に関与した人物へ向かうとされる。高権威Evidenceで固定できない具体的人名や被害種別は一般化しない。

**この伝承における現れ方**

「塚へ不敬を行った者」が祟りの対象として選ばれる。

### 2.3.3. D13: 作用機構

**この伝承における現れ方**

具体的な物理機構ではなく、異なる不幸を一つの祟り作用として説明する。

### 2.3.4. D14: 帰結極性

**この伝承における現れ方**

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.OPP.LUCK_MISFORTUNE` — 幸運・不運
- Primary Parent: `D15.OPP`

異伝により事故、病気、死亡等の具体形が変わり、高権威Evidenceで一つの身体帰結へ固定できないため、広い不運・災厄を終端領域とする。

**この伝承における現れ方**

具体的な被害種別は揺れても「不敬の後に良くないことが起きる」という帰結が保持される。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.STA.STATIC_RULE` — 静的規則
- Primary Parent: `D16.STA`
- Secondary: なし
- Status: `I`

**判定根拠**

Scopeで安定しているのは「将門塚への不敬が祟り・災厄へ結び付く」という条件規則であり、同一因果エピソードが歴史上何度も反復したことを高権威Evidenceで直接固定できない。待ち時間や段階進行も中心ではない。

**この伝承における現れ方**

時代ごとの具体事故を必要とせず、「不敬なら災厄」という規則として語られる。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.RIT.RITUAL_CLOSURE` — 儀式終了・祓い
- Primary Parent: `D17.RIT`
- Secondary: `D17.CST.ONGOING_MANAGEMENT` — 継続管理
- Status: `I`

**判定根拠**

神田明神の前近代鎮魂伝承、1925年慰霊祭、現在の例祭・保存活動により、供養・鎮魂と継続的な祭祀・保存が確認できる。これらを祟り制御へ写像する部分には解釈を含むため `I` とする。

**この伝承における現れ方**

将門の御霊は消去する対象ではなく、鎮魂・祭祀・保存を継続する対象として扱われる。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `1`
- Status: `I`

**判定根拠**

L1では不敬に対する祟り因果がある。L3は神田明神公式に慰霊祭、例祭、保存会、複数回の整備が記録され、将門の慰霊・祭祀・保存に関係する現実実践が確認できる。L2=0は「知るだけで祟られる」構造を今回確認していないという不在判断であり、vector全体を `D` とはしない。

**この伝承における現れ方**

伝承内の祟り因果に加え、現実側では将門塚の慰霊・祭祀・保存という実践が継続する。ただし改修そのものを禁止する社会効果とはしない。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.LOC.LOCAL_TRADITION` — 地域伝承圏
- Primary Parent: `D19.LOC`

- Status: `I`

**判定根拠**

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U`

**判定根拠**

神田明神や保存会が祭祀・由緒・保存の実務知を持つことは確認できるが、それはD20が問う「祟りの真相・追加情報を伝承内で特権的に保持する主体」と同一ではない。誰がその種の真相情報を独占するかを固定できない。

**この伝承における現れ方**

一般受容者より詳しい祭祀・保存知識を持つ組織は存在するが、祟りの真相保持者としてはコードしない。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A4` — 史実・記録・既存伝承を因果統合
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

平将門という歴史人物、実在する将門塚、関東大震災後の整地、慰霊祭、保存・改修等の実在記録が祟り・鎮魂伝承へ組み込まれる。ただし実在史が超自然因果を実証するわけではない。

**この伝承における現れ方**

具体的史跡だけでなく、確認可能な歴史・祭祀・保存記録群が伝承を現実世界へ固定する。
