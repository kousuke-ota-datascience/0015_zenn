# 1. 伝承内容

## 1.1. summary

将門塚をめぐる資料には、平将門の首が京都から東国へ飛来したとする首伝説、将門塚周辺の荒廃後に天変地異が起こり真教上人が将門の御霊を慰めたとする神田明神の宗教伝承、近現代の慰霊祭・例祭・保存活動、塚の撤去・破壊・粗末な扱いと事故・病気・災厄を結び付ける祟り語りが確認できる。

神田明神の現在の由緒説明では、嘉元年間に周辺で天変地異が起こり、1307年に真教上人が将門の御霊を慰めたと伝えられる。また1309年には神田明神へ奉祀したと説明される。これらは現代の神社公式資料が保持する宗教伝承であり、1307年当時の原資料を今回直接確認したものではない。

近現代については、関東大震災後の整地・慰霊、1925年の大蔵省構内での慰霊祭、戦後の史蹟将門塚保存会、1961年以降の複数回の整備、2021年の第6次改修が公式資料で確認できる。したがって「将門塚は祟りのため物理的に一切改修できない」という強い主張は、確認済みの改修史とは一致しない。

一方、「大蔵省関係者の連続死」「占領期のブルドーザー事故」など個別の有名な祟り逸話については、今回参照した高権威資料だけでは日時・当事者・事故記録を十分に固定できていない。実際の事故・病気の原因が超自然的な祟りであったことも確認していない。

## 1.2. 詳細展開

### 1.2.1. 平将門と首伝説

平将門は10世紀の歴史人物で、討死後に首が京都で晒されたとされる。後代の地域伝承では、その首が故郷の東国へ戻ろうとして飛来し、落下地点の一つが現在の将門塚であると語られる。首の飛来は伝説として扱う。

### 1.2.2. 前近代の祟り・鎮魂伝承

神田明神の現在の由緒説明では、将門塚周辺で天変地異が起こり、人々が将門の御神威を恐れ、真教上人が御霊を慰めたと伝えられる。供養・奉祀が行われたという内容までを宗教伝承として記録する。

### 1.2.3. 関東大震災後の整地・慰霊

神田明神の公式史では、関東大震災後に塚周辺が整地・再建され、1925年に大蔵省構内で平将門公御霊の慰霊祭が行われたと説明される。整地・再建・慰霊の実施と、個々の不幸を祟りへ結び付ける因果主張は区別する。

### 1.2.4. 戦後の保存・改修

戦後、神田明神と近隣企業等を中心に史蹟将門塚保存会が形成され、1961年以降複数回の整備が実施された。2021年にも第6次改修が竣功している。

### 1.2.5. 後代の祟り語り

後代には、塚の撤去・破壊・粗末な扱い、供養の不足等と関係者の事故・病気・災厄を結び付ける話が広く語られる。ただし、個別事故の史実性・原因関係は逸話ごとに別途検証が必要である。

## 1.6. 条件・規則・禁忌

資料上、塚の荒廃、粗末な扱い、撤去・破壊・改変、供養の不足等と災厄を結び付ける祟り語りが確認される。前近代の神田明神伝承では荒廃後の天変地異と鎮魂が語られ、後代の祟り語りでは工事・不敬と不幸が結び付けられる。どの行為が必ず祟りを起こすか、どの改修なら安全かを00では確定しない。

## 1.7. 異常・不可解な現象／中心命題

- 平将門の御霊・祟りが将門塚と結び付けて語られる。
- 塚の荒廃・不敬・改変と事故・病気・災厄が因果的に結び付けられる型がある。
- 御霊を慰める供養・慰霊・奉祀が語られる型がある。
- 実際の個別事故の超自然的原因は確認されていない。

## 1.8. 行動・対応

資料上、真教上人による鎮魂伝承、1925年慰霊祭、現在の例祭、保存会による保存・改修が確認できる。これらの実践がどの伝承形で「祟り回避手順」として機能するかは10で判定する。

## 1.9. 帰結・終端状態

- 宗教伝承上: 天変地異・災厄が将門の御神威と結び付けられる。
- 後代祟り語り: 事故・病気・不幸・災厄。
- 現実史: 祭祀・保存活動・複数回の改修が継続している。
- 未確認: 個別事故が祟りによって生じたという因果。

## 1.10. 未解決点・不確実性

1. 1307年・1309年の出来事を記録する同時代原資料を今回直接固定していない。
2. 首が飛来したという説は伝説であり、歴史的事実として扱わない。
3. 関東大震災後の整地・慰霊は公式史で確認できるが、後代に語られる個々の死亡・事故との因果は別問題である。
4. 占領期の重機事故等の有名な派生は、今回の高権威資料だけでは詳細未固定である。
5. 公式改修史は「一切工事不能」という強い版と両立しないが、そこから祟り伝承の正しい禁忌・制御規則を00で再定義しない。

# 2. 伝承史・異伝

## 2.1. 最古確認層

現在の資料では、神田明神が1307年の鎮魂、1309年の奉祀を前近代伝承として紹介している。これは伝承年代を示す現代の公式由緒説明であり、現存する最古一次文書を直接確認したものではない。

## 2.2. 近代以前から近代

1906年の故蹟保存碑建立が神田明神資料で説明され、近代にも将門塚が保存対象として扱われていたことが確認できる。

## 2.3. 関東大震災後

1923年の関東大震災後に塚周辺が整地され、1925年に大蔵省構内で慰霊祭が行われたと神田明神の公式史が記録する。後代の祟り逸話ではこの時期の改変と不幸が結び付けられるが、個別因果は今回確定しない。

## 2.4. 戦後から現在

戦後に史蹟将門塚保存会が組織され、1961年以降複数回の整備が行われ、2021年には第6次改修が竣功した。現在も例祭・保存活動が続く。
