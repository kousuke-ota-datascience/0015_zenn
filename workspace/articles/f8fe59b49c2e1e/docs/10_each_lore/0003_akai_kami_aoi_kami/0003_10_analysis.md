# 1. 伝承エントリ基本情報

- `Entry_ID`: `3`
- `伝承エントリ名称`: 赤い紙・青い紙／赤マント系
- `Macro_Category`: 学校・大学
- `Entry_Type`: 物語・伝説
- `Version_Scope`: 学校・便所で怪異から色・紙・衣服等の選択を迫られ、回答に対応する危害または回避が生じる型。現代的な赤／青二択を中心に、1972年赤／白、1986年赤／紫・赤いちゃんちゃんこ、1990年赤いマント等を構造比較用の異伝として参照する。
- `Evidence_Rank`: `B`
- `主な成立・流通期`: 1970年代採録〜
- `ネット発祥`: No

# 2. 分析概念次元

## 2.1. 来歴・流通・提示

### 2.1.1. D01: 生成年代
- Value: `D01.G3` — 1970年代
- Status: `D`

**判定根拠:** 日文研DBに1972年兵庫県の「赤い紙／白い紙」便所怪談採録があり、少なくとも1970年代に同型構造が実流通していたことを確認できる。

**この伝承における現れ方:** 現在の赤／青定型より前に、紙の色を選ばせる学校便所怪談が存在する。年代コードは「赤／青という語の成立年」ではなく、分析対象とする選択型の確認可能な層を指す。

**境界・留保:** 採録年は起源年ではない。また昭和初期の赤マント流言をこのEntryの成立年へ直接繰り上げない。

### 2.1.2. D02: 最古確認流通媒体
- Primary Child: `D02.ORL.SCHOOL_ORAL` — 学校内伝承
- Primary Parent: `D02.ORL`
- Status: `I`

**判定根拠:** 1972年兵庫例は「低学年、特に1年生の間に伝説が広がる」と採録され、学校内で児童間に流通したことが明示される。原録音等ではないため媒体判定はIとする既存判断を維持する。

**この伝承における現れ方:** 特定トイレと回答ルールが同じ学校の児童に共有され、「一人で便所へ行かない」行動まで生む。学校という限定共同体が、場所情報と攻略規則を保持する媒体になる。

### 2.1.3. D03: 確認流通媒体ポートフォリオ
- Primary Child: `D03.ORL.SCHOOL_ORAL` — 学校内伝承
- Primary Parent: `D03.ORL`
- Status: `I`

**判定根拠:** 1972、1986、1990年の採録はいずれも学校・児童生徒集団に結び付く。Version Scopeの中心を初期・採録型に置く既存Pilot Codingでは学校内口承をPrimaryとしている。

**この伝承における現れ方:** 「うちの学校の何番目の個室」というローカル情報と「何色を答えるとどうなる」というルールが同時に伝わるため、学校内口承が内容形成そのものに関与する。

**境界・留保:** 旧末尾メモには `D03:U` が残っており本文コードと矛盾する。正本Excel再照合対象。

### 2.1.4. D04: 生成・変容パターン
- Primary Child: `D04.STB.STABILIZED_CANON` — 定型化・カノン化
- Primary Parent: `D04.STB`
- Status: `I`

**判定根拠:** 色・物品・帰結は変わるが、「便所で問いを受ける→選択する→選択に応じた結果」という型が1970年代以降の複数地域採録で反復する。

**この伝承における現れ方:** 赤／白、赤／紫、赤いちゃんちゃんこ、赤／青へ語彙が変わっても、選択強制という骨格がカノンとして残る。

**境界・留保:** 内容差は大きいため、安定核と変異増殖のどちらをD04で優先するかは再検討余地がある。

### 2.1.5. D05: 提示形式
- Primary: なし
- Secondary: なし
- Status: `U`

**判定根拠:** Pilot Codingは、物語・警告・学校内規則のどれを代表形式とするか一意に決めずUを保持した。

**この伝承における現れ方:** 「○番目のトイレで声がする」という場所怪談としても、「赤を選ぶとこうなる」という警告規則としても、「ある子が答えて死んだ」という短い物語としても提示できる。採録ごとに表現形式が違う。

**境界・留保:** 高密度化によって複数形式の実例が明確になったが、文書化作業ではコード変更しない。

### 2.1.6. D06: 真実性提示
- Value: `D06.T3` — 共同体既知事実
- Status: `I`

**判定根拠:** 1990年神奈川例では「先生は知らないが、生徒は誰もが知っている」とされ、学校共同体内で共有された既知情報として機能する。

**この伝承における現れ方:** 公的に証明された事実ではなく、「この学校の生徒なら知っている危険なトイレ」というローカル常識が真実らしさを与える。

## 2.2. 意味形成

### 2.2.1. D07: 意味形成対象
- Primary Child: `D07.ANO.UNKNOWN_EXISTENCE` — 未知存在
- Primary Parent: `D07.ANO`
- Status: `I`

**判定根拠:** 姿の見えない声・便所のお化け・赤マント等、通常では説明できない主体が学校内に存在するとされる。

**この伝承における現れ方:** 誰もいない個室から声がするという異常を、「色を選ばせる怪異」という再認識可能な存在・型へまとめる。

### 2.2.2. D08: 意味形成契機
- Primary Child: `D08.CLM.UNSUPPORTED_ASSERTION` — 根拠未提示の主張
- Primary Parent: `D08.CLM`
- Status: `I`

**判定根拠:** 多くの児童は自ら遭遇する前に、「あのトイレではこう聞かれる」という噂を受け取る。証拠より主張が先行する。

**この伝承における現れ方:** 先行する噂が特定個室を危険な場所として意味付けし、通常の便所利用を警戒行動へ変える。

### 2.2.3. D09: 意味付与操作
- Primary Child: `D09.CAT.NAMING` — 命名
- Primary Parent: `D09.CAT`
- Status: `I`

**判定根拠:** 「赤い紙・青い紙」「赤いちゃんちゃんこ」「赤マント」といった短い名称が、色選択型の出来事を一まとまりの怪異として識別可能にするというPilot判断。

**この伝承における現れ方:** 姿が見えない型でも、問いに含まれる語がそのまま怪異の呼称になる。名称が外見ではなくルールを圧縮している。

**境界・留保:** 意味形成の中心は命名より「選択と帰結の規則化」と読む余地が強い。再コーディング候補。

### 2.2.4. D10: 因果源存在論
- Primary Child: `D10.SUP.YOKAI_ENTITY` — 妖怪・人格怪異
- Primary Parent: `D10.SUP`
- Status: `I`

**判定根拠:** 問いかけ、回答に応じて危害を与える意図的主体が想定される。姿が見えなくても会話的反応を示すため人格怪異として機能する。

**この伝承における現れ方:** トイレそのものが自動的に危害を与えるのではなく、「声の主」が選択を評価し結果を実行する。

## 2.3. 因果・行動モデル

### 2.3.1. D11: 発動・接触条件
- Primary Child: `D11.MAN.RESPOND_CHOOSE` — 答える・選択する
- Primary Parent: `D11.MAN`
- Status: `D`

**判定根拠:** 複数採録で怪異が色・衣服を提示し、遭遇者の回答後に帰結が生じる構造が直接確認できる。

**この伝承における現れ方:** トイレへ入ることが遭遇条件、問いへ答えることが危害ルールを確定する操作条件になる。言語行為がスイッチとして働く。

### 2.3.2. D12: 作用対象
- Primary Child: `D12.FOC.PROTAGONIST_EXPERIENCER`
- Primary Parent: `D12.FOC`
- Status: `I`

**判定根拠:** 問いを受けた個々の児童・人物が、その回答に応じた危害を直接受ける。

**この伝承における現れ方:** 同じ学校全体が呪われるのではなく、一人で個室へ入り回答した焦点人物へ作用が集中する。

### 2.3.3. D13: 作用機構
- Primary Child: `D13.PHY.PHYSICAL_ATTACK` — 物理攻撃
- Primary Parent: `D13.PHY`
- Status: `I`

**判定根拠:** 首切り、引き込み、窒息、出血等、身体へ直接危害を加える型が主要異伝に反復する。

**この伝承における現れ方:** 選んだ色が抽象的な予言で終わらず、血・皮膚色・身体移動等として物理的に実現する。

### 2.3.4. D14: 帰結極性
- Value: `D14.NEG`
- Status: `I`

**判定根拠:** 主要二択型ではどの選択でも危害・死が中心であり、基本帰結は負。

**この伝承における現れ方:** 安全色を持つ異伝はあるが、それは負のデフォルトから逃れる例外として機能する。

### 2.3.5. D15: 帰結領域
- Primary Child: `D15.BOD.SEVERE_INJURY`
- Primary Parent: `D15.BOD`
- Secondary 1 Child: `D15.BOD.DEATH`
- Secondary 1 Parent: `D15.BOD`
- Status: `I`

**判定根拠:** 出血、首切り、窒息、引き込み等が身体重傷・死亡へ結び付く。

**この伝承における現れ方:** 色語の意味が身体状態へ変換され、「赤＝血」「青＝青ざめる」と記号と身体結果が対応する。

### 2.3.6. D16: 因果時間構造
- Primary Child: `D16.EVT.IMMEDIATE`
- Primary Parent: `D16.EVT`
- Status: `I`

**判定根拠:** 回答後、同一トイレ内・同一遭遇エピソードの中で直ちに結果が生じる型が中心。

**この伝承における現れ方:** 待機期間や再発を必要とせず、選択が即座に結果へ変換されるため、回答の瞬間に緊張が集中する。

### 2.3.7. D17: 回避・制御方式
- Primary Child: `D17.RUL.CORRECT_ANSWER`
- Primary Parent: `D17.RUL`
- Status: `I`

**判定根拠:** 紫などの安全色、拒否回答等、Versionによって「正しい選択」が危害回避に結び付く。

**この伝承における現れ方:** 罠のルールを知ることが制御可能性を生む。児童は正解を共有し、危険な個室そのものを避ける場合もある。

**境界・留保:** 両方不正解の型では正答が存在しないため、このコードは異伝依存性が高い。

### 2.3.8. D18: 作用レイヤー
- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `0`
- Status: `I`

**判定根拠:** Pilotは怪異→遭遇者という伝承内部因果のみを採用。

**この伝承における現れ方:** L1では回答と危害の規則が作動する。ただし1972年採録には、児童が一人で行かず連なって便所へ行くという明瞭な現実行動が記録される。

**境界・留保:** 上記はL2/L3再評価に直接関係する証拠であり、明示的再コーディング時の重要候補。

## 2.4. 社会的埋め込み

### 2.4.1. D19: 流通範囲
- Primary Child: `D19.MAS.NATIONAL_PUBLIC`
- Primary Parent: `D19.MAS`
- Status: `D`

**判定根拠:** 兵庫・東京・神奈川・島根等の離れた地域に構造類似の採録があり、後代には全国的な学校怪談として整理される。

**この伝承における現れ方:** 各学校でローカルな個室番号や色を持ちながら、同型ルールが広域に反復する。「全国型だが局所化される」流通構造を持つ。

### 2.4.2. D20: 特権情報保持者
- Primary Child: `D20.NON.COMMON_KNOWLEDGE`
- Primary Parent: `D20.NON`
- Status: `I`

**判定根拠:** 怪異の場所・回答ルールは児童集団内で共有され、特定の専門家や秘密組織だけが保持しない。

**この伝承における現れ方:** 1990年例では先生が知らず生徒は皆知っているとされるが、「生徒共同体内では一般共有」という構造であり、個人の特権知ではない。

### 2.4.3. D21: 現実アンカー
- Value: `D21.A1` — 一般的現実背景
- Status: `I`

**判定根拠:** 学校・トイレという実在の日常環境を必要とするが、特定の歴史事件や唯一の実在地点に固定されない。

**この伝承における現れ方:** どの学校にもある個室へ移植でき、学校名を交換しても構造が保たれる。現実空間への接続は強いが固有名への固定は弱い。
