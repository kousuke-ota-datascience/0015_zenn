# 1. 伝承エントリ基本情報

- `Entry_ID`: `3`
- `伝承エントリ名称`: 赤い紙・青い紙／赤マント系
- `Macro_Category`: 学校・大学
- `Entry_Type`: 物語・伝説
- `Version_Scope`: 学校・便所で怪異から色・紙・衣服等の選択を迫られ、回答に対応する危害または回避が生じる型。現代的な赤／青二択を中心に、1972年赤／白、1986年赤／紫・赤いちゃんちゃんこ、1990年赤いマント等を構造比較用の異伝として参照する。

# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: `D01.G3` — 1970年代
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

`0003_00_contents.md` で確認できる早い具体例は、1972年兵庫県の「赤い紙／白い紙」便所怪談採録である。今回のVersion Scopeは色選択型の構造を対象とするため、少なくとも1970年代に同型が成立・流通していたことを直接確認できる。

**この伝承における現れ方**

現在著名な赤／青の組合せより前に、学校便所で色を選ばせる同型構造が確認できる。採録年は実際の起源年ではなく、1970年代より前へ成立を遡及する証拠には用いない。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Child / Value: `D02.ORL.SCHOOL_ORAL` — 学校内伝承
- Primary Parent: `D02.ORL` — 口承・限定共同体
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

1972年兵庫例は、低学年、特に1年生の間に伝説が広がっていたことを記録し、学校共同体内部の対人伝承を示している。録音等による媒体直接記録ではないためStatusは`I`とする。

**この伝承における現れ方**

同じ学校の児童が「便所でこう聞かれる」「一人で行くと危ない」と共有し、実際に複数人で便所へ行く。場所情報と対処知識が学校内伝承として保持される。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Child / Value: `D03.ORL.SCHOOL_ORAL` — 学校内伝承
- Primary Parent: `D03.ORL` — 口承・限定共同体
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

1972年兵庫、1986年東京、1990年神奈川等の採録はいずれも学校共同体と結び付いており、Version Scopeで内容を形成・保持する主要媒体は学校内伝承と判断する。

**この伝承における現れ方**

「何番目の個室」「何色を答えるとどうなる」といった局所情報が、学校ごとの児童集団で共有される。外部媒体へ移しても、学校内ローカル知の形が伝承核を支える。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.VAR.ORAL_VARIATION` — 口承変異
- Primary Parent: `D04.VAR` — 再話・変異
- Secondary: `D04.VAR.ACCRETION` — 増補
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

赤／白、赤／紫、赤いちゃんちゃんこ、赤いマント、赤／青等、地域・時期ごとに選択語と帰結が置換される。さらに安全色・新しい死因・新しい回避規則が追加される。

**この伝承における現れ方**

「便所で問いを受ける→選択する→選択に対応した結果」という骨格を保ちながら、色と結果の対応表が学校ごとに書き換えられる。安定カノンより、口承変異と増補を主な変容パターンとして扱う。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.RUL.WARNING` — 警告
- Primary Parent: `D05.RUL` — 規則・警告形式
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

採録は短い物語を伴う場合もあるが、学校共同体内で実用的に機能する部分は「あのトイレではこう聞かれる」「この色を答えると危ない」という危険情報である。複数形式を理由にUとせず、Scopeの中心機能を警告としてコードする。

**この伝承における現れ方**

受容者は特定のトイレを利用する前に、危険な選択肢と結果を教えられる。怪異を呼び出す手順ではなく、遭遇時の危険と選択ルールを知らせる形式である。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T3` — 共同体既知事実
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

1990年神奈川例では、教師は知らないが生徒には広く知られているとされる。公的事実ではなく、学校共同体内部の共有知が真実らしさを支える。

**この伝承における現れ方**

「この学校の生徒なら知っている危険なトイレ」というローカル常識が、個別の検証より強い確信を与える。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ANO.UNKNOWN_EXISTENCE` — 未知存在
- Primary Parent: `D07.ANO` — 異常体験・存在
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

誰もいない便所から問いかける声、赤マント等、通常では説明できない主体の存在が中心的な不可解さである。

**この伝承における現れ方**

姿を見せない型でも、「選択を要求し、その結果を実行する何者か」という人格的怪異として再認識される。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.UNSUPPORTED_ASSERTION` — 根拠未提示の主張
- Primary Parent: `D08.CLM` — 命題先行
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

多くの児童は自分が遭遇する前に、「あのトイレではこう聞かれる」という噂を受け取る。直接体験より先に、特定場所と危険規則に関する主張が共有される。

**この伝承における現れ方**

先行する噂が通常の便所を危険な空間へ変換し、個室利用そのものを警戒対象にする。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CTL.AVOIDANCE_RULE` — 回避規則
- Primary Parent: `D09.CTL` — 制御規則形成
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

伝承は怪異を単に「赤い紙・青い紙」と命名するだけでなく、どの色を選ぶと危険か、安全色があるか、危険な個室を避けるべきかという制御規則を形成する。意味形成の中心は命名より規則化にある。

**この伝承における現れ方**

未知の便所怪異が、選択肢と結果の対応表として理解されることで、児童は「何を選ぶ／どこへ行かない」という行動知へ変換できる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SUP.YOKAI_ENTITY` — 妖怪・人格怪異
- Primary Parent: `D10.SUP` — 超自然主体・力
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

問いかけ、回答に応じて危害を与える意図的主体が想定される。姿が見えない型でも、会話的反応を示すため人格怪異として機能する。

**この伝承における現れ方**

トイレ自体が自動的に身体変化を起こすのではなく、「声の主」が回答を受け取り、結果を実行する構造である。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.MAN.RESPOND_CHOOSE` — 答える・選択する
- Primary Parent: `D11.MAN` — 操作・儀式
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

複数採録で怪異が色・衣服を提示し、遭遇者の回答後に対応する帰結が生じる構造が直接確認できる。

**この伝承における現れ方**

トイレへ入ることが遭遇条件となり、問いへ答えることが結果を確定する操作になる。言語的選択が因果スイッチとして働く。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC` — 焦点人物
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

問いを受けて回答した児童・人物が、その選択に対応した危害を直接受ける。

**この伝承における現れ方**

学校全体に一律の災厄が起こるのではなく、一人で個室へ入り選択した焦点人物へ作用が集中する。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.PHY.PHYSICAL_ATTACK` — 物理攻撃
- Primary Parent: `D13.PHY` — 身体・物質作用
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

首切り、便器への引き込み、窒息、出血等、身体へ直接危害を加える型が主要異伝に反復する。

**この伝承における現れ方**

選んだ色が抽象的な予言で終わらず、血・皮膚色・身体移動等の物理的結果として実現する。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

主要二択型では危害・死が中心であり、安全色を持つ異伝も負のデフォルトから逃れる例外として機能する。

**この伝承における現れ方**

回答を迫られること自体が危険で、最良の場合でも通常状態へ戻るだけで正の利益は生じない。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.BOD.SEVERE_INJURY` — 重傷・障害
- Primary Parent: `D15.BOD` — 身体・健康
- Secondary: `D15.BOD.DEATH` — 死亡
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

出血、首切り、窒息、引き込み等が身体重傷・死亡へ結び付く。死亡はすべての異伝に共通しないためSecondaryとする。

**この伝承における現れ方**

色語の意味が身体状態へ変換され、「赤＝血」「青＝青ざめる」のように記号と身体結果が対応する。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.EVT.IMMEDIATE` — 即時
- Primary Parent: `D16.EVT` — 単一エピソード・事象内
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

回答後、同一トイレ内・同一遭遇エピソードで直ちに結果が生じる型が中心である。

**この伝承における現れ方**

待機期間や再発を必要とせず、選択の直後に結果が実現するため、回答の瞬間に緊張が集中する。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.RUL.CORRECT_ANSWER` — 正答・選択
- Primary Parent: `D17.RUL` — 規則遵守
- Secondary: `D17.AVO.DO_NOT_ENGAGE` — 接触回避
- Status: `C` — Conflict（競合）

**判定根拠**

紫などの安全色を選べば助かるVersionがある一方、赤／青のどちらも危険で正答が存在しないVersionもある。また危険な個室自体を避けるという現実側の回避行動も確認できる。

**この伝承における現れ方**

伝承共同体は「正しい答え」を攻略知識として共有する場合と、「そもそもその個室へ入らない」とする場合がある。Version間で制御可能性が競合するため一律に確定しない。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=1`
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

L1では回答と身体被害の因果が伝承内で作動する。1972年兵庫採録では、噂を恐れた低学年児童が実際に数珠つなぎで便所へ行くという現実行動が記録されており、流言が社会現実上の行動を変えるL3を直接確認できる。伝承を聞くだけで受容者自身が怪異の因果対象になる規則はないためL2は0とする。

**この伝承における現れ方**

怪談内部では選択が危害を生み、現実の学校生活では児童のトイレ利用行動が変化する。内容上の呪いと、噂の流通による行動結果を分離して二つのレイヤーへ記録する。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

兵庫、東京、神奈川、島根等の離れた地域に構造類似の採録があり、後代には全国的な学校怪談として整理される。

**この伝承における現れ方**

各学校では個室番号・色・安全回答がローカル化される一方、同じ選択型構造が広域で反復する。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.NON.COMMON_KNOWLEDGE` — 一般共有
- Primary Parent: `D20.NON` — 特権なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

怪異の場所・回答規則は児童共同体内部で共有され、特定の専門家や秘密保持者に独占されない。

**この伝承における現れ方**

教師が知らない型でも、生徒共同体の内部では多数が知る共有知として機能する。個人の特権知ではなく共同体内常識である。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

学校・トイレという実在の日常環境を必要とするが、特定の歴史事件や唯一の実在地点には固定されない。

**この伝承における現れ方**

どの学校にもある個室へ移植でき、学校名や地域を交換しても選択型の意味形成核が保たれる。
