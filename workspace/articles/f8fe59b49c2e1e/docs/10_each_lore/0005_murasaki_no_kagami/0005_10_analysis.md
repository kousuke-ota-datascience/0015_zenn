# 1. 伝承エントリ基本情報

- `Entry_ID`: `0005`
- `伝承エントリ名称`: 紫の鏡
- `Macro_Category`: 学校・大学
- `Entry_Type`: 物語・伝説
- `Version_Scope`: **1998–1999年の静岡県・栃木県採録群で直接確認できる「危険語の記憶期限→死亡」型の最小安定共有核**。すなわち、「紫の鏡」という語を知った者が、その語を将来の一定年齢・節目まで忘れずに記憶していると、期限到達時に死亡するとされる記憶期限型の俗信。期限を20歳へ固定する型、不幸型、複合危険語、対抗語、人格怪異型、実物の鏡を用いる儀式、後代の由来譚はCoding Scopeへ混成しない。

# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Parent: なし

**判定根拠**

### 2.1.2. D02: 最古確認流通媒体

**判定根拠**

**この伝承における現れ方**

現時点で最古に固定できる流通定点は学校怪談集という書籍である。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**判定根拠**

1998–1999年Scopeは高校生・若者から採録された学校怪談・俗信圏の内容であり、学校・若者集団内の対人伝承を受容回路として推定する。研究DB自体は流通媒体に含めない。

**この伝承における現れ方**

危険語と期限規則が若者共同体の対人伝達で共有される形として再構成される。

### 2.1.4. D04: 生成・変容パターン

1998–1999年採録群で期限年齢、帰結、複合語、対抗語、人格怪異化が併存することは確認できる。ただし、それらがどの具体的伝達過程で変化・増補されたかは直接観察していない。

**この伝承における現れ方**

期限・帰結・補助語を差し替えながら同種の記憶期限型が反復される。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.PRP.PREDICTIVE_CLAIM` — 予測命題

**この伝承における現れ方**

将来の死亡条件を告げる予測命題として共有され、それ自体が警告として働く。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

**この伝承における現れ方**

無条件の実在断定ではなく、一定条件が成立すると結果が生じるという信念形式を取る。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.DCF.FATE_OMEN` — 運命・予兆
- Primary Parent: `D07.DCF` — 運命・未来不確実性
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

この伝承がなければ、現在の記憶状態と将来の死のあいだにどのような関係があるのかは説明されない。未知存在の正体ではなく、未来の災厄・運命予測を意味形成対象とする。

**この伝承における現れ方**

「今この語を覚えていること」が、将来の死亡可能性を判断する条件として扱われる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.UNSUPPORTED_ASSERTION` — 根拠未提示の主張
- Primary Parent: `D08.CLM` — 命題先行
- Secondary: `D08.STY.COMMUNITY_REPETITION` — 共同体反復証言
- Status: `I` — Inferred

**判定根拠**

物的痕跡や事件記録ではなく、「覚えていると死ぬ」という根拠未提示の主張が先に与えられる。学校・若者圏での反復伝達が、その命題を保持する追加契機となる。

**この伝承における現れ方**

証拠より先に規則が提示され、共同体で繰り返し共有されることで危険命題として定着する。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.PPR.CORRELATION_RULE` — 相関規則化
- Primary Parent: `D09.PPR` — パターン化・予測
- Secondary: `D09.NOR.TABOOIZATION` — 禁忌化
- Status: `I` — Inferred

**判定根拠**

「期限時の記憶保持」と「死亡」を条件付き規則として結び、その結果として危険語を覚え続ける状態を禁忌化する。禁忌化だけでなく、X→Yの予測規則形成をPrimaryとする。

**この伝承における現れ方**

曖昧な将来不安を「期限まで覚えていれば死亡する」という条件規則に変換する。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.OBJ.INFORMATION_CONTENT` — 情報内容
- Primary Parent: `D10.OBJ` — 物・情報
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

Scoped Contentでは人格怪異・実物の鏡を必須とせず、「紫の鏡」という情報内容の記憶保持が因果条件として扱われる。独立した呪詛主体を追加推定しない。

**この伝承における現れ方**

危険の原因は特定の場所や人物ではなく、受容者が保持する情報内容に置かれる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.INF.SAY_NAME_REMEMBER` — 言う・名前を唱える・記憶する
- Primary Parent: `D11.INF` — 情報曝露
- Secondary: `D11.CON.AGE_LIFESTAGE` — 年齢・ライフステージ
- Status: `D` — Direct

**判定根拠**

危険条件は語を期限まで記憶していること。16・18・20歳等の年齢・ライフステージ条件が期限を形成する。一度聞くだけではなく、期限時までの記憶保持が発動条件である。

**この伝承における現れ方**

危険語を知って記憶し続け、指定年齢へ達することで帰結条件が完成する。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.AUD.READER_LISTENER` — 読者・聞き手
- Primary Parent: `D12.AUD` — 受容者
- Secondary: なし
- Status: `D` — Direct

**判定根拠**

D13の認知災害が直接向くのは、伝承を受容して危険語を知り、その記憶を保持する者である。特定の物語主人公に限定されず、現実側の受容者が伝承内容上の作用対象へ入る。

**この伝承における現れ方**

話を聞いた受容者自身が将来の危害対象として伝承構造へ組み込まれる。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.COG.COGNITION_TRIGGERED_HARM` — 認知災害
- Primary Parent: `D13.COG` — 認知・情報作用
- Secondary: なし
- Status: `D` — Direct

**判定根拠**

「紫の鏡」という情報を記憶している認知状態が、期限到達時の致死的作用条件になる。死亡はD15の終端帰結として分離し、人格怪異による攻撃や独立した運命固定機構はScopeへ追加しない。

**この伝承における現れ方**

受容者の認知状態そのものが危害条件として扱われる。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct

**判定根拠**

Scoped Contentの終端は死亡であり、明確に負である。

**この伝承における現れ方**

期限条件が成立した場合の主帰結は致死的である。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.BOD.DEATH` — 死亡
- Primary Parent: `D15.BOD` — 身体・健康
- Secondary: なし
- Status: `D` — Direct

**判定根拠**

死亡型の安定共有核へScopeを固定した。複数の1998–1999年採録で死亡が直接示される。「不幸になる」型はVariationとして00に保持する。

**この伝承における現れ方**

主帰結は身体・生命の終端としての死亡である。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.DLY.DEADLINE` — 期限付き
- Primary Parent: `D16.DLY` — 遅延・期限
- Secondary: なし
- Status: `D` — Direct

**判定根拠**

情報曝露直後ではなく、指定年齢・節目まで記憶が残っているかが帰結発生条件となる。期限そのものが構造核である。

**この伝承における現れ方**

危害は即時ではなく、年齢・節目という将来の期限に結び付けられる。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: なし — **taxonomy gap: 忘却／記憶消去による制御**
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct

**判定根拠**

Evidence上、期限前に「紫の鏡」を忘れることが回避方式として明示される。しかし現行D17 taxonomyには、「一度知った情報を忘れる／記憶から失う」ことを直接表現するChildがない。`DO_NOT_ENGAGE` は接触前回避、`OBEY_TABOO` は禁止事項遵守であり、忘却そのものとは一致しない。

したがって最も近いChildへ無理に押し込まず、コード空欄のまま**D17忘却制御**をコードブック改訂候補として保持する。Status `D` はEvidence上の回避構造が直接明示されることを示し、既存Childへの適合を意味しない。

**この伝承における現れ方**

危険を避ける方法は「何かをしない」ではなく、すでに知った危険語を期限までに記憶から失うことである。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=1; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

- `L1=1`: 伝承内で記憶条件→死亡の因果が作動する。
- `L2=1`: 伝承を聞いて危険語を知る現実側受容者が、そのまま伝承内容上の将来の作用対象になる。
- `L3=0`: 噂流通による現実の行動・制度・市場等の外部効果を示すX Evidenceは確認していない。

L1/L2には直接Evidenceがある一方、L3=0はX Evidence不在に基づく不在判定を含むため、vector全体のStatusは保守的に `I` とする。

**この伝承における現れ方**

物語内因果だけでなく、話を聞いた受容者自身が伝承内の危険条件へ接続される点が特徴である。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.KIN.SCHOOL_YOUTH` — 学校・若者集団
- Primary Parent: `D19.KIN` — 家族・仲間
- Secondary: `D19.LOC.REGIONAL` — 地域・地方
- Status: `D` — Direct

**判定根拠**

1995年学校怪談集と1998年静岡県・1999年栃木県の若者採録により、学校・若者文化を中心に複数地域へまたがる存在を確認できる。全国的大衆までの広がりは推測しない。

**この伝承における現れ方**

学校・若者文化を中心に、複数地域で変異を伴って共有される。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.NON.COMMON_KNOWLEDGE` — 一般共有
- Primary Parent: `D20.NON` — 特権なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

Scope内では危険語と期限規則が学校・若者共同体で共有され、特定の専門家・内部者だけが追加真相や回避情報を独占する構造は確認しない。`D20.HAZ.DANGEROUS_TO_KNOW` は「情報へのアクセス自体が危害条件」という定義だが、本Scopeでは**知るだけでは危害条件が完成せず、期限まで記憶保持することが必要**なので採用しない。

**この伝承における現れ方**

危険規則は特権者の秘密ではなく、受容者共同体へ共有される知識として流通する。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A0` — 匿名・抽象
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

学校・若者圏で流通するが、Scoped Contentの因果成立は特定校、地域、実在の鏡、事件、制度を必要としない。「紫の鏡」という危険語と記憶期限だけで別の場所へ移植できる。

**この伝承における現れ方**

具体的実在対象へ固定されず、抽象的な危険語と期限規則だけで成立する。
