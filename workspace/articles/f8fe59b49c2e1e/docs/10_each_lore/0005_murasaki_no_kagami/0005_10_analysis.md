# 2. 分析概念次元

## 2.1. 来歴・流通・提示

### D01 生成年代
- Value: `D01.G4` — 1980年代
- Status: `I`

**判定根拠:** Pilotは昭和後期から1990年代の学校伝承として1980年代成立を推定。今回直接確認できた採録は1996年研究書、1998–99年民俗採録である。

**この伝承における現れ方:** Web以前の若者口承として既に定着しており、1990年代末の複数地域採録で同型規則が反復する。

**留保:** 1980年代を直接示す一次・同時代採録は今回固定できていない。再コーディング候補。

### D02 最古確認流通媒体
- Primary: `D02.ORL.SCHOOL_ORAL` — 学校内伝承
- Parent: `D02.ORL`
- Status: `D`

**判定根拠:** 1998–99年の「若者の俗信」「高校生が知っている不思議な話」は学校年齢層から採録された伝承で、学校・同世代口承として記録される既存判断を維持する。

**現れ方:** 友人から言葉と期限を聞くこと自体が因果系への入口になるため、流通媒体と危険条件が重なる。

### D03 確認流通媒体ポートフォリオ
- Primary: `D03.ORL.SCHOOL_ORAL`
- Parent: `D03.ORL`
- Status: `D`

**判定根拠:** Version Scopeの採録群は高校生・若者の俗信として対人共有される。

**現れ方:** 長い物語を必要とせず、「この言葉を20歳まで覚えていると死ぬ」という一文だけで口承可能である。

**留保:** 旧末尾メモ `D03:U` と本文コードが矛盾するためExcel正本照合が必要。

### D04 生成・変容パターン
- Primary: `D04.STB.STABILIZED_CANON`
- Parent: `D04.STB`
- Status: `I`

**判定根拠:** 年齢・帰結・補助語は変わるが、「特定語を期限まで記憶すると災厄」という核は静岡・栃木・兵庫等で反復する。

**現れ方:** 20歳→18歳→16歳、死→不幸、紫地蔵・赤い沼の追加など、パラメータを変えながら規則核が保持される。

### D05 提示形式
- Primary: `D05.RUL.TABOO` — 禁忌
- Parent: `D05.RUL`
- Status: `I`

**判定根拠:** 内容は「この語を期限まで覚えていてはいけない」という禁止・警告規則として伝えられる。

**現れ方:** 受容者は出来事の物語を聞くより、自分の記憶状態に適用される禁忌を直接渡される。

### D06 真実性提示
- Value: `D06.T3` — 共同体既知事実
- Status: `I`

**判定根拠:** 学校・若者集団内で「知っていると危ない言葉」として共有され、公式根拠ではなく共同体知が信憑性を支える。

**現れ方:** 聞き手が「みんな知っている」と認識することで、単なる創作語ではなく実効的な禁忌として機能する。

## 2.2. 意味形成

### D07 意味形成対象
- Primary: `D07.ANO.UNKNOWN_EXISTENCE`
- Parent: `D07.ANO`
- Status: `I`

**判定根拠:** Pilotは不可解な効力を持つ「紫の鏡」という情報的存在を未知の異常として捉えた。

**現れ方:** 具体的怪異が見えないのに、言葉の記憶だけで将来の死が説明されるという異常な存在／効力が問題化される。

**留保:** 対象は「未知存在」より「不可解な情報作用・未来災厄」と読む余地がある。

### D08 意味形成契機
- Primary: `D08.CLM.UNSUPPORTED_ASSERTION`
- Parent: `D08.CLM`
- Status: `I`

**判定根拠:** 「覚えていると死ぬ」という主張が経験的証拠に先行して受容者へ渡される。

**現れ方:** 聞き手は災厄を観察してから原因を探すのではなく、先に規則を知り、自分の将来をその規則で解釈する。

### D09 意味付与操作
- Primary: `D09.NOR.TABOOIZATION`
- Parent: `D09.NOR`
- Status: `I`

**判定根拠:** 無意味な語列だった「紫の鏡」を、保持してはいけない危険情報へ変える。

**現れ方:** 記憶という通常は価値中立の認知状態が「期限まで残してはいけない」規範へ転換される。

### D10 因果源存在論
- Primary: `D10.OBJ.INFORMATION_CONTENT`
- Parent: `D10.OBJ`
- Status: `I`

**判定根拠:** 基本形では人格怪異や物理鏡ではなく、語・情報内容そのものが因果源として置かれる。

**現れ方:** 場所を離れても、実物を捨てても、記憶内に情報がある限り因果関係が継続する。

## 2.3. 因果・行動モデル

### D11 発動・接触条件
- Primary: `D11.INF.SAY_NAME_REMEMBER`
- Parent: `D11.INF`
- Status: `D`

**判定根拠:** 採録文が「覚えている」ことを明示的条件とする。

**現れ方:** 情報を聞いた後、記憶保持という内的状態が長期の発動条件になる。実物接触は不要。

### D12 作用対象
- Primary: `D12.FOC.PROTAGONIST_EXPERIENCER`
- Parent: `D12.FOC`
- Status: `I`

**判定根拠:** 言葉を覚えている当人が将来の不幸・死を受ける。

**現れ方:** 他人が同じ語を知っていても、各人の記憶状態ごとに因果が独立して成立する。

### D13 作用機構
- Primary: `D13.COG.COGNITION_TRIGGERED_HARM`
- Parent: `D13.COG`
- Secondary: `D13.FAT.FATE_FIXING`
- Secondary Parent: `D13.FAT`
- Status: `I`

**判定根拠:** 認知状態が危害条件となり、期限到達時の死・不幸を未来に固定する。

**現れ方:** 「記憶している」という認知事実が、時間を隔てて運命的帰結を発生させる。物語化異伝では怪異襲撃が追加されるが核ではない。

### D14 帰結極性
- Value: `D14.NEG`
- Status: `I`

**判定根拠:** 死または不幸のみが主要帰結。

**現れ方:** 対抗語型も負の帰結を中和するだけで、基本規則は明確に負。

### D15 帰結領域
- Primary: `D15.OPP.LUCK_MISFORTUNE`
- Parent: `D15.OPP`
- Status: `I`

**判定根拠:** 「不幸になる」採録があり、Pilotは吉凶・機会領域をPrimaryとした。

**現れ方:** 抽象的な不幸型では、具体的傷害より人生全体の吉凶が変化する。

**留保:** 「死ぬ」採録が多数であり、身体・生命領域をどう扱うかは再検討余地がある。

### D16 因果時間構造
- Primary: `D16.DLY.DEADLINE`
- Parent: `D16.DLY`
- Status: `D`

**判定根拠:** 16・18・20歳等の期限が直接明示される。

**現れ方:** 情報曝露直後には何も起こらず、指定年齢まで記憶が残った場合にのみ帰結が成立する。期限そのものが恐怖の時計になる。

### D17 回避・制御方式
- Primary: `D17.AVO.DO_NOT_ENGAGE`
- Parent: `D17.AVO`
- Status: `I`

**判定根拠:** Pilotは危険語を保持しない／忘れることを接触回避として整理した。

**現れ方:** 「忘れる」ことが基本制御。ピンクの鏡等を覚える対抗型もある。

**留保:** 一度聞いた後の「忘却」は単純な接触回避ではないためコード適合性に再検討余地。

### D18 作用レイヤー
- `D18.L1`: 1
- `D18.L2`: 0
- `D18.L3`: 0
- Status: `I`

**判定根拠:** Pilotは伝承内の情報→災厄因果のみを採用。

**現れ方:** L1では記憶が死・不幸へ作用する。現実の受容者が「忘れようとする」心理・行動はあり得るが、採録だけでは外部効果として十分に固定していない。

## 2.4. 社会的埋め込み

### D19 流通範囲
- Primary: `D19.MAS.NATIONAL_PUBLIC`
- Parent: `D19.MAS`
- Status: `D`

**判定根拠:** 静岡・栃木・兵庫等、複数地域の若者伝承として採録される。

**現れ方:** 特定校の場所伝説ではなく、語だけで持ち運べるため地理的移植性が高い。

### D20 特権情報保持者
- Primary: `D20.NON.COMMON_KNOWLEDGE`
- Parent: `D20.NON`
- Status: `I`

**判定根拠:** ルールは若者集団で広く共有され、真相を独占する専門家がいない。

**現れ方:** 伝えるほど新たな危険主体を作るため、共有そのものが伝承再生産になる。

### D21 現実アンカー
- Value: `D21.A1` — 一般的現実背景
- Status: `I`

**判定根拠:** 年齢・学校・記憶という現実要素を使うが、特定地・史実・制度に固定されない。

**現れ方:** どこに住んでいても「20歳」という個人的期限だけで成立する。
