# 0. INTRODUCTION

## 0.1. 文書の役割

**伝承名:** 紫の鏡

本文書は、「紫の鏡」という語を一定年齢まで記憶していることが不幸・死へ結び付くとする若者の俗信について、確認できる伝承内容・採録・異伝・証拠上の不確実性を記録する Evidence / Content layer である。分析コードは `0005_10_analysis.md` に分離する。

パイロット Evidence Rank は `B`。重要なのは、実物の紫色の鏡を見たり使ったりする儀式ではなく、**「紫の鏡」という言語記号を知り、期限まで記憶し続けること自体が危険条件になる**点である。

# 1. 伝承内容

## 1.1. summary

「紫の鏡」は、聞いた瞬間に直ちに危害を受けるのではなく、**将来のある年齢までその言葉を忘れずに覚えていること**が不幸や死を招くとする記憶条件型の俗信である。典型形では「『紫の鏡』を20歳まで覚えていると死ぬ」と告げられる。受容者はその語を聞いたことで、以後「忘れなければならない」という逆説的な課題を背負う。

採録では期限が16歳・18歳・20歳・高校入学までなどに変わり、帰結も死亡と不幸の間で揺れる。また「紫の鏡」単独ではなく「紫地蔵」「赤い沼」等を一緒に覚えていると死ぬ型がある。逆に「ピンクの鏡」を覚えておけばよいとする対抗規則も確認される。

この伝承の特徴は、危険な物体・場所・怪異へ近づかなくても、**記憶内容そのものが時間差をもって運命へ作用する**とされることにある。しかも「忘れろ」と言われた語ほど意識に残りやすいため、伝承の警告自体が危険条件を強化する自己言及的構造を持つ。

一部の異伝では、期限まで覚えていると鏡の中から血まみれの女が現れて殺す等、抽象的な運命作用が人格怪異による襲撃へ物語化される。しかし、これは全Versionに共通する必須要素ではない。

## 1.2. 詳細構造

1. **情報曝露:** 学校・友人集団などで「紫の鏡」という語と規則を聞く。
2. **危険条件の成立:** 語を忘れず記憶し続ける。
3. **期限:** 16・18・20歳、または高校入学等の節目が設定される。
4. **帰結:** 期限に達した時点で死亡・不幸が起こるとされる。
5. **回避:** 期限前に忘れる、または「ピンクの鏡」等の対抗語を保持する異伝がある。
6. **物語化:** 一部では鏡内の女など、帰結を実行する主体が追加される。

## 1.3. 主体

| 主体 | 役割 |
|---|---|
| 伝承を聞いた若者 | 記憶主体・作用対象 |
| 友人・学校共同体 | 伝達主体 |
| 血だらけの女等 | 一部異伝で死を実行する怪異主体 |

## 1.4. 場所・空間

因果作用は特定地点に固定されない。学校・若者集団は主に**流通空間**であり、危害が起こる場所ではない。これにより、受容者が移動しても危険条件が継続する。

## 1.5. 物・記号・媒体

| 要素 | 役割 |
|---|---|
| 「紫の鏡」という語 | 危険情報そのもの |
| 年齢（16/18/20等） | 期限を設定する時間記号 |
| 「紫地蔵」「赤い沼」 | 複合条件を作る異伝語 |
| 「ピンクの鏡」 | 対抗・中和語とされる異伝 |

## 1.6. 条件・規則・禁忌

- 語を知るだけでなく、指定年齢まで**覚えていること**が主要条件。
- 「忘れる」が典型的回避。
- 対抗語を覚える型もある。
- 実物の鏡を見ることは中心条件ではない。

## 1.7. 中心命題

> 特定の言葉を期限まで記憶しているという認知状態が、将来の不幸・死を確定する。

## 1.8. 行動・対応

- 忘れようとする。
- 別の語で上書き・中和しようとする。
- 友人に伝える。伝える行為は他者にも同じ記憶課題を生じさせる。

## 1.9. 帰結

- 死亡。
- 不幸。
- 一部の物語化異伝では人格怪異の出現と殺害。

## 1.10. 不確実性

- 年齢は固定されない。
- 「死亡」と「不幸」は同一Versionの表現差とは限らない。
- 対抗語はすべての採録にない。
- 1998–99年採録から1980年代成立を直接証明することはできない。

# 2. 伝承史・異伝

## 2.1. 最古確認

現時点で本文・書誌まで直接確認できる強い採録は1998年『静岡県民俗学会誌』、1999年『下野民俗』等である。『走るお婆さん』（1996）でも研究対象となっており、それ以前の流通は確実だが、パイロットの「1980年代」という成立判定は今回確認した資料だけでは直接固定できない。

## 2.2. 流通

学校・高校生・若者の口承として地域横断的に流通し、期限・帰結・補助語を差し替えながら維持された。Web以前から存在する点が重要である。

## 2.3. 主要異伝

| 型 | 差分 |
|---|---|
| 20歳死亡型 | 最も広く採録される代表形 |
| 16/18歳死亡型 | 期限短縮 |
| 不幸型 | 死亡から吉凶へ弱化 |
| 紫地蔵・赤い沼併記型 | 危険語を複合化 |
| ピンクの鏡型 | 対抗語・回避規則を追加 |
| 鏡の女型 | 抽象的運命作用を怪異襲撃へ物語化 |

## 2.4. 変容上の重要点

語と期限という極小構造を維持しつつ、**期限・帰結・語の組合せだけを交換する**ため、短く記憶しやすく再生産性が高い。
