# 1. 伝承エントリ基本情報

- `Entry_ID`: `0060`
- `伝承エントリ名称`: タクシー幽霊
- `Macro_Category`: 交通・インフラ
- `Entry_Type`: 物語・伝説
- `Version_Scope`: 日本で1950年代までには広く知られていたと専門家資料が整理する全国型の共有核。タクシー運転手が通常の乗客として人物を乗せ、その人物が移動中・到着時に不在となる、または目的地で既に死亡した人物だったと判明し、結果として「生者ではない乗客／幽霊との接触」と理解される型を対象とする。夜・雨・特定墓地・濡れた座席・特定死因等は必須条件にしない。

## 2.2. 意味形成

### 2.2.1. D07: 意味形成対象
- Primary Child / Value: `D07.ANO.UNEXPLAINED_EVENT` — 説明不能事象
- Primary Parent: `D07.ANO` — 異常体験・存在
- Secondary: `D07.ANO.UNKNOWN_EXISTENCE` — 未知存在
- Status: `I`

**判定根拠**

通常の乗客として接触した人物が、移動途中・終端で生者としての連続性を失うことが中心問題であり、その人物が何者だったかという存在論的不確実性も伴う。

**この伝承における現れ方**

日常的な乗客輸送の途中で「さっきまで普通に会話していた人物が、通常の生者ではなかった」という不連続が発生する。

### 2.2.2. D08: 意味形成契機
- Primary Child / Value: `D08.DEX.DIRECT_EVENT` — 出来事への直接遭遇
- Primary Parent: `D08.DEX` — 直接経験
- Secondary: `D08.STY.WITNESS_REPORT` — 目撃証言
- Status: `I`

**判定根拠**

物語内では運転手自身の異常遭遇が起点となり、伝承としてはその体験報告が受容者に提示される。

**この伝承における現れ方**

運転手は通常営業の途中で客の不在化や故人判明に直面し、その証言が怪異を共有する手掛かりになる。

### 2.2.3. D09: 意味付与操作
- Primary Child / Value: `D09.CAT.TYPE_ASSIGNMENT` — 類型化
- Primary Parent: `D09.CAT` — カテゴリー化

- Status: `I`

**判定根拠**

説明不能な乗客事案を「幽霊・死者の乗客」という既知の怪異類型へ割り当て、背後に死者主体を置くことで理解可能にする。

**この伝承における現れ方**

遺影・家人の証言・不自然な消失等をもとに、単なる乗り逃げや見落としではなく「幽霊客だった」と再分類する。

### 2.2.4. D10: 因果源存在論
- Primary Child / Value: `D10.SUP.GHOST_SPIRIT` — 幽霊・死者霊
- Primary Parent: `D10.SUP` — 超自然主体・力
- Secondary: なし
- Status: `D`

**判定根拠**

Scopeは、通常の乗客が最終的に死者・幽霊として理解される全国型を対象とする。朝里2023も明示的に「タクシー幽霊」として整理する。

**この伝承における現れ方**

死者が一見ふつうの乗客として生者世界へ現れ、短時間だけ通常の社会関係を結ぶ主体として置かれる。

## 2.3. 因果・行動モデル

### 2.3.1. D11: 発動・接触条件
- Primary Child / Value: `D11.PAS.SPONTANEOUS_SELECTION` — 偶然選ばれる・遭遇する
- Primary Parent: `D11.PAS` — 受動発生
- Secondary: `D11.SOC.MEET_INTERACT` — 会う・会話する
- Status: `I`

**判定根拠**

通常のタクシー営業は再現的な召喚手順ではなく、運転手が偶然その乗客に当たることが怪異への入口となる。実際の接触は乗車・会話という相互行為で成立する。

**この伝承における現れ方**

運転手は禁忌破りや儀式を行わず、日常業務の延長で怪異側から接触される。

### 2.3.2. D12: 作用対象
- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC` — 焦点人物
- Secondary: なし
- Status: `I`

**判定根拠**

D13のPrimaryを死者の顕現と置くと、その顕現を直接経験する対象はタクシー運転手である。

**この伝承における現れ方**

幽霊客は運転手に対して通常の乗客として知覚・会話され、後からその認識が覆される。

### 2.3.3. D13: 作用機構
- Primary Child / Value: `D13.MAN.MANIFEST_ONLY` — 顕現のみ
- Primary Parent: `D13.MAN` — 顕現・観測
- Secondary: なし
- Status: `I`

**判定根拠**

全国型の共有核に最も安定する作用は、死者・幽霊が通常の乗客として生者に顕現することである。瞬間消失は主要異伝だが全型共通ではないためPrimaryにしない。

**この伝承における現れ方**

死者は攻撃・呪詛を必須とせず、短時間だけ「乗客」として現れ、通常世界にいた痕跡や記憶を残す。

### 2.3.4. D14: 帰結極性
- Primary Child / Value: `D14.NEU` — 中立
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

怪異は恐怖を伴うが、共有核では運転手への身体危害・呪い・利益を必須としない。中心帰結は認識の転換である。

**この伝承における現れ方**

運転手は異常な経験をするが、その後に死亡・負傷することまでは全国型の必須帰結ではない。

### 2.3.5. D15: 帰結領域
- Primary Child / Value: `D15.KNW.BELIEF_REVISION` — 信念変更
- Primary Parent: `D15.KNW` — 世界認識・知識
- Secondary: `D15.KNW.REVELATION_KNOWLEDGE` — 真相・知識獲得
- Status: `I`

**判定根拠**

通常の生者だと思っていた乗客が死者・幽霊だったと理解されることで、体験者の出来事解釈が変わる。故人確認型では遺影・家人等から追加情報を得る。

**この伝承における現れ方**

「普通の客を運んだ」という日常経験が、「死者を乗せた」という世界観上の出来事へ書き換えられる。

### 2.3.6. D16: 因果時間構造
- Primary Child / Value: `D16.EVT.SEQUENTIAL_EPISODE` — エピソード内段階進行
- Primary Parent: `D16.EVT` — 単一エピソード・事象内
- Secondary: なし
- Status: `D`

**判定根拠**

接触→乗車・移動→不在化／目的地到着→故人確認という複数段階が、一つの短いエピソード内で順に進行する。

**この伝承における現れ方**

異常は長期潜伏せず、通常営業として始まった一回の乗車の中で段階的に怪異へ転換する。

### 2.3.7. D17: 回避・制御方式
- Primary Child / Value: `D17.NON.OBSERVATIONAL_ONLY` — 観測のみ
- Primary Parent: `D17.NON` — 制御不要
- Secondary: なし
- Status: `I`

**判定根拠**

全国型の共有核には安定した回避手順・祓い・正答等がない。対処法が確認できないことを「不可避」とは読まない。

**この伝承における現れ方**

運転手は怪異を事前に選別・制御するのではなく、事後に異常だったと知るだけである。

### 2.3.8. D18: 作用レイヤー

- `D18.L2`: `0`
- `D18.L3`: `0`
- Status: `D`

**判定根拠**

**この伝承における現れ方**

因果作用は基本的に物語内部の運転手と幽霊客の接触で閉じる。

# 3. R4 QA

## 3.1. causal chain

```text
D11: 通常営業中に偶然、異常な乗客へ遭遇する
→ D12: 運転手が直接の体験者となる
```

## 3.4. taxonomy gap

0060のPrimary構造は既存taxonomyで表現できる。ただし「車内で客が消える」異伝単独では、0059で確認済みのD13「対象の消失／不在化」gapが再出する。Global Reconciliationで再検討する。

## 3.5. 旧10との差分

R3 freeze後に旧10を確認した。主要差分は、D01 `U→G2`、D02 `U→NEWSPAPER`、D03 `BOOK→NEWSPAPER`、D04 Primary `LOCALIZATION→RETELLING`、D05 `FOAF→NEWS_STYLE`、D11 `RIDE_BOARD→SPONTANEOUS_SELECTION`、D15を認識変化中心へ再定義した点である。差分はEvidence補強と現行coding rulesの再適用によるもので、旧値への一致を目的としていない。
