**判定根拠**

口承・新聞・怪談集等の流通形はあり得るが、現Evidenceではどれが最古か分からない。「運転手の間で昔から口承されたはず」という推測では埋めない。

各地の「消える乗客」類話が書籍上で一つの全国型として再提示され、地域を越えて同じ類型として受容可能になる。

**この伝承における現れ方**

全国共通の骨格が各地域の地名・災害記憶・施設へ接続され、その土地固有の怪談として再構成される。同時に、幽霊解釈を補強する痕跡や身元確認場面が増補される。

**この伝承における現れ方**

「実際の運転手が経験したらしい」という現実感を保ちつつ、超自然的核心は確定されないまま語られる。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ANO.UNEXPLAINED_EVENT` — 説明不能事象
- Primary Parent: `D07.ANO` — 異常体験・存在
- Secondary: なし
- Status: `D` — Direct（共有核に乗客消失が明示）

**判定根拠**

全国型に共通して説明されないまま残る中心問題は、直前まで車内にいた乗客が通常の降車過程なしに消える出来事である。特定地域や災害史は各異伝の説明要素であり、全国型の中心対象ではない。

**この伝承における現れ方**

日常の乗車行為の中で「いたはずの人物がいなくなる」という不連続が発生し、その出来事をどう理解するかが物語を駆動する。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.DEX.DIRECT_EVENT` — 出来事への直接遭遇
- Primary Parent: `D08.DEX` — 直接経験
- Secondary: `D08.TRC.PHYSICAL_TRACE` — 物的痕跡
- Status: `I` — Inferred（共有核と一部異伝を分けて判定）

**判定根拠**

運転手は、乗せていた客が突然いなくなったことへ直接遭遇する。一部異伝では濡れた座席や残置物が、その接触があったことを示す追加手掛かりとなる。

**この伝承における現れ方**

意味形成は「幽霊がいるらしい」という命題を先に受け入れることではなく、車内の不在という異常を体験者が確認するところから始まる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAT.TYPE_ASSIGNMENT` — 類型化
- Primary Parent: `D09.CAT` — カテゴリー化
- Secondary: なし
- Status: `I` — Inferred（後段の幽霊解釈から判定）

**判定根拠**

不可解な乗客消失を、「幽霊・死者が一時的に生者世界へ現れた」という既知の怪異類型へ割り当てることで理解可能にする。

**この伝承における現れ方**

故人情報や痕跡が加わると、単なる失踪・逃走ではなく「幽霊客」という既知の型へ整理され、各地の類話を同じ種類の出来事として再話できる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SUP.GHOST_SPIRIT` — 幽霊・死者霊
- Primary Parent: `D10.SUP` — 超自然主体・力
- Secondary: なし
- Status: `I` — Inferred（代表形の説明から判定）

**判定根拠**

代表形では、消えた乗客をすでに死亡した人物の霊として理解することが中心的な因果説明となる。

**この伝承における現れ方**

死者が一見普通の乗客として会話・移動し、その後消える存在として世界内に置かれる。日常交通と死者世界の境界がタクシー車内で一時的に重なる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.MOV.RIDE_BOARD` — 乗る
- Primary Parent: `D11.MOV` — 移動・空間進入
- Secondary: なし
- Status: `I` — Inferred（共有核の接触場面から判定）

**判定根拠**

全国型の共有核では、乗客がタクシーへ乗り、運転手と同じ車内空間へ入ることが怪異体験の開始点となる。

**この伝承における現れ方**

召喚儀式や禁忌破りはなく、通常の営業行為として客を乗せることが超自然的接触になる。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC` — 焦点人物
- Secondary: なし
- Status: `I` — Inferred（物語焦点から判定）

**判定根拠**

乗客消失を観測し、死者と接触したかもしれないという認識変化を引き受ける中心人物はタクシー運転手である。

**この伝承における現れ方**

運転手は通常業務を行っていただけなのに、突然、日常世界と死者世界が接続した体験の当事者になる。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.MAN.MANIFEST_ONLY` — 顕現のみ
- Primary Parent: `D13.MAN` — 顕現・観測
- Secondary: なし
- Status: `I` — Inferred（共通核に直接危害を要しない）

**判定根拠**

幽霊客は通常の人間のように現れ、その後消えることが中心で、運転手への物理攻撃・呪詛等は全国型の共有核ではない。

**この伝承における現れ方**

死者は乗客として一時的に可視化され、会話や移動を成立させた後に不在となる。怪異の主作用は顕現・観測そのものにある。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEU` — 中立
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（共有核に必須の危害・利益がない）

**判定根拠**

全国型の共有核では、乗客が消え、場合によって死者と判明するが、運転手に身体的・社会的・運命的損失が必ず生じるわけではない。怪談として恐怖を喚起することと、伝承内の主帰結が負であることを分離する。

**この伝承における現れ方**

運転手は不可解な出来事を経験するが、共通核としては傷害・死亡・呪い等へ必ず進まない。中心は異常の観測と説明である。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.KNW.UNCERTAINTY_PRESERVED` — 不確実性維持
- Primary Parent: `D15.KNW` — 世界認識・知識
- Secondary: なし
- Status: `I` — Inferred（共有核の終端状態から判定）

**判定根拠**

幽霊と説明される場合でも、なぜ死者が現れたか、どのように消えたか、何が実際に起きたかは確定しない。

**この伝承における現れ方**

「普通の乗客ではなかった」という解釈は得られても、出来事の仕組みまでは説明されず、日常世界に死者が入り込む可能性だけが残る。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.EVT.SEQUENTIAL_EPISODE` — 連続エピソード
- Primary Parent: `D16.EVT` — 単一エピソード・事象内
- Secondary: なし
- Status: `I` — Inferred（乗車から消失・確認までの順序が意味を持つ）

**判定根拠**

共有核は「乗車→移動→消失」で順序立って進み、正体確認型では「問い合わせ→故人と判明」が後続する。単なる一点観測より、一続きの出来事の順序が意味形成に寄与する。

**この伝承における現れ方**

普通の営業として始まった一便が、乗客の消失、場合によっては故人確認へ段階的に転換する。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.NON.OBSERVATIONAL_ONLY` — 観測のみ
- Primary Parent: `D17.NON` — 制御不要
- Secondary: なし
- Status: `I` — Inferred（共通の制御規則を持たない）

**判定根拠**

全国型に共通する識別法・禁忌・解除法・利益利用法は確認できない。対処法がないことを「不可避」とはせず、共有核では追加介入を要求しない観測型として扱う。

**この伝承における現れ方**

普通の客と幽霊客を事前に見分ける規則はなく、運転手は事後に怪異だったと理解するだけである。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（確認可能な因果を伝承内部に限定）

**判定根拠**

死者が現れて消える因果は物語内の運転手・乗客関係に作用する。話を聞いた受容者自身が因果対象になる構造や、全国型の流通によって制度・市場・集団行動が変化したX証拠は現Evidenceでは確認しない。

**この伝承における現れ方**

怪異は一便のタクシー内部で生じ、伝承を知ること自体が次の怪異を発動させるわけではない。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: なし
- Status: `I` — Inferred（全国各地の類話整理から判定）

**判定根拠**

主典拠は各地の類話を全国型として整理しており、一つの地域共同体へ限定されない。個々のローカル版が共通の類型へまとめられている。

**この伝承における現れ方**

深泥池、病院、墓地、被災地など場所を差し替えながら同じ骨格が各地で再生産され、地域を越えて理解可能な都市伝説型になる。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.NON.COMMON_KNOWLEDGE` — 一般共有

**判定根拠**

全国型の核心を知るために秘密の専門家・内部者は必要ない。一方、正体確認型の一部では目的地の家族・遺族が「その人物はすでに死亡している」という追加情報を持つ。

**この伝承における現れ方**

基本の怪談情報は一般に共有されるが、一部異伝では遺族の証言が乗客を死者と確定する最後の情報として機能する。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし

**判定根拠**

全国型はタクシー、道路、病院、自宅等の一般的な現実背景を用いるが、特定の一地点・一事件へ固定されない。A2相当の地域版は別Entryまたは異伝として扱う。

**この伝承における現れ方**

物語の現実感は日常的なタクシー営業から生じるが、舞台は地域ごとに差し替え可能であり、全国型そのものは特定地点へ依存しない。
