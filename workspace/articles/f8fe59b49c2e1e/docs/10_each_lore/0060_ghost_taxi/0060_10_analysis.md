# 1. 伝承エントリ基本情報

- `伝承エントリ名称`: タクシー幽霊
- `Macro_Category`: 交通・インフラ

# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: `D01.G2` — 1945–1969
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

パイロットでは、タクシーが大衆交通として普及した戦後に各地で反復する型として扱い、1945–1969の成立帯に置いた。全国型の単一の最古一次資料は未固定であるため、成立年代そのものは推定である。

**この伝承における現れ方**

この伝承は、タクシーという近代的な都市交通サービスが日常化した社会を前提とする。見知らぬ客を乗せて目的地まで運ぶという職業行為が怪異との接点になるため、古い徒歩・旅籠型の幽霊譚ではなく、戦後都市生活に適応した死者遭遇譚として現れる。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（証拠不足）

**判定根拠**

全国型について、最古の一例を示す一次資料を固定できていない。特定地域版には新聞記事等があるが、それを全国型全体の最古流通媒体とみなすことはできない。

**この伝承における現れ方**

この伝承は口承・新聞・怪談集など複数媒体で見られるが、どれが最初だったかを現在の証拠から一意に言えない。したがって「昔から運転手の間で口承されていたはず」と推定して埋めず、最古媒体は `U` とする。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Child / Value: `D03.ORL.PEER_ORAL` — 友人・仲間内伝承
- Primary Parent: `D03.ORL` — 口承・限定共同体
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

全国型は「運転手が体験した」「知人の運転手から聞いた」という伝聞型で再話されやすく、パイロットでは仲間内口承をPrimaryとした。

**この伝承における現れ方**

タクシー運転手という職業集団や、その周辺の知人関係を通じて「こんな客を乗せた運転手がいた」と語られる構図が、物語の実話らしさを支える。固定された一つの原文より、同じ骨格を持つ再話が人から人へ渡ることが重要である。旧レビュー用メモには `D03:U` が残るため、本文値との不整合はtask 3で再確認する。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.STB.STABILIZED_CANON` — 定型化・カノン化
- Primary Parent: `D04.STB` — 安定・固定
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

地域・人物・目的地を差し替えながらも、「乗せる→移動する→客が消える→死者と判明することがある」という核が反復するため、定型化を保持する。

**この伝承における現れ方**

伝承は一つの固定作品としてではなく、深泥池、病院、墓地、事故現場、震災被災地などへ舞台を移し替えながら生き残る。細部は変わっても、タクシー車内で生者と死者が一時的に同席するという骨格は安定している。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.HRS.LOCAL_HEARSAY` — 地元伝聞
- Primary Parent: `D05.HRS` — 伝聞叙述
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

典型的には特定の運転手の体験を第三者が「聞いた話」として語るため、地元伝聞を保持する。

**この伝承における現れ方**

受容者は幽霊を直接観察するのではなく、「ある運転手が客を乗せたところ消えた」という経験談を間接的に聞く。話者と体験者の距離があるため、細部の差し替えが起こりやすく、それ自体が都市伝説らしい流通形式になる。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T6` — 真偽未確定
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

運転手・実在道路・具体的目的地といった現実的要素を用いる一方、幽霊の実在や消失機構は確定されないため、真偽未確定を保持する。

**この伝承における現れ方**

「実際にタクシー運転手が体験したらしい」という現実感と、「本当に幽霊だったのかは証明できない」という余白が同居する。完全な創作宣言でも、検証済み事実でもない中間状態が伝承の説得力を作る。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（証拠不足）

**判定根拠**

全国型には、乗客消失、死者の再来、災害死者との接触など複数の意味形成焦点があり、パイロット時点の資料では一つに固定できないため `U` を保持する。

**この伝承における現れ方**

どの型でも「いたはずの客がいない」ことは不可解だが、物語によって焦点は、人物の消失そのもの、死者が日常世界へ戻ること、特定場所に死者が現れることへずれる。全国型を一括する本Entryでは、その違いを一つのD07に押し込めない。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.UNSUPPORTED_ASSERTION` — 根拠未提示の主張
- Primary Parent: `D08.CLM` — 命題先行
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

乗客消失と「死者だった」という説明が伝聞として提示され、独立検証の根拠が十分示されないため、このコードを保持する。

**この伝承における現れ方**

物語は、車内の不在や後から聞く死亡情報を手掛かりに、「あの客は幽霊だった」という意味付けへ進む。受容者はその因果説明を物語の一部として受け取るが、証明手続きは伝承の外へ開かれている。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAT.NAMING` — 命名
- Primary Parent: `D09.CAT` — カテゴリー化
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

消えた乗客を「幽霊」「死者」という既知のカテゴリーへ置くことで、不可解な消失を理解可能にするため命名を保持する。

**この伝承における現れ方**

単なる未払い逃走や記憶違いでは説明できない消失が、後から故人情報や痕跡と結び付くことで「幽霊客」という型へ整理される。名前が付くことで、各地の異なる事例が同じ種類の出来事として比較・再話可能になる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SUP.GHOST_SPIRIT` — 幽霊・死者霊
- Primary Parent: `D10.SUP` — 超自然主体・力
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

代表形では、乗客の正体を死者の霊とみなすことが物語の中心的説明になるため、この存在論コードを保持する。

**この伝承における現れ方**

因果源は抽象的な呪いではなく、人間の外見と会話能力を持つ死者である。死者は一時的に生者の交通制度へ参加できる存在として置かれ、日常世界と死者世界の境界がタクシー車内で曖昧になる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.MOV.RIDE_BOARD` — 乗る
- Primary Parent: `D11.MOV` — 移動・空間進入
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

共通核では乗客がタクシーへ乗ることによって運転手と怪異主体が同じ因果系へ入るため、乗車を保持する。

**この伝承における現れ方**

特別な召喚や禁忌破りは必要ない。運転手が営業としてドアを開け、客を乗せるという通常行為がそのまま超自然的接触になる。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC` — 焦点人物
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

異常を観測し、乗客の消失や死者情報に直面する中心人物はタクシー運転手であるため、このコードを保持する。

**この伝承における現れ方**

運転手は日常業務を続ける側から、突然「死者を運んでいたかもしれない人物」へ立場を変えられる。怪異の作用は、運転手の身体よりも知覚と世界理解へ強く及ぶ。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.MAN.MANIFEST_ONLY` — 顕現のみ
- Primary Parent: `D13.MAN` — 顕現・観測
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

幽霊客は通常の人間のように顕現し、その後消えることが中心で、運転手への直接攻撃や呪詛が共通核ではないため、顕現のみを保持する。

**この伝承における現れ方**

死者は乗客として一時的に可視化され、会話や移動を成立させた後に不在となる。怪異の機構は「見える／乗れる存在として現れ、普通の乗客では不可能な形で消える」ことにある。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

運転手に恐怖・混乱を残す怪談として語られ、利益や救済が共通の帰結ではないため負を保持する。

**この伝承における現れ方**

身体被害がなくても、乗客が突然消え、場合によっては死者だったと知ることで、日常業務に対する安心感が崩れる。帰結は認識的・情動的に負である。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.KNW.UNCERTAINTY_PRESERVED` — 不確実性維持
- Primary Parent: `D15.KNW` — 世界認識・知識
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

正体を幽霊と説明しても、なぜ現れたか、どう消えたか、何が本当に起きたかは確定しないため、不確実性維持を保持する。

**この伝承における現れ方**

運転手は「普通の客ではなかった」と理解しても、出来事を完全には説明できない。伝承は謎を解くより、日常世界に死者が入り込む余地を残すことで終わる。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.EVT.SINGLE_OBSERVATION` — 単発観測
- Primary Parent: `D16.EVT` — 単一エピソード・事象内
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

一回の乗車から消失、場合によっては直後の正体確認までが一つのエピソードとして構成されるため、単発観測を保持する。

**この伝承における現れ方**

怪異は長期の呪いとして累積するのではなく、ある一便の乗車中に凝縮される。正体確認型でも、体験直後の確認が物語の終端を作る。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.NON.OBSERVATIONAL_ONLY` — 観測のみ
- Primary Parent: `D17.NON` — 制御不要
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

全国型に共通する禁忌・解除・利用法はなく、運転手は事後に怪異を認識するだけであるため観測のみを保持する。

**この伝承における現れ方**

「この客を乗せなければ防げる」という明確な識別規則は提示されない。普通の客と同じように見えることが恐怖の条件であり、体験者は事前に制御できない。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

超自然的効力は、物語内の乗客と運転手の出来事として扱われ、話を聞いた受容者に自動的な害が及ぶ構造ではないためL1のみを保持する。

**この伝承における現れ方**

伝承を知っただけで幽霊が来る、社会制度が実際に変わる、といった作用は共通核にない。怪異は物語内の一便のタクシーで完結する。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

主典拠は全国各地の類話をまとめる現代怪異事典であり、単一地域に限定されない類型として確認されるため、全国的大衆を保持する。

**この伝承における現れ方**

深泥池など個別地域版はあるが、「タクシーに幽霊が乗る」という型は場所を差し替えて広域に再生産される。受容者は自分の地域版として再ローカライズできる。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.NON.COMMON_KNOWLEDGE` — 一般共有
- Primary Parent: `D20.NON` — 特権なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

秘密の内部者や専門家だけが真相を知る構造ではなく、伝承自体が一般に共有されるため特権なしを保持する。

**この伝承における現れ方**

正体確認型の遺族は「その人物は亡くなっている」という追加情報を持つことがあるが、世界の真相を独占する存在ではない。物語の核心は一般の再話で共有可能である。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

全国型はタクシー、道路、病院、自宅など現実的背景を用いるが、特定の一地点・一事件へ必ず固定されるわけではないためA1を保持する。

**この伝承における現れ方**

物語の現実感は、誰もが理解できるタクシー営業の状況から生じる。深泥池版のようにA2相当の強い地理固定を持つ個別例もあるが、全国型そのものは一般的現実背景の上に成立する。
