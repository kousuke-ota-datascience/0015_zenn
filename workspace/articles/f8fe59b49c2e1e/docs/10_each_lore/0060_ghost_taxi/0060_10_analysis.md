# 1. 伝承エントリ基本情報

- `Entry_ID`: `0060`
- `伝承エントリ名称`: タクシー幽霊
- `Macro_Category`: 交通・インフラ
- `Entry_Type`: 物語・伝説
- `Version_Scope`: 朝里2023で日本の「タクシー幽霊」として整理される再話群のうち、タクシー運転手が人物を客として乗せ、移動中・到着時にその客が不在となる、または目的地で既に死亡した人物と一致すると判明し、死者・幽霊の乗客として理解される型を対象とする。夜・雨・特定墓地・濡れた座席・特定死因は必須条件にしない。1950年代新聞本文は未実見であり、その記事固有の提示形式・真実性姿勢はScope Evidenceとして固定しない。

# 2. 分析概念次元

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U`

**判定根拠**

`0060_00_contents.md` では、朝里2023が「1950年代には新聞掲載され広く知られていた」と整理していることを確認できるが、当該新聞本文・紙名・日付は未実見であり、生成時期を独立に限定するHistory Evidenceはない。1950年代の存在確認を生成年代へ変換しない。

**この伝承における現れ方**

1950年代までには同型の話が流通していた可能性を示す確認点はあるが、それ以前の成立時期を現在の証拠から特定できない。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Parent: `D02.PRT` — 印刷・書簡
- Secondary: なし

**判定根拠**

朝里2023が1950年代の新聞掲載を明示している。新聞本文を直接確認していないため、媒体の確認は二次資料を介した間接Evidenceとする。

**この伝承における現れ方**

現在追跡できる早い確認点として、タクシー幽霊の話が新聞に掲載されていたと整理されている。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Child / Value: `D03.PRT.NEWSPAPER` — 新聞
- Primary Parent: `D03.PRT` — 印刷・書簡
- Secondary: `D03.NET.WEB_ARTICLE` — Web記事
- Status: `I`

**判定根拠**

1950年代新聞掲載は朝里2023による間接確認であり、2023年のwebムー記事では複数のタクシー幽霊再話を本文で直接確認できる。したがってScope内で確認できる媒体として新聞とWeb記事を区別して保持する。

**この伝承における現れ方**

古い流通点として新聞が言及され、後代にはWeb記事上で複数の地域版・異伝が整理されている。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.VAR.RETELLING` — 再話
- Primary Parent: `D04.VAR` — 再話・変異
- Secondary: `D04.VAR.LOCALIZATION` — 地域化; `D04.REC.EVENT_ATTACHMENT` — 実事件・災害への付着
- Status: `D`

**判定根拠**

朝里2023は、乗客属性・地名・消失方法・物的痕跡が異なる複数の再話、青山墓地・深泥池等への地域化、東日本大震災後の被災地での再文脈化を本文で整理している。

**この伝承における現れ方**

タクシー運転手と異常な乗客という構図を保ちながら、舞台・乗客属性・故人確認方法・痕跡が各地の再話で変化する。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ANO.UNEXPLAINED_EVENT` — 説明不能事象
- Primary Parent: `D07.ANO` — 異常体験・存在
- Secondary: `D07.ANO.UNKNOWN_EXISTENCE` — 未知存在
- Status: `I`

**判定根拠**

00では、通常の乗客として同乗していた人物が途中で不在になる型、後から死亡済み人物と一致する型が確認される。出来事の不連続と、乗客が何者だったのかという存在論的不確実性の双方がある。

**この伝承における現れ方**

「さっきまで普通の客としていた人物が、通常の生者として連続しない」という出来事が問題化される。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.DEX.DIRECT_EVENT` — 出来事への直接遭遇
- Primary Parent: `D08.DEX` — 直接経験
- Secondary: `D08.STY.WITNESS_REPORT` — 目撃証言
- Status: `I`

**判定根拠**

物語内では、運転手自身が客の不在化または故人確認に直面する。伝承としては、その経験が体験談・伝聞として再話される。

**この伝承における現れ方**

運転手が通常営業の途中で異常に遭遇し、その経験が後から他者へ伝達される。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAT.TYPE_ASSIGNMENT` — 類型化
- Primary Parent: `D09.CAT` — カテゴリー化
- Secondary: `D09.AGN.AGENCY_ATTRIBUTION` — 主体化
- Status: `I`

**判定根拠**

消失や故人との一致という異常を、「死者・幽霊の乗客」というカテゴリーへ割り当てることで出来事を理解可能にする。

**この伝承における現れ方**

遺影、住人の説明、突然の不在等が、普通の乗客ではなく「幽霊客だった」という理解へ接続される。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SUP.GHOST_SPIRIT` — 幽霊・死者霊
- Primary Parent: `D10.SUP` — 超自然主体・力
- Secondary: なし
- Status: `D`

**判定根拠**

Version Scopeを、乗客が死者・幽霊として理解される型に限定している。00の故人確認型では、乗せた人物と死亡済み人物との一致が明示される。

**この伝承における現れ方**

死者が一時的に通常の乗客として現れたものとして出来事が再構成される。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.PAS.SPONTANEOUS_SELECTION` — 偶然選ばれる・遭遇する
- Primary Parent: `D11.PAS` — 受動発生
- Secondary: `D11.SOC.MEET_INTERACT` — 会う・会話する
- Status: `I`

**判定根拠**

00で確認される話では、運転手が通常営業中に客を乗せることで出来事が始まり、召喚手順や禁忌違反は確認されない。

**この伝承における現れ方**

運転手は怪異を意図して呼び出すのではなく、日常業務の延長で異常な乗客と接触する。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC` — 焦点人物
- Secondary: なし
- Status: `I`

**判定根拠**

幽霊客の顕現・消失・故人判明を直接経験する焦点人物はタクシー運転手である。

**この伝承における現れ方**

運転手が乗客を通常の人間として扱った後、その認識を覆す出来事に直面する。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.MAN.MANIFEST_ONLY` — 顕現のみ
- Primary Parent: `D13.MAN` — 顕現・観測
- Secondary: なし
- Status: `I`

**判定根拠**

Scope内で安定して確認できるのは、死者・幽霊と理解される人物が通常の乗客として運転手の前に現れること。攻撃・呪詛・身体侵襲はScopeの主要作用として確認できない。

**この伝承における現れ方**

因果源は「乗客として現れる」ことで運転手に作用し、その後の消失または故人確認によって異常性が明らかになる。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEU` — 中立
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

00で確認されるScopeでは、運転手への身体危害・死亡・利益を主要帰結として固定できない。中心は異常な経験と認識の転換である。

**この伝承における現れ方**

運転手は不可解な出来事を経験するが、Scope内で必ず害を受けるとはされない。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.KNW.BELIEF_REVISION` — 信念変更
- Primary Parent: `D15.KNW` — 世界認識・知識
- Secondary: `D15.KNW.REVELATION_KNOWLEDGE` — 真相・知識獲得
- Status: `I`

**判定根拠**

普通の乗客だという初期認識が、死者・幽霊だったという理解へ変更される。故人確認型では遺影や家人の説明による追加知識が加わる。

**この伝承における現れ方**

「通常の客を運んだ」という出来事が、「死者を乗せた」という解釈へ書き換えられる。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.EVT.SEQUENTIAL_EPISODE` — エピソード内段階進行
- Primary Parent: `D16.EVT` — 単一エピソード・事象内
- Secondary: なし
- Status: `D`

**判定根拠**

接触→乗車・移動→不在化または目的地到着→故人確認という順序が、一回の乗車エピソード内で段階的に進む。

**この伝承における現れ方**

通常営業として始まった短い出来事が、その途中または終端で怪異経験へ転換する。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U`

**判定根拠**

00では、確認した資料に共通の回避手順が明示されていないことまでしか言えない。回避法が確認できないというabsenceは、「観測のみ」「制御不能」という伝承内規則の正Evidenceではない。

**この伝承における現れ方**

運転手が怪異を避けるための確立した方法があるか、ないかを、現在のScope Evidenceからは判定できない。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `0`
- Status: `I`

**判定根拠**

L1は、物語内部で幽霊客の顕現と運転手の認識変化が起きるため1とする。L2について、話を知った受容者自身へ同じ因果が自己適用される規則は確認していないため0。L3について、同一Version Scopeに対する制度・市場・行動等の独立した社会現実X Evidenceは確認していないため0。ただし、L2=0・L3=0はabsenceに基づくためvector全体のStatusは`I`とする。

**この伝承における現れ方**

確認できる因果作用は主として物語内部の運転手と幽霊客の接触にある。受容者・社会現実への作用は現在のEvidenceでは積極的に確認されない。

### 2.4.3. D21: 現実アンカー
