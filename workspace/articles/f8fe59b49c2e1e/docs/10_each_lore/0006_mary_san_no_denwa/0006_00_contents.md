# 0. INTRODUCTION

## 0.1. 文書の役割

**伝承名:** メリーさんの電話

本文書は、捨てられた人形等から反復して電話がかかり、その都度現在地が近づいて最終的に至近距離へ到達する「メリーさんの電話」について、伝承内容・典拠・変容・証拠上の不確実性を記録する Evidence / Content layer である。分析コードは `0006_10_analysis.md` に分離する。

パイロット Evidence Rank は `B`。本伝承は「捨てた人形」「電話」「段階的接近」という核が広く定型化している一方、初出年代・リカちゃん電話との系譜・人形を捨てた理由・最終的な危害の有無は資料間で揺れる。確証のない起源説を原型へ遡及させない。

# 1. 伝承内容

## 1.1. summary

代表形では、少女または語りの主人公が、長く持っていた人形「メリー」を捨てる・処分する・引っ越し等の事情で手放す。その後、自宅の電話に「私、メリーさん。今○○にいるの」といった電話がかかってくる。最初の場所はごみ捨て場、駅、街角など主人公から離れた地点だが、次の電話では駅から近所へ、近所から家の前へというように、告げられる場所が着信のたびに主人公へ近づく。

主人公は電話を切る、無視する、家を確認する、逃げる等の対応を試みるが、電話は距離の縮小を通知し続ける。恐怖の中心は「人形がどう移動したのか」が見えないまま、**通信だけが接近の進捗を正確に報告する**ことにある。電話は安全な遠隔通信手段ではなく、逃れられない追跡の測距装置へ反転する。

終盤では「今、家の前にいる」「今、あなたのいる部屋の前にいる」等と告げられ、最後に「今、あなたの後ろにいるの」といった至近距離の通知へ到達する型が著名である。そこで語りが切れる型、主人公が襲われる型、振り返ることを禁じる型などがあり、最終危害は必須ではない。

構造上重要なのは、単発の驚かせではなく、**現在地通知→着信終了→再着信→距離短縮**を何度も反復する段階接近である。聞き手は各地点から残り距離を推定できるため、次の電話を予測しながら恐怖を増幅させる。固定電話中心の時代には「なぜ移動中の人形が各地点から電話できるのか」という矛盾自体が怪異性を強め、携帯電話普及後の再話では通信媒体のみ更新されることがある。

## 1.2. 詳細展開

1. **発端:** 人形を捨てる・置き去りにする。
2. **最初の着信:** 人形が名乗り、遠方の現在地を告げる。
3. **反復:** 着信ごとに現在地が主人公へ近づく。
4. **対応:** 主人公は切断・無視・逃走・戸締まり等を試みる。
5. **侵入:** 現在地が家の前、家の中等へ移る。
6. **終端:** 「後ろ」等、距離ゼロに近い位置が告げられる。
7. **未確定部分:** その後の危害・主人公の生死はVersion差。

## 1.3. 主体

| 主体 | 役割 |
|---|---|
| メリーさん／人形 | 電話発信者・追跡主体 |
| 元所有者 | 電話受信者・追跡対象 |
| 電話の聞き手 | 位置通知を通して接近を認識する焦点人物 |

## 1.4. 場所・空間

- 遠方の地点→近所→自宅周辺→家屋内部→背後、という**相対距離列**が重要。
- 固有地名は差し替え可能で、話者の生活圏にローカライズされる。

## 1.5. 物・記号・媒体

- **人形:** 捨てられた物が主体化する物的基体。
- **電話:** 接近位置を逐次通知する媒体。
- **現在地表現:** 位置の変化を聞き手が計算可能にする反復句。

## 1.6. 条件・規則

- 人形を手放すことが発端になる型が多い。
- 電話への応答で現在地が認識されるが、応答しないことが接近を止めるとは限らない。
- 接近は一方向で、通常は距離が縮む。

## 1.7. 中心異常

離れた場所にあるはずの人形が自律移動し、通信を介して正確な現在位置を知らせながら元所有者へ到達する。

## 1.8. 行動・対応

電話を切る、無視する、外を確認する、逃げる、戸締まりする等。多くのVersionで有効な停止手段は示されず、行動しても接近が継続する。

## 1.9. 帰結

- 至近距離への到達による強い恐怖。
- 一部異伝では襲撃・死亡。
- 到達文句だけで終える型では、何が起きたかは明示されない。

## 1.10. 不確実性

- 初出年・発祥地は未確定。
- リカちゃん電話との関係を直接起源と断定しない。
- 「後ろにいる」の文句が最初期から固定されていたか未確認。
- 人形がどのように電話を使うかは説明されない。

# 2. 伝承史・異伝

## 2.1. 最古確認

パイロットは1980年代成立を推定しているが、今回直接固定できる最初期一次資料は得られていない。1990年代の学校怪談ブーム以前から流通していたとする整理はあるが、成立年は証拠上の留保を要する。

## 2.2. 流通

口承→学校怪談書籍→映像・テレビ→Web再話へ展開。通信技術が固定電話から携帯へ変化しても、逐次位置通知という構造は保持されやすい。

## 2.3. 主要異伝

| 異伝 | 差分 |
|---|---|
| 背後到達型 | 距離ゼロの言葉で終了 |
| 玄関・家前終端 | 家への到達で終了 |
| 襲撃型 | 到達後の身体危害を追加 |
| リカちゃん型 | 人形名・企業サービスとの関連を付加 |
| 携帯電話型 | 媒体を後代技術へ更新 |

## 2.4. 変容上の重要点

固有地点・通信端末は更新されても、**反復着信が残り距離を段階的に減らす構造**がカノンとして強く維持される。
