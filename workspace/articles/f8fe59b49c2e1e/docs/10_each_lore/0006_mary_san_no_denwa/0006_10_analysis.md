# 1. 伝承エントリ基本情報

- `Entry_ID`: `0006`
- `伝承エントリ名称`: メリーさんの電話
- `Macro_Category`: 全国型怪異・儀式
- `Entry_Type`: 物語・伝説
- `Version_Scope`: **1999年までに直接確認できる「人形の怪異メリーさんから反復して電話がかかる」という核を基礎とし、同じ意味形成核を維持する後代の安定代表形から「元所有者が人形を手放す→電話開始→現在地を反復通知しながら段階的に接近→至近距離到達」までを含む**。後代代表形を1999年へ遡及せず、襲撃・死亡、リカちゃん電話直接起源説、携帯電話化それ自体はScope外とする。

# 2. 分析概念次元

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ANO.UNKNOWN_EXISTENCE` — 未知存在
- Primary Parent: `D07.ANO` — 未知・異常存在／現象
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

この伝承がなければ、捨てた／手放した通常の人形がなぜ自ら名乗り、電話し、見えないまま移動して元所有者を追跡する主体として戻ってくるのかが説明されない。

**この伝承における現れ方**

通常の所有物だった人形が、自律的な通信・移動能力を持つ未知の追跡主体へ変換される。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.DEX.DIRECT_EVENT` — 出来事への直接遭遇
- Primary Parent: `D08.DEX` — 直接経験
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

物語内部の受信者にとって、問題化の契機は人形を名乗る異常な着信を受けることであり、後代代表形では現在地通知がその異常性を強める。

**この伝承における現れ方**

電話という日常的出来事が、捨てた人形からの通信として現れることで異常として立ち上がる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.AGN.AGENCY_ATTRIBUTION` — 主体化
- Primary Parent: `D09.AGN` — 主体・意図帰属

**判定根拠**

異常な電話と位置変化を、人形「メリーさん」という意思ある主体の行為へ帰属する。後代代表形では、着信の反復ごとに距離が縮むという規則も付与される。

**この伝承における現れ方**

無関係な着信・位置変化ではなく、一つの人格主体が反復的に接近しているというモデルを与える。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SUP.YOKAI_ENTITY` — 妖怪・人格怪異
- Primary Parent: `D10.SUP` — 超自然主体・力
- Secondary: `D10.OBJ.CURSED_OBJECT` — 呪物
- Status: `I` — Inferred

**判定根拠**

メリーさんは名乗り、位置を告げ、対象へ接近する人格的怪異として機能する。同時に人形という物体基体と不可分に描かれるため、物体側の異常性をSecondaryに保持する。

**この伝承における現れ方**

原因は抽象的な通信異常ではなく、人形を基体とする人格怪異として世界内に置かれる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: なし — **taxonomy gap: 人形の廃棄・放棄・手放しによる発動**
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct

**判定根拠**

Version Scopeへ含めた後代代表形では、元所有者が人形を捨てる／手放すことが電話開始に先行する安定した発動前件として整理される。これは本人の行為なしに対象化される `SPONTANEOUS_SELECTION` とは整合しない。

現行D11 taxonomyには「捨てる／廃棄する／放棄する」に直接対応するChildがない。`TAKE_OWN_CARRY` は取得・所持、`CREATE_ALTER_MANIPULATE` は作成・加工・操作であり、廃棄・放棄の反対方向を正確に表現しない。したがって最も近いChildへ押し込まず、コード空欄のまま改訂候補として保持する。

**この伝承における現れ方**

所有関係を切って人形を手放したことが、その人形からの電話と追跡が始まる前件となる。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.OTH.VICTIM_TARGET` — 特定被害者
- Primary Parent: `D12.OTH` — その他の対象
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

D13の主作用である追跡・接近が直接向けられるのは、後代代表形では人形を手放した元所有者・電話受信者である。

**この伝承における現れ方**

怪異は不特定多数ではなく、元所有者を個別の追跡対象として選ぶ。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.REL.PURSUIT` — 追跡
- Primary Parent: `D13.REL` — 関係・接近作用
- Secondary: なし

**判定根拠**

後代代表形では、現在地を反復通知しながら元所有者との距離を縮めることが主作用である。Scope外の身体攻撃を持ち込まない。

**この伝承における現れ方**

電話通知と位置移動を組み合わせ、対象の安全圏へ段階的に接近する。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

元所有者への追跡と至近距離への侵入は利益・保護として提示されず、脅威的な終端を形成する。ただしScope内で身体被害そのものを必須とはしないため、極性は構造からの推定とする。

**この伝承における現れ方**

距離が縮まり安全な隔たりが失われることが負の方向として提示される。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.KNW.UNCERTAINTY_PRESERVED` — 不確実性維持
- Primary Parent: `D15.KNW` — 世界認識・知識
- Secondary: なし
- Status: `D` — Direct

**判定根拠**

Scopeは襲撃・死亡を必須としない。後代代表形には、メリーさんが背後等の至近距離へ到達したところで語りが終わり、その後に何が起きたかを明示しない型がある。資料が受信者の恐怖・トラウマを直接帰結として確定しないため、`FEAR_TRAUMA` を推測で置かない。

**この伝承における現れ方**

怪異が距離ゼロまで到達した後の状態を説明せず、最終的な危害・正体・結末を未確定のまま残す。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.EVT.SEQUENTIAL_EPISODE` — エピソード内段階進行
- Primary Parent: `D16.EVT` — 単一エピソード・事象内
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

後代代表形では、人形の手放し→電話開始→反復着信→位置更新→距離短縮→至近距離到達が一つの追跡エピソード内で順に進む。

**この伝承における現れ方**

単発の着信ではなく、複数段階を経て接近が進行する。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown

**判定根拠**

電話を切る、無視する、逃げる、戸締まりする等の対応は語られるが、Scope共通の有効な停止規則を固定できない。資料不足を `NO_KNOWN_ESCAPE` や `FIXED_OUTCOME` へ読み替えない。

**この伝承における現れ方**

対処行動は存在するが、何をすれば確実に接近を止められるかは不明のまま残る。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

- `L1=1`: 伝承内部では電話・位置通知・追跡・接近の因果が作動する。
- `L2=0`: 怪談を聞く・読むこと自体が、現実側受容者をメリーさんの追跡対象にする自己適用規則は確認しない。
- `L3=0`: 噂流通による現実社会の制度・市場・集団行動等のX Evidenceは確認していない。

L1には正のEvidenceがある一方、L2/L3の0はScope内での不在判定を含むため、vector全体のStatusは `I` とする。

**この伝承における現れ方**

作用は伝承内部の元所有者への追跡として成立し、受容者層・社会現実層へ自動拡張しない。

### 2.4.2. D20: 特権情報保持者

- Primary Child / Value: なし
- Primary Parent: なし
