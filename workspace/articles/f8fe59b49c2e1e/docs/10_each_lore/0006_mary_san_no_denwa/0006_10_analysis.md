# 2. 分析概念次元

## 2.1. 来歴・流通・提示

### D01 生成年代
- Value: `D01.G4` — 1980年代
- Status: `I`
**判定根拠:** Pilotは昭和後期の電話環境と学校怪談流通から1980年代を推定している。
**現れ方:** 固定電話が家庭の日常装置となった環境を前提に、遠隔通信が家庭侵入の通知装置へ反転する。
**留保:** 今回、1980年代の直接初出資料は固定できていない。

### D02 最古確認流通媒体
- Primary/Secondary: なし
- Status: `U`
**判定根拠:** 最初期の実流通媒体を直接確定できる資料が不足する。
**現れ方:** 後代には口承・書籍・映像等で確認できるが、どの媒体が最古かを完成形から逆算しない。

### D03 確認流通媒体ポートフォリオ
- Primary: `D03.ORL.PEER_ORAL` — 友人・仲間内伝承
- Parent: `D03.ORL`
- Status: `I`
**判定根拠:** 学校怪談・若者口承として共有されたという既存判定。
**現れ方:** 地元の駅名・交差点等を差し込みながら友人間で再話でき、各話者の生活圏へ容易にローカライズされる。
**留保:** 旧メモ `D03:U` と本文値が矛盾するためExcel正本照合が必要。

### D04 生成・変容パターン
- Primary: `D04.STB.STABILIZED_CANON`
- Parent: `D04.STB`
- Status: `I`
**判定根拠:** 人形名・地点・終端は変化しても、反復電話と段階接近は長期に安定する。
**現れ方:** 技術が携帯電話へ変わっても「電話ごとに近づく」というカノンは保持される。

### D05 提示形式
- Primary: `D05.RUL.RITUAL_PROCEDURE`
- Parent: `D05.RUL`
- Status: `I`
**判定根拠:** Pilotは着信→位置通知→反復→到達という定型手順性を重視した。
**現れ方:** 受容者は次に起きる段階を順序付きで学び、接近のプロトコルとして物語を記憶する。
**留保:** 主人公が能動的に実行する「儀式」ではなく、物語的逐次進行であるためコード適合性は再検討候補。

### D06 真実性提示
- Value: `D06.T6` — 真偽未確定
- Status: `I`
**判定根拠:** 実話らしく語り得るが、特定事件・公的記録へ固定されない。
**現れ方:** 「誰かが実際に受けた電話」のような距離感を保ちつつ、怪異の実在は確定されない。

## 2.2. 意味形成

### D07 意味形成対象
- Primary: `D07.ANO.UNKNOWN_EXISTENCE`
- Parent: `D07.ANO`
- Status: `I`
**判定根拠:** 捨てた人形が意志と移動能力を持つ未知存在へ変化する。
**現れ方:** 所有物だった人形が自律主体化し、元所有者との関係を一方的に回復しようとする怪異として理解される。

### D08 意味形成契機
- Primary: `D08.CLM.UNSUPPORTED_ASSERTION`
- Parent: `D08.CLM`
- Status: `I`
**判定根拠:** 物語は検証済み事件より、伝聞される怪談命題として先行する。
**現れ方:** 「捨てた人形から電話が来る」という主張が、電話・人形という日常物を不気味な因果系に組み込む。

### D09 意味付与操作
- Primary: `D09.CTL.RITUAL_RULE`
- Parent: `D09.CTL`
- Status: `I`
**判定根拠:** Pilotは段階接近の定型ルール化を制御規則形成として読む。
**現れ方:** 現在地通知が「次はさらに近い」という予測規則を作り、不可視の移動を理解可能な段階へ分解する。
**留保:** 実際には制御より予測・系列化が中心であり再検討余地がある。

### D10 因果源存在論
- Primary: `D10.SUP.YOKAI_ENTITY`
- Parent: `D10.SUP`
- Status: `I`
**判定根拠:** メリーさんは電話し、移動し、対象を追跡する人格的怪異として振る舞う。
**現れ方:** 単なる呪物ではなく、自己紹介と現在地報告を行う意思主体が恐怖を生む。

## 2.3. 因果・行動モデル

### D11 発動・接触条件
- Primary: `D11.INF.RECEIVE_MESSAGE`
- Parent: `D11.INF`
- Status: `I`
**判定根拠:** 接近の各段階は電話という通知の受信によって体験者に認識される。
**現れ方:** 受信者はメッセージを聞くたび、怪異との距離が縮んだことを知る。
**留保:** 物語上の発端は人形を捨てる行為であり、D11を受信だけに置く代表性には再検討余地。

### D12 作用対象
- Primary: `D12.FOC.PROTAGONIST_EXPERIENCER`
- Parent: `D12.FOC`
- Status: `I`
**判定根拠:** 元所有者一人が電話・追跡の対象になる。
**現れ方:** 読者は元所有者へ自己投射し、電話のたびに自分の安全圏が縮むように経験する。

### D13 作用機構
- Primary: `D13.REL.PURSUIT`
- Parent: `D13.REL`
- Status: `I`
**判定根拠:** 中心作用は人形が対象との空間距離を継続的に縮める追跡。
**現れ方:** 電話が単なる脅迫ではなく、実際の接近位置を逐次示すことで追跡を可視化する。

### D14 帰結極性
- Value: `D14.NEG`
- Status: `I`
**判定根拠:** 接近・侵入・恐怖・一部Versionの危害は負の帰結。
**現れ方:** 安全な利益を得る型はなく、距離ゼロが危機の最大化となる。

### D15 帰結領域
- Primary: `D15.MND.FEAR_TRAUMA`
- Parent: `D15.MND`
- Status: `I`
**判定根拠:** Pilotは危害が必須でない代表形を踏まえ、最終的な恐怖・精神的衝撃をPrimaryとした。
**現れ方:** 「後ろにいる」という到達だけで物語が成立し、身体攻撃を描かなくても恐怖が完成する。

### D16 因果時間構造
- Primary: `D16.CON.PURSUIT_DURATION`
- Parent: `D16.CON`
- Status: `I`
**判定根拠:** 複数回の着信にわたり追跡が継続する。
**現れ方:** 一回の即時攻撃ではなく、距離が段階的に短縮する持続時間そのものが緊張を生む。

### D17 回避・制御方式
- Primary: `D17.AVO.FLEE_ESCAPE`
- Parent: `D17.AVO`
- Status: `I`
**判定根拠:** 異伝では逃走・電話を切る等が試みられる。
**現れ方:** 主人公は位置通知を受けて逃げるが、追跡が止まらないため回避の不確実性が恐怖を強める。
**留保:** 安定した有効回避法がないVersionが多く、このコードは主人公の試行を表すに留まる。

### D18 作用レイヤー
- L1: `1`; L2: `0`; L3: `0`
- Status: `I`
**判定根拠:** Pilotは伝承内部の追跡因果のみを採用。
**現れ方:** L1で電話→接近が機能する。現実の電話利用忌避等の外部効果は本Scopeで直接確認していない。
