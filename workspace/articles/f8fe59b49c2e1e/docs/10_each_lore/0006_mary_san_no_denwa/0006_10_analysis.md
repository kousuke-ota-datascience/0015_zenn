# 1. 伝承エントリ基本情報

- `Entry_ID`: `6`
- `伝承エントリ名称`: メリーさんの電話
- `Macro_Category`: 全国型怪異・儀式
- `Entry_Type`: 物語・伝説
- `Version_Scope`: 捨てた人形等から反復着信があり、現在地を告げながら段階的に元所有者へ接近し、最終的に家・背後等へ到達する代表形。最終危害は異伝として扱う。

# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（証拠不足）

**判定根拠**

`0006_00_contents.md` では、1990年代の人形怪談として後代研究の対象となっていることは確認できるが、1980年代その他の成立年代を直接示す初期一次資料を固定できていない。後代の完成形や電話技術の普及時期から成立年代を逆算しない。

**この伝承における現れ方**

固定電話を使う代表形は昭和後期以降の生活環境と整合するが、それだけでは伝承がいつ生成されたかを決められない。D01では「存在可能な年代」と「実際の生成」を区別する。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（証拠不足）

**判定根拠**

成立初期の口承・印刷物・放送等を直接固定できる資料が不足している。後代研究が学校怪談として扱うことから、最古媒体を学校口承と推定して埋めない。

**この伝承における現れ方**

後代には口承・書籍・映像・Web等で広く再話されるが、今回の証拠だけでは最初にどの媒体で人から人へ流通したかは確定できない。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Child / Value: `D03.ORL.SCHOOL_ORAL` — 学校内伝承
- Primary Parent: `D03.ORL` — 口承・限定共同体
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

後代研究は1990年代の学校怪談ブームにおける人形怪談としてメリーさんを扱っており、代表形も短い定型句と段階進行で対人再話しやすい。直接の最初期採録ではないためStatusは`I`とする。

**この伝承における現れ方**

聞き手は「人形を捨てる→電話が来る→現在地が近づく→背後へ到達する」という短い段階列を学校・同世代集団で再話できる。地名を生活圏に置き換えても構造が維持される。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.STB.STABILIZED_CANON` — 定型化・カノン化
- Primary Parent: `D04.STB` — 安定・固定
- Secondary: `D04.MIG.MEDIUM_SHIFT` — 媒体移行
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

人形名、地名、端末、最終危害は変化する一方、「反復着信ごとに現在地が近づく」という構造は後代再話でも強く保持される。固定電話から携帯電話への更新は、基本構造を保つ媒体移行として扱う。

**この伝承における現れ方**

怪談の識別核は具体的な駅名や電話機ではなく、着信→位置通知→距離短縮の反復である。そのため通信技術が変わっても同じ物語として認識される。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.HRS.SCHOOL_WORK_HEARSAY` — 学校・職場伝承
- Primary Parent: `D05.HRS` — 伝聞叙述
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

代表形は主人公が能動的に手順を実行する儀式ではなく、「こういう電話の怪談がある」という学校怪談・伝聞として再話される。旧 `RITUAL_PROCEDURE` は物語の段階順序を儀式手順と誤認していたため変更する。

**この伝承における現れ方**

聞き手は、誰かが捨てた人形から電話を受け、段階的に追い詰められた話として受容する。受容者自身が同じ手順を再現することは要求されない。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T6` — 真偽未確定
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

実話らしい体験談形式で再話できる一方、特定事件・公的記録へ固定されず、人形の自律移動・発信も検証不能である。

**この伝承における現れ方**

「誰かに本当に起きたかもしれない」という距離を保ちつつ、事実認定を要求しないことで学校怪談として流通する。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ANO.UNKNOWN_EXISTENCE` — 未知存在
- Primary Parent: `D07.ANO` — 異常体験・存在
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

捨てた人形が意思・移動能力・通信能力を持つ主体として振る舞うことが中心的異常である。

**この伝承における現れ方**

通常は所有物である人形が自ら名乗り、元所有者を追跡する存在へ転じることで、「これは何者なのか」という不確実性が生じる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.UNSUPPORTED_ASSERTION` — 根拠未提示の主張
- Primary Parent: `D08.CLM` — 命題先行
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

受容者は自分で人形の自律移動を観察する前に、「捨てた人形から電話が来て近づいてくる」という怪談命題を受け取る。

**この伝承における現れ方**

日常的な人形と電話が、先行する怪談によって「所有者を追う主体」「接近を知らせる媒体」として再解釈される。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.AGN.AGENCY_ATTRIBUTION` — 主体化
- Primary Parent: `D09.AGN` — 主体・意図帰属
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

不可視の接近・着信を、単なる機械故障や偶然ではなく、捨てられた人形自身が意思を持って元所有者へ戻ってくる行為として理解する。旧 `RITUAL_RULE` のような制御規則は中心にない。

**この伝承における現れ方**

「私、メリーさん」と名乗る発話により、人形へ自己認識・意図・追跡行為が帰属される。物体が人格的な追跡者として意味付けられる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SUP.YOKAI_ENTITY` — 妖怪・人格怪異
- Primary Parent: `D10.SUP` — 超自然主体・力
- Secondary: `D10.OBJ.CURSED_OBJECT` — 呪物
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

メリーさんは名乗り、現在地を報告し、対象へ接近するため人格怪異として機能する。一方、その主体は捨てられた人形という物体に結び付いているため呪物性をSecondaryとする。

**この伝承における現れ方**

危険は無人格な電話現象ではなく、人形を基体とする意思ある主体が元所有者との距離を縮めることに置かれる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.INF.RECEIVE_MESSAGE` — 通知・メッセージを受ける
- Primary Parent: `D11.INF` — 情報曝露
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

物語上の背景原因は人形を捨てる行為だが、体験者が怪異の因果系へ明確に入ったことを認識する契機は、メリーさんを名乗る最初の電話を受信することである。現行D11体系に「捨てる」専用Childはないため、接触条件として受信をPrimaryとする。

**この伝承における現れ方**

最初の着信によって、処分済みの人形との関係が再接続される。その後の各着信が接近の進行を更新する。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC` — 焦点人物
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

電話と接近は、人形を手放した元所有者へ集中する。

**この伝承における現れ方**

第三者一般が無差別に危害を受けるのではなく、過去に人形を所有・処分した焦点人物が追跡対象になる。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.REL.PURSUIT` — 追跡
- Primary Parent: `D13.REL` — 追跡・対象関係操作
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

中核作用は、メリーさんが元所有者との空間距離を反復的に縮めることにある。最終的な身体攻撃はVersion共通ではない。

**この伝承における現れ方**

電話による現在地通知が追跡の進行を可視化し、遠方から自宅・背後へ距離が縮むほど危険が増す。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

追跡・安全圏への侵入・恐怖・一部Versionの襲撃はいずれも負の結果であり、主人公に利益を与える型は中心形にない。

**この伝承における現れ方**

着信が増えるほど距離と安全余地が減少し、距離ゼロが危機の最大化として機能する。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.MND.FEAR_TRAUMA` — 恐怖・トラウマ
- Primary Parent: `D15.MND` — 精神・認知
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

代表形は「背後にいる」等の至近距離到達だけで成立し、身体攻撃を必須としない。したがってVersion Scope全体で安定する最終変化は恐怖・認知的安全感の崩壊である。

**この伝承における現れ方**

自宅や電話が安全を保証しないと分かり、主人公は見えない追跡者がすぐ近くにいるという強い恐怖へ到達する。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.CON.PURSUIT_DURATION` — 追跡継続
- Primary Parent: `D16.CON` — 持続・追跡
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

一回の即時作用ではなく、複数回の着信にわたり追跡が継続し、その都度距離が縮小する。

**この伝承における現れ方**

反復着信の間隔そのものが恐怖を蓄積し、次の現在地がどこまで近づくかという予期を生む。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（証拠不足）

**判定根拠**

主人公は電話を切る、無視する、逃げる、戸締まりする等を試みるが、Version Scope全体で「これをすれば確実に追跡を止められる」という安定した有効規則を確認できない。試行された行動を、そのまま有効な回避コードへ置き換えない。

**この伝承における現れ方**

主人公が行動しても現在地通知は続くため、制御不能性そのものが恐怖を強化する。有効性が確認できないため `FLEE_ESCAPE` 等をPrimaryにはしない。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

伝承内部では電話→接近→到達の因果が作用する。一方、怪談を聞く・読むだけで現実の受容者自身がメリーさんの追跡対象になる規則はなく、社会現実上の制度・行動変化も今回の証拠では固定していない。

**この伝承における現れ方**

因果効力は主人公と怪異の関係内に閉じており、受容者はその追跡を観察する立場にある。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

全国型の学校怪談・現代怪異として後代事典・研究で扱われ、固有地域を必要としないため広域流通性が高い。ただし今回固定した資料だけで全国的認知を定量的に直接確認していないためStatusは`I`とする。

**この伝承における現れ方**

各地域の駅名・街路を差し替えても段階接近構造が保たれ、生活圏ごとにローカライズしながら広域再話できる。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.NON.COMMON_KNOWLEDGE` — 一般共有
- Primary Parent: `D20.NON` — 特権なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

段階接近の展開・終端句は共同体内で共有される怪談知識であり、真相を独占する専門家・組織を必要としない。

**この伝承における現れ方**

聞き手が結末を知っていても反復して再話でき、情報の共有が怪談の成立を妨げない。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

家庭、電話、人形、駅、道路等の一般的な現実背景を利用するが、特定の唯一地点・実在人物・史実へは固定されない。完全な匿名・抽象A0より、一般的日常環境を必要とするA1が適合する。

**この伝承における現れ方**

受容者自身の町の駅・通り・自宅へ容易に置換できるため、固有地名を失っても意味形成核が維持される。
