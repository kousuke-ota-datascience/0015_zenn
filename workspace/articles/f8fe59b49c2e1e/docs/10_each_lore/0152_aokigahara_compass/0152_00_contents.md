# 1. 伝承内容

## 1.1. summary

中心命題は、**青木ヶ原樹海では地下・地表の溶岩や磁性鉱物が強い磁気を生じさせるため、方位磁針が正常な方向を示さず、入った人は方角を失って脱出できなくなる**というものである。単に「樹海は迷いやすい」という危険情報ではなく、迷いやすさを「磁気異常 → 方位磁針の機能不全 → 経路判断不能」という目に見えない自然科学的因果へ変換する点が伝承の核である。

この説明には現実のアンカーが複数ある。青木ヶ原樹海は実在し、貞観噴火の溶岩流上に成立した森林である。また、磁性を持つ岩石の近傍で方位磁針が影響を受け得ることは、俗説を支えるもっともらしい足場になる。しかし、そこから「樹海では方位磁針が使えない」「磁針がぐるぐる回る」「方位を一切知れない」と一般化する部分が俗説化している。

2009年の千葉大学の科学体験活動では、この言い伝え自体を検証課題とし、樹海内3地点で方位磁針の磁北とGPSの真北を比較した。偏角補正後はいずれも一致し、少なくともその条件では通常の方位磁針が利用できた。静岡大学防災総合センターも、溶岩へよほど近づかなければ磁石が狂うことはない一方、樹海内は凹凸が激しく目印に乏しいため迷いやすいと説明する。したがって、**伝承内の「全面的な機能不全」と、局所的な磁気影響や現実の道迷いリスクは同一ではない。**

一方、流通過程では命題が拡張している。2007年の再録資料には、「デジタル時計が狂う」「車の計器や放送機器に異常が出る」「GPSも使えない」といった派生が記録される。ここでは「磁性のある樹海」という説明モデルが、方位磁針以外の電子機器・測位技術へ増補されている。ただしGPSの動作原理は方位磁針と異なるため、これらを原型へ遡及させない。

この伝承の終端は、必ず死亡・失踪になるわけではない。共有核で直接主張されるのは、方位磁針が頼れず、進むべき方向や帰還経路を判断しにくくなることである。「一度入れば絶対に出られない」「死ぬ」といった強い終端は別の樹海怪談との混成を疑い、中心Versionには自動的に含めない。

## 1.2. 詳細展開

### 1.2.1. 対象となる状況

青木ヶ原樹海の内部で現在位置・進行方向を判断しようとする状況が前提となる。伝承は樹海を、通常の森林よりも方位判断が困難な特殊環境として提示する。

### 1.2.2. 中心命題

樹海の地面を構成する溶岩・磁性鉱物が磁場へ作用し、方位磁針を狂わせると説明される。これにより、通常なら方向確認に使える器具が樹海では信頼できないとされる。

### 1.2.3. 想定作用

方位磁針が正しい北を示さない、針が安定しない、または「効かない」とされる。その結果、利用者は進行方向を確定できず、道迷い・帰還困難へ移行すると説明される。

### 1.2.4. 科学的検証との衝突

2009年の現地測定では、3地点で偏角補正後の方位磁針の磁北がGPSによる真北と一致した。静岡大学の解説も、通常の使用条件では磁石が狂うという説明を否定する。これらは「樹海全域で方位磁針が使えない」という強い形を支持しない。ただし、あらゆる地点・条件で局所的な磁気影響が存在しないことまで意味しない。

### 1.2.5. 派生拡張

流通過程では、方位磁針からGPS、デジタル時計、車載計器、放送機器へ異常対象が拡張される。これらは「樹海の磁気が機器を狂わせる」という上位モデルを共有するが、機器ごとの原理差を無視して一括説明する点に変容がある。

# 2. 伝承史・異伝

## 2.1. 最古確認

今回の資料群では、2007年2月のWeb記録が「富士の樹海の中では方位磁石は効かない」という命題を明示し、それ以前にテレビ番組『トリビアの泉』の「ガセビアの沼」No.037として反証対象になっていたことを記録している。番組のレギュラー放送期間は2002〜2006年であるため、**遅くとも2000年代半ばにはテレビで検証対象となる程度に命題が流通していた**と判断できる。ただし、これを伝承の生成時期とはみなさない。

2009年にはYahoo!知恵袋で直接質問され、同年の千葉大学教育学部研究紀要でも「方位磁針で方角を知ることができず、迷うと言われる」として現地検証の対象になっている。ここまでで、放送・公開Web・研究教育文脈の複数経路が確認できる。

## 2.2. 流通・拡散

確認できる流通は、少なくとも以下の層を持つ。

1. 2002〜2006年の範囲内: 『トリビアの泉』で「方位磁石が効かない」という命題が反証対象として放送されたことが後代番組記録から確認できる。
2. 2007年: 番組内容のWeb再録で、中心命題と複数派生形が再流通する。
3. 2009年: 公開Q&Aで一般利用者が真偽を問い、体験談・反証・局所差の主張が並存する。
4. 2009年: 大学の科学体験活動が俗説を明示的に検証する。
5. 2020年: 全国の都市伝説を扱う事典に収録される。

重要なのは、反証が流通を終わらせるのではなく、**「本当に狂うのか」という検証・反証そのものが命題を再提示し続ける回路**になっていることである。

## 2.4. 変容上の重要点

原型の意味形成核は「樹海で迷う／方位が分からない」という不安を、溶岩・磁性鉱物によるコンパス異常へ直接因果化することである。その後、説明モデルがGPSや電子機器全般へ拡張される一方、テレビ・Web・科学教育による反証も繰り返し流通した。したがって本伝承は、固定された一方向のカノンというより、**疑似科学的説明の増補と反証を伴う再流通**によって維持される型として把握するのが安全である。

## 3.2. 短い原文引用

千葉大学2009年論文は、検証対象となる言い伝えを「**方位磁針で方角を知ることができず，迷う**」と記す。静岡大学の解説も、磁石が狂うため出られなくなるという言説を紹介したうえで、通常条件ではその説明を支持しない。引用は必要最小限とし、検証結果・文脈は上記のパラフレーズで保持する。

## 3.3. 証拠上の保留事項

- 1980年代成立を直接支える資料は今回固定できず、生成年代へ遡及しない。
- テレビ番組での反証は後代記録から確認できるが、元放送映像・正確な放送日は今回未固定である。
- 科学的検証結果は「通常の使用条件で全面的に使えなくなるという主張を支持しない」という範囲で扱い、樹海全域の局所磁場を一律に否定する根拠にはしない。
- 実在する溶岩地質は伝承の現実アンカーであり、強い磁気異常命題そのものの直接証拠ではない。
- GPS等の派生は方位磁針説と機構が異なるため、同じ原因が科学的に成立するとみなさない。
