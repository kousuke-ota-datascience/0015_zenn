# 1. 伝承エントリ基本情報

- `Entry_ID`: `152`
- `伝承エントリ名称`: 青木ヶ原樹海で方位磁針が狂う
- `Macro_Category`: 地域・場所ロア
- `Entry_Type`: 物語・伝説
- `Version_Scope`: 青木ヶ原樹海では溶岩・磁性鉱物等の磁気のため方位磁針が正常に使えず、方向判断・帰還が困難になるという代表命題。2000年代までに確認できるテレビ・Web上の反証付き再流通を含む。GPS・デジタル時計・車載機器等への拡張は派生として扱い、中心命題へ遡及させない。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown（成立年代を安全に固定できる証拠不足）

**判定根拠**

今回確認した資料では、2000年代半ばまでに「富士の樹海では方位磁石が効かない」という命題がテレビで反証対象となり、2007年にはWeb上でその内容が再提示され、2009年には公開Q&Aと大学の科学体験活動でも検証対象となっている。しかし、これらは当時すでに流通していた命題を扱った資料であり、1980年代等の特定年代に成立したことを直接示さない。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

**判定根拠**

2007年Web記録および後代の番組データベースは、フジテレビ系『トリビアの泉』の「ガセビアの沼」No.037として「富士の樹海の中では方位磁石が効かない」という命題が反証対象になったことを記録する。元放送映像と正確な放送日は今回固定できていないため `D` ではなく `I` とするが、2007年Web記録より前のテレビ流通が示される。

**この伝承における現れ方**

**この伝承における現れ方**

「コンパスが効かない」という命題は、テレビで反証され、その反証内容がWebで再流通し、後代には都市伝説資料へ収録される。単一媒体に閉じず、検証・反証とともに複数媒体を横断している。

### 2.1.4. D04: 生成・変容パターン

**この伝承における現れ方**

**この伝承における現れ方**

視界、地形、目印の乏しさ等から生じ得る現実の迷いやすさが、「磁気異常を持つ特殊な森」という一つの環境異常モデルへ整理される。

**この伝承における現れ方**

受容者はまず「樹海では方位磁針が狂う」という既成命題に接し、その後に磁鉄鉱・溶岩という説明や反証へ接続する。

**この伝承における現れ方**

複雑な道迷いリスクを、磁気という一つの原因へ圧縮することで、場所の危険性が理解しやすい因果モデルへ変換される。

**この伝承における現れ方**

**この伝承における現れ方**
