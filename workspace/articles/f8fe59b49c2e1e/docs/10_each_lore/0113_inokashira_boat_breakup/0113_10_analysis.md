**何が不可解・不確実なのか**

- Primary Parent: `D07.DCF` — 死・偶然・不運
- Secondary: なし
- Status: `I` — Inferred（未来の恋愛帰結を特定行為へ結び付ける）

**判定根拠**

このジンクスが扱うのは、失敗が連続する「不運の偏り」より、現在の乗船行為が将来の恋愛関係破綻を予告・決定するという未来帰結の不確実性である。

**この伝承における現れ方**

通常は予測できない「この恋愛が続くか」を、井の頭池でボートへ乗ったか否かという観測可能な出来事で読めるようにする。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.CLM.INHERITED_SAYING` — 既存の言い伝え
- Primary Parent: `D08.CLM` — 命題先行
- Secondary: なし
- Status: `I` — Inferred（既存ジンクスが出来事解釈に先行）

**判定根拠**

**この伝承における現れ方**

噂を知ることで、将来の破局は単なる恋愛上の出来事ではなく、過去の乗船によって説明可能な確認例へ変わる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAU.DIRECT_CAUSE` — 直接原因化
- Primary Parent: `D09.CAU` — 原因帰属

- Status: `I` — Inferred（乗船と破局を直接因果で結ぶ）

**判定根拠**

ジンクスは「井の頭池でボートに乗ったため別れた」という直接的な原因関係を提供する。乗船を「恋愛上悪い行為」と評価する機能もあるが、中心操作は本来独立な二出来事を因果接続することにある。

**この伝承における現れ方**

恋人同士の破局という複雑な関係変化が、過去の単一行為へ遡及して説明される。その結果、ボート乗船自体も避けるべき凶行為として価値付けられる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SPC.SPECIFIC_PLACE` — 特定場所
- Primary Parent: `D10.SPC` — 場所・時空
- Secondary: `D10.SUP.DEITY_DIVINE` — 神格・超越主体
- Status: `C` — Competing（純ジンクス型と弁財天嫉妬型で因果源が異なる）

**判定根拠**

最小核では「井の頭池で」ボートに乗ること自体が場所固有の因果条件で、主体は明示されない。一方、三鷹市サイト等で確認できる主要異伝では、井の頭弁財天の嫉妬という人格神格が恋人の仲を裂く原因として説明される。両型を一つへ潰さず競合として保存する。

**この伝承における現れ方**

純ジンクス型では池・ボートの組合せ自体が効力を持つように語られ、弁財天型では同じ結果が神格の意思へ人格化される。後者を正式な宗教教義へ遡及しない。
