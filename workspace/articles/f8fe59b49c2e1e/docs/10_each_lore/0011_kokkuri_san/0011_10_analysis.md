# 1. 伝承エントリ基本情報

- `Entry_ID`: `11`
- `伝承エントリ名称`: こっくりさん
- `Macro_Category`: 全国型怪異・儀式
- `Entry_Type`: 儀式伝承
- `Version_Scope`: 明治期の器具型から現代学校型までの歴史的連続性を背景としつつ、分析の中心は、複数人が可動媒体へ触れて呼び出し・質問・回答・終了を行う「こっくりさん」儀式。明治期の器具・現代の紙と硬貨は同一手順へ混成しない。

- `主な成立・流通期`: 戦前〜現代

# 2. 分析概念次元

## 2.1. 来歴・流通・提示

### D01 生成年代
- Value: `D01.G1` — 1868–1944
- Status: `I`

**判定根拠:** 1886年新聞記事の所在、1887年井上円了『妖怪玄談 狐狗狸の事』、東洋大学の近代資料整理から、少なくとも明治期に「こっくり」が社会的流行として存在したことを確認できる。

**この伝承における現れ方:** 現代学校型より前に、近代日本でテーブル・ターニングを翻案した占い遊戯として成立・流行している。したがってネット以前どころか戦前に遡る長期伝承である。

**境界・留保:** 現代の紙・硬貨型そのものが1880年代に完成していたという意味ではない。年代は伝承系譜の成立層を示す。

### D02 最古確認流通媒体
- Primary/Secondary: なし
- Status: `U`

**判定根拠:** 1886年新聞は同時代の流行を記録するが、その記事以前に対人実践として広がっていたことが前提であり、現在の資料だけでは最古の実流通媒体を一意に固定できない。

**この伝承における現れ方:** 器具を囲んで複数人が実践する遊戯が先行し、それを新聞・研究書が記録したと考えられる。記録媒体と流通媒体を同一視しない。

**境界・留保:** 新たに1886年新聞という確実な記録点を固定できたため、明示的再コーディング時にはD02定義との再照合が必要。

### D03 確認流通媒体ポートフォリオ
- Primary: `D03.ORL.SCHOOL_ORAL` — 学校内伝承
- Parent: `D03.ORL`
- Status: `I`

**判定根拠:** Pilot Codingは現代Version Scopeにおける学校・若年者集団の口承・実践を中心媒体とする。

**この伝承における現れ方:** 手順は「放課後に何人でやる」「紙に何を書く」「終わるとき何をする」といった実践知として友人から友人へ伝わる。内容の伝達と実施が同じ共同体内で反復される。

**境界・留保:** 旧末尾メモの `D03:U` と本文値が矛盾する。Excel正本の最終値を別工程で照合する。

### D04 生成・変容パターン
- Primary: `D04.STB.STABILIZED_CANON` — 定型化・カノン化
- Parent: `D04.STB`
- Status: `I`

**判定根拠:** 器具・文字盤・主体解釈・危険規則は時代で変化しても、「共同で媒体へ触れ、問い、媒体の移動を外部回答として読む」という中核は保持される。

**この伝承における現れ方:** 明治期の飯櫃や竹脚から現代の硬貨・五十音表へ道具が変わっても、共同運動を異界からの返答へ変換する機能がカノンとして残る。

**境界・留保:** 長期変容が大きいため、安定だけでなく変容の再分析余地がある。

### D05 提示形式
- Primary: `D05.RUL.RITUAL_PROCEDURE` — 儀式・手順
- Parent: `D05.RUL`
- Status: `I`

**判定根拠:** 実践には準備、呼び出し、質問、回答解釈、終了という順序と、途中離脱等の禁忌がある。

**この伝承における現れ方:** 聞き手は「怖い話」を聞くだけでなく、再現可能なやり方を教わる。伝承がそのまま行動手順として実行される点が特徴である。

### D06 真実性提示
- Value: `D06.T6` — 真偽未確定
- Status: `I`

**判定根拠:** 媒体が実際に動くという経験は参加者に直接起こり得る一方、その原因を霊的主体とするか無意識運動とするかは確定しない。

**この伝承における現れ方:** 「本当に動いた」という経験的確実性と、「誰が動かしたのか分からない」という原因不確定性が共存する。

## 2.2. 意味形成

### D07 意味形成対象
- Primary: `D07.ANO.UNKNOWN_EXISTENCE` — 未知存在
- Parent: `D07.ANO`
- Status: `I`

**判定根拠:** 参加者が意図していないと感じる媒体運動と、その背後に想定される外部主体が不可解さの中心になる。

**この伝承における現れ方:** 「なぜ硬貨が動いたのか」という運動原因の不確実性を、「こっくりさんが来た」という存在仮説で理解可能にする。

**境界・留保:** 問題対象を「未知存在」より「原因不明の共同運動」と捉える余地がある。

### D08 意味形成契機
- Primary: `D08.CLM.UNSUPPORTED_ASSERTION` — 根拠未提示の主張
- Parent: `D08.CLM`
- Status: `I`

**判定根拠:** 実施前に「こっくりさんを呼べば答えが得られる」「失敗すると祟られる」という命題が共有され、それに従って実践される。

**この伝承における現れ方:** 先行する規則が、実際の媒体運動を霊的回答として解釈する枠組みを提供する。

### D09 意味付与操作
- Primary: `D09.CTL.RITUAL_RULE` — 儀式規則
- Parent: `D09.CTL`
- Status: `I`

**判定根拠:** 不確実な外部主体との接触を、呼び出し・質問・終了という再現可能なルールへ整える。

**この伝承における現れ方:** 「どう呼ぶか」「どう問うか」「どう帰すか」が定まることで、不可視の存在との交信が操作可能な手続へ変換される。

### D10 因果源存在論
- Primary: `D10.SUP.GHOST_SPIRIT` — 幽霊・死者霊
- Parent: `D10.SUP`
- Status: `I`

**判定根拠:** 現代の危険な招霊型では、媒体を動かす主体が霊・霊的存在として説明されることが多い。

**この伝承における現れ方:** 参加者自身の運動ではなく、外部の霊が指示媒体を動かし、答えや祟りを与えるという因果モデルが成立する。

**境界・留保:** 明治期には神下し、狐狗狸等の多様な主体解釈があり、必ずしも「死者霊」へ一意に固定されない。再コーディング候補。

## 2.3. 因果・行動モデル

### D11 発動・接触条件
- Primary: `D11.MAN.PERFORM_RITUAL` — 儀式・唱和を行う
- Parent: `D11.MAN`
- Status: `D`

**判定根拠:** 参加者が媒体を用意し、指を置き、呼び出しを行うことで因果系へ入ることが手順上明示される。

**この伝承における現れ方:** 単に噂を知るだけではなく、共同操作を実行することが交信開始条件になる。

### D12 作用対象
- Primary: `D12.FOC.PROTAGONIST_EXPERIENCER`
- Parent: `D12.FOC`
- Status: `I`

**判定根拠:** 実施した参加者が回答・恐怖・禁忌違反時の危害を受ける焦点主体になる。

**この伝承における現れ方:** 交信の利益とリスクは、儀式を囲む当事者へ集中する。

### D13 作用機構
- Primary: `D13.COG.INFORMATION_INDUCED_ACTION` — 情報誘導・行動誘発
- Parent: `D13.COG`
- Status: `I`

**判定根拠:** Pilotは、媒体が示す情報が参加者の判断・行動を変える点をPrimaryとしている。

**この伝承における現れ方:** 「好きな相手」「未来」「禁忌」等の回答を受け、参加者がその情報を信じて行動・不安・選択を変える。

**境界・留保:** 伝承内部の中心現象は「媒体が動く／回答が生成される」ことであり、情報誘導をPrimaryに置く代表性は再検討余地がある。

### D14 帰結極性
- Value: `D14.MIX` — 混合
- Status: `I`

**判定根拠:** 欲しい情報を得るという正・中立的帰結と、祟り・恐怖・憑依等の負の帰結が共存する。

**この伝承における現れ方:** 成功すれば知識獲得、失敗すれば危害という二面性が遊戯の魅力と怖さを同時に作る。

### D15 帰結領域
- Primary: `D15.KNW.REVELATION_KNOWLEDGE` — 真相・知識獲得
- Parent: `D15.KNW`
- Status: `I`

**判定根拠:** 占い型の主目的は、通常は知り得ない未来・秘密・答えを得ることである。

**この伝承における現れ方:** 媒体の指示位置が未知情報へ翻訳され、参加者は「外部存在しか知らない答え」を受け取ったと理解する。

### D16 因果時間構造
- Primary: `D16.EVT.SEQUENTIAL_EPISODE` — エピソード内段階進行
- Parent: `D16.EVT`
- Status: `I`

**判定根拠:** 準備→呼び出し→質問→回答→終了という複数段階が一回の実施エピソード内で順次進行する。

**この伝承における現れ方:** 各段階を正しい順で完了すること自体が安全性に関わるため、時間順序が因果モデルの一部になる。

**境界・留保:** 旧末尾メモ `D16:U` と本文値が矛盾する。Excel正本照合が必要。

### D17 回避・制御方式
- Primary: `D17.RIT.RITUAL_CLOSURE` — 儀式終了・祓い
- Parent: `D17.RIT`
- Status: `I`

**判定根拠:** 危険型では、呼んだ存在を正しく帰し、終了手順を守ることが霊障回避の中心とされる。

**この伝承における現れ方:** 問題が起きた後に逃げるのではなく、交信関係を正式に閉じる手順によって危険を制御する。

### D18 作用レイヤー
- L1: `1`; L2: `0`; L3: `0`
- Status: `I`

**判定根拠:** Pilotは伝承内部の霊的回答・祟り因果をL1として採用し、受容者・社会現実効果は0としている。

**この伝承における現れ方:** L1では外部主体が回答し、禁忌違反に反応する。歴史的には新聞・警察・学校対応へ波及した可能性があるため、L2/L3は再調査余地がある。

## 2.4. 社会的埋め込み

### D19 流通範囲
- Primary: `D19.MAS.NATIONAL_PUBLIC`
- Parent: `D19.MAS`
- Status: `D`

**判定根拠:** 明治期に全国的流行として記録され、後代も学校文化・雑誌・テレビ等で広域再流通する。

**この伝承における現れ方:** 特定地域の聖地伝説ではなく、簡単な器具と手順さえあれば各地で再現できるため全国化しやすい。

### D20 特権情報保持者
- Primary: `D20.NON.COMMON_KNOWLEDGE`
- Parent: `D20.NON`
- Status: `I`

**判定根拠:** 儀式手順・禁忌は友人集団で広く共有され、特定の専門家や秘密保持者を必要としない。

**この伝承における現れ方:** 「やり方を知っている子」が教えることはあっても、その知識は公開・再伝達可能で共同体知へなる。

### D21 現実アンカー
- Value: `D21.A0` — 匿名・抽象
- Status: `I`

**判定根拠:** 個々の儀式は特定地・史実に固定されず、どこでも再現可能な手順として成立する。

**この伝承における現れ方:** 歴史的成立には明治期という具体的背景がある一方、伝承内部の実践は教室・家庭へ自由に移植できる。

**境界・留保:** 成立史の強い近代アンカーをD21へどこまで反映するかは再検討余地がある。
