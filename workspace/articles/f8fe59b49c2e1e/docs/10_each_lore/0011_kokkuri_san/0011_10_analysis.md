# 1. 伝承エントリ基本情報

- `Entry_ID`: `11`
- `伝承エントリ名称`: こっくりさん
- `Macro_Category`: 全国型怪異・儀式
- `Entry_Type`: 儀式伝承
- `Version_Scope`: 1886–1887年に直接確認できる明治器具型の最小安定核。複数人がテーブルまたは飯櫃の蓋等の可動器具へ手を置き、問いを発し、参加者が意図的に動かしていないと感じる器具の動きを、外部的・霊的な主体からの意味ある回答として読む占い／神意判断の実践を対象とする。現代紙・硬貨型、学校型禁忌、憑依・祟り・終了規則、1970年代学校流行はScope外とする。

# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

`0011_00_contents.md` では、東洋大学公式整理が1884年頃の伝来、1886年頃の各地流行、1887年の井上円了『妖怪玄談 狐狗狸の事』刊行を示す。1884年を唯一の起源年とは断定しないが、明治期の成立層へ安全に写像できる。

**この伝承における現れ方**

今回扱うこっくりさんは、1970年代の学校遊戯から遡及したものではなく、19世紀末に流行した器具型の占い・神意判断として成立している。

**この伝承における現れ方**

こっくりさんは少なくとも1886年には新聞上で名称付きの社会現象として流通・可視化されていた。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ANO.UNEXPLAINED_EVENT` — 説明不能事象
- Primary Parent: `D07.ANO` — 異常体験・存在
- Secondary: `D07.ISU.INFORMATION_VOID` — 情報空白
- Status: `I` — Inferred

**判定根拠**

`0011_00_contents.md` が明示する安定核は、参加者が意図的に動かしていないと感じる器具が動き、その運動が問いへの意味ある回答として読まれることである。まず説明を要求するのは「なぜ器具が自律的に動き、回答らしい振る舞いをするのか」という異常事象である。未来・恋愛・秘密等の未知情報を得たいという情報空白は独立した実践目的として残るが、器具運動の意味付けより上位には置かない。

**この伝承における現れ方**

通常なら人間の力で動くはずの器具が、参加者の意図を超えて動いたように見える。その異常を単なる物理運動として残さず、「外部の何者かが答えている」という共有可能な説明へ変換することが、この伝承の意味形成核になる。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.DEX.DIRECT_EVENT` — 出来事への直接遭遇
- Primary Parent: `D08.DEX` — 直接経験
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

意味形成を具体的に立ち上げる手掛かりは、参加者自身が、意図的に動かしていないと感じる器具の運動を経験することである。未来の不確実性そのものと、異常を問題化する観察事実を分ける。

**この伝承における現れ方**

質問後に器具が動くという直接経験が、「ただの道具がなぜ応答するのか」という問題を発生させ、外部主体を仮定する解釈へ接続する。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.AGN.AGENCY_ATTRIBUTION` — 主体化
- Primary Parent: `D09.AGN` — 主体・意図帰属
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

器具の運動を偶然・無主体の物理現象ではなく、外部の意思ある主体が質問へ応答した結果として解釈することが中心的な認知操作である。特定の未来予測は利用例の一部であり、明治期最小核のPrimaryにはしない。

**この伝承における現れ方**

曖昧な器具運動へ「誰かが答えている」という主体性を付与することで、ランダムに見える動きが意味を持つ回答へ変わる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `C` — Conflict

**判定根拠**

明治期Evidenceでは神意判断という神格的枠組みと、「狐狗狸」等の人格的怪異を想定する表現が併存する。現代の死者霊解釈を明治期へ遡及できず、`D10.SUP.DEITY_DIVINE` と `D10.SUP.YOKAI_ENTITY` のどちらか一つへ安全に固定できない。

**この伝承における現れ方**

器具を動かして答える主体がいる、という存在論までは共有されるが、その主体が神格なのか狐狗狸のような人格怪異なのかはScope内で一意に閉じない。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

東洋大学公式整理は1886年頃に「日本各地で大流行」とする。単一地域内部に限定されない広域流行と判断できるが、当時の認知率を直接測定していないためIとする。

**この伝承における現れ方**

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown

**判定根拠**

実践内部では、参加者が知らない回答・神意を「こっくりさん／外部主体」が保持し、器具運動を通じて提示する構造がある。しかし現行D20には、超自然的主体が特権情報を保持する構造を直接表すChildがない。Evidence不足ではなくtaxonomy gapであり、既存Childへ無理に近似しない。

### 2.4.3. D21: 現実アンカー

- Primary Parent: なし
