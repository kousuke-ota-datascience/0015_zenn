# 1. 伝承エントリ基本情報

- `Entry_ID`: `11`
- `伝承エントリ名称`: こっくりさん
- `Macro_Category`: 全国型怪異・儀式
- `Entry_Type`: 儀式伝承
- `Version_Scope`: 明治期の器具型から現代学校型までの歴史的連続性を背景としつつ、分析の中心は、複数人が可動媒体へ触れて呼び出し・質問・回答・終了を行う「こっくりさん」実践。明治期の器具・現代の紙と硬貨は同一手順へ混成しない。

# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: `D01.G1` — 1868–1944
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

`0011_00_contents.md` では、1880年代半ばにテーブル・ターニング系実践が日本へ導入され、1886年頃に狐狗狸として流行したことを井上円了資料・東洋大学整理から確認できる。1886年新聞記事、1887年『妖怪玄談 狐狗狸の事』も同時代の存在を固定する。

**この伝承における現れ方**

現代学校型より前に、明治期の日本で共同可動媒体による占い・交信実践が「こっくり／狐狗狸」として形成・流行している。年代コードは伝承系譜の成立層を示し、紙・硬貨型の成立年を1880年代へ遡及させるものではない。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Child / Value: `D02.PRT.NEWSPAPER` — 新聞
- Primary Parent: `D02.PRT` — 印刷・書簡
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

現在直接固定できる最古の公開流通媒体は、1886年7月16日『朝日新聞（大阪）』「神下しと狐狗狸の拘引」である。実践そのものは記事以前に存在したが、その対人伝達回路を具体的媒体コードへ確定できる資料は今回固定していないため、推測で口承へ遡らない。

**この伝承における現れ方**

狐狗狸が社会現象として新聞で読者へ提示される時点を、現在証拠で最も古く固定できる流通媒体とする。起源媒体ではなく「最古確認媒体」をコードする。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Child / Value: `D03.ORL.SCHOOL_ORAL` — 学校内伝承
- Primary Parent: `D03.ORL` — 口承・限定共同体
- Secondary: `D03.PRT.NEWSPAPER` — 新聞; `D03.PRT.BOOK` — 書籍
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

現代Versionでは手順・禁忌が学校・若者共同体で実践知として共有される。一方、歴史的には1886年新聞、1887年書籍による広域提示も直接確認できる。Version Scopeが長期歴史を含むため、現代実践に近い学校内伝承をPrimary、確実な印刷媒体をSecondaryとする。

**この伝承における現れ方**

「何人でやるか」「紙に何を書くか」「どう帰すか」という手順知は対人共有され、新聞・書籍はその実践を広域社会へ記録・再提示する。媒体ごとに役割が異なる。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: `D04.VAR.ACCRETION` — 増補
- Primary Parent: `D04.VAR` — 再話・変異
- Secondary: `D04.VAR.ORAL_VARIATION` — 口承変異
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

明治期の器具型から現代の紙・硬貨型へ道具が変化し、さらに「途中で指を離してはいけない」「正しく帰さなければ祟る」等の危険規則・終了規則が後代に増補されている。

**この伝承における現れ方**

共同可動媒体から回答を得る核を残しつつ、器具、呼び出し主体、終了法、禁忌、危険性が再話ごとに追加・変更される。単なる定型化より、長期の増補変容をPrimaryとする。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.RUL.RITUAL_PROCEDURE` — 儀式・手順
- Primary Parent: `D05.RUL` — 規則・警告形式
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

準備、呼び出し、質問、回答解釈、終了という実行可能な順序を持ち、禁忌・終了規則も手順の一部として伝達される。

**この伝承における現れ方**

受容者は怪談を聞くだけでなく、実際にこっくりさんを行うための方法を教わる。伝承内容がそのまま再現可能な実践手順になる。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T6` — 真偽未確定
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

媒体が実際に動いたという体験は参加者に起こり得る一方、その運動原因を霊的主体とするか、人間の無意識運動等とするかは確定しない。

**この伝承における現れ方**

「本当に動いた」という観察可能な出来事と、「誰が動かしたのか分からない」という因果不確定性が共存する。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ANO.UNEXPLAINED_EVENT` — 説明不能事象
- Primary Parent: `D07.ANO` — 異常体験・存在
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

中心的な不可解さは、参加者が自分では動かしていないと認識する媒体が、質問に対応する意味ある方向へ移動する現象である。外部主体の正体は、その現象を説明するため後から付与される。

**この伝承における現れ方**

「なぜ硬貨・器具が動いたのか」という説明不能事象が問題となり、参加者は霊・狐狗狸等を原因候補として置く。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.DEX.DIRECT_EVENT` — 出来事への直接遭遇
- Primary Parent: `D08.DEX` — 直接経験
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

実践者にとって意味形成の直接契機は、共同で触れている媒体が意図せず動いたと感じる出来事である。実施前の「こっくりさんが答える」という主張は解釈枠組みを提供するが、異常を実感させる契機は運動経験にある。

**この伝承における現れ方**

参加者は媒体の移動を直接経験し、その運動を誰が起こしたのかという問いを立てる。先行知識がその出来事を霊的交信として読ませる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CTL.RITUAL_RULE` — 儀式規則
- Primary Parent: `D09.CTL` — 制御規則形成
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

原因不明の媒体運動を、呼び出し・質問・回答・終了という再現可能な交信手順へ整理することで、不可視の主体との関係を操作可能なものとして扱う。

**この伝承における現れ方**

「どう呼ぶか」「どう質問するか」「どう帰すか」を規則化することで、偶発的な物体運動が一回限りの異常ではなく、再実行可能な交信システムへ変わる。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.SUP.YOKAI_ENTITY` — 妖怪・人格怪異
- Primary Parent: `D10.SUP` — 超自然主体・力
- Secondary: `D10.SUP.GHOST_SPIRIT` — 幽霊・死者霊
- Status: `C` — Conflict（競合）

**判定根拠**

明治期には狐狗狸、神下し等の多様な人格的外部主体が語られ、現代危険型では霊・死者霊として説明されることが多い。歴史的Version間で存在論が一致しないため、人格怪異を広いPrimary、死者霊をSecondaryとして競合を保持する。

**この伝承における現れ方**

同じ媒体運動が、ある時代・語りでは狐狗狸等、別のVersionでは霊として解釈される。現象核を一つの超自然種へ固定しない。

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

**判定根拠**

参加者が器具・紙・硬貨等を準備し、共同で接触し、呼び出しを行うことによって交信実践が開始される。

**この伝承における現れ方**

噂を知るだけではなく、規定された共同操作を実際に行うことが因果系への入口になる。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC` — 焦点人物
- Secondary: なし

**判定根拠**

回答・驚き・禁忌違反時の危険を直接受けるのは、こっくりさんを実施した参加者である。

**この伝承における現れ方**

交信の利益とリスクが実践者へ集中し、外部の見物人が同じ因果対象になる規則は中心形にない。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.PHY.ENV_OBJECT_MANIPULATION` — 環境・物体操作
- Primary Parent: `D13.PHY` — 身体・物質作用
- Secondary: `D13.COG.INFORMATION_INDUCED_ACTION` — 情報誘導・行動誘発
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

伝承内部の直接作用は、外部主体が硬貨・器具等を動かして回答位置を示すことにある。得られた回答が参加者の判断・行動を変える作用はその後に生じるためSecondaryとする。

**この伝承における現れ方**

不可視の主体が可動媒体を物理的に操作し、移動位置が情報へ翻訳される。旧Pilotの情報誘導だけでは、こっくりさん固有の物体運動を捉え切れないためPrimaryを変更する。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.MIX` — 混合
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

未知情報・占い結果を得るという利益と、恐怖・霊障・憑依・不幸等の負の可能性が共存する。

**この伝承における現れ方**

成功すれば知識を得られるが、手順違反や危険型では同じ実践が災厄の入口になる。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

**判定根拠**

占い・交信型の主目的は、未来・恋愛・秘密等、通常は知り得ない答えを得ることである。危険帰結はVersion差が大きいため、共通目的として知識獲得をPrimaryに置く。

**この伝承における現れ方**

媒体の移動が文字・数字へ変換され、参加者は「外部主体から答えを得た」と理解する。

### 2.3.6. D16: 因果時間構造

準備→呼び出し→質問→回答→終了という複数段階が、一回の実践エピソード内で順序を持って進む。

**この伝承における現れ方**

各段階を正しく完了することが安全性に関わるため、時間順序そのものが因果モデルの一部になる。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.RIT.RITUAL_CLOSURE` — 儀式終了・祓い

**判定根拠**

危険型では、呼び出した存在を正しく帰し、所定の終了手順を完了することが霊障回避の中心とされる。

**この伝承における現れ方**

問題が起きてから逃げるのではなく、交信関係を正式に閉じることが安全策となる。終了規則自体にはVersion差がある。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=1`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

L1では外部主体が媒体を動かし、回答・危険を生む。1886年新聞記事の見出しが「狐狗狸の拘引」として社会的介入を示しており、実践流行が現実社会の対応対象となったことを示唆するためL3を1とする。ただし本文全体を固定していないためStatusは`I`とする。読むだけで受容者が霊的因果対象になる規則はないためL2は0とする。

**この伝承における現れ方**

伝承内部の交信に加えて、実践の流行が新聞・社会的規制や介入の対象となる。超自然的作用と社会現実上の反応を別レイヤーとして保持する。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: なし
- Status: `D` — Direct（典拠に直接明示）

**判定根拠**

東洋大学の資料整理は1886年頃に各地で大流行したとし、後代も学校文化・書籍・放送等を通じて広域に再流通する。

**この伝承における現れ方**

特定聖地を必要とせず、身近な器具と共同手順があれば各地域で再現できるため、地域固有伝承に閉じない。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.NON.COMMON_KNOWLEDGE` — 一般共有
- Primary Parent: `D20.NON` — 特権なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

手順・禁忌は実践共同体で反復共有され、専門家だけが実施法を独占する構造ではない。

**この伝承における現れ方**

「やり方を知っている子」が他者へ教えることで共同体知となり、誰でも再現可能な実践として拡散する。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred（定義と証拠から合理的に推定）

**判定根拠**

実践は学校・家庭・身近な器具という一般的現実環境を必要とするが、特定地点・実名人物・一つの歴史事件を因果的前提としない。成立史には明治期の具体的記録があるが、個々の伝承実践は場所を自由に移植できる。

**この伝承における現れ方**

教室でも家庭でも、必要な器具と参加者が揃えば同じ実践を再現できる。歴史的起源の実在性と、各Versionの場所非固定性を分離する。
