# 1. 伝承内容

## 1.1. summary

1880年代に確認できるこっくりさんは、複数人がテーブルや飯櫃の蓋等の可動器具へ手を置き、問いを発し、器具の動きを回答として読む占い・神意判断の実践として記録・整理されている。

東洋大学の公式整理では、1884年頃に伊豆下田へテーブル・ターニングが伝わり、日本では飯櫃の蓋と竹脚等を用いる形が現れ、1886年頃に各地で流行したとされる。1886年新聞には「神下しと狐狗狸の拘引」の見出しが確認され、1887年には井上円了『妖怪玄談 狐狗狸の事』が刊行された。

後代には、紙に鳥居・五十音・数字・「はい／いいえ」等を書き、硬貨へ複数人が指を置く学校型、終了手順、指を離してはいけない等の危険規則、憑依・祟りを伴う型が確認される。これらは1880年代の器具型と区別して記録する。

## 1.2. 詳細展開

### 1.2.1. 器具と参加

- 複数人が可動する器具へ手を置く形式が確認される。
- 日本ではテーブルのほか、飯櫃の蓋と竹脚等を用いる形が公式研究整理に記される。

### 1.2.2. 質問

- 参加者は器具を用いて問いを発する。
- 実践は占い・神意判断として整理され、未知の事柄について回答を得る目的で用いられる。

### 1.2.3. 器具運動と回答

- 質問後の器具の動きが応答として扱われる。
- 明治期資料整理では「神意」や「狐狗狸」と結び付く表現が確認されるが、回答主体の存在論は一種類に固定されない。

### 1.2.4. 後代学校型

- 後代には紙・五十音・数字・鳥居等の記号面と硬貨を用いる形式が広く整理される。
- 呼び出し、質問、回答、終了という手順や、終了禁忌・危険規則が付加される型がある。
- 1970年代には児童生徒間の高頻度流行と精神症状が医学研究で報告された。

## 1.6. 条件・規則・禁忌

- 明治期器具型では、複数人が可動器具へ接触し、問いを発し、器具の動きを回答として扱う形式が確認される。
- 後代学校型では、呼び出し→質問→回答→終了という手順が付加・定型化した型がある。
- 指を途中で離さない、終了手順を守る等の危険規則は後代型に確認されるが、1880年代の器具型へ遡及しない。

## 1.7. 異常・不可解な現象／中心命題

- 通常の参加者だけでは分からない問いに対し、所定の器具実践を通じて回答が得られるとされる。
- 質問後の器具の運動が、単なる移動ではなく意味を持つ回答として扱われる。
- 回答源は「神意」「狐狗狸」等と結び付けられるが、Scope横断で一種類の主体に固定されない。

## 1.8. 行動・対応

- 実践: 複数人で器具へ接触し、問いを発する。
- 読み取り: 器具の動きを回答として解釈する。
- 利用: 占い・神意判断として、未知の事柄への答えを得ようとする。
- 後代型: 紙・硬貨を用いた実践、終了手順の遵守等が語られる。

## 1.9. 帰結・終端状態

- 明治期器具型では、問いに対する回答を得たと参加者が理解することが実践上の終端となる。
- 回答内容自体は吉凶・利益・危害のいずれかに固定されない。
- 後代学校型では、憑依・祟り・精神症状等が語られる／報告される場合があるが、明治期器具型の必須帰結とはしない。

- 明治期に回答源が神格、狐狗狸、その他の何として理解されたかは一義的でない。
- 現代の死者霊解釈、紙・硬貨型、終了禁忌を1880年代へ遡及しない。

# 2. 伝承史・異伝

## 2.1. 最古確認

- 1884年頃: 東洋大学の井上円了研究整理では伊豆下田へのテーブル・ターニング伝来が記される。
- 1886年: 東洋大学公式整理では日本各地で流行したとされる。『朝日新聞（大阪）』7月16日には「神下しと狐狗狸の拘引」の見出しが確認できる。
- 1887年: 井上円了『妖怪玄談 狐狗狸の事』が刊行される。

現時点では、少なくとも1880年代後半に名称付きの実践・流行が存在したことを固定できる。

## 2.2. 流通・拡散

19世紀末の研究整理では、こっくりさんは子どもだけに限定されず、成人を含む日常生活の実践として扱われる。1995年の社会心理学的調査では、1930–45年の安定伝承期、戦後の低迷期、1974–92年の興隆期が整理される。1976年の群馬県調査では児童生徒間で高頻度の流行が確認される。
