# 1. 伝承内容

## 1.1. 明治期の確認核

1880年代に確認できるこっくりさんは、西洋のテーブル・ターニング系実践を日本の生活環境へ適応させた占い・神意判断の実践である。複数人が可動する器具へ手を置き、問いを発し、器具の動きを意味ある応答として解釈する。

東洋大学公式資料によれば、日本ではテーブルの代わりに飯櫃の蓋と三本の竹脚等が使われ、1886年頃に各地で大流行した。1886年新聞には「神下しと狐狗狸の拘引」という見出しが確認され、1887年には井上円了が『妖怪玄談 狐狗狸の事』を刊行している。

ここで重要なのは、**現代の紙・五十音・硬貨型、学校での危険な招霊遊戯、終了禁忌を明治期の確認核へ自動的に混入しないこと**である。

## 1.2. 現代学校型

1970年代には児童生徒間で大規模な流行が確認される。後代の典型では、紙に鳥居・五十音・数字・「はい／いいえ」等を書き、硬貨へ複数人が指を置いて呼び出し、質問し、硬貨の移動を回答として読む。終了手順や「途中で指を離してはいけない」等の危険規則が付加される型もある。

1976年の医学研究は、単なる伝承内容ではなく、学校現場での高頻度流行と精神症状という現実効果を記録している。

## 1.3. 安定する意味形成核

時代によって器具・主体観・危険規則は変わるが、次の構造は強く連続する。

1. 複数人が可動媒体へ接触する。
2. 質問を行う。
3. 参加者が意図的に動かしていないと感じる媒体が動く。
4. その動きを、外部主体からの意味ある回答として解釈する。

外部説明としての観念運動・無意識運動と、伝承内部の「狐狗狸／霊的主体が答える」という説明は区別する。

## 1.4. 主体・物・場所

| 要素 | 明治期 | 現代型 | 備考 |
|---|---|---|---|
| 参加者 | 複数人 | 複数人、主に学齢集団 | 実践者・質問者 |
| 因果主体 | 神意・狐狗狸等、解釈は一定しない | 霊・こっくりさん等 | 同一存在論へ統一しない |
| 可動媒体 | テーブル、飯櫃の蓋・竹脚等 | 硬貨等 | 回答の物理的指標 |
| 記号面 | 必須とは限らない | 五十音・数字等 | 後代形式 |
| 場所 | 家庭・日常空間 | 学校・家庭等 | 特定聖地は不要 |

## 1.5. 条件・規則・帰結

- 明治期確認核: 共同で器具へ接触し、問いを発して、その動きを回答として読む。
- 現代学校型: 呼び出し→質問→回答→終了の手順が強化される。
- 危険規則: 指を離す、終了しない、使用物を不適切に扱う等へ不幸・憑依等を結ぶ型があるが、明治期へ遡及しない。
- 利用目的: 未来、恋愛、秘密、未知情報等への回答を得る。

# 2. 伝承史・異伝

## 2.1. 最古確認

- 1884年頃: 東洋大学による井上円了研究整理では伊豆下田へのテーブル・ターニング伝来。
- 1886年: 日本各地で大流行したと東洋大学公式資料が整理。『朝日新聞（大阪）』7月16日記事の存在をNDLが確認。
- 1887年: 井上円了『妖怪玄談 狐狗狸の事』刊行。

したがって、少なくとも1880年代後半の実践・流行は強く固定できる。

## 2.2. 20世紀以降

1995年の広域調査は、1930–45年の安定伝承期、戦後の低迷期、1974–92年の興隆期を示す。1976年の群馬県調査では児童生徒に高頻度で流行しており、現代学校型が社会現実上の問題としても観測されている。

## 2.3. 主要異伝

| 型 | 主な特徴 | Scope上の扱い |
|---|---|---|
| 明治器具型 | テーブル／飯櫃等を共同操作し回答を読む | 最初期に直接確認できるまとまり |
| 紙・硬貨型 | 五十音表等と硬貨を用いる | 後代の現代学校型 |
| 占い型 | 回答獲得を中心とする | 明治期から確認可能 |
| 危険招霊型 | 禁忌・憑依・祟り・終了規則を強調 | 後代増補として分離 |
