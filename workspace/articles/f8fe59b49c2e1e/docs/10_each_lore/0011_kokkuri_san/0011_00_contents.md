# 0. INTRODUCTION

## 0.1. 文書の役割

**伝承名:** こっくりさん

本文書は、近代日本へ導入されたテーブル・ターニング系の占い遊戯が「こっくりさん／狐狗狸」として定着し、学校文化では招霊儀式・危険な遊びとして再編された伝承について、内容・典拠・流通史・異伝・不確実性を記録する Evidence / Content layer である。分析コードは `0011_10_analysis.md` に分離する。

パイロット Evidence Rank は `B`。こっくりさんは近代の流行史を比較的追跡できる一方、明治期の器具型と、現代の紙・五十音・硬貨型を同一の固定手順として扱ってはならない。

## 0.3. 証拠上の区別

1. **明治期の実流行:** 1880年代半ば、テーブル・ターニング由来の占いとして全国的に流行。
2. **器具・手順の変容:** お櫃の蓋・竹脚等から、紙・文字・硬貨を使う学校型へ変化。
3. **意味の変容:** 占い・遊戯から「霊を呼ぶ」「失敗すると祟られる」という危険儀式へ強調点が移る。
4. **科学的説明と伝承内部説明:** 無意識運動等の説明と、霊・狐狗狸が動かすという伝承内説明を分離する。

# 1. 伝承内容

## 1.1. summary

現代的なこっくりさんでは、複数の参加者が紙に鳥居、五十音、数字、「はい／いいえ」等を書き、中央付近に硬貨を置いて全員が指を軽く触れる。参加者が「こっくりさん」を呼び出し、質問すると、誰も意図的に動かしていないはずの硬貨が文字・数字へ移動し、その軌跡を回答として読む。

この遊戯は、単なる占いとして「好きな人は誰か」「未来はどうなるか」を聞く形でも行われるが、学校怪談的なVersionでは、呼び出した存在を正しく帰さない、途中で指を離す、規定の終了手順を守らない、使用物を不適切に扱う等によって霊障・憑依・不幸が起こるとされる。したがって、**未知の回答を得る情報獲得装置**と、**規則を誤ると危険な招霊儀式**が一体化している。

歴史的には、井上円了の調査で、1880年代に西洋のテーブル・ターニングが日本へ入り、テーブルの代わりに身近な器具を用いた「こっくり」が流行したことが記録される。1886年の新聞記事には「狐狗狸」が社会的問題として扱われた痕跡があり、1887年には円了が『妖怪玄談 狐狗狸の事』を刊行した。現代学校型の紙・硬貨手順をこの時点へそのまま遡及させることはできない。

伝承構造上の核心は、参加者全員が「自分は動かしていない」と感じる共同操作物の運動を、**外部主体からの回答**として意味付ける点にある。原因が参加者自身にある可能性と、霊的主体にあるという解釈の間の不確定性が、遊戯を占い・怪異体験へ変える。

## 1.2. 詳細展開

1. **準備:** 参加者、紙、硬貨等を用意する。
2. **呼び出し:** 定型句等でこっくりさんの来訪を求める。
3. **質問:** 恋愛・未来・秘密等を問う。
4. **運動:** 硬貨等が動き、文字・数字を指す。
5. **解釈:** 動きを外部主体の回答として読む。
6. **終了:** 帰還を求め、儀式を終える。
7. **禁忌:** 途中離脱・終了失敗・器具処理違反等に危険が結び付けられる異伝がある。

## 1.3. 主体

| 主体 | 役割 |
|---|---|
| 参加者 | 共同操作・質問・回答解釈 |
| こっくりさん | 伝承内部では回答を与える霊的主体 |
| 学校共同体 | 手順・禁忌・体験談を伝える流通主体 |

## 1.4. 場所・空間

明治期には家庭・座敷等、現代には放課後の教室・家庭など複数人で集まれる場所。特定聖地を必要とせず、手順を再現できる場所なら移植可能。

## 1.5. 物・記号・媒体

- 明治期: テーブル、飯櫃の蓋、竹脚等。
- 現代型: 紙、鳥居・文字表、硬貨等。
- 共同接触する可動物が「人間の手」と「外部主体」の境界媒体になる。

## 1.6. 条件・規則・禁忌

- 複数人で共同接触する。
- 呼び出し・質問・回答・終了の順序を守る。
- 途中で指を離さない等の禁忌が後代に強調される。
- 終了手順、紙・硬貨の処理法はVersion差が大きい。

## 1.7. 中心異常

誰も自分の意志で動かしていないと認識する媒体が質問に意味ある回答を返す。その運動を霊・神・狐狗狸等の外部主体によるものと解釈する。

## 1.8. 行動・対応

参加者は質問し、回答を読む。危険型では適切に終了させ、禁忌違反を避けることが重要とされる。

## 1.9. 帰結

- 情報・予言・答えを得る。
- 怖さ・驚き・集団体験。
- 異伝では憑依、祟り、不幸、精神的混乱等。

## 1.10. 不確実性

- 1880年代型と現代学校型の手順を混成しない。
- 「狐・犬・狸の霊」が起源時から固定した正体だったとは限らない。
- 終了規則は後代の増補が多い。
- 現実の運動原因の説明と伝承内部因果を分離する。

# 2. 伝承史・異伝

## 2.1. 最古確認

東洋大学の井上円了資料は、1884年頃の伊豆下田でテーブル・ターニングが伝わり、1886年頃に各地で大流行したと整理する。1886年新聞記事の実在は国立国会図書館レファレンスで確認できる。1887年『妖怪玄談』は同時代研究資料として重要。

## 2.2. 流通

- 1880年代: 近代的占い・流行現象。
- 20世紀: 呼称・霊的説明を保ちながら継続。
- 1970年代以降: 学校・児童生徒集団で再流行し、危険な招霊遊戯として強く定型化。
- 後代: 書籍・漫画・テレビ・Webで再流通。

## 2.3. 主要異伝

| 型 | 差分 |
|---|---|
| 明治器具型 | テーブル／飯櫃等を用いる |
| 紙・硬貨型 | 五十音表と硬貨を用いる現代学校型 |
| 占い型 | 回答獲得が主目的 |
| 危険招霊型 | 禁忌・憑依・祟りを強調 |
| 動物霊型 | 狐・狗・狸等を主体として説明 |

## 2.4. 変容上の重要点

**可動媒体による回答**という機能を残しつつ、器具・主体観・危険性が大きく変化した。特に後代は「正しく終わらせなければならない」という終了規則が意味形成の中心へ加わる。
