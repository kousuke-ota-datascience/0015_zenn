# 1. 伝承エントリ基本情報

- `Entry_ID`: `0091`
- `伝承エントリ名称`: ベッドの下の男
- `Macro_Category`: 犯罪・社会不安
- `Entry_Type`: FOAF
- `Version_Scope`: 1996年までに日本の現代伝説集へ採録されたことが確認でき、2025年4Gamerの後代二次資料で具体Contentを直接確認できる「私的空間への侵入者潜伏型」。Content codingでは、自宅・ホテル等のベッド下へ見知らぬ人物が先行潜伏する型、および4Gamer 2025のホテル型（入室→違和感→ベッド下確認→退室→救援→警察確認）を対象とする。1996年書籍本文は未実見のため、同書はD01/D02等のHistory Evidenceに限定し、具体Content・提示形式・真実性姿勢を遡及しない。最初期口承、成立年代、武器・殺害意図、違和感の具体種別は必須化しない。

# 3. 横断QA

## 3.1. Version Scope整合

- 1996年書籍はD01/D02の早い流通確認点としてのみ使用し、本文未実見のためD03以降の具体Contentへ遡及しない。
- 具体的なContent codingは、位置固定した4Gamer 2025 `第1話：ベッドの下の男` の記述へ接続する。
- 自宅型・ホテル型の併存から変容方向を推定しない。
- 武器・殺害意図・具体的な察知cueを全異伝共通へ引き上げない。

## 3.2. Sense-making chain

```text
安全なはずの私室に未知の人間が潜伏している脅威
→ 何らかの違和感で問題化（cue種別はU）
→ 違和感を人間侵入者の存在へ主体帰属
→ 人間個人を因果源として置く
→ 侵入者が先行潜伏する空間へ居住者・宿泊者が入る
→ 焦点人物が見えなかった侵入者の存在を認識する
→ 追加作用を必須としない顕現・認識
→ 侵入者の存在という真相知識を得る
→ ホテル型では逃走・制度介入によって危険から離れる
→ 作用レイヤーはL1=1、L2=0、L3=0
```

D12→D13→D15は「体験者→侵入者の存在の認識→真相知識獲得」として直接作用列を揃え、退避はD17へ分離する。

## 3.3. taxonomy / Status QA

- D03: 現行taxonomyの `D03.WEB.WEBSITE` を使用し、1996年書籍はHistory Evidenceへ限定。
- D07: 実現していない誘拐・暴行をSecondaryへ置かない。
- D08: 「違和感」から具体cueを推定せずU。
- D12/D13/D15: 直接作用規則に従い、体験者→`MANIFEST_ONLY`→`REVELATION_KNOWLEDGE`へ再構成。
- D17: 退避・施設／警察介入を制御方式として保持。
- D18: 現行作用レイヤーとしてL1=1/L2=0/L3=0。L3の独立X Evidenceは未固定。
- D19: 全国大衆への過拡張を避け、直接固定できる `D19.KIN.SCHOOL_YOUTH` を採用。
- 全Dimensionで単一Statusを維持する。
