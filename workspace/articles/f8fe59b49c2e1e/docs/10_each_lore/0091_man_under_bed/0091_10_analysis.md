# 3. 横断QA

## 3.1. Version Scope整合

- 1996年書籍はD02の早い流通確認点としてのみ使用し、本文未実見のためD03以降の具体Contentへ遡及しない。
- 具体的なContent codingは、位置固定した4Gamer 2025 `第1話：ベッドの下の男` の記述へ接続する。
- 自宅型・ホテル型の併存から変容方向を推定しない。
- 武器・殺害意図・具体的な察知cueを全異伝共通へ引き上げない。

## 3.2. Sense-making chain

```text
安全なはずの私室に未知の人間が潜伏している脅威
→ 何らかの違和感で問題化（cue種別はU）
→ 違和感を人間侵入者の存在へ主体帰属
→ 人間個人を因果源として置く
→ 侵入者が先行潜伏する空間へ居住者・宿泊者が入る
→ 居住者・宿泊者が潜在的被害対象となる
→ 物理的な潜伏・待ち伏せ（taxonomy gap）
→ ホテル型では察知後に退避し、侵入者の存在が警察確認される
→ 逃走・制度介入によって危険から離れる
```

D08は具体cue種別を固定せずUとし、D07→D09→D17の連鎖にEvidence外の物的痕跡を挿入しない。

## 3.3. taxonomy / Status QA

- D03: 1996年書籍本文未実見のため、現Version Scope媒体としてBOOKを外し、直接Content確認可能なWeb記事へ限定。
- D08: 「違和感」から `PHYSICAL_TRACE` を推定せずU。
- D13: 現行taxonomyに「物理的な潜伏・待ち伏せ」の直接Childがないためtaxonomy gapを保持。
- D18: 外部効果の独立X Evidenceがないため0/0/0。
- 全Dimensionで単一Statusを維持する。
