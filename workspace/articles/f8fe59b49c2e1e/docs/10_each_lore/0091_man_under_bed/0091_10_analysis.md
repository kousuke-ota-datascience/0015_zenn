# 1. 伝承エントリ基本情報

- `Entry_ID`: `91`

- `Macro_Category`: 犯罪・社会不安
- `Entry_Type`: FOAF
- `Version_Scope`: 私室・ホテル等で侵入者がベッド下に潜伏し、主人公が気づかず入室した後に第三者・警察等によって発見される共有核

# 2. 分析概念次元

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代
- Value: `D01.G4` — 1980年代
- Status: `I`

**判定根拠**
1990年代の現代伝説集で代表的犯罪不安型として採録され、パイロットでは1980年代成立帯を採用した。最初期口承は未固定である。

**この伝承における現れ方**
一人暮らしやホテル客室など近代的な私的生活空間を前提に、住居侵入への不安を現代伝説として可視化する。

### 2.1.2. D02: 最古確認流通媒体
- Primary: なし
- Secondary: なし
- Status: `U`

**判定根拠**
採録以前に口承・新聞等のどの媒体で最初に確認できるかを直接示す証拠が不足している。

**この伝承における現れ方**
FOAFとして口頭流通しやすいが、それを理由に口承を最古媒体と推定しない。証拠上の起点は未確定である。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）
- Primary Child: `D03.ORL.PEER_ORAL` — 友人・仲間内伝承
- Primary Parent: `D03.ORL`
- Secondary: なし
- Status: `I`

**判定根拠**
「知人の部屋で起きた」等の近接伝聞として再話される性格から、仲間内口承をPrimaryとしたパイロット判定を保持する。

**この伝承における現れ方**
自分の友人関係の先で起きた防犯事件として伝わることで、受容者の自室にも起こり得る危険として感じられる。

### 2.1.4. D04: 生成・変容パターン
- Primary Child: `D04.STB.STABILIZED_CANON` — 定型化・カノン化
- Primary Parent: `D04.STB`
- Secondary: なし
- Status: `I`

**判定根拠**
自宅／ホテル、発見方法、武器等を変えながらも「ベッド下の侵入者」という中心場面が安定しているため定型化を保持する。

**この伝承における現れ方**
鏡やメモ、友人の機転など演出は変化するが、視界外のすぐ近くに人間の脅威が潜むという核は変わらない。

### 2.1.5. D05: 提示形式
- Primary Child: `D05.HRS.FOAF` — FOAF
- Primary Parent: `D05.HRS`
- Secondary: なし
- Status: `D`

**判定根拠**
代表形は友人・知人の周辺で実際に起きたように語られる近接伝聞である。

**この伝承における現れ方**
聞き手から近いが直接確認しにくい人物を被害者に置くことで、単なる創作ホラーではなく実際の防犯事件らしさを持たせる。

### 2.1.6. D06: 真実性提示
- Value: `D06.T2` — 近接伝聞事実
- Status: `D`

**判定根拠**
「友人の知人に本当にあった」という形式で提示されるため、近接伝聞事実を保持する。

**この伝承における現れ方**
侵入犯罪自体が現実に可能なため、近接伝聞形式と組み合わさると「自分にも起こるかもしれない」事実感が生じる。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象
- Primary Child: `D07.ICT.STRANGER_THREAT` — 見知らぬ他者の脅威
- Primary Parent: `D07.ICT`
- Secondary: なし
- Status: `I`

**判定根拠**
安全なはずの私室へ見知らぬ人物が侵入し、意図不明のまま潜伏している危険を意味形成するため、このコードを保持する。

**この伝承における現れ方**
「外には危険がある」ではなく、「もう家の中に知らない人がいる」という形で、他者脅威を最も私的な領域へ侵入させる。

### 2.2.2. D08: 意味形成契機
- Primary Child: `D08.STY.FOAF_REPORT` — 近接伝聞
- Primary Parent: `D08.STY`
- Secondary: なし
- Status: `D`

**判定根拠**
危険は統計的防犯情報ではなく、知人周辺の体験談として問題化される。

**この伝承における現れ方**
「実際に知り合いの部屋であったらしい」という証言が、ベッド下という普段確認しない死角を危険として意識させる契機になる。

### 2.2.3. D09: 意味付与操作
- Primary Child: `D09.CAT.NAMING` — 命名
- Primary Parent: `D09.CAT`
- Secondary: なし
- Status: `I`

**判定根拠**
漠然とした室内違和感を「侵入者が隠れている」というカテゴリーへ整理するため命名を保持する。

**この伝承における現れ方**
気配や物の変化といった曖昧な手掛かりが、「ベッド下の男」という明確な脅威へ変換されることで、違和感の意味が閉じる。

### 2.2.4. D10: 因果源存在論
- Primary Child: `D10.HUM.INDIVIDUAL_HUMAN` — 個人
- Primary Parent: `D10.HUM`
- Secondary: なし
- Status: `I`

**判定根拠**
原因は幽霊ではなく、意図を持って侵入・潜伏する人間であるため、このコードを保持する。

**この伝承における現れ方**
恐怖は超自然ではなく、普通の人間が鍵や生活習慣の隙を突いて最接近できるという現実的悪意に置かれる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件
- Primary Child: `D11.SOC.MEET_INTERACT` — 会う・会話する
- Primary Parent: `D11.SOC`
- Secondary: なし
- Status: `I`

**判定根拠**
パイロットでは、主人公と侵入者が同一私的空間へ入り社会的接触可能な状態になることを因果系への入口として扱った。

**この伝承における現れ方**
主人公は侵入者に自発的に近づくのではなく、帰宅・入室するだけで、すでに潜んでいる他者と極端に近い距離へ置かれる。

### 2.3.2. D12: 作用対象
- Primary Child: `D12.FOC.PROTAGONIST_EXPERIENCER` — 主人公・体験者
- Primary Parent: `D12.FOC`
- Secondary: なし
- Status: `I`

**判定根拠**
侵入者の潜伏によって直接危険にさらされる居住者・宿泊者が焦点人物である。

**この伝承における現れ方**
主人公は何も知らないまま危険の真上で日常行動を行い、後から「すでに襲撃圏内にいた」と理解させられる。

### 2.3.3. D13: 作用機構
- Primary Child: `D13.PHY.PHYSICAL_ATTACK` — 物理攻撃
- Primary Parent: `D13.PHY`
- Secondary: なし
- Status: `I`

**判定根拠**
侵入者は潜在的な襲撃・殺傷主体として構成されるため、物理攻撃を保持する。

**この伝承における現れ方**
代表形では実際の攻撃前に発見される場合が多いが、刃物等の異伝が「発見されなければ物理的に襲われた」という切迫した作用を示す。

### 2.3.4. D14: 帰結極性
- Value: `D14.NEG` — 負
- Status: `I`

**判定根拠**
恐怖、襲撃可能性、私的空間の安全喪失という負の帰結である。

**この伝承における現れ方**
救助に成功する型でも、主人公は自宅・客室が安全ではなかったと知り、日常空間への信頼を損なう。

### 2.3.5. D15: 帰結領域
- Primary Child: `D15.MND.FEAR_TRAUMA` — 恐怖・トラウマ
- Primary Parent: `D15.MND`
- Secondary: なし
- Status: `I`

**判定根拠**
パイロットでは実際の傷害より、危険発覚後の恐怖・心理的衝撃を主要帰結として判定している。

**この伝承における現れ方**
「知らない男と同じ部屋にいた」という事後認識が、身体被害を受けなくても強い恐怖を残す。安全な場所の意味が反転する。

### 2.3.6. D16: 因果時間構造
- Primary Child: `D16.EVT.SINGLE_EPISODE` — 単一エピソード
- Primary Parent: `D16.EVT`
- Secondary: なし
- Status: `I`

**判定根拠**
入室から危険察知・退避・発見までが一つの連続したエピソード内で完結するため、このコードを保持する。

**この伝承における現れ方**
長期的に呪われるのではなく、一晩・一回の入室という短時間に「安全→潜在危険→発覚」の転換が起きる。

### 2.3.7. D17: 回避・制御方式
- Primary Child: `D17.AVO.DO_NOT_ENGAGE` — 接触回避
- Primary Parent: `D17.AVO`
- Secondary: なし
- Status: `I`

**判定根拠**
異変を察した後に直接ベッド下を確認せず、部屋から離れて警察等へ任せる型があるため接触回避を保持する。

**この伝承における現れ方**
生存の鍵は侵入者と対決することではなく、気づいていないふりをして退避することに置かれる。防犯教訓としても「一人で確認しない」へつながる。

### 2.3.8. D18: 作用レイヤー
- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `0`
- Status: `I`

**判定根拠**
危険因果は物語内の主人公・侵入者に生じ、話を聞いただけで同じ被害が起こる構造ではないためL1のみを保持する。

**この伝承における現れ方**
受容者に防犯意識を与え得るが、伝承が主張する直接危険は「侵入者と同室になった人物」に限定される。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲
- Primary Child: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS`
- Secondary: なし
- Status: `D`

**判定根拠**
日本の現代伝説集に広域的な犯罪不安型として採録され、特定地域に固定されないため全国的大衆を保持する。

**この伝承における現れ方**
ベッドと個室があれば舞台をどこへでも移せるため、一人暮らし・ホテル利用者など広い受容者層へ再配置できる。

### 2.4.2. D20: 特権情報保持者
- Primary Child: `D20.ORG.PERPETRATOR_CRIMINAL` — 加害者・犯罪者
- Primary Parent: `D20.ORG`
- Secondary: なし
- Status: `I`

**判定根拠**
主人公が知らない侵入状況・意図を把握しているのは潜伏する加害者であり、パイロットでは加害主体を特権情報保持者とした。

**この伝承における現れ方**
侵入者だけが「自分がベッド下にいる」「いつ襲うつもりか」を知っており、主人公は情報格差の中に置かれる。恐怖はこの非対称性から生まれる。

### 2.4.3. D21: 現実アンカー
- Value: `D21.A1` — 一般的現実背景
- Status: `I`

**判定根拠**
寝室、ホテル、住居侵入、警察等の現実的背景を使うが、特定の検証済み事件・場所へ固定されないためA1を保持する。

**この伝承における現れ方**
超自然要素がなく、誰の部屋でも成立し得る現実的条件だけで構成されることが、本当らしさを支える一方、固有事件へのアンカーは弱い。
