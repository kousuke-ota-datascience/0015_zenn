# 1. 伝承エントリ基本情報

- `Entry_ID`: `0091`
- `伝承エントリ名称`: ベッドの下の男
- `Macro_Category`: 犯罪・社会不安
- `Entry_Type`: FOAF
- `Version_Scope`: 1996年までに日本の現代伝説集へ採録され、後代二次資料でも複数異伝が確認できる「私的空間への侵入者潜伏型」。自宅・ホテル等のベッド下へ見知らぬ人物が先行潜伏し、居住者・宿泊者はその存在を知らずに入室する。察知後に退避・救援要請し、後から侵入者が確認される型を対象とする。最初期口承、成立年代、武器・殺害意図等は必須化しない。

# 2. 分析概念次元

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U`

**判定根拠**

1996年採録と1990年代流行の後代整理は確認できるが、成立時期を独立に限定するHistory Evidenceはない。流通確認を生成年代へ変換しない。

**この伝承における現れ方**

1996年までには採録されているが、いつ成立したかは現在のEvidenceから特定できない。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Child / Value: `D02.PRT.BOOK` — 書籍
- Primary Parent: `D02.PRT`
- Secondary: なし
- Status: `I`

**判定根拠**

1996年刊『走るお婆さん―日本の現代伝説』の目次に「ベッドの下に」の収録を確認できる。ただし本文未実見のため、当該伝承の提示内容までDirectとはしない。

**この伝承における現れ方**

現在固定できる早い確認点は現代伝説集への収録である。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Secondary: `D03.NET.WEB_ARTICLE` — Web記事
- Status: `I`

**判定根拠**

書籍収録は目次で、後代Web記事上の再話・整理は本文で確認できる。初期口承媒体は固定しない。

**この伝承における現れ方**

現代伝説集に採録され、後代にはWeb記事で複数異伝が再提示される。

実話らしさの程度は異伝・媒体ごとに異なる可能性があり、現Evidenceでは一意に決められない。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ICT.STRANGER_THREAT` — 見知らぬ他者の脅威
- Primary Parent: `D07.ICT`
- Secondary: `D07.ICT.ABDUCTION_ASSAULT` — 誘拐・暴行
- Status: `I`

**判定根拠**

00では、私的空間内に未知の侵入者が潜伏し、居住者・宿泊者がそれを知らないまま同室する型が確認される。

**この伝承における現れ方**

安全と想定される私室の内部に、見知らぬ人間による脅威が存在する。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.TRC.PHYSICAL_TRACE` — 物的痕跡
- Primary Parent: `D08.TRC`
- Secondary: なし
- Status: `I`

**判定根拠**

後代二次資料で、違和感・手掛かりを介して潜伏者を察知する型が確認される。具体的手掛かりは異伝差がある。

**この伝承における現れ方**

通常なら見過ごす室内の違和感が、侵入者存在の手掛かりへ変わる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.AGN.AGENCY_ATTRIBUTION` — 主体化
- Primary Parent: `D09.AGN`
- Secondary: なし
- Status: `I`

**判定根拠**

室内の異常・違和感を、人間侵入者という意図主体の存在へ帰属する。

**この伝承における現れ方**

曖昧な異変が「誰かが室内にいる」という具体的な脅威へ再分類される。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: `D10.HUM.INDIVIDUAL_HUMAN` — 個人
- Primary Parent: `D10.HUM`

原因主体は超自然存在ではなく、室内へ侵入し潜伏する人間として描かれる。

**この伝承における現れ方**

怪異の説明に人間侵入者を置く。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.CON.LOCATION_STATE` — 特定場所・状態にいる
- Primary Parent: `D11.CON`
- Secondary: なし
- Status: `I`

**判定根拠**

観察可能な入口は、侵入者が先に私的空間へ潜伏しており、居住者・宿泊者がその空間へ入る状態である。加害者側の「選択」はEvidenceから補わない。

**この伝承における現れ方**

危険人物がすでに潜伏する空間へ本人が入ることで因果系へ入る。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.OTH.VICTIM_TARGET` — 被害者・標的
- Primary Parent: `D12.OTH`
- Secondary: なし
- Status: `I`

**判定根拠**

潜伏者と同室する居住者・宿泊者が潜在的な被害対象となる。

**この伝承における現れ方**

本人は危険を知らないまま作用対象となっている。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: なし — **taxonomy gap: 物理的な潜伏・待ち伏せ**
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

00で中心的に確認される作用は、侵入者がベッド下等へ物理的に隠れ、対象と至近距離で同室し続けること。現行D13 taxonomyにはこの「潜伏・待ち伏せ」を直接表すChildがない。`TARGETING` 等へ意味拡張して押し込まない。

**この伝承における現れ方**

侵入者は見えない位置で待機し、対象が危険を認識しない状態を維持する。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEG` — 負
- Primary Parent: なし
- Secondary: なし
- Status: `I`

**判定根拠**

潜伏・侵入という中心作用は脅威であり、退避成功を中心因果の正帰結へ置き換えない。

**この伝承における現れ方**

実害が未遂でも、侵入・潜伏は負の危険として描かれる。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.BEH.AVOIDANCE_ROUTE_CHANGE` — 回避・経路変更
- Primary Parent: `D15.BEH`
- Secondary: `D15.KNW.REVELATION_KNOWLEDGE` — 真相・知識獲得
- Status: `I`

**判定根拠**

確認できる退避型では、本人が室外へ移動し、後から侵入者の存在を知る。未実現の殺害・傷害は帰結にしない。

**この伝承における現れ方**

室内に留まる行動から退避へ切り替わり、侵入者確認によって危険が確定する。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

- Primary Child / Value: `D16.EVT.SEQUENTIAL_EPISODE` — エピソード内段階進行
- Primary Parent: `D16.EVT`
- Secondary: なし
- Status: `I`

**判定根拠**

先行潜伏→入室→察知→退避→確認という段階進行が一つのエピソード内で構成される。

**この伝承における現れ方**

侵入者の存在が後から段階的に明らかになる。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.AVO.FLEE_ESCAPE` — 逃走
- Primary Parent: `D17.AVO`
- Secondary: `D17.RIT.LEGAL_OFFICIAL` — 公的・法的介入
- Status: `I`

**判定根拠**

後代資料で、危険察知後に室外へ退避し、警察等へ救援・確認を求める型が確認される。受容者一般への防犯教訓はEvidenceから推論しない。

**この伝承における現れ方**

直接対峙せず距離を取り、公的主体へ処理を移す。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- `D18.L1`: `1`
- `D18.L2`: `0`
- `D18.L3`: `0`
- Status: `I`

**判定根拠**

物語内部の侵入者・対象間の作用は確認できる。一方、受容行為自体が作用条件となるEvidenceや、流通が社会現実を変えた独立X Evidenceは固定していない。不在を含むvector全体はIndirectとする。

**この伝承における現れ方**

確認できる因果作用は物語内部にある。

## 2.4. 社会的埋め込みの次元
