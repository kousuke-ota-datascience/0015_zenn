## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ICT.STRANGER_THREAT` — 見知らぬ他者の脅威
- Primary Parent: `D07.ICT` — 対人・犯罪脅威
- Secondary: `D07.ICT.ABDUCTION_ASSAULT` — 誘拐・暴行
- Status: `D` — Direct（私室内の見知らぬ侵入者が共有核）

**判定根拠**

伝承が問題化するのは、安全なはずの私室へ見知らぬ人間がすでに侵入し、意図不明のまま至近距離に潜伏できるという脅威である。刃物・殺害意図等を強調する異伝では暴行危険がさらに前面化する。

**この伝承における現れ方**

「危険は外にある」という境界が崩れ、「もう家の中に知らない人がいる」という形で他者脅威が最も私的な領域へ入り込む。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: `D08.STY.FOAF_REPORT` — 近接伝聞
- Primary Parent: `D08.STY` — 社会的証言
- Secondary: なし
- Status: `D` — Direct（FOAF証言が危険認識の手掛かり）

**判定根拠**

受容者にとって、ベッド下の死角が危険として問題化される契機は、統計的防犯情報ではなく「知人の周辺で実際にあった」という体験報告である。

**この伝承における現れ方**

「実際に知り合いの部屋で男が見つかったらしい」という証言形式が、普段は無視する家具下の空間を危険な場所として再認識させる。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.CAU.HIDDEN_CAUSE` — 隠れた原因化
- Primary Parent: `D09.CAU` — 原因帰属
- Secondary: `D09.AGN.AGENCY_ATTRIBUTION` — 主体化
- Status: `I` — Inferred（違和感を潜伏者へ帰属させる構造から判定）

**判定根拠**

鏡、物の位置、気配等の曖昧な違和感を、「ベッド下に侵入者が潜んでいる」という見えない人間主体で説明する。単に「ベッド下の男」と名付けることより、目に見えない危険の原因を具体的人間へ帰属させる操作が中心である。

**この伝承における現れ方**

小さな異変は偶然として放置されず、「誰かがすでに室内にいる」ことの兆候へ変換される。警察等による発見が、その隠れた原因モデルを物語内で確定する。

**この伝承における現れ方**

普通の人間が生活空間の隙を利用して、居住者の認識外で数十センチの距離まで接近できるという現実的悪意が因果源になる。

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.MOV.ENTER_PASS_CROSS` — 入る・通る・越える
- Primary Parent: `D11.MOV` — 移動・空間進入
- Secondary: なし
- Status: `D` — Direct（主人公の入室により潜伏者と同一空間になる）

**判定根拠**

主人公は侵入者と会話・交流して因果系へ入るのではない。侵入者が先に潜伏している私室へ、主人公が安全だと思って入室することで同一空間・襲撃可能距離へ入る。

**この伝承における現れ方**

帰宅・ホテル入室という日常的移動が、そのまま知らない人間との危険な共在状態への境界通過になる。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.OTH.VICTIM_TARGET` — 特定被害者
- Primary Parent: `D12.OTH` — 他者個人
- Secondary: なし
- Status: `D` — Direct（居住者・宿泊者が潜在的襲撃対象）

**判定根拠**

侵入者から見た作用対象は、自室へ戻ってきた居住者・宿泊者である。物語の焦点人物であるだけでなく、潜伏・待機の対象にされる潜在的被害者として位置付けられる。

**この伝承における現れ方**

主人公は知らないまま侵入者の至近距離に入り、「あと少し室内に留まれば襲われていた」と示唆される対象になる。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.REL.TARGETING` — 標的化
- Primary Parent: `D13.REL` — 追跡・対象関係操作
- Secondary: `D13.PHY.PHYSICAL_ATTACK` — 物理攻撃
- Status: `I` — Inferred（潜伏待機を共有核、実攻撃を異伝・暗示として分離）

**判定根拠**

共有核では、侵入者は主人公が戻る前から死角に潜伏し、主人公を襲撃可能な対象として待つ。実際の物理攻撃は発見・退避によって回避される型が多く、刃物や殺害意図は異伝で強化されるためSecondaryとする。

**この伝承における現れ方**

侵入者は無差別な環境異常ではなく、居住者が戻る空間に隠れて機会を待つ人間として描かれる。恐怖は「すでに自分が標的になっていた」という事後的認識にある。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.MIX` — 混合
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct（負の脅威と危険回避が重要帰結として併存）

**判定根拠**

物語の重要な負の要素は侵入・潜伏・襲撃可能性である一方、代表形の明示的終端では主人公が退避し、警察等が侵入者を発見して危険を回避する。負の危険と正の回避が双方とも物語上重要であるため `MIX` とする。

**この伝承における現れ方**

「もう襲われる寸前だった」という恐怖と、「違和感に気づき一人で確認しなかったため助かった」という救済が同じ結末に組み込まれる。

**この伝承における現れ方**

主人公は侵入者と直接対決せず室外へ逃れ、警察等の第三者による確認で襲撃を免れる。危険が現実化する直前に回避されることが終端を形成する。

### 2.3.6. D16: 因果時間構造

生存の鍵は侵入者を自力で捕まえることではなく、接触を避けて安全圏へ移り、公的主体へ処理を委ねることに置かれる。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: なし
- Status: `D` — Direct（現代伝説集で広域型として採録）

**判定根拠**

日本の現代伝説集に代表的犯罪不安型として採録され、特定地域に固定されない。自宅・ホテル等の舞台を差し替えて広域に再話できる。

**この伝承における現れ方**

ベッドと私室という一般的生活空間があれば地域を問わず成立し、一人暮らし・宿泊者等の広い受容者層へ再配置される。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: `D20.ORG.PERPETRATOR_CRIMINAL` — 加害者・犯罪者
- Primary Parent: `D20.ORG` — 組織・加害主体
- Secondary: なし

**判定根拠**

主人公が知らない侵入状況・潜伏意図を把握しているのは侵入者自身である。友人や警察が途中で存在を発見しても、侵入経路や最初の意図まで完全に共有するとは限らない。

**この伝承における現れ方**

侵入者だけが「自分がベッド下にいる」「何を待っているか」を知り、主人公はその情報非対称性の中で日常行動を続ける。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし
- Status: `D` — Direct（一般的住居・ホテル・警察背景に依存）

**判定根拠**

寝室、ホテル客室、住居侵入、警察等の現実的背景を使うが、特定の検証済み事件・場所へ固定されない。現実に可能な犯罪であることと、個別FOAFの事実性は分離する。

**この伝承における現れ方**

超自然要素なしに、誰の部屋でも成立し得る生活空間と犯罪リスクだけで本当らしさを作る一方、固有地点や実事件への依存は弱い。
