# 1. 伝承内容

## 1.1. 2005年6月6日 初回体験談の中核

投稿者Aは友人M・Mの恋人Kと自宅におり、遅れて来る友人Sを待っていた。Sは自宅の納屋の整理中に、パズルのように木片を組み合わせた小箱を見つけ、それを持参する。

Sの車が敷地へ入った段階で、代々神職を務める家の出身で霊感が強いとされるMが激しく動揺し、箱を見た後に嘔吐する。Mは父へ電話し、箱を「コトリバコ」、形を「シッポウ」と呼び、祖父のようには処理できないと恐怖を示す。

Mは父の電話指示を受けながら、自分の指・手を傷つけ、Sへ自分の血を飲ませ、祝詞様の文言を唱え、箱に手を置いて処置を行う。その後、Mは箱から手を離さないようにし、父の帰宅後に安置したと説明される。

約8日後、MはAへ、Sの地域にはこの種のものがある、箱の中身は「怨念そのもの」で、多数の指先や臍の緒が入っている、祖父の代までこうした箱を処理していた、と語る。ただし詳細については「知らない方がよい」として説明を止める。

Aがこの話を掲示板へ書いてよいか確認すると、Mは話しただけで呪いが取り憑くわけではない旨を答える。したがって、**初回投稿には「この話を読む／聞くこと自体で呪われる」という読者感染規則は存在しない。**

## 1.2. 初回投稿で直接確認できる主要要素

- 20cm四方程度とされる組木状の木箱。
- S家の納屋から発見され、SがA宅へ持ち込む。
- Mは箱が到着する前後から強い身体反応・恐怖を示す。
- M家は代々神職を担う家として提示され、父・祖父が箱の処理知識を持つ。
- 「コトリバコ」「シッポウ」という名称がMの発話として現れる。
- Mは儀式的・宗教的な処置でSと箱へ介入する。
- 箱内部について、指先・臍の緒・怨念という説明が与えられる。
- 投稿者は出来事を一人称回想として提示するが、霊的実在の判定自体は読者へ開く。

## 1.3. 2005年6月6日以降の即時増補

初回投稿後、専用スレッドと続編投稿が形成される。2005年6月11日の民俗・神話学板スレッドの冒頭では、初回体験談後に投稿者がMとともにS家へ赴き「真相」を聞き出したという展開が既に要約されている。

この早期増補では、次の設定が体系化される。

- 「コトリバコ」＝「子取り箱」という解釈。
- 箱は抑圧された集団が報復の武器として作ったとする由来。
- 箱を複数世代にわたり秘密管理したという設定。
- 女性・子どもを主な呪いの対象とする設定。
- 犠牲数等に応じたイッポウ、ニホウ等の等級と、最上位級としてのハッカイ。
- 1868年の隠岐騒動と箱の製法伝来を結びつける説明。

ただし、これらすべてが6月6日レス912〜919の初回体験談に存在したわけではない。**初回の「危険な箱との遭遇」から、数日間の投稿・調査・参加者応答によって由来体系・等級体系・歴史接続が増補された**と扱う。

## 1.4. 史実と怪談設定の分離

### 史実として独立確認できるもの
- 1868年に隠岐騒動が起きた。
- 隠岐島後で島民が武装蜂起し、一時的な自治政権を樹立した。

### 怪談内部でのみ確認される接続
- 隠岐騒動関係者が本土へ逃れ、箱の製法を伝えた。
- その製法が特定集落で報復用の呪物として利用された。
- 箱が100年以上にわたり秘密管理された。

上記の怪談内接続を、実在地域・実在集団の史実として扱ってはならない。

## 1.6. 因果・危害・対処

### 因果入口
初回体験談では、Sが納屋で見つけた箱を持ち出しA宅へ運ぶことが、具体的な遭遇の入口となる。箱を開けることは必須条件として確認できない。

### 危害
初回ではSに何らかの異常が及んでいるとMが判断し、緊急処置を行う。早期増補では、箱が女性・子どもへ重篤な病変・死亡を与える呪物として体系化される。

### 対処
- Mが父へ連絡する。
- 神職家系に伝わるとされる儀式的処置を行う。
- 箱を安置・管理し、後に専門知識を持つ家系で処理する。

したがって、危険対象から単に逃げる話ではなく、**専門家系による識別・儀式・管理**が制御モデルに組み込まれている。

# 4. Evidence上の結論

コトリバコは、現時点の証拠では**2005年6月の2ちゃんねる上で直接確認できるネット怪談**として扱うのが最も保守的である。初回遭遇譚は6月6日に確認でき、数日以内に専用スレッド・続編・民俗考察を通じて由来体系が急速に増補された。
