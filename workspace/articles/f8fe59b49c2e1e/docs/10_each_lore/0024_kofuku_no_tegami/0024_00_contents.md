# 1. 伝承内容

## 1.1. summary

「幸福の手紙」は、受信者に対し、同一またはほぼ同一の文面を一定数複製し、定められた期限内に他者へ送れば、受信者自身に幸運・成功・幸福等が訪れると告げるチェーンレターである。受信者は単なる読み手ではなく、指示に従うことで次の送信者となり、同じ規則を新しい受信者へ再生産する。

1922年の日本流行を扱う研究では、一定枚数の葉書へ文面を書き写して送ること、一定期間後の幸運、連鎖を断った場合の悪運が一つの文面に結び付いている。1951年国会会議録でも、受取後3日以内に友人3名へ同文を送れば幸運、送らなければ災難という例が明示される。したがって、日本で早くから確認できる型は、純粋な報酬だけでなく、**転送による報酬と不転送による制裁を併記する混合型**を含む。

本Entryでは、「幸福・幸運を得ること」が受信者を転送へ向かわせる主要な誘因として前景化する系統を扱う。不転送時の恐怖・災厄を主誘因とする後代の「不幸の手紙」は近縁だが別Entryとして管理する。

中心構造は、偶然で制御しにくい将来の吉凶を「同文を規定人数へ転送する」という再現可能な行為へ接続し、その行為を行った受信者自身に帰結が返るという循環である。さらに、転送行為それ自体が次の受信者を作るため、伝承の因果規則と伝播機構が同一行為に重なる。

## 1.2. 詳細展開

1. **受信:** 手紙・葉書等が受信者へ届く。
2. **由緒・権威付与:** 文面に発祥、世界を巡った履歴、過去例等が付く型がある。
3. **指示:** 一定人数・部数へ、一定期限内に同文を複写・送付するよう求める。
4. **報酬:** 指示に従えば幸運・成功等が訪れるとされる。
5. **制裁:** 混合型では、連鎖を止めると悪運・災難が訪れるとされる。
6. **転送:** 受信者が他者へ送り、自身が次段階の送信者になる。
7. **再帰:** 新しい受信者にも同じ規則が適用され、チェーンが継続する。

## 1.3. 登場主体

| 主体 | 役割 |
|---|---|
| 受信者 | 文面を受け取り、転送するかを選ぶ。転送時には次の送信者になる |
| 前段階の送信者 | 同文を複製・送信する。個別人物は通常重要でない |
| 次の受信者 | 同じ規則へ新たに組み込まれる |
| 手紙／葉書 | 転送指示、報酬、場合により制裁を保持する情報媒体 |

## 1.4. 場所・空間

特定聖地を必要とせず、郵便・通信ネットワークそのものが伝播空間となる。地理的位置より、送信者と受信者を接続する通信回路が重要である。

## 1.5. 物・記号・媒体

- 手紙・葉書: 1920年代および1951年資料で確認できる物理媒体。
- 複製文面: 同一規則を再生産する情報内容。
- 人数・部数・期限: 行為条件を定量化する規則。
- 電子メール・SNS等: 後代には同じ自己複製構造がデジタル通信へ移植され得るが、初期郵便型へ遡及しない。

## 1.6. 条件・規則・禁忌

- 条件: 幸運／災難と転送条件を記した文面を受信する。
- 規則: 指定された期間内に、指定人数・部数へ同文を複製・転送する。
- 禁忌: 混合型では、連鎖を止める、期限を破る等が悪運・災難と結び付く。
- 制御・利用: 伝承内部では転送を実行することが、幸運獲得および場合によっては災難回避の手段となる。

## 1.7. 異常・不可解な現象／中心命題

**同一文面を規定どおり他者へ転送する行為が、送った本人の将来の幸運を生み、連鎖を止めた場合には悪運を生み得る**という因果主張である。

郵便行為と運勢の間に通常確認できない因果を設定し、その不確実な将来を具体的な反復行為で制御可能なものとして提示する。

## 1.8. 行動・対応

- 文面を読み、転送条件を確認する。
- 指示に従う場合、同文を複製して他者へ送る。
- 現実には無視・廃棄も可能だが、伝承内部では混合型の制裁主張と衝突する。
- 1951年には、この種の郵便が郵便制度・通信の自由との関係で国会審議に現れている。

## 1.9. 帰結・終端状態

- Positive: 転送者へ幸運・成功等が訪れるとされる。
- Negative: 混合型では、不転送者へ悪運・災難が訪れるとされる。
- Propagation: 転送によって新しい受信者が作られ、伝承自体が増殖する。
- Evidence上、吉凶の超常因果が現実に成立することは確認されない。

## 1.10. 未解決点・不確実性

- 1922年は現在追跡できる古い日本流行層であり、伝承の世界的・日本的な絶対起源年とは限らない。
- 1922年新聞原紙は今回直接閲覧しておらず、丸山2012による資料提示を介して確認している。
- 「純幸福型」と「報酬＋制裁型」の境界は文面ごとに異なる。
- 不転送時の制裁が主誘因となる型は0025「不幸の手紙」と区別する。
- 後代デジタル型を1922年形へ遡及させない。

# 2. 伝承史・異伝

## 2.1. 最古確認

現時点で日本について追跡できる古い層は、丸山2012が資料化する**1922年の「幸運の手紙／幸運の葉書」流行**である。1922年1月27日付『東京朝日新聞』掲載の葉書では、複写枚数・期限・幸運・連鎖断絶時の悪運を組み合わせた構造が確認されると研究上整理されている。

これは「日本で1922年に新規創作された」ことを意味しない。海外先行例や翻訳・移入可能性があり、絶対起源は別問題として保留する。

1951年3月26日の国会会議録は、「幸運の手紙」という名称、同文転送、幸運／災難条件を直接記録しており、戦後にも同じ構造が社会的に認識されていたことを示す。

## 2.2. 流通・拡散

- 1922年: 東京の新聞資料で「幸運の手紙／葉書」の流行層が研究上確認される。
- 1925年等: 丸山2012は再流行資料を追跡している。
- 1951年: 国会審議で具体的な転送規則を伴う「幸運の手紙」が例示される。
- 後代: 郵便チェーンレターとして反復し、電子通信にも構造が移植される。

## 2.3. 主要な異伝・派生

| 型 | 差異 |
|---|---|
| 報酬中心型 | 転送後の幸運を前景化する |
| 報酬＋制裁型 | 幸運に加え、連鎖断絶時の悪運・災難を付加する。1922・1951資料で確認可能 |
| 由緒型 | 海外起源・長い伝播履歴等を権威付与に用いる |
| デジタル型 | 郵便から電子メール・Web・SNS等へ媒体を置換する |
| 不幸の手紙 | 不転送時の制裁を主誘因とする近縁Entry（0025） |

## 2.4. 変容上の重要点

枚数、期限、由緒、幸運の内容、制裁の強さ、通信媒体は変化し得る。一方、**受信者に同文転送を命じ、その行為を受信者自身の吉凶へ結び付ける自己複製因果**が安定した核となる。
