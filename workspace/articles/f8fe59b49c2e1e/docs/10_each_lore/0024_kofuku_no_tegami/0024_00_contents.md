# 0. INTRODUCTION

## 0.1. 文書の役割

**伝承名:** 幸福の手紙

本文書は、一定数の複製・転送を指示し、従えば幸福・幸運が得られるとする「幸福の手紙」について、伝承内容・流通史・異伝・証拠上の不確実性を記録する Evidence / Content layer である。分析コードは `0024_10_analysis.md` に分離する。

パイロット Evidence Rank は `B`。増補調査により、日本では少なくとも1922年の「幸運の手紙／幸運の葉書」流行を扱う研究、1951年国会会議録における「幸運の手紙」への言及を確認した。したがって「戦後に成立した」という単純な理解は採らない。

## 0.3. 証拠上の区別

1. **幸福型の核:** 転送すれば幸運が来る。
2. **混合型:** 転送しなければ不幸になるという脅しも併記する。
3. **不幸の手紙:** 不転送時の災厄を中心にする近縁だが別Entryとして管理する。
4. **媒体:** 郵便・葉書・電子メール・SNS等は交換可能で、複製指示という自己伝播構造が安定する。
5. **起源:** 日本で1922年頃の流行を確認できるが、海外のLucky Chain等との系譜を含む「実際の起源」と日本最古確認を同一視しない。

# 1. 伝承内容

## 1.1. summary

「幸福の手紙」は、受信者へ「この文章を一定数複製し、指定された期間内に別の人へ送れば幸運・成功・幸福が訪れる」と指示するチェーンレターである。受信者は単なる読者ではなく、文面を保存・複製して次の受信者へ渡す伝播装置の一部になる。文面自身が自己複製の手順と動機を内包している点が中心的特徴である。

代表形では、手紙が何らかの由緒・過去の成功例・世界を巡ってきた履歴を語り、一定人数への転送を求める。受信者が指示に従えば金運・仕事・家庭・願望成就等の正の結果が得られるとする。一方、古い幸運の手紙の中にも連鎖を止めた者への「大悪運」など負の警告を含む型があり、幸福型と不幸型は完全に切断された二系統ではなく、報酬と制裁の比重が異なる連続体として現れる。

日本では、国立歴史民俗博物館の研究により1920年代の「幸運の手紙／幸運の葉書」が検討されており、1951年の国会会議録でも郵便制度上の問題例として「幸運の手紙等」が名指しされている。したがって、戦後の少年少女文化だけに限定されない、長期のチェーン通信現象である。

媒体が郵便からFAX、電子メール、SNSへ変化しても、「受信→一定人数へ複製→次の受信者にも同じ指示→連鎖継続」という因果構造は保持される。デジタル化により複製・一斉送信コストが低下すると、物理的な手紙という形を失っても同型のメッセージが継続する。

この伝承が意味形成するのは、偶然に訪れる幸運を、**情報伝播という自分で実行可能な操作へ結び付けること**である。未来の吉凶という制御困難な領域に対し、「送る」という簡単な行動で正の結果を得られるというルールを与える。そのルールを信じること自体が、情報を現実に複製・拡散させる。

## 1.2. 論理構造

1. **受信:** 手紙・メッセージが届く。
2. **権威付与:** 来歴・成功例・由緒等が示される場合がある。
3. **指示:** 指定人数・部数・期限内で複製するよう命じる。
4. **報酬:** 従えば幸福・幸運が得られるとされる。
5. **制裁（混合型）:** 止めれば不幸になるとされる。
6. **転送:** 受信者が次の受信者へ送る。
7. **再帰:** 次の受信者が同じ選択を迫られる。

## 1.3. 主体

| 主体 | 役割 |
|---|---|
| 受信者 | 規則を読んで転送するか選ぶ |
| 送信者 | 前段階の受信者であり、連鎖を維持する |
| 次の受信者 | 新たに同じ規則へ組み込まれる |
| 手紙／メッセージ | 指示・報酬・制裁を自己記述する情報主体的媒体 |

## 1.4. 空間

特定地点ではなく郵便網・通信網が作用空間。物理距離を越えて同じ文面が移動することが成立条件になる。

## 1.5. 物・記号・媒体

- 葉書・手紙: 古典的物理媒体。
- 複製文面: 伝承の意味形成核を保持。
- 人数・部数・期限: 行動を定量化する規則。
- 電子メール・SNS: 後代の低コスト複製媒体。

## 1.6. 条件・規則

- 受信後、一定人数へ送る。
- 期限・部数を守る型が多い。
- 文面を変更しないことを求める型もある。
- 混合型では不転送が禁忌化される。

## 1.7. 中心命題

情報を規定どおり他者へ伝播する行為が、受信者自身の将来の幸運を生む。

## 1.8. 行動・対応

複製・転送する、無視する、廃棄する。受信者の選択が同時にチェーンの存続可否を決める。

## 1.9. 帰結

- 幸運・成功・幸福。
- 混合型では不転送時の不幸。
- 現実レベルでは、転送行動そのものが情報拡散を生む。

## 1.10. 不確実性

- 「幸福の手紙」の文面は単一ではない。
- 1922年の日本流行と海外先行例の具体的伝播経路は別途資料検証が必要。
- 幸福のみの型と脅迫型を混成しない。
- デジタル版を1920年代の文面へ遡及させない。

# 2. 伝承史・異伝

## 2.1. 最古確認

研究史上、日本では1922年頃の「幸運の手紙／幸運の葉書」流行が確認される。したがって、パイロットの「1945–1969」成立判定より古い確認資料が存在する。コードは本作業では変更せず、分析文書で再検討候補とする。

## 2.2. 流通

- 1920年代: 郵便・葉書による幸運チェーン。
- 1951年: 国会審議で社会問題的郵便の例として言及。
- 戦後後半: 少年少女・一般郵便のチェーンレターとして継続。
- 電子化後: 電子メール、掲示板、SNSへ移行。

## 2.3. 異伝

| 型 | 特徴 |
|---|---|
| 純幸福型 | 転送による正の報酬を前面化 |
| 報酬＋制裁型 | 幸運と不転送時の不幸を併記 |
| 由緒型 | 宗教・著名人・海外由来等の権威を付加 |
| デジタル型 | メール・SNSで複製指示を維持 |

## 2.4. 変容上の重要点

媒体・語彙・報酬内容が変わっても、**受信者を次の送信者へ変える自己複製命令**が保持される。
