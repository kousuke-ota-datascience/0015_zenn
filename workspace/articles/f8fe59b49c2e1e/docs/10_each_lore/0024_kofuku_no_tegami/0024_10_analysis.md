# 2. 分析概念次元

## 2.1. 来歴・流通・提示

### D01 生成年代
- Value: `D01.G2` — 1945–1969
- Status: `I`
**判定根拠:** 既存Pilot Codingを保持する。
**現れ方:** 戦後の郵便チェーンレターとして長く流通したというPilot理解に基づく。
**境界・留保:** 増補調査で1922年頃の日本の「幸運の手紙／幸運の葉書」を扱う研究、および1951年国会会議録を確認した。少なくとも日本での確認流通は1945年以前へ遡るため、D01は明示的再コーディングが必要な強い候補である。

### D02 最古確認流通媒体
- Primary: `D02.PRT.CHAIN_LETTER` — チェーンレター
- Parent: `D02.PRT`
- Status: `D`
**判定根拠:** 1920年代の日本流行は郵便・葉書として研究され、1951年公的記録でも郵便上の「幸運の手紙」として扱われる。
**現れ方:** 文面そのものが郵送され、受信者が複製して別の宛先へ送る物理的書簡ネットワークが最古層の確認可能な流通形態になる。

### D03 確認流通媒体ポートフォリオ
- Primary: `D03.PRT.CHAIN_LETTER`
- Parent: `D03.PRT`
- Status: `D`
**判定根拠:** Pilot Version Scopeは古典的な郵便チェーンを中心とする。
**現れ方:** 手紙・葉書の複製行為が伝承内容そのものと流通媒体を一致させる。
**留保:** 旧末尾メモ `D03:U` と本文コードは矛盾するため、Excel正本の値を確認する必要がある。

### D04 生成・変容パターン
- Primary: `D04.STB.STABILIZED_CANON`
- Parent: `D04.STB`
- Status: `I`
**判定根拠:** 媒体・人数・報酬は変わっても、一定人数へ複製し連鎖を続ける核が安定する。
**現れ方:** 郵便からメール・SNSへ移っても「受信者を次の送信者へ変える」自己複製規則が維持される。

### D05 提示形式
- Primary: `D05.RUL.CHAIN_INSTRUCTION`
- Parent: `D05.RUL`
- Status: `D`
**判定根拠:** 文面が受信者へ転送人数・期限等を直接指示する。
**現れ方:** 伝承は物語を読むだけで完結せず、「あなたもこの情報を送れ」という行動命令を内蔵する。

### D06 真実性提示
- Value: `D06.T6` — 真偽未確定
- Status: `I`
**判定根拠:** 幸運発生の因果は検証されない一方、過去の成功例・由緒等を添えて本当らしさを補強する型がある。
**現れ方:** 受信者は「本当に効くか分からないが、無視するより送った方が安全／得かもしれない」と判断し得る。

## 2.2. 意味形成

### D07 意味形成対象
- Primary/Secondary: なし
- Status: `U`
**判定根拠:** Pilotは、何を「不可解な対象」とするかを一意に固定していない。
**現れ方:** 候補としては将来の吉凶、偶然の幸運、あるいは情報と運命の不可解な接続があるが、現行コードでは確定しない。
**境界・留保:** 高密度化により「制御困難な将来の幸運」が意味形成対象と読めるため、再コーディング候補。

### D08 意味形成契機
- Primary: `D08.CLM.UNSUPPORTED_ASSERTION`
- Parent: `D08.CLM`
- Status: `I`
**判定根拠:** 「送れば幸運になる」という因果主張が証拠より先に提示される。
**現れ方:** 受信者は既存の幸運体験を説明するのではなく、先に規則を渡され、未来の結果をその規則に賭ける。

### D09 意味付与操作
- Primary: `D09.CAT.NAMING`
- Parent: `D09.CAT`
- Status: `I`
**判定根拠:** Pilot Codingを保持。
**現れ方:** 「幸福の手紙」という名称により、複製指示と幸運報酬を持つ情報群が一カテゴリとして認識される。
**境界・留保:** 実質的には「幸運を転送行動へ因果接続する規則形成」が中心であり、命名をPrimaryとする妥当性は再検討余地がある。

### D10 因果源存在論
- Primary: `D10.OBJ.INFORMATION_CONTENT`
- Parent: `D10.OBJ`
- Status: `I`
**判定根拠:** 超自然人格ではなく、手紙に記された規則・情報内容が幸運を媒介するとされる。
**現れ方:** 同じ文面を保存・複製することに意味があり、情報内容自体が因果効力を持つように扱われる。

## 2.3. 因果・行動モデル

### D11 発動・接触条件
- Primary: `D11.INF.READ_VIEW_MEDIA`
- Parent: `D11.INF`
- Status: `D`
**判定根拠:** 受信・読解によって転送規則と幸運条件を知る。
**現れ方:** 手紙を読むと、受信者はチェーンを続けるか止めるかの選択へ組み込まれる。

### D12 作用対象
- Primary: `D12.AUD.READER_LISTENER`
- Parent: `D12.AUD`
- Secondary: `D12.AUD.NEXT_RECIPIENT`
- Secondary Parent: `D12.AUD`
- Status: `D`
**判定根拠:** 現受信者だけでなく、転送によって次の受信者も同じ規則へ入る。
**現れ方:** 作用対象が世代的に増殖し、各受信者が同時に次の送信者になる。

### D13 作用機構
- Primary: `D13.TRN.PERSON_TRANSFER`
- Parent: `D13.TRN`
- Secondary: `D13.FAT.LUCK_BENEFIT`
- Secondary Parent: `D13.FAT`
- Status: `D`
**判定根拠:** 人から人への転送と、従った者への幸運付与が文面の明示的機構。
**現れ方:** 情報伝播という現実行動と、運命変化という伝承内効果が一つの規則で接続される。

### D14 帰結極性
- Value: `D14.POS`
- Status: `I`
**判定根拠:** Entry名・中心Versionでは幸福・幸運が主報酬。
**現れ方:** 転送を促すインセンティブは正の期待である。
**境界・留保:** 不転送時の不幸を含む混合型ではMIXになり得る。Version Scope依存。

### D15 帰結領域
- Primary: `D15.OPP.LUCK_MISFORTUNE`
- Parent: `D15.OPP`
- Status: `I`
**判定根拠:** 最終的に変化するとされるのは運勢・成功・幸福。
**現れ方:** 身体作用ではなく、将来の機会・吉凶が転送行動に反応するとされる。

### D16 因果時間構造
- Primary: `D16.TRN.CHAIN_SPREAD`
- Parent: `D16.TRN`
- Status: `D`
**判定根拠:** 一人の行為で終了せず、受信者から次の受信者へ世代的に連鎖する。
**現れ方:** 同じ規則が各ノードで再実行される再帰構造を持つ。

### D17 回避・制御方式
- Primary: `D17.CST.TRANSFER_SUBSTITUTE`
- Parent: `D17.CST`
- Status: `D`
**判定根拠:** 自分に与えられた条件を次の人へ転送することが幸運獲得／不運回避の操作になる。
**現れ方:** 受信者は情報を保持して解決するのではなく、他者へ渡すことで自分の帰結を制御する。

### D18 作用レイヤー
- L1: `1`; L2: `1`; L3: `0`
- Status: `I`
**判定根拠:** L1では転送により幸運が生じる。L2では受容者が実際に複製・転送する行動を取るため伝承外の受容者行動にも作用する。
**現れ方:** 信念内容そのものが自己複製を現実化し、受信者を媒介者へ変える。
**境界・留保:** 1920年代・1951年の社会問題化を踏まえるとL3再評価余地があるが、既存値は変更しない。
