# 1. 伝承内容

## 1.1. summary

新郷村の「キリストの墓」は、イエス・キリストの生涯について、一般的なキリスト教史とは異なる経路を提示する伝承である。地域側資料が記す形では、キリストは磔刑で死亡せず、弟イスキリが身代わりとなる。その後キリスト本人は日本へ渡り、現在の青森県新郷村戸来に住み、生涯を終えたとされる。村内の塚がキリストの墓、隣接する塚が弟イスキリに関係する墓として提示される。

現在追跡できる伝承史上の定点として、新郷村公式は、竹内家に伝わる古文書からこの仮説が出たのを1935年と説明し、竹内氏が新郷村を訪れて「キリストの墓」を発見したと記す。2001年の地域側資料も、竹内文書に記されたとされるキリストの再渡来・戸来居住・死亡と、1935年の現地比定を結び付けている。ただし竹内文書原資料と1935年同時代記録は今回直接固定していないため、これらは後代の地域側説明を通じたHistory / Content Evidenceである。

現地の塚、キリストの里伝承館、キリスト祭等は現実に存在する。現在の新郷村公式は「キリストの墓と弟のイスキリの墓であるかは判断を預ける」とし、伝承館でも原著・報道等を展示しながら受容者自身の判断へ委ねる提示を行う。したがって、伝承内容の存在、墓・祭礼・展示の存在と、古代の歴史主張が事実であることは区別する。

## 1.2. 詳細展開

### 1.2.1. 磔刑と身代わり

地域側の2001年資料では、ユダヤでキリストが捕らえられた後、十字架に上ったのは弟イスキリだったとする。これは竹内文書に書かれていたとされる伝承内容として記録されている。

### 1.2.2. 日本への再渡来

同資料では、キリスト本人は弟子らと移動し、各地を経て日本へ戻ったとされる。経路・年齢等の細部は資料差があり、本Entryの共有核として細部まで固定しない。

### 1.2.3. 戸来での居住と生涯の終端

キリストは現在の新郷村戸来に住居を定め、そこで長い生涯を終えたとされる。地域側資料には結婚・子孫等の追加情報もあるが、共有核では「戸来に定住し、そこで没した」までを主要展開とする。

### 1.2.4. 墓の比定と1935年の顕在化

新郷村公式は、1935年に竹内家の古文書から仮説が現れ、竹内氏が新郷村を訪れて墓を発見したと説明する。2001年の地域側資料も、1935年の現地訪問を、既存の塚がキリストの墓と比定される契機として記録する。

### 1.2.5. 現在の再提示

現在は、墓とされる塚、キリストの里伝承館、自治体Web、キリスト祭によって伝承が継続的に提示される。2025年の自治体広報は第61回キリスト祭の実施を直接記録している。
