# 1. 伝承内容

## 1.1. summary

日本で広く流通した「ノストラダムスの大予言」の代表形は、16世紀フランスのノストラダムス『予言集』第10巻72番にある1999年7月という年代と「恐怖の大王」と訳された表現を、20世紀末の人類規模の破局へ接続する解釈である。五島勉の1973年刊『ノストラダムスの大予言』は、副題自体に「迫りくる1999年7の月,人類滅亡の日」と掲げ、この終末的な読みを一般向けに強く提示した。

Kisalaの受容史研究によれば、五島は1999年7月の「恐怖の大王」について、爆撃、ICBM、人工衛星の墜落、彗星衝突、宇宙人、スモッグによる大量死等の複数の破局シナリオを紹介・検討し、単一の具体的作用機構へ固定しなかった。したがって共有核は「1999年7月に特定の一種類の災害が起こる」ことではなく、「1999年7月を期限として、恐怖の大王に結び付く人類規模の破局が起こり得る」という予測である。

一方、Kisalaは五島が完全な宿命論だけを採らず、破局をどう回避できるかを論じたことも記録する。1998年の『最終解答編』にも「最後の活路」という副題がある。ただし共有された危機回避法が一つの具体的手順として安定していたことまでは確認できない。

この1973年型は、ノストラダムスの日本初紹介そのものではない。鈴木2024は1947年の渡辺一夫による紹介を挙げる一方、1973年の五島本のベストセラー化によって、1999年の「恐怖の大王」とノストラダムスが日本で強く結び付いたと整理する。またKisalaは、1973年本の成功後に多数の関連出版が続き、阿含宗、オウム真理教、幸福の科学等がノストラダムス／1999年テーマをそれぞれの教説へ取り込んだと報告する。

## 1.2. 詳細展開

### 1.2.1. 予言詩の年代

中心のテキスト手掛かりは、ノストラダムス『予言集』第10巻72番に記された1999年7月である。年代が明示されるため、解釈は特定期限を持つ未来予測として展開する。

### 1.2.2. 「恐怖の大王」の解釈

五島1973年型では、空から来る「恐怖の大王」が20世紀末の破局と関連付けられる。Kisalaによれば、候補となる作用機構は複数提示され、単一の正体に固定されない。

### 1.2.3. 人類規模の破局

1973年版の副題は「人類滅亡の日」と明示する。日本での代表的受容形では、予言は個人の不運ではなく、人類・世界規模の危機として提示される。

### 1.2.4. 回避可能性

Kisalaは、五島の関心が単なる運命論的断罪ではなく、予言された破局をどう回避するかにも向けられていたと記す。東洋・仏教的伝統による救済という議論も紹介されるが、一般受容で一意の具体的回避手順が共有されたことまでは固定しない。

### 1.2.5. 1999年直前までの再提示

1998年には『最終解答編 : 1999年、“恐怖の大王”の正体と最後の活路』が刊行され、予言期限直前まで同系列の解釈が出版物として再提示された。

4. 破局原因は複数候補があり、単一の物理・超自然機構へ固定できない。

# 2. 伝承史・異伝

## 2.1. 最古確認

鈴木2024は、ノストラダムスへの日本語圏の言及が1973年以前にも存在し、とくに渡辺一夫「ある占星師の話」（1947年）を受容史上の重要な先行例として挙げる。そのため、1973年はノストラダムス一般の日本での生成・初紹介時点ではない。

一方、五島勉『ノストラダムスの大予言』は1973年に刊行され、副題で1999年7月と人類滅亡を直接結び付けた。Kisalaおよび鈴木は、この出版物の成功が、日本でノストラダムスと1999年「恐怖の大王」型終末解釈を強く結び付けたと評価する。

## 2.2. 流通・拡散

1. 1947年: 渡辺一夫によるノストラダムス紹介が存在したと受容史研究が確認する。
2. 1973年: 五島勉『ノストラダムスの大予言』刊行。NDL書誌で初版を直接確認できる。
3. 1973年以後: Kisalaは初巻が短期間に多数刷られ、出版成功が日本の「Nostradamus boom」を生じさせたとする。
4. 1979年以後: Kisalaはタイトルに“Nostradamus”を含む多数の関連書籍が出版されたと整理する。
5. 1980年代以後: Kisalaは阿含宗、オウム真理教、幸福の科学等がノストラダムス／1999年テーマを各自の教説へ取り込んだ例を挙げる。
6. 1998年: 『最終解答編』が刊行され、1999年直前まで「恐怖の大王」の正体と回避可能性が再提示される。
