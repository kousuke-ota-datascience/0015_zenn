# 0. INTRODUCTION

**伝承名:** 磐梯山の手長足長

本文書は磐梯山・会津地方に伝わる手長足長伝承のEvidence正本である。分析値は `0275_10_analysis.md` で扱う。

# 1. 典拠

## 1.1. 直接確認できる採録

国際日本文化研究センター「怪異・妖怪伝承データベース」には、1992年『あしなか』通巻227号、とよた時「天狗・仙人妖怪ばなし」に「手長、足長」の採録がある。福島県の事例として、磐梯山に手長・足長という怪物がおり、雲を集めて会津一帯を暗くし、洪水や嵐を起こして農作物を荒らしたため、弘法大師がだまして小箱に閉じ込め、磐梯明神として祀ったという筋が要約されている。

- https://www.nichibun.ac.jp/cgi-bin/YoukaiDB3/youkai_card.cgi?ID=0030434

## 1.2. 地域公的資料による継承確認

磐梯町「磐梯町歴史的風致維持向上計画」の「山々の伝説」では、磐梯山の手長足長伝説を代表的な伝説として紹介し、手長・足長の夫婦が天変地異を起こした後、旅の僧（弘法大師との説もある）に調伏され、人々に豊作・幸福を与える神となることを約束させられ、磐梯明神として祀られたとする。

- https://www.town.bandai.fukushima.jp/uploaded/attachment/1585.pdf

この公的資料は、怪物による災害・農作物被害、宗教者による調伏、磐梯明神への転換という共有核が地域文化資源として現在も維持されていることを示す。

## 1.3. 現代の社会実践

2025年、磐梯町立の磐梯山慧日寺資料館は企画展「妖怪か神様か？～摩訶不思議　手長・足長の世界～」を開催し、夜間観覧会・肝試し、手長足長を壺へ投げ入れる参加型企画、イラスト企画等を実施した。伝承が自治体文化施設の展示・催事へ転用され、現実の参加行動を生んでいることを直接確認できる。

- https://www.town.bandai.fukushima.jp/site/enichiji/blog_20250716.html

# 2. 伝承内容

Version Scopeの共有核として採用するのは、**磐梯山に巨大な手長・足長の夫婦または一対の怪物が住み、雲・雨・風・洪水等を起こして会津地方の農作物や暮らしに被害を与え、旅の僧／弘法大師が策略と宗教的力によって小さな容器へ封じ、のちに磐梯明神として祀る**という型である。

主要要素は以下。

- 手長・足長は異常に長い手足を持つ巨大な怪物として語られる。
- 磐梯山・猪苗代湖・会津盆地等の実在地理へ結び付けられる。
- 雲を集める、水をまく、風雨・洪水を起こすなど、自然環境を操作する。
- 被害は農作物不作や地域住民の困窮として表現される。
- 旅の僧または弘法大師が、相手の誇示欲を利用して小さくさせ、箱・壺・鉄鉢等へ封じる。
- 調伏・封印後、磐梯明神として祀られ、人々を守る側へ転換する版がある。

# 3. 変異・境界

- 1992年採録では「小箱」、別の地域再話では「壺」「鉄鉢」等、封印容器に差がある。
- 調伏者は「旅の僧」とする版と「弘法大師」と特定する版がある。
- 手長・足長の性別・夫婦関係、具体的な身体配置、雲・雨・洪水の起こし方には再話差がある。
- 『新編会津風土記』由来として紹介される磐梯山の「魔魅」・空海・磐梯明神伝承は、後代の手長足長型と親和的だが、今回確認できた資料だけから「手長足長」という具体型そのものを1809年以前へ直接遡及しない。
- 物語内で語られる806年等の年代は伝承内時間であり、伝承型の成立年を直接示すEvidenceとして扱わない。
- 鳥海山等、他地域の手長足長伝承は類話であり、磐梯山型のVersion Scopeへ混在させない。

# 4. Evidence summary

- 今回直接確認できる磐梯山手長足長型の印刷採録: 1992年『あしなか』227号。
- 地域公的資料: 磐梯町が手長足長を代表的な山岳伝説として掲載。
- 現代社会実践: 2025年に磐梯山慧日寺資料館が企画展・参加型催事を実施。
- 中心因果: 手長足長による風雨・洪水・農作物被害 → 宗教者による封印・調伏 → 磐梯明神としての神格化・地域保護。
- 成立年代判断では、伝承内年代や類似する古い「魔魅」記述から具体的手長足長型を自動的に前近代へ遡及しない。
