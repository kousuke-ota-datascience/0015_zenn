# 1. 伝承エントリ基本情報

- `Entry_ID`: `0113`
- `伝承エントリ名称`: 井の頭公園のボートに乗ると別れる
- `Macro_Category`: 恋愛・縁・吉凶
- `Entry_Type`: ジンクス／場所俗信
- `Version_Scope`: 井の頭恩賜公園の井の頭池で、恋人同士が二人でボートに乗ると、その後二人は別れるという場所固定型ジンクス。弁財天嫉妬説は主要な説明異伝として含めるが、原因主体を明示しないジンクス型も同じScopeに含める。受容者向けの回避・解除・試行規則は、00で直接確認できないためScopeの必須要素としない。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.PPR.CORRELATION_RULE` — 相関規則化
- Primary Parent: `D09.PPR`
- Secondary: `D09.AGN.AGENCY_ATTRIBUTION` — 主体化; `D09.CAU.DIRECT_CAUSE` — 直接原因化
- Status: `I`

**判定根拠**

中心ジンクスは乗船と破局を反復可能な規則として結び付けるため `CORRELATION_RULE` と解釈できる。弁財天嫉妬型では、別れの理由を神格の意図へ接続するため `AGENCY_ATTRIBUTION`、さらに乗船・神格作用から破局へ因果化するため `DIRECT_CAUSE` がSecondaryとして該当する。ただしこれらは分析概念への写像を含むためStatusは単一の `I` とする。

**この伝承における現れ方**

通常は独立し得る乗船行為と後日の破局が一つの規則へ結び付けられ、主要異伝ではその間に弁財天の嫉妬という主体的説明が置かれる。

- Secondary: なし
