# 1. 伝承内容

## 1.1. summary

確認できる文面では、受信者に対して、同一またはほぼ同一の文面を一定数複製し、定められた期限内に他者へ送るよう求める。指定どおり送った場合には幸運・成功等が訪れるとされ、送らない、または連鎖を止めた場合には悪運・災難が訪れるとする型がある。

1922年資料では、一定枚数への複写、期限、幸運、連鎖断絶時の悪運が同一文面に含まれると研究上整理されている。1951年国会会議録でも、受取後3日以内に友人3名へ送れば幸運、送らなければ災難という例が直接記録される。

## 1.2. 詳細展開

1. 手紙・葉書等が受信者へ届く。
2. 一定人数・部数へ、一定期限内に同文を複写・送付するよう指示される。
3. 指示に従えば幸運・成功等が訪れるとされる。
4. 文面によっては、連鎖を止めると悪運・災難が訪れるとされる。
5. 受信者が他者へ送り、新しい受信者が同じ文面を受け取る。

## 1.3. 登場人物・主体

| 主体 | 役割 |
|---|---|
| 受信者 | 文面を受け取り、転送するかどうかを選ぶ |
| 前段階の送信者 | 同文を複製して送る |
| 次の受信者 | 同じ転送指示・吉凶条件を受け取る |
| 手紙／葉書 | 転送指示、期限、報酬、場合により制裁を保持する媒体 |

## 1.4. 場所・空間

特定の聖地・地点を必須とせず、郵便・通信経路を通じて送信者と受信者が接続される。

## 1.5. 物・記号・媒体

- 手紙・葉書: 1920年代および1951年資料で確認できる物理媒体。
- 複製文面: 同じ指示・吉凶条件を次の受信者へ伝える情報内容。
- 人数・部数・期限: 転送行為の条件として明示される。
- 電子メール・SNS等: 後代の媒体差として存在し得るが、1922年資料へ遡及しない。

## 1.6. 条件・規則・禁忌

- 条件: 転送指示と吉凶条件を記した文面を受信する。
- 規則: 指定された期間内に、指定人数・部数へ同文を複製・転送する。
- 報酬: 条件を守れば幸運・成功等が訪れるとされる。
- 制裁: 文面によっては、連鎖を止める・期限を破ると悪運・災難が訪れるとされる。

## 1.7. 異常・不可解な現象／中心命題

同一文面を規定どおり他者へ転送することと、その受信者本人の将来の幸運・悪運との間に因果関係があるとする主張である。

## 1.8. 行動・対応

- 文面を読み、人数・部数・期限を確認する。
- 指示に従う場合、同文を複製して他者へ送る。
- 送らない、廃棄する、連鎖を止めるという行動も可能だが、文面によっては災難と結び付けられる。
- 1951年には、実際の転送行動が郵便制度上の問題として国会審議に現れる。

## 1.9. 帰結・終端状態

- 転送者へ幸運・成功等が訪れるとされる型がある。
- 不転送者へ悪運・災難が訪れるとされる型がある。
- 転送により新しい受信者が生まれ、同じ文面が連鎖する。
- 吉凶の超常因果が現実に成立することはEvidenceから確認されない。

## 1.10. 未解決点・不確実性

- 1922年は現在追跡できる古い日本流行層であり、絶対起源年とは限らない。
- 1922年新聞原紙は今回直接閲覧していない。
- 文面ごとに報酬と制裁の有無・強調度が異なる。
- 海外先行例や具体的な日本への移入経路は未確定。
- 後代デジタル型を1922年形へ遡及させない。

# 2. 伝承史・異伝

## 2.1. 最古確認

現時点で日本について追跡できる古い層は、丸山2012が資料化する1922年の「幸運の手紙／幸運の葉書」流行である。1922年1月27日付『東京朝日新聞』掲載資料では、複写枚数・期限・幸運・連鎖断絶時の悪運を組み合わせた構造が示されると研究上整理されている。

これは1922年に日本で新規創作されたことを意味しない。

1951年3月26日の国会会議録は、「幸運の手紙」という名称、同文転送、幸運／災難条件を直接記録している。

## 2.2. 流通・拡散

- 1922年: 新聞資料を介して流行が研究上確認される。
- 1925年等: 丸山2012は再流行資料を追跡する。
- 1951年: 国会審議で具体的な転送規則を伴う「幸運の手紙」が例示される。
- 後代: 郵便チェーンレターとして反復し、電子通信へ移植される型も現れる。

## 2.3. 主要な異伝・派生

| 型 | 内容上の差 |
|---|---|
| 報酬中心型 | 転送後の幸運を強調する |
| 報酬＋制裁型 | 幸運に加え、連鎖断絶時の悪運・災難を含む |
| 由緒付加型 | 発祥・伝播履歴・過去例等を文面へ付加する |
| デジタル型 | 郵便から電子メール・Web・SNS等へ媒体を置換する |
| 制裁強調型 | 不転送時の災難を強く前景化する |

## 2.4. 変容上の重要点

枚数、期限、由緒、幸運の内容、制裁の強さ、通信媒体は変化する。1922年資料と1951年資料の双方で、受信者へ同文転送を求め、転送／不転送と吉凶を結び付ける文面が確認される。
