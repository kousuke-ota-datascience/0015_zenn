# 1. 伝承エントリ基本情報

- `Entry_ID`: `0011`
- `伝承エントリ名称`: こっくりさん
- `Macro_Category`: 全国型怪異・儀式
- `Entry_Type`: 儀式伝承
- `Version_Scope`: **1886–1887年に確認できる明治器具型の最小安定核**。複数人がテーブルまたは飯櫃の蓋等の可動器具へ手を置き、問いを発し、器具の動きを外部的・霊的な回答として読む占い／神意判断の実践を対象とする。現代紙・硬貨型、学校型禁忌、憑依・祟り・終了規則、1970年代学校流行はCoding Scope外とする。

# 2. 分析概念次元

各次元は、単にコード値を記録するだけでなく、**当該伝承においてその次元が具体的にどのように現れているか**まで自然言語で記述する。

## 2.1. 来歴・流通・提示の次元

### 2.1.1. D01: 生成年代

**いつ成立したか**

- Primary Child / Value: `D01.G1` — 1868–1944
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

1886年新聞、1887年書誌、および1884年頃の伝来を記す公式研究整理から、今回対象とする器具型を明治期の成立層へ安全に写像できる。1884年を唯一の起源年とは断定しない。

**この伝承における現れ方**

今回の対象は1970年代学校遊戯ではなく、19世紀末に流行した器具型の占い・神意判断である。

### 2.1.2. D02: 最古確認流通媒体

**現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か**

- Primary Child / Value: `D02.PRT.NEWSPAPER` — 新聞
- Primary Parent: `D02.PRT` — 印刷・書簡
- Secondary: なし
- Status: `D` — Direct

**判定根拠**

現在直接固定できる最古の公共流通媒体は、1886年7月16日『朝日新聞（大阪）』「神下しと狐狗狸の拘引」である。実践自体が記事以前に存在したことと、現在確認できる最古媒体は分ける。

**この伝承における現れ方**

こっくりさんは少なくとも1886年には名称付きの社会現象として新聞上に現れている。

### 2.1.3. D03: 確認流通媒体ポートフォリオ（Version Scope）

**今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か**

- Primary Child / Value: `D03.PRT.NEWSPAPER` — 新聞
- Primary Parent: `D03.PRT` — 印刷・書簡
- Secondary: `D03.PRT.BOOK` — 書籍
- Status: `D` — Direct

**判定根拠**

1886年新聞と1887年『妖怪玄談 狐狗狸の事』がScope期間の確認媒体である。後代の学校口承は今回のScopeへ含めない。

**この伝承における現れ方**

明治期の流行は新聞と書籍という複数の印刷回路で可視化・共有される。

### 2.1.4. D04: 生成・変容パターン

**時間とともにどう変形したか**

- Primary Child / Value: なし — **taxonomy gap: 外来実践の文化的／物質的適応**
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

西洋のテーブル・ターニング系実践が、日本では飯櫃の蓋・竹脚等の生活器具を用いる形として整理されている。変容構造自体はEvidenceから合理的に認められるが、現行 `D04.VAR.LOCALIZATION` は地名・施設・人物の地域置換であり、器具・実践形式の文化的適応を直接表さない。

**この伝承における現れ方**

外来の実践が日本の日常器具へ置換されて受容されたが、この種の物質文化的適応を現taxonomyでは直接コードできない。

### 2.1.5. D05: 提示形式

**どんなコミュニケーション形式で提示されるか**

- Primary Child / Value: `D05.RUL.RITUAL_PROCEDURE` — 儀式・手順
- Primary Parent: `D05.RUL` — 規則・警告形式
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

複数人が器具へ手を置き、問いを発し、器具の動きを回答として読むという再現可能な実践手順が確認される。

**この伝承における現れ方**

完成済みの物語を聞くだけでなく、自ら参加する占い・神意判断の手順として受容される。

### 2.1.6. D06: 真実性提示

**どんな「本当らしさ」を要求するか**

- Primary Child / Value: `D06.T5` — 条件付き信念
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

「所定の実践を行えば器具の動きから回答・神意を得られる」という実践的信念を要求する。研究者による外部説明とは分離する。

**この伝承における現れ方**

参加者は、この手順を行えば通常は得られない答えが示されるという条件付きモデルを受け入れる。

## 2.2. 意味形成の次元

### 2.2.1. D07: 意味形成対象

**何が不可解・不確実なのか**

- Primary Child / Value: `D07.ISU.INFORMATION_VOID` — 情報空白
- Primary Parent: `D07.ISU` — 社会・制度・情報問題
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

この伝承がなければ、参加者が自力では知り得ない未来・秘密・判断対象等について、どのように回答を得られるかが未解決のまま残る。器具の運動は、その情報空白へ答えるために伝承内部で用いられる媒介作用であり、D13へ置く。

**この伝承における現れ方**

通常の知識手段では埋められない問いに対し、こっくりさんという回答経路を設けることで、未知情報を扱えるものへ変える。

### 2.2.2. D08: 意味形成契機

**何を手掛かりに問題化されるか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `U` — Unknown

**判定根拠**

現Evidenceから確認できるのは、明治期にこっくりさんが占い・神意判断として実践され、質問と器具運動を回答へ結び付けていたことまでである。参加者が実践開始前に、どの主張・証言・権威説明・出来事を手掛かりとして「この実践なら未知情報へ答えられる」と受容したのかは固定できない。Evidence不足そのものを `UNSUPPORTED_ASSERTION` というContent上のcueへ変換せず、器具運動もD13から逆流させない。

**この伝承における現れ方**

情報空白とこっくりさん実践が結び付いていたことは分かるが、その結び付きが受容者にとって何を契機に成立したのかは未確定のまま保持する。

### 2.2.3. D09: 意味付与操作

**不可解なものをどう理解可能にするか**

- Primary Child / Value: `D09.AGN.AGENCY_ATTRIBUTION` — 主体化
- Primary Parent: `D09.AGN` — 主体・意図帰属
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

情報空白を、回答能力を持つ外部主体へ接続し、その主体が器具を介して答えるものとして理解することが中心的な意味付与操作である。

**この伝承における現れ方**

「分からない」という状態を、より多くの情報を持つ外部主体へ質問可能な状態へ変換する。

### 2.2.4. D10: 因果源存在論

**原因を何として世界に置くか**

- Primary Child / Value: なし
- Primary Parent: なし
- Secondary: なし
- Status: `C` — Conflict

**判定根拠**

明治期Evidenceでは神意判断という神格的枠組みと、「狐狗狸」等の人格的怪異を想定する表現が併存する。`D10.SUP.DEITY_DIVINE` と `D10.SUP.YOKAI_ENTITY` のどちらか一つへ安全に固定できない。

**この伝承における現れ方**

## 2.3. 因果・行動モデルの次元

### 2.3.1. D11: 発動・接触条件

**何を契機に因果系へ入るか**

- Primary Child / Value: `D11.MAN.PERFORM_RITUAL` — 儀式・唱和を行う
- Primary Parent: `D11.MAN` — 操作・儀式
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

複数人が器具へ接触し問いを発する実践が回答現象の入口として公式研究整理から確認できる。ただし今回のEvidence正本では1887年原典本文の具体的頁・行へ直接トレースしていないため、DirectではなくInferredとする。

**この伝承における現れ方**

偶然遭遇する怪異ではなく、参加者が所定の実践を開始することで因果系へ入る。

### 2.3.2. D12: 作用対象

**誰／何に作用するか**

- Primary Child / Value: `D12.OTD.OBJECT_PRODUCT` — 物体・商品
- Primary Parent: `D12.OTD` — 物体・技術・データ
- Secondary: なし

**判定根拠**

D13の主作用は外部主体がテーブル・飯櫃の蓋等の可動器具を動かすことであり、直接作用を受ける対象は器具である。

**この伝承における現れ方**

外部主体の回答は、参加者へ直接作用するのではなく可動器具へ現れる。

### 2.3.3. D13: 作用機構

**因果源が対象へ何をするか**

- Primary Child / Value: `D13.PHY.ENV_OBJECT_MANIPULATION` — 環境・物体操作

伝承内部では、外部主体が可動器具を動かし、その運動が回答として解釈される。

**この伝承における現れ方**

意味の伝達は、物体の運動を媒介して成立する。

### 2.3.4. D14: 帰結極性

**結果は正・負・中立・混合か**

- Primary Child / Value: `D14.NEU` — 中立
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

明治期Scopeの必須帰結は回答取得であり、その内容は利益・危害のどちらにも固定されない。後代の霊障・祟りを混入しない。

**この伝承における現れ方**

実践は吉凶どちらかの結果を必ず与えるのではなく、問いへの情報を得る手段として成立する。

### 2.3.5. D15: 帰結領域

**何の領域が最終的に変わるか**

- Primary Child / Value: `D15.KNW.REVELATION_KNOWLEDGE` — 真相・知識獲得

実践の中心的終端は、器具の動きを通じて参加者が問いへの回答・未知情報を得たと理解することである。

**この伝承における現れ方**

情報空白が「答えを得た」という知識変化へ変換される。

### 2.3.6. D16: 因果時間構造

**発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか**

接触・質問→器具移動→回答解釈という段階列が、一つの実践内で順に成立する。

**この伝承における現れ方**

一回の占い実践の中で質問から回答までが段階的に完結する。

### 2.3.7. D17: 回避・制御方式

**結果をどう回避・制御・利用できるか**

- Primary Child / Value: `D17.USE.DELIBERATE_INVOCATION` — 意図的利用

**判定根拠**

明治期Scopeでは危害回避より、未知情報を得るために実践を意図的に起動・利用する構造が中心である。後代の終了禁忌はScope外とする。

**この伝承における現れ方**

こっくりさんは避ける対象ではなく、回答を得る目的で能動的に利用される。

### 2.3.8. D18: 作用レイヤー

**因果効力は伝承内／受容者／社会現実のどこに及ぶか**

- Primary Child / Value: `D18.L1=1; D18.L2=0; D18.L3=0`
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

- `L1=1`: 外部主体→器具移動→回答という伝承内部の因果がある。
- `L2=0`: 伝承を読む・聞くだけで受容者が作用対象になる自己適用規則は確認しない。
- `L3=0`: 1886年同時代新聞の見出し「神下しと狐狗狸の拘引」は社会的対応の存在を示唆するが、本文未実見の現状では、誰が何を理由に拘引されたのか、実践・流通がどのように現実社会上の結果を生じさせたのかという因果詳細を固定できない。見出しのみをL3成立の十分なX Evidenceとはしない。

0は「社会効果が存在しなかった」という積極否定ではなく、現EvidenceではScoped L3を成立させないという保守的判定である。

**この伝承における現れ方**

伝承内部の器具作用は確認できるが、明治期社会での制度的・行動的効果は現Evidenceのdirectnessでは確定しない。

## 2.4. 社会的埋め込みの次元

### 2.4.1. D19: 流通範囲

**誰の間に伝承が流通するか**

- Primary Child / Value: `D19.MAS.NATIONAL_PUBLIC` — 全国的大衆
- Primary Parent: `D19.MAS` — 大衆・広域社会
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

東洋大学公式整理は1886年頃に日本各地で流行したとする。単一地域内部に限定されない広域流行と判断できるが、認知率を直接測定していないためIとする。

**この伝承における現れ方**

一地域の閉じた習俗に留まらず、明治期に複数地域へ広がる大衆的実践として可視化される。

### 2.4.2. D20: 特権情報保持者

**誰が真相・追加情報を持つか**

- Primary Child / Value: なし — **taxonomy gap: 超自然的回答主体による情報保持**
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

実践内部では、参加者が知らない回答・神意を外部主体が保持し、器具運動を通じて提示するという情報非対称構造がある。Evidence不足ではない。一方、現行D20は人間・組織・専門家等の保持者を中心に構成され、超自然的回答主体を直接表すChildがない。

**この伝承における現れ方**

参加者より多くを知る存在が回答源として想定されるが、その保持者類型を現taxonomyでは直接コードできない。

### 2.4.3. D21: 現実アンカー

**実在世界へどの程度固定されるか**

- Primary Child / Value: `D21.A1` — 一般的現実背景
- Primary Parent: なし
- Secondary: なし
- Status: `I` — Inferred

**判定根拠**

日常的な家庭・器具・複数人の実践を用いるが、伝承内容自体が特定の唯一地点・人物・制度・史実を成立条件としない。

**この伝承における現れ方**

テーブルや飯櫃の蓋等の現実的な器具を使いながら、特定の土地や歴史事件に固定されず別の生活空間へ移植できる。
