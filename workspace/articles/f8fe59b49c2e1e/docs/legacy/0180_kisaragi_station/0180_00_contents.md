# 1. 伝承内容

## 1.1. summary

投稿者「はすみ」は、普段利用する静岡県内の私鉄で帰宅中、通常なら数分ごとに停車する列車が20分以上駅へ停車しないことに違和感を覚え、匿名掲示板へ実況相談する。列車は通常路線に存在しないはずのトンネルを通過し、見覚えのない無人駅「きさらぎ駅」へ停車する。

下車後、駅は検索でも通常の駅として確認できず、周囲に人家・タクシー等も見当たらない。家族・警察・携帯電話の位置確認でも場所を確定できない。はすみは線路沿いへ移動し、太鼓と鈴のような音、片足の老人、伊佐貫と読めるトンネル等を報告する。

トンネル通過後、近くにいた人物の車へ乗るが、運転者が示す現在地「比奈」を不自然に感じ、車は山側へ進む。運転者は会話をやめ、意味不明な独り言を始める。はすみは逃走機会をうかがうと書き込み、レス635を最後の投稿とする。初期ログ内では帰還・所在・身体状態は確定しない。

参加者は通常説明のほか「異界」「あの世」等の解釈も提示するが、投稿者自身がその世界構造を確定したとは扱わない。
