# 都市伝説 Parent/Child体系 — 406件本適用 評価 v1

## 結論

第2パイロットで確定した taxonomy v2 / coding rules v2 を、Round8の正規化母集団406伝承エントリへ一次適用した。
確定済み重複7行は履歴上の別IDとして保持されるが、本分析母集団からは除外した。

本適用は、49件の第2パイロットで確定したコードをそのまま引き継ぎ、残る357件はCandidate Masterの名称・系統・地域・流通期・典拠・調査メモに対してcoding rules v2を適用した一次コーディングである。
外部資料を406件すべてについて再調査したものではないため、直接根拠が不足する判断はIまたはUとして明示した。
